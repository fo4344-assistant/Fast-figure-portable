# Source Script에서 실제 동작을 설명하지 않는 문장 수정

Source Script 전체에서 알고리즘의 자리를 차지하고 있으면서 실제 동작을 설명하지 않는 문장을 찾아 수정한다.

예: `변경: - Frontend 선택과 선택 장식. 조건이 맞으면 빈 슬롯 종류.` 이 문장으로는 어느 상태 필드와 화면 요소를 바꾸는지, 빈 슬롯의 종류는 어떤 조건에서 어떤 명령으로 바뀌는지 알 수 없다.

- `변경`에는 실제로 바뀌는 값과 그 소유자를 적는다. 상태 필드와 화면 요소는 각각 식별할 수 있도록 명시한다.
- `처리`에는 변경을 결정하는 조건, 조건에 쓰는 값의 출처, 호출할 함수나 명령과 전달값, 변경 순서, 호출 결과의 사용처를 적는다. 거부·실패 시 그대로 남는 값도 해당 경로에서 확인한다.
- `조건이 맞으면`, `필요한 값을 갱신한다`, `기존 규칙에 따른다`로 처리를 대신한 곳을 실제 절차와 대조한다. 이미 정의된 동작은 담당 함수와 인수를 명시해 연결한다. 근거가 없는 조건이나 동작은 임의로 채우지 말고 확인할 사항으로 남긴다.

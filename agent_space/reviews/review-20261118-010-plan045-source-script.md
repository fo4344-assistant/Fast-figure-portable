# Plan045 Source Script 조회 계약 수정 검토

## 범위와 판정

Plan045의 Source Script 단계다. 기준 커밋은 `561a0df77895d3c58007fdb02516c7cdb6175c55`다. 기존 API 경계를 유지하면서 반환 필드와 내부 작업을 소비 목적에 맞췄다. pseudocode와 source code는 아직 이전 계약이다. 이 문서는 실행 성능 개선을 입증하지 않는다.

| 대상 | 변경과 소비자 |
|---|---|
| 자산 트리·휴지통 | 이름·경로·종류·참조 수·CSV 데이터 행 수. 본문 필드 제거, 호출별 참조 수집 한 번. 휴지통 범위부터 선택한다. |
| 삭제·생성 결과 | 삭제 확인은 식별 메타데이터와 실제 참조만, 생성 후 반환도 메타데이터만 사용한다. |
| 목록·미리보기 | `assets.readList(kind)`는 선택 옵션용 식별/이름. `readPreview(csvId,start,count)`는 최대 30행만 분리 복사한다. |
| 슬롯 목록 | `slots.readDisplay`로 연결 자산 표시만 요청한다. 자산 트리 표시 때문에 레이아웃 기하를 계산하지 않는다. |
| 그래프 편집 목록 | `graphs.readData`는 chart 식별·제목·editable, 편집 필드, 현재 CSV 메타데이터다. figure·원본 JSON·표·열 정의를 제외한다. |
| 그래프 입력 | `graphs.readControls`는 현재 object 하나와 식별·입력 값. 명령 후 확인과 버튼도 이 결과를 사용한다. |
| 열 선택 | `graphs.readColumns`는 명시 CSV 또는 원본 JSON conversion chart의 열 정의만 구한다. 기존 ragged row·헤더·중복 이름 규칙을 유지한다. |
| 나머지 입력 | 이미지/레이블/캡션 설정, 레이아웃 입력을 바이트·본문·기하·미리보기와 분리한다. 기존 표시 API는 해당 표시 소비자에 남긴다. |
| 공통 UI 객체 | `readCurrent`로 한 판정의 식별자·값·필수 동반 값을 읽고 내부 전송에 전달한다. `input`·`cancel` 반환, IME·원문·동일 값·Enter/blur 중복 방지·원래 오류를 유지한다. |
| 구독 | component별 필요한 원시 표시 key, 안정적인 subscribe, 로컬 입력 갱신, 팔레트 key 기반 theme. 공용 Project 복제 저장소를 만들지 않는다. |

## 논리·목적·중복 검토

- 필드 선별을 큰 원본 복사보다 먼저 수행하도록 각 Backend 분기에 명시했다. 트리의 행별 삭제 대상 조회와 숫자 입력의 별도 대상/값 조회를 제거했다.
- Backend가 현재 Project에서 정보를 구성하고 Application이 현재 Frontend 식별자를 전달한다. UI는 그 작업의 결과만 소비한다. 방문 집합은 반환값 읽기 전용 처리 한 호출에서 끝낸다.
- 기존 명령의 현재 대상 재검사·전체 검증·단일 반영·참조 보정은 변경하지 않았다. 작업 중 복사본의 다른 기능 공유를 추가하지 않았다.
- 확대·이동의 CSS 처리, 선택 슬롯 내용 갱신, 명시적 전체 렌더링과 별도 출력 수명은 유지한다. 새 위젯·API 전역 등록표·범위 소유자를 추가하지 않았다.
- API 등록과 Backend 분기, wrapper 후속 읽기, UI 표시/숫자/버튼 소비자를 함께 수정했다. 자동 빈 값·id 0·취소·명령 실패 조건을 유지한다.

## 확인과 한계

전체 실제 Source Script diff와 최종 수정 delta를 읽었다. Python AST는 문법만 확인한다. 실제 hash, 메타데이터 범위, native Git patch와 변경 제외 경로를 정적으로 확인한다. 테스트·앱·브라우저·프로파일·빌드·checker main은 실행하지 않았다. 실제 처리 횟수와 지연 시간 비교는 하위 번역 후 별도 실행 증거가 필요하다. 중복 명령 candidate 복사·전체 검증·실제 결과 비교 최적화는 이 단계에 포함하지 않았다.

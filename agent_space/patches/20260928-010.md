# 20260928-010

## 목적과 변경 내용

Mantine sidebar가 자체적으로 스크롤 lifecycle을 소유하도록 `AppShell.Navbar`의 일반 UI 목록을 Mantine `ScrollArea`로 감싼다.

기존 legacy sidebar는 custom CSS의 `aside { overflow-y: auto; }`가 스크롤을 담당했다. `20260928-006`에서 해당 legacy CSS를 제거했으므로, 동일한 책임을 Mantine 구성요소 안에서 명시적으로 맡긴다.

변경 후 구조:

```text
AppShell.Navbar
├─ ScrollArea
│  ├─ data actions
│  ├─ image editor
│  ├─ project tree/actions
│  ├─ graph editors/actions
│  ├─ palette
│  └─ status/debug/utilities
└─ sidebar resize Box
```

resize handle은 Navbar 전체 높이에 고정되는 interaction surface이므로 ScrollArea 바깥에 유지한다.

## 선택 이유

Mantine 전환 목적은 일반 UI 동작을 custom CSS와 DOM 규칙으로 재구현하지 않는 것이다. sidebar overflow도 같은 원칙을 적용하여 Mantine `ScrollArea`가 스크롤바와 overflow behavior를 소유하게 한다.

## 선택하지 않은 방향

- `AppShell.Navbar`에 다시 `overflowY: "auto"` inline style을 추가하지 않는다.
- 제거한 legacy `aside` CSS를 복원하지 않는다.
- sidebar 내용을 별도 custom scroll wrapper로 감싸지 않는다.

## 기능 보존

- sidebar collapse
- sidebar width resize
- 모든 editor/action 접근
- navbar width 360–620px
- Plotly resize scheduling
- renderer sibling layout

## 검증

- GitHub-generated diff 사용
- Actions `git apply --check`
- `git diff --check`
- JS syntax
- portable build
- split/portable `file://` smoke
- sidebar resize handle이 ScrollArea 바깥에 유지되는지 확인

## 롤백

역적용하면 Navbar contents가 다시 직접 children으로 배치된다. domain/EFSM/renderer 의미는 변경하지 않는다.

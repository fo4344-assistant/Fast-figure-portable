# 20260915-002 — Remove missed resize callbacks to deleted layout DOM helper

## Purpose
Repair the incomplete call-site cleanup left after successful patch 20260915-001 by removing the two remaining `syncLayoutMapSize()` calls from `installResizeObserver()`.

## Exact changes
- Remove `syncLayoutMapSize()` from the graph-area/window resize handler.
- Remove `syncLayoutMapSize()` from the dashboard `ResizeObserver` callback.
- Keep dashboard zoom/reference geometry updates and Plotly resize scheduling unchanged.

## Rationale
Patch 20260915-001 removed the obsolete `syncLayoutMapSize` definition because the native layout preview DOM no longer exists, but two resize callbacks in `fast-figure.js` still referenced that deleted function. Those calls are now invalid and can raise `ReferenceError` when the callbacks execute. They have no replacement responsibility because Mantine owns the layout overlay and its preview no longer requires native DOM sizing.

## Rejected alternatives
- Restore `syncLayoutMapSize` as a no-op: rejected because it would preserve a false legacy dependency solely to mask missed call sites.
- Redirect the calls to Mantine UI sizing: rejected because the overlay is React-owned and dashboard resize callbacks should not imperatively size it.
- Change dashboard zoom or Plotly resize behavior: rejected because those paths remain valid and are unrelated to the removed layout preview.

## Source of truth
No state ownership changes. Dashboard dimensions remain derived from the actual dashboard DOM and project layout state; Mantine overlay geometry remains derived from project state.

## EFSM/core impact
No intended domain behavior change. This is a dangling-reference repair following 20260915-001.

## Validation
Run the standard patch check, JavaScript syntax checks, portable build, and split/portable Chromium `file://` smoke tests. In addition, verify by source search after application that `syncLayoutMapSize` has no remaining references.

## Rollback
Revert the `Apply agent patch 20260915-002` commit. Restoring the removed calls without also restoring the deleted helper would reintroduce an invalid reference, so rollback should normally be paired with rollback of 20260915-001 if needed.

## Follow-up
Resume the planned legacy annotation helper audit only after confirming no `syncLayoutMapSize` or `renderLayout` references remain.

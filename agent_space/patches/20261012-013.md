# 20261012-013 — Remove undefined call-statements and restore FSM transition dispatch

## Purpose
Fix syntax-pattern and semantic issues found in the whole-tree PlusCal review.

## Corrections
- Side-effect helper invocations are represented as expressions assigned to an explicit pseudocode effect variable instead of undefined macro-like statements.
- ProcessRegion now calls Transition when a handler owns a target; the first-pass version only computed a pending target and therefore lost the Source Script send -> action -> transition sequence.
- No Source Script rule is changed.

## Remaining
Undefined helper operators are still abstract Source Script calculations/interfaces rather than executable TLA+ definitions. A later translator/executable-verification step may instantiate them, but the pseudocode layer does not invent those implementations. Whole-tree syntax-pattern review continues.

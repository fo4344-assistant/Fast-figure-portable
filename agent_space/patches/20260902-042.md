# 20260902-042 — Mantine graph palette reset action retry

## 목적

`20260902-041`의 기능 설계를 그대로 유지하면서 unified-diff hunk line-count 오류만 교정해 적용한다.

## 041 실패 원인

마지막 hunk는 기존 2줄에 11줄을 추가하므로 `old 2 / new 13`이어야 한다. `041.patch`에는 `new 12`로 기록되어 GitHub Actions `git apply --check`가 `corrupt patch ...:33`으로 중단됐다.

HTML에는 `041` 변경이 전혀 적용되지 않았다.

## 변경 범위

- `FastFigureGraphObjectListStaging()` Mantine import에 `Button` 추가
- `기본 색상` 버튼 추가
- 클릭 시 기존 `fastFigureUiBridge.setGraphObjectColors(DEFAULT_COLORS, chartId)` 호출
- 편집 불가 또는 object 없음 상태에서는 disabled
- 버전 `1.1.82-alpha` → `1.1.83-alpha`

## source of truth / EFSM

`041`과 동일하다.

- graph object 배열: `chart.editor.objects`
- 기본 palette: `DEFAULT_COLORS`
- mutation: `setGraphObjectColorsFromPalette()` → 기존 graph-object EFSM 경로

새 상태나 EFSM event를 추가하지 않는다.

## 기각안

기능 코드를 변경해서 재시도하는 안은 기각한다. 실패가 기능/context가 아니라 diff metadata 오류로 확인됐기 때문이다.

## rollback

Mantine 목록의 `Button` import와 `기본 색상` Button block, 버전 문자열 두 곳만 제거하면 된다.

## 검증

1. `git apply --check`
2. `git diff --check`
3. application JavaScript `node --check`
4. patch 적용 commit 성공

# 20260901-022

## 목적

프로젝트 상태와 파생값의 권위가 여러 곳으로 분산되는 것을 방지하기 위해 `AGENT.md`에 source of truth 단일성 원칙과 임시값 격리 원칙을 명시한다.

## 변경 내용

- 모든 영속 상태와 기능 의미에는 유일한 source of truth만 허용한다는 규칙을 추가한다.
- source of truth를 읽거나 변경하기 위해 만든 snapshot, draft, cache, adapter-local value 등 임시값은 해당 작업 범위 밖에서 다른 로직의 입력이나 권위 상태로 참조하지 못하도록 명시한다.
- 임시값을 여러 부분에서 공유해야 하는 상황은 임시값 공유로 해결하지 않고, 원래 source of truth에서 다시 읽거나 명시적인 공용 상태 모델로 승격하도록 규칙을 추가한다.
- source of truth와 임시값 사이의 양방향 동기화 또는 둘 중 어느 것이 최신인지 판정해야 하는 구조를 금지한다.

## 이 방향을 선택한 이유

React/Mantine 전환 과정에서 snapshot, draft, selector 결과와 같은 파생값이 늘어나고 있다. 이 값들이 다른 기능에서 재사용되기 시작하면 원래 domain/EFSM 상태와 별도의 사실상 source of truth가 생길 수 있다. 따라서 단순히 "source of truth를 하나로 유지"하는 수준을 넘어, 그 값을 읽어 만든 임시 표현의 참조 범위까지 제한해야 한다.

이 규칙은 특정 프레임워크에 종속되지 않으며 project/domain state, EFSM state, UI draft, cache, selector 결과 모두에 동일하게 적용할 수 있다.

## 선택하지 않은 방향

- React local state만을 대상으로 제한하지 않는다. 같은 문제는 일반 JavaScript 변수, cache, DOM value, adapter snapshot에서도 발생할 수 있기 때문이다.
- 모든 임시값 생성을 금지하지 않는다. 편집 draft, 계산 중간값, 캐시는 필요할 수 있으며 문제는 그 값이 다른 부분에서 권위 상태처럼 재사용되는 경우다.
- 기존 EFSM이나 domain 구조를 이 문서 변경과 함께 수정하지 않는다.

## 검증 항목

- 기존 `AGENT.md` 작업 원칙을 삭제하거나 완화하지 않을 것.
- source of truth 단일성, 임시값 참조 범위 제한, 공유 필요 시 원본 재조회/공용 상태 승격, 양방향 동기화 금지가 모두 명시될 것.

## 패치에 포함되지 않은 변경사항

Fast Figure 애플리케이션 코드는 변경하지 않는다. 이 패치는 작업 규칙 문서만 변경한다.

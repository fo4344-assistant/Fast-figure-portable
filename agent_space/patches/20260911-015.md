# 20260911-015 — overlay entry/exit cutover

## 목적
Mantine overlay가 `appFSM.state.overlay`를 직접 구독하므로 legacy overlay DOM entry/exit 동기화를 실행 경로에서 제거한다.

## 변경
- `enterOverlayState()`를 no-op으로 전환한다.
- `exitOverlayState()`를 no-op으로 전환한다.
- `setOverlayDomState()`는 이번 패치에서는 dead helper로 남기고 후속 참조 검사 후 제거한다.

## 근거
FSM overlay state 자체가 source of truth이고 Mantine Modal이 렌더링 책임을 가진다. legacy panel/toggle/dialog 동기화는 더 이상 필요하지 않다.

## 제외
파일 포맷, renderer, model, overlay state/event 정의는 변경하지 않는다.

## 검증
workflow patch check, JS syntax, portable build, split/portable smoke.

## 롤백
이 패치만 되돌리면 legacy overlay entry/exit 동기화가 복구된다.

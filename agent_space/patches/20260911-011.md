# 20260911-011 — Mantine status/debug and label interaction completion

## Purpose

Complete the two remaining Mantine interaction surfaces that do not depend on the layout preview rewrite: status/debug ownership and label-preview pointer positioning. `20260911-009` and `010` failed before source application in the later layout-preview hunk, so these previously matching changes are reapplied independently without preserving any legacy UI compatibility API.

## Exact changes

### `fast-figure.js`
- Add a transient UI telemetry snapshot/subscription channel for status and debug presentation.
- Route `status()` through that channel while temporarily continuing the WIP DOM projection until legacy markup removal.
- Publish retained debug lines through the same channel.
- Add UI-independent `setDebugEnabled()`, `clearDebugOutput()`, and `saveDebugOutput()` commands.

### `fast-figure-ui.js`
- Add `useUiTelemetry()`.
- Add Mantine `FastFigureStatusDebug` with live status, debug enable/disable, log save, clear, and visible log output.
- Mount and export `FastFigureStatusDebug` from the Mantine shell.
- Add direct pointer drag to the Mantine label preview.
- Convert pointer coordinates to selected-slot reference geometry and clamp the label inside that geometry.
- Notify the existing label update path when dragging completes.

## Rationale

Status/debug and label drag are required Mantine functionality, not legacy compatibility. React must not read old `#status` or `#debugLog` DOM as an API. Label positioning must use the same project settings and reference geometry as dashboard rendering rather than delegate to the old preview DOM.

## Source of truth

- Status/debug transient presentation: runtime telemetry channel.
- Debug enable state and sequence: existing debug runtime state.
- Label position: `activeProject.labelSettings`.
- Label geometry: `gridSlotGeometry()` and `dashboardGeometry()`.
- Persistent project/UI state: existing project model and `appFSM`.

## EFSM / core impact

No persistent project schema or EFSM transition semantics change. Telemetry is transient and non-persistent. Label drag uses the existing label settings and notification semantics.

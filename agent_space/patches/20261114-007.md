# 공개 슬롯 선택 인자 연결

`contract.pcal`의 `slots.select` 경로와 `adapter.pcal`의 인자 순서 `(slotId, pendingContentType, direction)`에 맞춰 공개 binding에서 기존 helper의 `(slotId, direction, pendingContentType)` 순서로 전달한다. renderer가 주입받는 별도 콜백은 기존 순서를 유지한다.

helper의 `slotId = null` 기본값도 제거했다. 누락한 identity를 선택 해제용 명시적 null로 바꾸지 않고, 그대로 기존 검증 경로에 전달한다.

Git 기준 `5f98adc3f71eda64e959c2a96ab74af8bd81c699` 이후 세 파일 변경을 `git diff`로 기록했다. code153/stale이며 fingerprint는 기존 버전 도구의 계산 함수로 갱신했다.

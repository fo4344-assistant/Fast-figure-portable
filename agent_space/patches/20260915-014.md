# 20260915-014 — Remove native caption editor CSS

## Purpose
Continue the validated annotation cleanup after `20260915-013` by removing CSS used only by the deleted native caption editor while preserving shared popup, print, layout, and actual dashboard-caption styling.

## Exact changes
- Remove `.caption-heading` membership from the shared popup heading selector.
- Remove `.caption-heading strong` while preserving `.popup-heading strong`.
- Remove native-only `.caption-heading button`, `.caption-popup`, `.caption-heading`, `.caption-toggle-setting`, `.caption-actions`, and `.caption-settings` rules.
- Preserve `.popup-heading` for remaining legacy ownership areas.
- Preserve `.print-controls` / `.print-actions` for the not-yet-audited print/export cleanup.
- Preserve actual figure caption renderer styles (`.dashboard-caption`, `.caption-prefix`, `.caption-body`, `.caption-section`, `.caption-edit-region`).

## Patch construction
The patch was generated from the exact current `Fast-figure.html` excerpt after `20260915-013` and its hunk counts/positions were calculated automatically. The generated patch was checked with `git apply --check` against a synthetic file preserving the current source lines and line positions before queueing.

## Why this direction
The active caption editor is Mantine-owned and `20260915-009` removed the remaining native caption JavaScript ownership. These selectors therefore have no live editor DOM. Removing them now finishes the presentation side of the caption cutover without touching actual dashboard caption rendering.

## Rejected alternatives
- Remove print/layout CSS in the same patch: rejected because those ownership units require separate source audits.
- Remove dashboard caption styles: rejected because they render figure output rather than editor chrome.
- Combine native label CSS here: rejected to keep each post-failure CSS patch small and independently rollbackable.

## Source of truth
No state ownership changes. `activeProject.annotations.captions` remains authoritative, Mantine owns caption editing, and `syncDashboardCaption()` remains responsible for actual figure caption rendering.

## EFSM/core impact
None intended. No JavaScript, UI-FSM/EFSM transition, project schema, persistence, export geometry, or renderer behavior is changed.

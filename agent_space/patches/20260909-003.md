# UI palette patch format correction

## 목적

`20260909-002`는 UI palette Mantine 포팅을 의도했지만 application source에 적용되기 전에 `git apply --check`에서 `corrupt patch at ...:29`로 중단되었다. 이 패치는 `002`의 기능 의도를 바꾸지 않고 unified diff hunk count만 교정해 동일 변경을 다시 큐에 올린다.

## 002 실패 원인

workflow run `34299473878`에서 `Select patch`는 성공했고 `Check and apply patch` 단계의 첫 `git apply --check`가 실패했다. JS syntax/build/smoke에는 도달하지 않았다.

원인은 `fast-figure-ui.js` import hunk의 header count가 실제 context와 일치하지 않은 것이었다. `002`에는 `@@ -8,6 +8,7 @@`로 적었지만 해당 hunk에 포함된 기존 context line은 5개이므로 `@@ -8,5 +8,6 @@`가 맞다.

`002` 실패 기록은 그대로 보존하며 파일을 덮어쓰지 않는다.

## 변경 내용

기능 내용은 `20260909-002.md`와 동일하다.

### `fast-figure.js`
- `applyUiPaletteValues(values, notify = true)` 추가.
- `DEFAULT_UI_PALETTE` key 집합과 기존 `projectColor()`를 사용해 값을 정규화.
- `activeProject.appearance.uiPalette`에 기록 후 기존 `applyUiPalette(false, notify)`로 CSS projection/dashboard rerender/notify 재사용.

### `fast-figure-ui.js`
- Mantine `ColorInput` 사용.
- `FastFigurePaletteActions` 추가.
- `UI 색상` 버튼과 standard Mantine Modal.
- 10개 palette color 편집.
- React local state는 Modal draft/open 여부만 소유.
- 적용 시 `applyUiPaletteValues(draft)` 호출.
- 기본값은 `DEFAULT_UI_PALETTE`를 즉시 적용.
- 취소/close는 미적용 draft를 버림.

## source of truth / EFSM 영향

- 영속 authority: 기존 `activeProject.appearance.uiPalette` 하나.
- React draft는 Modal 입력 동안만 존재한다.
- `APP_STATE_DEFINITIONS`, project schema, FFPX/FFSX/Plotly 의미 변경 없음.
- Mantine callback에서 legacy DOM `.click()`/`.value`를 사용하지 않는다.
- 기존 `UI_PALETTE_CHANGED` notify 의미를 유지한다.

## 선택 이유와 기각안

`002`의 설계 판단을 그대로 따른다. legacy color input을 조작한 뒤 apply button을 클릭하는 bridge, React에 palette를 영속 복제하는 store, CSS projection을 React에 중복 구현하는 방향은 모두 선택하지 않는다.

## 검증

workflow에서 다음 전체를 통과해야 실제 적용으로 간주한다.

1. `git apply --check`
2. `git diff --check`
3. `node --check fast-figure.js`
4. `node --check fast-figure-ui.js`
5. portable HTML build
6. split/portable `file://` smoke
7. applied patch commit

수동 검증 항목은 `20260909-002.md`와 동일하다.

## 관련 보류 사항

- README는 legacy `<dialog>` 내부 정적 HTML이 현재 내용 source이므로, `innerHTML` clone이나 JS 내용 복제를 하지 않는다. content source를 하나로 정리하는 작업과 함께 Mantine Modal로 옮긴다.
- CSV header line 수는 legacy graph/data preview renderer가 `#headerLines`를 직접 읽으므로 graph/data form ownership 단위에서 함께 포팅한다.

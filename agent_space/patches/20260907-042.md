# 20260907-042 — Mantine README 호출 UI 추가

## 목적

sidebar의 README 호출 버튼을 Mantine으로 옮긴다. README 표시 상태는 기존 UI FSM의 `overlay` region을 그대로 사용한다.

## 변경 범위

변경 대상은 `fast-figure-ui.js` 하나뿐이다.

- `FastFigureUtilityActions`를 추가한다.
- Mantine `README` 버튼을 추가한다.
- 버튼은 기존 `toggleOverlay("readme")`를 통해 `appFSM.send("TOGGLE_OVERLAY", ...)`를 직접 호출한다.
- `appFSM.state.overlay === "readme"`인 동안 Mantine 버튼의 active 표현과 `aria-expanded`를 동기화한다.

## 유지되는 기존 구조

- UI FSM overlay transition
- 기존 README 내용과 renderer
- `fast-figure.js`의 overlay entry/exit 로직
- EFSM/project model

이번 patch에서는 README dialog 자체를 Mantine Modal로 교체하지 않는다. 먼저 호출 버튼과 FSM 연결만 동일 경로로 옮긴다.

## 하지 않는 변경

- legacy README 버튼 `.click()` 호출 안 함
- README DOM clone 안 함
- overlay FSM 변경 안 함
- `fast-figure.js` 수정 안 함
- cutover 안 함

## 이유

README open/close는 이미 UI FSM event로 표현되므로 새 bridge나 helper 없이 Mantine Button을 직접 연결할 수 있다.

## rollback

이 patch를 revert하면 `FastFigureUtilityActions`와 Navbar의 README 버튼만 제거된다. 기능 핵심에는 변경이 없다.

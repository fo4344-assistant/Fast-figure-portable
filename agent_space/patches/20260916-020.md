# 20260916-020 — hidden native graph editor markup removal

## 목적과 변경 내용

Mantine graph editor가 이미 소유하고 있고 현재 application JavaScript에서 참조되지 않는 native graph editor fieldset을 `Fast-figure.html`에서 제거한다.

삭제 범위는 `#buildBox` fieldset 전체이며, 여기에는 이전 native graph UI의 FFSX/Plotly import/export buttons, editable toggle, global/axis form, object form/list, graph palette controls가 포함된다.

## 선택 이유

`20260916-015`~`019`에서 해당 native form의 reader, apply path, object-list renderer/handlers, CSV preview buffer가 제거되었다. 현재 source에서 `buildBox`, `graphObjects`, `headerLines`, `editorEditable`, `importSlotJson` 등 native graph control ID의 active JavaScript 참조가 없고 `#buildBox` 자체도 이미 `hidden` 상태다.

Mantine 쪽에는 graph object add/select/move/delete/edit, header-lines, global/axis settings, palette, FFSX/Plotly import/export가 독립적으로 구현되어 있다. 따라서 이 markup은 backend/core 또는 logic EFSM의 API가 아니라 제거 가능한 legacy frontend projection이다.

## 선택하지 않은 방향

- 전체 legacy `<aside>`를 한 번에 제거하지 않는다. `fileName`/`status` native fallback과 React bootstrap root의 `hidden` 속성은 별도 ownership/visibility 감사가 필요하다.
- native control을 Mantine의 hidden bridge로 남기지 않는다. 이는 AGENT.md의 WIP 포팅 규칙과 충돌한다.
- EFSM event, `graphEditor*` functional command, ProjectObject, renderer는 변경하지 않는다.

## 전제 / 후속 작업 / 누락

- 이 패치는 HTML markup만 제거한다. 해당 markup 전용 CSS는 후속 패치에서 current selector 소비를 재검사한 뒤 제거한다.
- React bootstrap root가 실제 shell visibility에 미치는 영향은 별도로 확인한다. 이 패치는 이미 숨겨진 `#buildBox`만 제거하므로 그 결과에 의존하지 않는다.
- rollback은 이 패치 하나를 되돌리면 markup 전체가 복구되며 application model/schema에는 영향이 없다.

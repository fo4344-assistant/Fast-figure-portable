# 20261014-020 — Translate Source Script r22 command coverage to PlusCal r8

## 변경

- `project_efsm.pcal`: r22 PROJECT_COMMANDS 전체와 public persistent mutation coverage assertion 번역.
- `layout_annotations_export.pcal`: 직접 project commit을 제거하고 persistent mutation을 application project command dispatch로 수렴.
- project read projection은 command 후 `ReadActiveProject()`로 갱신.
- pseudocode r8 / Source Script r22 lineage와 translation review 갱신.
- verification/source-code는 stale 유지.

## 선택 이유

Source Script의 module decomposition과 명시적 mutation path를 그대로 보존하면서, pseudocode가 별도 authoritative project owner가 되지 않게 한다.

## 기각

- 기존 직접 `projectAuthority := candidate` 유지: r22 projectEFSM single mutation path와 충돌.
- generic mutation procedure 추가: application/projectEFSM 경계와 중복된다.
- Source Code부터 재개: TLC gate와 계층 순서를 위반한다.

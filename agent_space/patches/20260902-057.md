# 20260902-057 — Mantine Label preview / drag interaction 이식

## 목적

`20260902-056`에서 분리한 preview renderer와 pointer 좌표 계산을 실제 Mantine Label Modal에 연결한다.

Label preview는 장식이 아니라 X/Y pixel 위치를 직접 조작하는 기능 요소이므로 cutover 전에 반드시 이식한다.

## 변경 내용

- `FastFigureLabelModalStaging`에 transient `dragging` ref를 추가한다.
  - pointer id와 label 내부 click offset만 보관한다.
  - persisted/domain state가 아니다.
- Modal이 열려 있고 draft가 바뀔 때 `fastFigureUiBridge.renderLabelPreview(draft)`를 requestAnimationFrame에서 호출한다.
- Mantine form 안에 기존 class contract를 유지하는 preview host를 추가한다.
  - `#labelPreview.label-preview`
  - `.label-preview-slot`
  - `#labelPreviewLabel.label-preview-label`
- preview label pointerdown에서 pointer capture와 offset을 기록한다.
- pointermove에서 `fastFigureUiBridge.labelPreviewPosition(...)`을 호출해 기존 실제 slot geometry/label size constraint로 X/Y를 계산한다.
- 계산 결과는 React draft의 x/y만 갱신한다.
- pointerup/cancel에서 capture를 해제하고 transient drag ref를 비운다.
- 기존 NumberInput X/Y와 preview drag는 같은 draft를 공유하므로 서로 즉시 반영된다.

## 동작 의미

legacy preview는 drag 중 canonical label state와 dashboard를 즉시 갱신했다. Mantine Modal에서는 preview 자체가 작업 surface이므로 drag 중에는 draft만 변경하고 `레이블 적용`에서 기존 command로 commit한다.

이 차이는 파일/domain 의미를 바꾸지 않으며 다음 이점이 있다.

- Modal 취소 시 미적용 draft를 버릴 수 있음
- React controlled input과 domain live mutation 충돌 방지
- preview와 X/Y NumberInput의 단일 draft 유지

## 재사용하는 기존 계산

- `dashboardGeometry()`
- `gridSlotGeometry()`
- `labelPreviewGeometry()`
- `constrainLabelPreviewPosition()`
- `targetSlotIdentifier()`

slot 비율, label 실제 크기, drag boundary를 새로 구현하지 않는다.

## 파일/EFSM 영향

- 파일 schema 변경 없음
- 새 EFSM event 없음
- apply 시 기존 `applyLabelSettingsFromValues` / `applyLabelPositionFromValues` 사용

## 회귀 확인

- `git apply --check`
- `git diff --check`
- JavaScript `node --check`
- staging inactive 상태에서 legacy active UI 영향 없음

## rollback

이 patch만 되돌리면 Mantine preview surface/drag wiring만 제거되고 `056` preview helper와 기존 legacy preview는 유지된다.

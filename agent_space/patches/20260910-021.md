# 20260910-021 — Legacy asset DnD executor/listener removal

## 목적
017에서 설치 경로를 끊고 020에서 legacy DnD policy를 제거한 뒤 완전히 실행 불가능해진 legacy asset-tree DnD executor 및 listener installer를 삭제한다. 이로써 asset explorer의 drag/drop generic UI 구현은 Mantine 경로만 남는다.

## 변경 내용
- `executeAssetTreeDrop()` 전체 제거. 이 함수의 legacy internal move, trash native confirm, slot link, 외부 파일 import/rollback 구현을 삭제한다.
- `closeAssetTreeActionMenus()` 제거. legacy action menu는 018에서 이미 제거되었다.
- `installAssetTreeInteractions()` 전체 제거. legacy document click/keydown, tree dragstart/dragover/dragleave/drop/keyboard navigation listener 설치 코드를 삭제한다.
- `connectProjectAssetToSlot()`은 Mantine `/slots` drag/drop이 사용하는 UI-independent command이므로 유지한다.
- `refreshCsvControls()` 이후 graph/data 기능은 변경하지 않는다.

## Source of truth 및 EFSM 영향
없음. internal move는 Mantine이 `PROJECT_NODE_MOVED`를 직접 사용하고, project asset→slot link는 `connectProjectAssetToSlot()`을 사용한다. 외부 폴더 import는 016의 `importProjectFilesToDirectory()`와 공용 collision Modal을 사용한다. 삭제되는 executor의 rollback/confirm 의미는 이미 Mantine parity 경로에 이전되어 있다.

## 기각안
- legacy executor를 fallback으로 유지: 설치 경로가 끊겼어도 동일 semantics의 두 구현이 남아 이후 수정 시 divergence 위험이 생기므로 기각.
- `connectProjectAssetToSlot()`까지 삭제 후 React에서 SLOT events를 중복 구현: 기능 command 경계를 약화시키므로 기각.
- keyboard navigation만 legacy tree에 유지: generic explorer ownership을 다시 둘로 나누므로 기각.

## 검증
Workflow의 patch check, diff check, JavaScript syntax, portable build, split/portable `file://` smoke를 통과해야 한다. Mantine internal move, trash confirm/cascade, project asset→slot link, 외부 file→folder/slot drop, collision rename/replace와 batch rollback이 유지되어야 한다.

## 롤백
이 패치만 revert하면 legacy executor/listener 함수 정의가 돌아오지만 017에서 init 호출은 여전히 제거된 상태다. 따라서 runtime ownership은 그대로 Mantine이며 dead-code 제거만 독립적으로 되돌릴 수 있다.

## 후속
legacy `renderProjectDataTree()`와 renderer helper 호출 관계를 정리한 뒤 `Fast-figure.html`의 `assetTree`/legacy explorer controls 및 `REQUIRED_CONTROL_IDS`를 제거한다.

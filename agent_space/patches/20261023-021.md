# 20261023-021 — 경로 안내와 작업 기록 분리

## 목적·실제 범위

사용자 지시에 따라 경로명과 동명인 Markdown 10개와 README 3개를 Git 최초/변경 이력과 비교했다. 메모가 없는 안내 9개는 그대로 유지한다. tests/tests.md는 최초303292f의 역할 설명 5줄로 복원하고, 실행 절차는 tests/browser-regression.md, case/revision/실행 상태와 README에서 옮긴 기록은 reviews/review-20261023-019-document-placement.md에 둔다. 루트 README는 제품/설치/소스 배치 안내를 유지하며 진행 메모만 제거한다. pseudocode/README.md와 verification/README.md는 표기·모델 범위 안내를 유지하고 특정 revision/current/과거 run 상태를 기록 문서로 옮긴다.

## 선택 이유·기각한 대안

경로 안내는 해당 경로의 역할을 설명해야 하므로 revision별 작업 일지를 계속 누적하지 않는다. 현재 구조와 무관한 최초 README 전체로 되돌리는 방법은 유효한 사용법/현재 계층 안내까지 잃으므로 기각했다. 옮길 기록을 삭제하거나 현재 실행 결과로 재해석하지 않고 원문과 출처·시점의 한계를 보존한다. 정책 원문, 일반 문서 전체, 배포 파일은 수정하지 않는다.

## 기준·검증·미포함

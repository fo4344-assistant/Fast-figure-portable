# 20260915-003 — Remove final dangling legacy layout renderer call

## Purpose
Complete the dangling-reference repair after the native layout renderer was removed by 20260915-001.

## Exact changes
- Remove the remaining `renderLayout()` call from `clearAllSlotSelections()`.
- Keep `setSelectedSlot(null)` and `layoutSelected.clear()` unchanged.

## Rationale
`renderLayout()` was the native layout-preview DOM projector and was intentionally removed after the Mantine layout overlay became authoritative for UI rendering. `clearAllSlotSelections()` still contained one missed call. The state changes themselves remain sufficient: selected dashboard slot state is updated through the existing command path, and Mantine layout selection observes the authoritative selection state/revision path rather than the deleted native preview DOM.

## Rejected alternatives
- Restore `renderLayout()` as a no-op: rejected because it would preserve dead UI ownership only to mask a missed call site.
- Reimplement a renderer inside `clearAllSlotSelections()`: rejected because that would duplicate Mantine rendering and violate the single-owner cutover.
- Change selection semantics or EFSM events: rejected because this patch only removes an invalid projection call.

## Source of truth
`selectedSlotId`, `layoutSelected`, and the existing selection/EFSM command paths remain authoritative. No persistent state is added or changed.

## EFSM/core impact
No intended domain behavior change. This removes a call to a function that no longer exists.

## Validation
Run the standard patch check, JavaScript syntax checks, portable build, and split/portable Chromium `file://` smoke tests. After application, verify that `renderLayout` and `syncLayoutMapSize` have no remaining references in `fast-figure.js` or `fast-figure-ui.js`.

## Rollback
Revert the `Apply agent patch 20260915-003` commit. Restoring this call alone would be invalid unless the legacy renderer from before 20260915-001 were also restored.

## Follow-up
Continue with the legacy annotation preview/helper audit after confirming all deleted layout helper references are gone.

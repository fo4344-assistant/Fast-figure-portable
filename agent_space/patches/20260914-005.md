# 20260914-005 — Mantine layout and palette command ownership (non-overlapping)

## 목적
20260914-003/004가 동일 경계 줄을 두 hunk가 공유해 적용되지 않았으므로, layout handler 삭제와 palette 함수 전환을 하나의 비중첩 hunk로 합쳐 같은 cutover를 적용한다.

## 변경
- `setDashboardZoomLocked()`의 legacy zoom control DOM write 제거.
- dashboard zoom/reset, layout numeric/aspect, merge/split legacy event wiring 제거.
- `uiPaletteFromControls()` 제거.
- `applyUiPalette()`를 persistent project palette 단일 source로 전환하고 legacy color-input 역동기화 제거.
- old palette apply/reset button handler 제거.

## 이유
Mantine layout/palette가 기존 model/command 경계를 직접 사용하므로 legacy controls는 실행 경로에서 제거되어야 한다.

## Source of truth
layout은 `activeProject.layout`/`slotStyle`, palette는 `activeProject.appearance.uiPalette`, zoom은 기존 runtime state다.

## EFSM/core 영향
FFPX/FFSX/Plotly, project schema와 layout 알고리즘은 변경하지 않는다.

## 검증
workflow 전체 검증을 통과해야 한다.

## 롤백
patch revert로 복구 가능하며 데이터 migration은 없다.

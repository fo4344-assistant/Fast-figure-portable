# 20260906-020 — Mantine sidebar compatibility parity host

## 목적

visible Mantine shell owner 전환 전에 legacy aside를 숨겨도 기능이 사라지지 않도록 아직 React/Mantine control로 완전히 이관되지 않은 UI를 Mantine sidebar 안에서 접근 가능하게 한다.

현재 Mantine sidebar는 프로젝트/슬롯/파일/이미지/그래프 편집 기능 대부분을 갖고 있지만 project data tree, selected asset download/delete, 새 폴더, 슬롯 초기화, status/data preview, UI palette, debug, README 진입이 legacy aside에 남아 있다. 이 상태에서 owner를 전환하면 실제 기능 누락이 발생한다.

## 변경 내용

- 앱 버전 `1.1.123-alpha` → `1.1.124-alpha`
- `fastFigureUiBridge`에 기존 command를 재사용하는 transitional entry point 추가
  - `createAssetDirectory()`
  - `downloadSelectedAsset()`
  - `deleteSelectedAsset()`
  - `resetSelectedSlot()` — 현재 legacy reset command handler를 compatibility adapter로 호출
- Mantine toolbar에 기존 policy와 같은 README 진입 버튼 추가
  - 슬롯 선택 중에는 숨김
- Mantine sidebar에 project data action buttons 추가
  - 새 폴더
  - 선택 에셋 다운로드
  - 선택 에셋 삭제
  - 선택 슬롯 초기화
- `FastFigureSidebarCompatibilityStaging` 추가
  - 기존 `#assetTree`, `#status`, `#tableWrap` node를 React host로 **이동**한다. clone/rebuild하지 않는다.
  - 기존 `details.palette`, `details.debug-box`도 compatibility tools host로 이동한다.
  - effect cleanup 시 원래 parent/position으로 복구한다.
  - 기존 event listener, drag/drop state, imperative renderer를 그대로 보존한다.
- Mantine sidebar 안에 compatibility host를 배치한다.

## 의미 보존

- asset tree 렌더링/선택/drag-drop 알고리즘 변경 없음
- directory/VFS 모델 변경 없음
- CSV/image 삭제 규칙과 confirm 정책 변경 없음
- 슬롯 reset EFSM 경로 변경 없음
- palette/debug 동작 변경 없음
- 프로젝트/FFPX/FFSX schema 변경 없음

## EFSM / core 경계

새 state나 transition을 만들지 않는다. Mantine 버튼은 이미 존재하는 command/functions를 호출하며, asset tree 자체도 기존 DOM과 event listener를 이동해서 재사용한다.

## compatibility debt

`resetSelectedSlot()` bridge는 아직 legacy button handler를 command adapter로 사용한다. 또한 palette/debug UI는 이 패치에서 Mantine component로 재작성하지 않고 기존 widget을 host 안에 유지한다. 이는 owner cutover에서 기능을 잃지 않기 위한 명시적 transitional compatibility layer이며, cutover 안정화 후 별도 작은 패치에서 command extraction/component 이관 대상으로 남긴다.

## 선택하지 않은 방향

### asset tree를 React로 즉시 재작성

directory selection, drag/drop, slot linking, action menu semantics를 동시에 복제해야 하므로 cutover와 결합하기에는 회귀 위험과 구현 중복이 크다.

### legacy aside를 먼저 숨긴 뒤 누락 기능을 추후 추가

사용 가능한 기능이 일시적으로 줄어드므로 선택하지 않는다.

### DOM clone

listener와 internal DOM state가 분리되므로 node 자체를 reparent한다.

## 회귀 위험

중간. DOM node를 이동하지만 동일 document 안에서 node identity와 listener를 유지한다. cleanup restoration을 함께 두어 React owner rollback 시 원래 위치로 되돌릴 수 있게 한다.

## 검증

1. `git apply --check`
2. `git diff --check`
3. `node --check fast-figure.js`
4. portable build
5. split/portable `file://` smoke test
6. compatibility host가 clone 없이 existing nodes를 append하는지 확인
7. cleanup restoration 정보(parent/nextSibling)가 저장되는지 확인
8. Mantine asset buttons가 기존 command를 재사용하는지 확인
9. README button이 기존 overlay EFSM event를 사용하는지 확인
10. project/FFPX/FFSX/core functions 변경 없음 확인

## rollback

`FastFigureSidebarCompatibilityStaging`, 관련 bridge entry points와 Mantine action/README buttons를 제거하고 앱 버전을 `1.1.123-alpha`로 복원한다. cleanup effect가 mount 중 이동한 node를 기존 위치로 되돌린다.

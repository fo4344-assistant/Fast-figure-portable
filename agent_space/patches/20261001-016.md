# 20261001-016 — Source Script r7 횡단 정합성 정리

## 변경 원인

r6 이후 Source Script 전체에서 stale 의미를 검색했다.

실제 모순으로 남아 있던 항목은 renderer_runtime.py의 slot swap 설명으로,
r5에서 caption 이동 규칙이 확정되었는데도 “현재 미확정 rule”이라는 r4 문구가 남아 있었다.

또한 project_state.py와 portable_build.py의 header가 하위 구현을 계속 “현재 구현 원천”이라고 표현해
Source Script > lower source precedence와 표현상 충돌할 수 있어 검증 원천으로 정리한다.

## 의미 변경

새 domain 의미는 추가하지 않는다.

- renderer swap 설명을 r5 slot-local ownership rule과 일치시킴
  - GUI 위치 geometry는 유지
  - chart/image/contentType/caption local properties 전체를 함께 교환
- project_state.py의 fast-figure.js 표기를 하위 구현 검증 원천으로 변경
- portable_build.py의 build files 표기를 하위 build 구현 검증 원천으로 변경

## 선택 이유

Source Script closure는 모듈 전체가 같은 의미를 사용해야 한다.
이미 확정된 rule을 다른 module이 미확정으로 표현하면 pseudocode가 어느 쪽을 번역해야 하는지 다시 판단해야 하므로 닫힌 상태가 아니다.

## 기존 안을 채택하지 않은 기록

### renderer에서 caption rule을 별도 분기로 유지

채택하지 않는다.

r5에서 slot caption은 slot-local property이고 slot object local state와 함께 이동한다고 확정했으므로
renderer가 독립적으로 caption 이동 여부를 선택할 이유가 없다.

### lower source를 Source Script의 “구현 원천”이라고 계속 표현

채택하지 않는다.

현재 version precedence는 Source Script > pseudocode > source code다.
lower source는 reverse review와 회귀 확인 자료일 수 있지만 Source Script 의미의 권위 원천은 아니다.

## 닫힘 판정 영향

검색으로 발견된 stale caption semantics는 제거되었다.
이제 r7 전체에 대해 별도 closure review를 수행할 수 있다.

review 통과 전까지 closure는 open이다.

## 하위 단계 전파 범위

새 의미 추가는 없으며 r5/r6의 하위 전파 범위와 동일하다.

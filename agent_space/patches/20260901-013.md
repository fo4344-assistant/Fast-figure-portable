# 20260901-013 — Mantine Caption staging 계약 연결

## 목적

`plan-003.md` Commit B의 Caption staging 단계입니다. `20260901-011`과 `20260901-012`에서 만든 DOM-free caption 계약을 비활성 Mantine Caption Modal에 연결합니다. legacy UI는 계속 유일한 활성 UI이며 shell cutover는 수행하지 않습니다.

## 변경 내용

- 애플리케이션 버전을 `1.1.43-alpha`로 갱신합니다.
- `FastFigureCaptionModalStaging({ opened })`을 추가합니다.
- Modal이 열릴 때 `fastFigureUiBridge.readCaptionEditor()`로 draft를 초기화합니다.
- Mantine `Switch`로 캡션 표시 및 슬롯별 캡션 모드를 편집합니다.
- 현재 실제 편집 대상이 전체 Figure인지 특정 slot인지 `Text`로 표시합니다.
- slot 대상일 때 기존 의미와 동일하게 global caption name/nameBold 입력을 비활성화합니다.
- Mantine `TextInput`, `Select`, `NumberInput`, `Textarea`로 이름, 글꼴, 글자 크기, 행간, 본문을 편집합니다.
- 적용 버튼은 native control이나 legacy handler를 호출하지 않고 `fastFigureUiBridge.applyCaptionEditor(draft)` 하나만 호출합니다.
- 적용 결과로 반환된 실제 editor state를 draft에 다시 반영해 slot mode 전환 뒤 대상 변경까지 동기화합니다.
- 기존 Caption summary staging을 `FastFigureCaptionModalStaging`으로 교체하고 `window.FastFigureReactShell`에 export합니다.

## 선택지와 범위의 근거

Caption font family는 현재 native `captionFontFamily`의 실제 값만 사용합니다.

- `system-ui, sans-serif`
- `Arial, sans-serif`
- `Times New Roman, serif`
- `Georgia, serif`
- `Courier New, monospace`

글자 크기 6~96, 행간 0.8~4 및 0.05 step도 현재 native control과 기존 mutation 규칙을 그대로 유지합니다.

## 상태 소유권

- 영속 caption 상태와 target 결정은 기존 project object/EFSM/domain 함수가 소유합니다.
- React local state는 Modal에서 아직 적용하지 않은 draft만 소유합니다.
- slot mode 변경 후 실제 target 재판정은 `applyCaptionEditor()` 내부에서 수행합니다.
- overlay open/close는 기존 EFSM이 계속 소유합니다.

## 검증 기준

- patch target은 `Fast-figure.html` 하나뿐이어야 합니다.
- `git apply --check`, `git diff --check`, main inline JavaScript `node --check`를 통과해야 합니다.
- staging component는 native Caption DOM ID나 `.click()`을 사용하지 않아야 합니다.
- slot target에서 name/nameBold가 global caption state를 수정하지 않아야 합니다.
- slot mode 변경과 text 저장은 기존 EFSM event 경로를 유지해야 합니다.
- staging shell은 아직 mount되지 않아 현재 사용자 UI 동작이 변하지 않아야 합니다.

## 후속 작업

다음 단계는 Print/Export 설정의 DOM 결합을 조사하고 values/payload 계약을 분리하는 것입니다. Print는 실제 파일 저장 side effect와 설정 validation을 구분해 Mantine form이 export renderer를 직접 소유하지 않도록 합니다.

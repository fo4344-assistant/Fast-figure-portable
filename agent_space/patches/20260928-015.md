# 20260928-015

## 목적과 변경 내용

Fast Figure의 사용자 정의 스타일에 남은 두 가지 중복 reset을 제거한다.

- `* { box-sizing: border-box; }`
- `body { margin: 0; }`

앞선 Mantine core 스타일이 이미 `*, *::before, *::after { box-sizing: border-box; }`와 `body, :host { margin: 0; }`을 정의한다. 사용자 정의 스타일의 `body` 배경·글자색·overflow 및 renderer 규칙은 그대로 둔다.

## 선택 이유

일반 UI의 기본 geometry를 Mantine core와 사용자 정의 CSS에 반복 소유시키지 않는다. 사용자 정의 `box-sizing`은 Mantine보다 적용 범위가 좁고 같은 값을 다시 지정할 뿐이다.

## 선택하지 않은 방향

- Mantine core의 reset이나 vendored CSS를 수정하지 않는다. 해당 스타일은 runtime의 버전 고정 자산이다.
- `body`의 팔레트 색상과 overflow는 화면/renderer에 실제 영향을 주므로 이번 패치에서 변경하지 않는다.
- `.app`과 dashboard geometry는 React shell 옆의 기능 renderer 배치 규칙이므로 제거하지 않는다.

## 검증

- main `2df221cf72af9f382253d6b070f53a10d9362dba` 기준 patch
- Mantine core 스타일과 제거 대상 값의 일치 확인
- `git diff --check`, `git apply --check`, JS syntax, portable build 통과
- Chrome/Chromium을 이용한 split/portable `file://` smoke는 Actions에서 검증

## 후속 작업과 롤백

남은 CSS는 기능 renderer와 palette 소비 여부를 기준으로 계속 검토한다. 역적용하면 동일한 reset 선언만 다시 추가된다.

# 패치 설명

## 목적과 변경 내용

사용자의 Source Script → pseudocode 번역 불일치 검토 요청에 따라 `agent_space/reviews/review-20261115-002-source-script-pseudocode.md`를 추가한다. 현재 commit `959f154dfbec5441945593b5a36740e9347de316`의 Source Script 52와 pseudocode 26을 기준으로 15개 모듈 쌍을 전체 확인하고, 20건의 차이에 경로·행·대조 입력·결과·영향을 기록했다. 실행 실패 재현, 설정 의존적 차이, 절차 누락과 독립 반환 경계의 차이를 구분했다.

## 선택한 방향과 이유

검토 결과는 독립 review 문서에 둔다. Source Script를 의미 기준으로 사용하며, 함수 추출이나 class/record 표현 차이만으로 결함을 추가하지 않는다. source code 동작을 역으로 적용하지 않는다. 확인한 차이와 Source Script 내부 설명 연결을 추가 확인해야 하는 항목을 분리하여 후속 수정의 범위를 식별할 수 있게 한다.

## 다른 방향을 선택하지 않은 이유

이번 요청은 검토와 기록이므로 pseudocode를 함께 고치거나 계층 상태를 승격하지 않았다. 실행 검증을 요청한 작업으로 확대하지 않았다. plan·memo·정책·index를 중복 수정하지 않았다. 고정된 기본 설정에서는 같은 결과인 항목과 후속 constructor가 보완하는 반환 경계 차이를 즉시 제품 실패로 표현하지 않았다.

## 실제 diff와 포함하지 않은 범위

- 동명 `.patch`는 위 review와 이 설명 문서의 실제 새 파일 diff다.
- 비교 기준은 위 commit이다. 생성에는 Git의 `diff --no-index --binary --full-index`를 사용한다. patch 자체는 자기 diff에 포함하지 않는다.
- Source Script·pseudocode·source code·설정·빌드 스크립트·배포물·정책·AGENT·계층 메타데이터는 수정하지 않는다.
- Source Script 52의 `stale/open`과 pseudocode 26·source code 157의 기존 상태를 유지한다.
- 프로그램·테스트·빌드·TLC·version checker·브라우저·Actions를 실행하지 않는다. 커밋·푸시도 수행하지 않는다.
- 정적 근거와 한계는 review 본문에 있다. 20건은 이번 대조에서 확인한 항목 수이며 미발견 결함 부재나 Source Script 논리 닫힘을 뜻하지 않는다.

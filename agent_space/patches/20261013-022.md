# 20261013-022 — Implement plan-009 Source Code against r17/r11

## 목적

현재 closed Source Script r17과 current/TLC-passed verification-model r11에서 확정된 plan-009 interaction 및 Mantine UI 의미를 Source Code r13으로 반영한다.

## 변경 전 문제

- graph/image content가 있는 미선택 slot surface click이 selection으로 들어가지 않았다.
- dashboard background click이 selected slot을 해제하지 않았다.
- 일반 빈 CSV 생성 public command와 UI control이 없었다.
- trash subtree asset의 일반 selection disabled 상태가 row action Menu target까지 비활성화했다.
- Layout/Label/Caption/Print overlay가 각각 lg/xl size를 소유했다.
- Layout preview는 requested width로 geometry를 계산한 뒤 CSS maxWidth로 실제 width만 줄일 수 있어 height/gap/margin/radius와 rendered width가 분리될 수 있었다.
- preview surface와 resize handle이 width를 별도로 계산했다.

## 변경 내용

### fast-figure.js

- APP_BUILD를 1.1.33-wip로 갱신한다.
- createEmptyProjectCsv를 추가한다.
  - rows = [["X", "Y"], ["", ""]]
  - name = "빈 CSV.csv"
  - MIME = text/csv
  - headerLines = 1
  - 기존 createProjectCsv와 VFS unique-path 규칙만 사용한다.
- assets.createEmptyCsv public command를 추가한다.
  - 일반 CSV asset 생성 후 기존 graphEditorSelectCsv selection 경로를 사용한다.
  - chart 또는 graph object를 자동 생성하지 않는다.
- installSlotClickController를 selection-state-first 분기로 변경한다.
  - 미선택 visible slot surface는 graph/image/empty 공통으로 선택한다.
  - 선택된 graph/image content surface는 content interaction으로 통과시킨다.
  - 선택된 empty surface와 bookmark는 기존 toggle semantics를 사용한다.
  - dashboard controller 내부의 non-slot background click은 기존 SELECT_SLOT none 경로로 deselect한다.

### fast-figure-ui.js

- 네 설정 overlay가 공유하는 FAST_FIGURE_SETTINGS_MODAL_SIZE를 하나만 정의하고 theme.other에 둔다.
- Layout/Label/Caption/Print만 그 공통 size를 참조한다. README와 UI palette Modal은 포함하지 않는다.
- trash asset row에서 selection Button disabled와 Menu Target enabled 여부를 분리한다.
- graph/data editor에 "빈 CSV 삽입" control을 추가하고 assets.createEmptyCsv에 직접 연결한다.
- Layout preview requested width와 actual rendered width를 구분한다.
- ResizeObserver로 preview wrapper의 실제 rendered width를 읽고 layoutApi.readState의 geometry 입력으로 사용한다.
- preview surface와 resize handle을 같은 wrapper 아래 두고 width/alignment ownership을 공유한다.
- DOM 측정값은 React renderer-local state이며 project state에 추가하지 않는다.

### browser regression

- r17/r11/r13 metadata로 갱신한다.
- content slot의 selection-state-first 동작과 background deselection을 검증한다.
- selected empty slot surface의 toggle-off를 검증한다.
- 빈 CSV 생성/선택이 chart/object를 자동 변경하지 않는지 검증한다.

### development-versions.json

- source-code revision을 r13으로 증가시킨다.
- source-code status를 current로 갱신한다.
- 새 source-code fingerprint를 기록한다.
- derived_from을 현재 Source Script r17 및 verification-model r11 fingerprint로 갱신한다.

## Source of Truth

새 persistent state는 추가하지 않는다.

- slot selection authority: 기존 ApplicationStateMachine / SELECT_SLOT
- CSV asset authority: 기존 activeProject csvFiles / DATA_OBJECT_CREATED
- current CSV selection: 기존 SELECT_ASSET + graphEditorSelectCsv
- Modal size: 하나의 UI-local common definition
- preview actual width: renderer-local measurement projection

requested preview width와 actual rendered width 사이에 양방향 동기화는 만들지 않는다.

## 선택 이유

새 command나 UI가 기존 mutation 의미를 우회하지 않도록 r17에서 이미 확정된 command 조합만 사용했다. Layout 측정은 project/domain state가 아니므로 persistent state나 별도 FSM field를 만들지 않고 renderer 내부 measurement로 제한했다.

## 검토했지만 선택하지 않은 방향

- content type별 slot selection handler: selection authority와 분기 규칙이 중복되므로 사용하지 않는다.
- 빈 CSV 생성과 graph object 생성을 한 command로 결합: Source Script r17의 의미와 다르므로 사용하지 않는다.
- trash asset의 selection 자체를 다시 활성화: Menu 접근과 selection 의미를 결합하므로 사용하지 않는다.
- Modal마다 동일 px 값을 반복: common ownership 요구를 위반하므로 사용하지 않는다.
- CSS max-width만 유지하고 requested geometry를 그대로 사용: rendered geometry 불일치를 남기므로 사용하지 않는다.
- preview actual width를 project state에 저장: renderer projection을 domain state로 승격하므로 사용하지 않는다.

## 회귀 위험

- capture 단계의 slot click 분기가 Plotly/image interaction보다 먼저 실행되므로 selected 여부 판정이 잘못되면 interaction을 소비할 수 있다.
- ResizeObserver가 동작하지 않는 환경에서는 preview actual-width projection이 갱신되지 않는다. 지원 대상 modern browser의 표준 API를 전제로 한다.
- 공통 Modal maximum이 넓어지므로 작은 viewport에서는 Mantine의 viewport constraint와 함께 동작해야 한다.

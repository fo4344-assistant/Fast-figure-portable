# 20261014-029 — Derive verification r24 from pseudocode r10

## 변경

- Slot Core에 `SLOT_IMAGE_IMPORTED` representative action을 추가한다.
- image import는 target slot의 기존 chart ownership 제거, image asset/reference 추가, contentType=image 변경을 한 candidate로 표현한다.
- commit/reject 뒤 selectedSlotId 자체는 project action에서 바뀌지 않는다는 assertion을 둔다.
- command ownership mapping에 `SLOT_IMAGE_IMPORTED`를 추가한다.
- Source Script r23 / pseudocode r10 lineage로 verification r24를 갱신하고 TLC는 pending으로 둔다.

## 생략 근거

- `PROJECT_NAME_CHANGED`: project meta만 변경하며 slot/reference/selection/tree property와 독립적이다.
- `APPEARANCE_CHANGED`: persistent palette만 변경하며 modeled project reference state와 독립적이다.
- `SLOT_TYPE_CHANGED`: empty/explicit slot의 contentType intent 변경이며 chart/image reference 자체를 생성·삭제하지 않는 범위는 현재 ownership invariant와 독립적이다.
- `SLOTS_RESET`은 기존 Slot Core에서 이미 직접 모델링한다.

이 생략은 해당 field validation 전체를 TLC로 증명한다는 뜻이 아니다. 이후 reference나 selection invariant에 영향을 주는 의미가 추가되면 다시 모델에 포함한다.

## 선택 이유

SLOT_IMAGE_IMPORTED는 chart→image 전환에서 chart collection과 slot reference를 함께 바꾸므로 현재 Slot Core property에 직접 영향을 준다.
반대로 독립 settings/meta state를 추가하면 검증 property와 무관한 상태공간만 증가한다.

## 후속

push-trigger bounded Slot Core config에는 `ProjectCommandOwnershipInvariantSpec`가 포함되어 있다.
두 model의 translation/parse/TLC가 실제 성공한 뒤 validation review와 `tlc: passed`를 기록한다.

# 20260831-001

## 목적

`agent_space` 아래 작업 기록을 역할별로 분리해 이후 에이전트 작업에서 자료의 성격과 보관 위치가 혼동되지 않도록 한다.

## 적용한 방향

다음 경로를 사용한다.

- `patches`: 실제 diff 패치와 동명 설명 문서
- `docs`: 장기 기준 문서와 확정 설계
- `logs`: 실행·오류·디버그 원시 기록
- `memo`: 미확정 아이디어와 임시 메모
- `history`: 주요 변경과 결정의 시간순 맥락
- `research`: 외부 조사와 근거 자료 정리
- `tests`: 테스트 절차와 구조화된 검증 결과
- `reviews`: 독립적인 코드·설계·회귀 위험 검토

각 디렉터리에는 디렉터리와 같은 이름의 Markdown 파일을 두어 용도를 설명한다.

## 이 방향을 선택한 이유

기록 종류별 책임을 분리하면서도 경로 수를 필요한 수준으로 제한할 수 있다. `tests`는 실제 수정의 회귀 검증을, `reviews`는 패치 설명과 별개의 검토 판단을 담당하므로 기존 여섯 경로에 합치면 서로 다른 성격의 기록이 섞인다.

## 선택하지 않은 방향

- `plans`를 별도 경로로 만들지 않았다. 확정 전 계획은 `memo`, 확정된 설계와 작업 기준은 `docs`로 나눌 수 있어 별도 경로가 중복된다.
- `artifacts`를 별도 경로로 만들지 않았다. 현재 저장소의 에이전트 작업에서 독립된 산출물 분류가 아직 필요하다고 확인되지 않았다.
- `decisions`를 별도 경로로 만들지 않았다. 장기적으로 유효한 결정은 `docs`, 시간순 결정 맥락은 `history`, 검토 판단은 `reviews`로 표현할 수 있다.

## 패치에 포함되지 않은 변경사항

이 작업에서 다음 파일도 함께 추가되었으나, 자기 자신을 포함하는 재귀적인 diff를 피하기 위해 `20260831-001.patch`에는 포함하지 않았다.

- `agent_space/patches/patches.md`
- `agent_space/patches/20260831-001.patch`
- `agent_space/patches/20260831-001.md`

`patches.md`는 `patches` 경로의 용도를 설명하며, `20260831-001.patch`와 이 문서는 이번 변경을 기록하는 동명 쌍이다.

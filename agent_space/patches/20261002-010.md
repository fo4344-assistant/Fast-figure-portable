## QA review

`review-022-mantine-ui-regression-qa.md`에 각 항목별로 다음을 기록했다.

- 현상
- 현재 원인 위치
- 구 버전 동작
- Source Script 변경 필요 여부
- 실제 수정 계층
- QA 누락 원인
- 후속 acceptance criteria
- 영향도 우선순위

주요 판정:

- 초기 slot 미렌더는 `sourcescript/system.py::initializeFastFigure`의 기존 요구를
  source code startup이 지키지 않은 명확한 하위 구현 불일치다.
- layout preview는 geometry renderer cell을 Mantine Button으로 치환하면서
  generic Button height가 geometry에 침범한 문제다.
- label preview는 실제 slot label과 달리 line-height projection이 빠졌다.
- font selector는 graph/label/caption에서 TextInput으로 단순 치환되며 기존 option UX가 사라졌다.
- label font-size는 transient input까지 즉시 최소 6으로 commit해 editing이 깨진다.
- slot caption domain API는 남아 있지만 overlay/selection interaction composition이 끊겼다.
- 나머지 button color와 field alignment는 UI source-level parity/consistency 문제다.

## 선택한 방향

구 버전 UI를 권위 구현으로 되돌리는 대신 reference fixture로만 보존하고,
현재 Source Script의 의미와 현 구현을 각각 대조했다.

이렇게 하면:

- 구 CSS/interaction에만 있던 parity 정보를 확인할 수 있고
- 과거 구현의 obsolete domain 구조를 다시 current authority로 승격하지 않으며
- 이후 실제 수정에서 Source Script 변경이 필요한 문제와 하위 UI 구현 문제를 구분할 수 있다.

## 고려했지만 선택하지 않은 방향

### 구 버전 전체를 Plotly 포함 그대로 저장

inline Plotly가 대부분의 파일 용량을 차지하고 UI parity 조사에는 필요하지 않다.
사용자 지시에 따라 library block만 제거했다.

### 문제를 조사하면서 바로 모두 수정

9개 항목은 startup, layout, label, caption, generic action styling처럼 ownership이 다르다.
원인과 Source Script 경계를 먼저 고정하라는 현재 요청에 맞지 않아 이번 패치에는 포함하지 않았다.

### 구 버전 동작을 그대로 Source Script에 추가

field alignment, widget 종류, line-height 같은 renderer/UI 세부를 domain semantic rule로
승격하면 상위 계층이 특정 UI 구현에 불필요하게 결합된다.

### 기존 review-012 완료 판정을 그대로 유지

실제 fixture 비교 없이 logical/domain regression 중심으로 완료 판정되어 이번 회귀를
놓쳤다는 근거가 확인되었으므로 QA 문서에 범위 한계를 명시했다.

## 관련 누락 및 후속 작업

이번 패치는 진단만 수행하므로 9개 문제는 아직 수정되지 않았다.

후속 source 수정 시 `review-022`의 acceptance criteria를 regression에 추가하고,
특히 다음을 실제 DOM 수준에서 검사해야 한다.

- startup 직후 4 slot 존재
- layout preview cell rect와 grid track geometry
- label preview/rendered label line-height parity
- font selector option/custom value 보존
- NumberInput transient editing
- slot-caption target selection flow
- caption field/button vertical alignment
- action button variant consistency

# 20260916-004 — Remove orphaned native print/export CSS

## Purpose
Complete the native print/export UI ownership cleanup after `20260916-003` by removing CSS selectors that only styled deleted native print controls and popup markup, while preserving the active Mantine print overlay and all export/rendering functionality.

## Exact changes
Remove native print-only CSS from `Fast-figure.html`:

- remove `#printToggle` from the legacy toolbar primary-width selector;
- remove the standalone `#printToggle` right-alignment rule;
- remove `.print-panel` membership from the shared fixed-popup panel rule, leaving `.layout-panel` unchanged;
- remove `.print-panel > *` membership from the shared popup child sizing rule;
- remove `.print-controls` and its label/input/select styling;
- remove `.print-actions`, button, and hint styling;
- remove the print-only icon-size selector combining `#printToggle.icon-only` and `.print-actions button.icon-only`;
- remove `.print-panel` from the centralized palette panel override, leaving `.layout-panel` unchanged.

Preserve:

- generic `.popup-heading` styling, because remaining legacy ownership areas have not yet been fully audited;
- generic `.icon-only` and `.icon-only > .iconoir-mount` rules;
- all layout panel/control/map styling;
- active Mantine `FastFigurePrintOverlay` component styling supplied by Mantine;
- all actual dashboard, caption, label, Plotly, image, and export renderer styling.

## Why this direction
Current `Fast-figure.html` contains no native print-control markup (`printToggle`, `printStatus`, `printWidth`, `printHeight`, `printDpi`, `printFormat`, print panel/actions/controls). `20260916-003` removed the last executable JavaScript fallback to those controls. The remaining print CSS therefore has no live owner and only obscures the final ownership structure.

Removing it as a separate presentation-only patch keeps the export algorithm rollback boundary independent from CSS cleanup and follows the `plan-006` cutover policy.

The patch was generated from exact current `Fast-figure.html` excerpts after `20260916-001` and after successful `20260916-003` (which changed JavaScript only). Unified-diff hunk positions/counts were generated automatically. The resulting patch passed a synthetic `git apply --check` against the exact fetched source segments at their repository line positions before queueing.

## Rejected alternatives
- Remove `.layout-panel` or layout controls together with print CSS: rejected because layout is a separate ownership unit and still requires its own audit.
- Remove `.popup-heading` now: rejected because it may still style a remaining legacy popup ownership area.
- Remove generic `.icon-only`: rejected because it is shared presentation infrastructure rather than print-specific dead CSS.
- Modify Mantine print component or export functions in this patch: rejected because the functional cutover was already completed and validated in `20260916-003`.
- Keep the CSS until a final bulk deletion: rejected because the print ownership cutover is now complete and removing dead selectors immediately makes the next legacy audit more precise.

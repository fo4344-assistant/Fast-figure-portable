# 슬롯 파일 가져오기 순서 번역

`assets.pcal`의 `importProjectFileToSlot`은 대상 슬롯을 확인한 뒤 파일 종류를 조회한다. 기존 코드는 대상이 없어도 파일 종류를 먼저 조회했다. 조회를 대상 검사 다음으로 옮겨 잘못된 대상에서 파일 조회·관련 예외가 먼저 발생하지 않도록 했다.

대조한 graph 및 layout/annotation 공개 절차에서는 추가 변경이 필요한 차이를 찾지 못했다. 해당 코드는 수정하지 않았다.

Git 기준 `dc6aafbc9a10a8a2308162b1aa128e0d5ad4d69e` 이후의 두 파일 변경을 `git diff`로 기록했다. code150/stale이며 fingerprint는 기존 버전 도구의 계산 함수를 사용해 갱신했다.

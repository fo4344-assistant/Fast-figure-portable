# 20260911-014 — overlay legacy DOM cutover

## 목적
Mantine Modal이 layout/label/caption/print/README overlay를 모두 소유하므로 FSM overlay entry/exit에서 legacy panel, toggle, dialog를 직접 갱신하는 경로를 제거한다.

## 변경
- `setOverlayDomState()`를 제거한다.
- `enterOverlayState()`를 DOM 비의존 no-op entry로 전환한다.
- `exitOverlayState()`를 DOM 비의존 no-op exit로 전환한다.
- overlay FSM state/event 정의 자체는 유지한다.

## 근거
Overlay의 source of truth는 `appFSM.state.overlay`이고 Mantine overlay component가 이를 직접 구독한다. 기존 panel/toggle/dialog에 같은 상태를 복제하는 것은 중복 UI ownership이며 old markup 제거를 막는다.

## 제외
- layout/label/caption/print의 모델 및 renderer 동작은 변경하지 않는다.
- README content authority는 이번 패치에서 변경하지 않는다.
- FFPX/FFSX/Plotly 파일 계층은 변경하지 않는다.

## 검증
workflow의 patch check, JS syntax, portable build, split/portable smoke test를 사용한다.

## 롤백
이 패치만 되돌리면 legacy overlay DOM 동기화가 복구된다.

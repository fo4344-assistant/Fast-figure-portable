# 20260902-065 — Mantine dashboard zoom component 정의 분리

## 목적

`20260902-064`는 Layout Modal wiring hunk의 current context 불일치로 apply-check 단계에서 실패했고 HTML에는 반영되지 않았다.

이번 patch에서는 `FastFigureDashboardZoomStaging()` component 정의만 먼저 적용한다.

## 변경 내용

- `FastFigureDashboardZoomStaging()` 추가
- `readDashboardZoomModel()`로 초기 runtime 상태 읽기
- Mantine Slider 50~200%
- zoom percent / 실제 dashboard width 표시
- 현재 폭 고정/해제 Button
- 100% reset Button
- 모든 기능은 `063`의 common command 사용

## source of truth

component local model은 command 반환 snapshot을 표시하기 위한 transient state다. 권위 상태는 기존 dashboard zoom runtime state다.

## 파일/EFSM 영향

없음.

## 후속

`066`에서 Layout Modal의 `layoutMap` anchor 앞에 이 component를 한 줄로 연결한다.

## rollback

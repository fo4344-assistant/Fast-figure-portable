# 20260928-020

## 목적과 변경 내용

`20260928-019`의 팔레트 `기본값` 명령 의미 변경을 정확히 역적용한다. UI 버튼은 다시 기존 `appearance.resetPalette()`를 호출하고, 019에서 추가한 `appearance.readDefaultPalette()` API와 helper를 제거한다.

## 선택 이유

019는 Mantine 그래픽 UI 및 색상 투영 통합 범위를 넘어, `기본값` 명령이 언제 영속 프로젝트 상태를 바꾸는지 변경했다. 사용자의 지적에 따라 그 명령의 기존 의미를 복원한다. `20260928-017`의 Mantine 색상 투영은 그대로 적용된 상태이므로, 기본값 명령이 발생하면 현재 프로젝트 팔레트가 Mantine에 반영된다.

## 고려했지만 선택하지 않은 방향

- **019의 초안 초기화 의미를 유지하며 취소 동작까지 추가 수정:** 기존 명령 의미를 더 넓게 변경하고 별도 복구 규칙을 만든다. 이번 UI 통합 범위와 맞지 않는다.
- **기본값 버튼을 제거:** 의미 충돌은 없애지만 기존 팔레트 초기화 기능을 없앤다.
- **색상 투영 패치 017까지 되돌리기:** 문제는 명령 의미를 바꾼 019에 한정된다. 017의 Mantine 표시 소유권까지 되돌리면 통합 작업 자체를 역행한다.

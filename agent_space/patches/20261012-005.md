# 20261012-005 — Translate project authority and graph semantics to PlusCal

## Purpose
Continue r13 PlusCal translation from the closed Source Script without changing Source Script semantics.

## project_state.pcal
Translates whole-project authority replacement, pure validation, slot normalization, default-project construction, unique chart ownership resolution, and CSV/image/chart reference resolution.

## graphs.pcal
Translates graph-object creation/commit/edit, editable conversion, projection rebuild, graph-file import, and editable/imported export selection. Persistent writes are emitted through the existing mutation-command boundary instead of creating chart authority inside the pseudocode module.

## Translation boundary
Helper names such as ValidateVfsDirectories or NormalizeGraphObjects stand for calculations already specified by Source Script. They do not add new state or new failure rules.

## Rejected
Mutating projectAuthority before whole-project validation; storing CSV rows in graph objects; creating fake default objects/CSV; treating renderer projection as graph authority.

## Remaining
assets_files, layout_annotations_export, the rest of renderer_runtime/api_ui/application_fsm, system initialization, and portable_build remain to translate. No TLC claim.

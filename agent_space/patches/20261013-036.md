# 20261013-036 — Separate PlusCal procedure and harness symbols

## 목적과 변경 내용

verification r13의 InteractionCore가 PlusCal generated namespace에서 procedure parameter와 harness `with` binding을 중복 정의한 문제를 수정한다.

- `MoveAsset` procedure parameter를 `assetMoveSourceArg`, `assetTargetLocationArg`로 변경.
- harness binding을 `requestedMoveSource`, `requestedTargetLocation`으로 별도 명명.
- verification revision을 r14로 증가시키고 fingerprint를 갱신.
- TLC 상태는 성공 확인 전까지 `pending` 유지.

도메인 상태전이, precondition, invariant 의미는 변경하지 않는다.

## 선택 이유

실패 로그가 SANY의 multiply-defined symbol 오류를 명시했다. 의미 변경 없이 verification 표현의 식별자 충돌만 제거하는 최소 수정이다.

## 고려했지만 선택하지 않은 방향

- global variable로 source/target을 승격: verification state를 불필요하게 늘리므로 기각.
- procedure를 제거하고 harness에 move logic 복제: pseudocode의 procedure boundary를 훼손하므로 기각.
- Source Script 식별자 변경: 하위 verification 표현의 문제이므로 상위 의미를 수정할 이유가 없다.

## 후속

hosted TLA workflow에서 r14를 다시 translation/parse/model-check한다. 성공 로그가 확인되기 전에는 passed로 전환하지 않는다.

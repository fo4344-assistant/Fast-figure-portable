# 20260902-027 — graph object mutation command / legacy renderer 분할 재시도

## 배경

`20260902-026`은 `git apply --check`에서 실패했고 HTML에는 적용되지 않았다.

job log의 실제 오류는 다음과 같다.

```text
error: patch failed: Fast-figure.html:18110
error: Fast-figure.html: patch does not apply
```

따라서 앞의 `saveGraphObjects()` 분리 hunk가 아니라 후반 `applySelectedGraphObjectFromValues()` 호출 전환 hunk가 현재 main의 line/context와 맞지 않았다.

## 목적

`026`을 두 단계로 분할한다.

이번 `027`에서는:

- `saveGraphObjects()`의 domain mutation 본문을 `replaceGraphObjects()`로 분리
- 기존 `saveGraphObjects()`를 legacy list renderer wrapper로 유지

까지만 수행한다.

`applySelectedGraphObjectFromValues()`의 호출 전환은 후속 `028`에서 별도 적용한다.

## 변경 내용

- 앱 버전 `1.1.70-alpha` → `1.1.71-alpha`
- `replaceGraphObjects(objects, expectedChartId = null)` 추가
- 기존 mutation/EFSM/updateGraphView/notify 본문을 이 함수가 소유
- 성공 시 chart 반환, 실패 시 null 반환
- 기존 `saveGraphObjects(objects)`는:
  - `replaceGraphObjects(objects)` 호출
  - 성공 시 `renderGraphObjects(chart.editor.objects)` 호출

## 기능 보존

현재 active legacy caller는 모두 `saveGraphObjects()`를 계속 사용하므로 목록 렌더 동작이 변하지 않는다.

이번 패치만 적용된 시점에는 selected Mantine form도 아직 `saveGraphObjects()`를 호출하므로 사용자 동작 변화가 없다. 후속 패치에서만 legacy renderer 의존을 제거한다.

## source of truth / EFSM

변경 없음.

- objects source: chart `editor.objects`
- mutation authority: `GRAPH_OBJECTS_REPLACED`
- `replaceGraphObjects()`는 기존 payload/action을 그대로 재사용

## Plotly 범위

`updateGraphView()`는 기존 위치와 순서를 유지한다. Plotly renderer나 인라인 Plotly library는 읽거나 수정하지 않는다.

## 선택하지 않은 방향

- `026` 전체를 같은 형태로 다시 적용하지 않는다. 실패 hunk를 분리해 원인을 좁힌다.
- legacy `renderGraphObjects()`를 지금 제거하지 않는다. active legacy UI가 아직 소유자다.
- 새 EFSM event를 만들지 않는다.

## 검증

- save/replace 함수 hunk만 포함
- `git apply --check`
- 실제 apply
- `git diff --check`
- application inline JavaScript `node --check`
- legacy `saveGraphObjects()` 호출자 식별자 유지
- Plotly/trace diff 없음

## rollback

`replaceGraphObjects()` 본문을 다시 `saveGraphObjects()`로 합치고 `renderGraphObjects()`를 원 위치로 복원한 뒤 버전을 `1.1.70-alpha`로 되돌린다.

## 후속

성공 후 `028`에서 `applySelectedGraphObjectFromValues()`의 단일 호출만 `replaceGraphObjects(next, chart.id)`로 교체한다.

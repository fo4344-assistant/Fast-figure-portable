# 20260831-010

## 목적

첫 Mantine vendoring 실행에서 확인된 잘못된 검증 조건을 수정하고, 재실행 결과 기록 순번을 `20260831-011`로 조정한다.

## 변경 내용

- runtime bundle 안의 모든 `http://`/`https://` 문자열을 금지하던 검사를 제거한다.
- 외부 `<script src>` 또는 HTTP dynamic import가 없는 inline IIFE인지 확인하는 조건으로 바꾼다.
- 성공 시 생성하는 patch/설명 파일 순번을 `20260831-011`로 변경한다.
- 수정본은 별도 workflow 파일로 추가해 실패한 첫 builder를 수정 재실행하지 않고, 보정된 실행을 한 번만 수행한다.

## 이 방향을 선택한 이유

React/Mantine 코드에는 문서 링크나 오류 메시지 같은 URL 문자열이 포함될 수 있다. URL 문자열의 존재와 runtime 네트워크 의존성은 같은 조건이 아니다. esbuild `--bundle --format=iife` 결과를 HTML에 inline으로 넣고 외부 module import/script reference가 없는지를 확인하는 것이 실제 요구와 일치한다.

## 고려했지만 선택하지 않은 방향

- 실패한 workflow를 그대로 재실행하지 않았다. 같은 검증 오류가 반복되기 때문이다.
- URL 문자열을 bundle에서 강제로 제거하지 않았다. third-party 코드 의미를 불필요하게 변형할 수 있다.
- CDN 접근을 허용하지 않았다. portable/offline 요구는 그대로 유지한다.

## 패치에 포함되지 않은 변경사항

첫 실패 실행은 저장소 파일을 변경하지 않았다. 수정 workflow가 성공하면 실제 runtime 변경은 `20260831-011.patch/.md`와 함께 별도 커밋으로 기록된다.

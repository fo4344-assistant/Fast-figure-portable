## 선택·기각 대안

한 기존 JSON에 backend 두 블록을 두고 기존 owner들이 경로를 소비한다. Python settings 모듈/여러 설정 파일/loader registry/복제 DEFAULT 목록은 만들지 않는다. ProjectObject 전체를 config에 넣거나 config 전체를 현재 Project에 merge하는 대안은 데이터와 기본값 권위를 섞으므로 기각했다. 저장 데이터의 유효 설정은 유지하고 생성/누락/reset의 해당 field만 기본값을 사용한다.

caption text/afterText/name, CSV rows/filename, 빈 SVG bytes, assets/charts/slots/id/nextId는 인스턴스/생성 데이터이므로 config에서 제외한다. codec·enum·참조관계·수학/geometry 계산은 알고리즘으로 남기며 사용자 옵션으로 발명하지 않는다. 새 Frontend section도 넣지 않는다. checker는 Backend 구조/필수 object 경로/금지 data key를 확인하지만 일반 schema engine이나 application validation 대체물은 아니다.

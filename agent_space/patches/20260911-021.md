# 20260911-021 — legacy overlay audit removal

## 목적
Mantine overlay cutover가 완료된 상태에서 `auditApp()`이 더 이상 legacy layout/label/caption/print panel, toolbar toggle, popup CSS class, README dialog 상태를 검사하지 않도록 한다.

## 변경
- `overlayPanels` 기반 legacy panel visibility 검사 제거.
- legacy overlay toggle highlight/aria-expanded 검사 제거.
- `dashboard-popup-open`, `layout-open` CSS class 동기화 검사 제거.
- legacy `readmeDialog.open` 검사 제거.

## 근거
Overlay source of truth는 `appFSM.state.overlay`이며 Mantine Modal들이 이를 직접 구독한다. 016에서 old DOM entry/exit 동기화가 끊겼으므로 old DOM 상태를 audit invariant로 유지하면 오히려 잘못된 요구가 된다.

## 유지
- FSM lifecycle/workspace/overlay state 유효성 검사.
- project object 및 slot/chart/asset invariant 검사.
- FFPX/FFSX/Plotly 관련 함수/포맷.

## 검증
workflow patch check, JS syntax, portable build, split/portable smoke.

## 롤백
이 패치를 되돌리면 audit의 legacy overlay 상태 검사가 복구된다.

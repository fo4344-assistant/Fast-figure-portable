# 20260922-010

## 목적과 변경 내용

Mantine label overlay가 labels SoT, selected slot, dashboard geometry, renderer functions를 직접 참조하던 경로를 `FastFigureApi.labels`로 이동한다.

추가 API:

- `readState()`: enabled, frozen settings, 현재 target slot의 reference geometry, sample text
- `setEnabled(enabled)`
- `setSettings(patch)`
- `setPosition(x, y)`
- `previewPosition(x, y)`
- `commitPosition()`
- `resetPosition()`

drag 중에는 기존과 같이 label position SoT를 갱신하고 renderer를 다시 그리지만 graph/app state notify는 하지 않는다. pointer release에서 `commitPosition()`이 기존 `LABEL_POSITION_DRAGGED` notify를 발생시킨다.

일반 X/Y 입력은 `setPosition()`에서 기존 `LABEL_POSITION_CHANGED` notify를 유지한다.

## 선택 이유

label settings와 position은 project annotations의 실제 SoT다. frontend가 mutable `activeProject.labelSettings`를 직접 변경하지 않고 SoT 구현체의 API를 통해 읽고 변경해야 한다.

preview geometry도 layout/project state에 의존하므로 frontend에서 core state를 직접 조합하지 않고 labels read API가 현재 selected slot 기준으로 계산한다.

드래그 pointer 정보와 DOM element 측정값은 순수 UI input이므로 Mantine local ref/state로 유지한다.

## 선택하지 않은 방향

### label settings snapshot을 frontend state에 복제

label 값은 즉시 적용되는 SoT이므로 React mirror를 두지 않는다. render마다 API snapshot을 읽는다.

### drag 위치를 별도 global preview buffer에 저장

다른 로직이 참조할 수 있는 두 번째 상태가 되므로 만들지 않는다.

### `activeProject` 자체를 API로 반환

frontend mutation 우회가 가능해지므로 primitive/frozen snapshot만 반환한다.

### drag move마다 appFSM notify

기존 동작은 drag 중 renderer를 갱신하고 pointer release에서 notify한다. 해당 동작을 유지한다.

## 전제와 후속 작업

- label font size에는 기존처럼 6pt 하한만 유지하며 96pt 등의 상한을 추가하지 않는다.
- preview drag bounds는 reference slot width/height와 실제 preview label DOM 크기를 사용해 기존 pixel clamp를 유지한다.
- overlay close의 application event 경계는 별도 UI-FSM/router 작업에서 정리한다.
- caption overlay도 같은 annotation API pattern으로 후속 정리한다.

## 롤백

역적용하면 label overlay가 다시 `activeProject.labelSettings`, selected-slot geometry, renderer/notify 함수를 직접 호출한다. project schema와 label 저장 형식에는 변화가 없다.

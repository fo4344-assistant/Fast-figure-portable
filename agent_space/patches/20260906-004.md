# 20260906-004 — split source portable build 경계 재적용 2

## 목적

실패한 `20260906-003`의 변경을 동일한 설계로 재적용한다.

`003`은 unified-diff 형식과 line count는 정상이었지만, 첫 HTML hunk에서 줄이 추가된 뒤 후속 hunk의 new-file 시작 위치에 누적 line delta를 반영하지 않았다. `git apply --check`는 `Fast-figure.html:11562`에서 중단됐고 실제 source에는 아무 변경도 반영되지 않았다.

## 변경 내용

`002`/`003`과 동일하다.

- 앱 버전 `1.1.110-alpha` → `1.1.111-alpha`
- `scripts/build-portable.py` 추가
- split development source에서 `dist/Fast-figure.html` 단일-file portable build 생성
- top-level README와 built-in README의 source/portable 설명 교정
- application/EFSM/file format 의미는 변경하지 않음

## hunk 교정

파일별 누적 delta를 반영해 후속 hunk의 new-file start를 다시 계산했다.

- Fast-figure.html: +12 → +16 → +20 → +21 누적 반영
- README.md: 첫 hunk +26 반영
- 각 hunk old/new line count와 빈 context prefix도 다시 검산

## 검증

workflow에서 `git apply --check`, 세 JavaScript syntax check, portable build, split/portable `file://` headless Chrome smoke test, `git diff --check`를 모두 통과해야 한다.

## rollback

이 patch를 역적용하면 build script와 문서/버전 변경만 되돌아가며 `20260906-001` source split은 유지된다.

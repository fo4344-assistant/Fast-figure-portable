# 20260910-007 — Print target export value entry

## 목적
반복된 unified diff 좌표 오류를 제거하기 위해 `exportDashboardTarget` 한 영역만 현재 `main`의 exact context로 교체한다. 이는 print ownership 구현의 일부이며 별도 설계 단계가 아니다.

## 변경
- `exportDashboardTarget(options = null)`로 확장한다.
- Mantine 호출은 `width`, `height`, `dpi`, `format`, `onStatus`를 값으로 전달할 수 있다.
- options가 있는 경우 legacy print controls를 입력 source나 출력 projection으로 사용하지 않는다.
- options가 없는 기존 legacy 호출은 기존 동작을 유지한다.

## 선택 이유
출력 알고리즘을 복제하지 않고 하나의 renderer를 유지하면서 legacy DOM 의존만 호출 경계에서 제거한다. 이전 003~006의 실패는 application source가 아니라 patch 표현 문제였으므로 기능 설계는 바꾸지 않는다.

## 기각안
- React에서 target export를 재구현: 기능 source 중복 때문에 기각.
- Mantine이 legacy input을 채우는 방식: DOM bridge이므로 기각.

## Source of truth / EFSM 영향
project model과 기존 export renderer가 source of truth다. options는 일회성 호출 값이다. FFPX schema와 EFSM 의미는 변경하지 않는다.

## 선택 이유·기각 대안

- Source 자체의 command 실패 무변경, explicit none/absent index hint, original-index map, model-to-fsm asset 보존 경계를 먼저 서로 맞추어 번역한다. Source 0-based index를 PlusCal sequence의 1-based subscript와 혼동하지 않는다.
- 미완성 전체를 `current`라고 기록하는 방식을 기각했다. 명명만 된 generic domain 호출을 완성 구현처럼 남기지 않고 미전개 범위를 작업본과 진행 기록에 명시했다.
- 기존 Source에 없는 registry/command engine/persistent revision/선택 authority 또는 임시 runtime bridge를 만들지 않는다. freshness 참조는 기존 ProjectObject 내부 authoritative state reference이며 call-local다.
- 일부 활성 .pcal만 바꾸어 r37 전체 lineage처럼 보이게 하지 않는다. 기존 r11 활성 번역은 stale 유지하고, 전체 번역·연결·충실도 확인 후 coherent cutover한다.

# 20260902-020 — graph object 목록 selector 단독 재시도

## 배경

`20260902-019`는 graph object 목록의 순수 selector와 UI bridge read method를 한 patch에 추가하려 했으나 `git apply --check`에서 실패했다. HTML에는 적용되지 않았다.

이번 패치는 두 hunk를 더 분리하여 **selector 본문만** 추가한다. bridge 연결은 다음 patch에서 처리한다.

## 목적

현재 selected chart의 `editor.objects`에서 목록 표시용 read-only snapshot을 직접 계산하는 `selectedGraphObjectsModel()`을 추가한다.

## 변경 내용

- 앱 버전 `1.1.66-alpha` → `1.1.67-alpha`
- `selectedGraphObjectsModel(slot = getSelectedSlot())` 추가
- bridge에는 아직 연결하지 않음

반환값:

- `slotId`
- `chartId`
- `editable`
- `selectedObjectIndex`
- frozen `objects[]`

각 item:

- `index`
- `selected`
- `csvId`, `csvName`
- `x`, `y`
- `xAxisSide`, `yAxisSide`
- `legendName`
- `type`
- `color`
- `label`

## read 순수성

`ensureGraphObjects()`를 호출하지 않는다.

기존 `chart.editor.objects` 배열을 읽어 파생 snapshot만 만든다. chart/editor/object를 보정하거나 대입하지 않는다.

## 표시 의미 보존

구형 기준 `renderGraphObjects()`의 label과 color fallback 의미를 그대로 사용한다.

- label: 순번 + legendName 또는 `x · y` + CSV 이름 + X/Y 축 위치
- color: object.color 문자열, 없으면 `DEFAULT_COLORS[index % DEFAULT_COLORS.length]`

이 값은 presentation 파생값이며 persisted object에 쓰지 않는다.

## source of truth

- 목록: `chart.editor.objects`
- 선택: `selectedObjectIndex` / 기존 graphObject EFSM
- CSV 이름: `object.csvId`에 대응하는 project CSV

selector 반환 객체는 snapshot이며 다른 기능의 권위 상태로 사용하지 않는다.

## 변경하지 않음

- bridge
- `selectGraphObject()`
- `saveGraphObjects()`
- `renderGraphObjects()`
- selection/reorder/color/delete/add handler
- graphObject EFSM event/action
- renderer/import/export

## `019`과의 관계

`019`는 실패 기록으로 보존한다. `020`이 성공하면 selector hunk는 유효함이 확인되고, `021`에서 bridge hunk만 별도로 추가한다.

## rollback

- `selectedGraphObjectsModel()` 제거
- 앱 버전 `1.1.66-alpha` 복원

## 후속

`021`: `fastFigureUiBridge.readGraphObjects()` 한 메서드만 추가.

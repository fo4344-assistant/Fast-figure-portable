# 20260902-022 — graph object 목록 bridge read 연결

## 배경

`20260902-021`에서 `selectedGraphObjectsModel()` selector가 정상 적용되었다.

이번 패치는 selector를 UI bridge에 노출하는 단일 메서드만 추가한다.

## 목적

Mantine sidebar/list staging이 legacy DOM이나 전역 변수를 직접 읽지 않고 graph object 목록 snapshot을 받을 수 있도록 한다.

## 변경 내용

- 앱 버전 `1.1.67-alpha` → `1.1.68-alpha`
- `fastFigureUiBridge.readGraphObjects()` 추가

```text
readGraphObjects()
→ selectedGraphObjectsModel()
```

## source of truth

bridge는 selector 결과를 저장하지 않는다. 호출 시마다 canonical selected chart/object state에서 새 snapshot을 계산한다.

## 변경하지 않음

- selector 본문
- graph object action
- selection/reorder/color/delete/add
- EFSM event/action
- active legacy UI
- renderer/import/export

## `019/020` 실패와의 관계

`019`는 selector+bridge를 함께 추가하려 했고, `020`은 selector만 재시도했으나 둘 모두 selector hunk line-count 오류로 실패했다.

`021`에서 selector를 정확한 hunk metadata로 적용했으므로 이번 bridge patch는 해당 실패와 독립적인 작은 hunk다.

## 검증

- patch apply
- JavaScript syntax
- bridge method 중복 없음
- `selectedGraphObjectsModel`을 그대로 반환하며 별도 상태 저장 없음

## rollback

- `readGraphObjects()` 제거
- 앱 버전 `1.1.67-alpha` 복원

## 후속

목록 action의 의미를 분리한 뒤 Mantine list renderer를 연결한다.

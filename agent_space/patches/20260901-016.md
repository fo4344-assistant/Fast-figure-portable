# 20260901-016

## 목적

준비된 `FastFigurePrintModalStaging`을 staging overlay host의 print 상태에 연결한다. 활성 legacy UI는 그대로 두고 staging 내부에서만 read-only summary를 실제 Mantine Print form으로 교체한다.

## 변경 내용

- 애플리케이션과 built-in README 버전을 `1.1.46-alpha`로 올린다.
- `FastFigureOverlayHostStaging`의 `snapshot.fsm.overlay === "print"` 분기를 `FastFigurePrintModalStaging`으로 교체한다.
- 기존 print summary가 표시하던 appearance/selected slot JSON은 제거한다.
- overlay open/close ownership은 기존 EFSM overlay 상태와 `FastFigureOverlayModalStaging`의 `CLOSE_OVERLAY` 경로를 그대로 사용한다.

## 실패 재검토

최초 큐는 HTML 적용 전에 `git apply --check`에서 중단되었다. print 교체 hunk는 앞뒤 문맥 3줄과 제거 6줄로 old count 9, 문맥 3줄과 추가 2줄로 new count 5가 되어야 하지만 `8 → 4`로 기록되어 있었다. 구현 내용은 변경하지 않고 unified diff header를 `9 → 5`로 바로잡았다. 실패 실행에서는 HTML이 수정되지 않았다.

## 이 방향을 선택한 이유

`014`는 export domain 입력 계약, `015`는 Mantine form 자체, 이번 커밋은 host wiring만 담당한다. 세 책임을 분리하면 export 엔진 회귀와 React UI wiring 회귀를 독립적으로 추적할 수 있다.

## 선택하지 않은 방향

- legacy print panel은 아직 제거하지 않는다.
- 전체 shell을 활성화하지 않는다.
- export format이나 크기 제한을 변경하지 않는다.
- 다른 overlay의 동작을 함께 수정하지 않는다.

## 검증 항목

- `git apply --check`
- `git diff --check`
- 메인 JavaScript `node --check`
- APP_BUILD와 built-in README 버전 일치
- staging print overlay가 `FastFigurePrintModalStaging` 하나만 렌더링
- EFSM overlay 상태 및 close event 경로 비변경

## 패치에 포함되지 않은 변경사항

이 `.patch`와 설명 `.md` 자체는 재귀적인 diff에 포함하지 않는다. 실제 HTML 수정은 제한된 patch workflow가 검증 후 적용한다.

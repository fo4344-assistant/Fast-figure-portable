# 20260928-014

## 목적과 변경 내용

legacy generic UI 제거 후 사용처가 없어진 CSS 색상 변수 9개와 `applyUiPalette()`의 대응 DOM 투영을 제거한다.

- `--line`, `--accent`, `--panel`, `--ui-bg`, `--ui-surface`, `--ui-muted`, `--ui-disabled-bg`, `--ui-disabled-text`, `--ui-shadow`
- 활성 소스(`Fast-figure.html`, `fast-figure.js`, `fast-figure-ui.js`, `scripts/`)에서 이 변수들은 정의와 `setProperty` 호출 외에 참조되지 않는다.

기능 renderer가 사용하는 `--ui-color`, `--paper`, `--ui-subtle`, `--ink`, `--graph-bg`와 팔레트의 영속 필드·가져오기/저장하기 형식은 그대로 둔다. Mantine의 색상과 컴포넌트 규칙도 바꾸지 않는다.

## 선택 이유

기존 generic UI CSS가 삭제된 뒤에도 팔레트 적용 시 DOM에 사용하지 않는 변수를 쓰고 있었다. UI 색상 소유권을 혼동시키는 투영을 제거하되, 프로젝트 팔레트 데이터의 의미와 renderer의 실제 색상 소비는 유지한다.

## 선택하지 않은 방향

- 팔레트 객체의 필드나 파일 직렬화 구조를 축소하지 않는다. 기존 FFPX 의미와 저장 데이터 호환성에 영향을 줄 수 있다.
- `--ui-subtle` 등의 활성 renderer 변수는 제거하거나 Mantine theme로 옮기지 않는다. 캡션 placeholder 등 기능 surface에서 직접 사용한다.
- `body`의 `--paper`/`--ink`는 이번 단계에서 변경하지 않는다. 팔레트와 화면 배경의 동작을 별도로 검토해야 한다.

- `git diff --check`, `git apply --check`, JS syntax, portable build 통과
- 로컬 환경에는 Chrome/Chromium이 없어 `file://` smoke는 Actions에서 검증

## 후속 작업과 롤백

남은 legacy generic UI 마크업·CSS·popup lifecycle의 소유권을 계속 감사한다. 이 패치를 역적용하면 사용되지 않는 CSS 정의와 DOM 투영만 복원된다. EFSM·팔레트 영속 상태·renderer 계산에는 변경이 없다.

# 20261014-016 — Correct Source Code r25 fingerprint ordering

## 원인

`fingerprint_algorithm`은 상대 경로를 Python 기본 문자열 정렬로 정렬한다. 이전 계산에서 locale-aware 정렬을 사용해 대문자 `Fast-figure.html`과 소문자 경로의 순서가 달라졌다.

## 변경

- Source Code r25 fingerprint를 실제 검사 스크립트와 같은 ASCII/Unicode code-point 순서로 다시 계산한다.
- 코드, revision, lineage, status는 변경하지 않는다.
- r25는 계속 `stale`이며 TLC와 후속 cutover 완료 전 current로 올리지 않는다.

## 검증

직전 r25 push에서 JS syntax, browser regression, distribution build는 성공했다. 이 커밋은 development-layer version check를 다시 실행해 fingerprint 일치 여부만 확인한다.

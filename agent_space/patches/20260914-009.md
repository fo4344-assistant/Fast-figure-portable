# 20260914-009 — legacy sidebar and lifecycle startup cutover

## 목적
Mantine AppShell/sidebar 및 React lifecycle actions가 이미 소유하는 old sidebar resize/collapse와 hidden control lifecycle wrapping을 startup에서 제거한다.

## 변경
- `syncHeaderHeight()` 및 `installSidebarControls()` legacy 함수 제거.
- `connectLifecycleTasksToFSM()` 제거. Mantine actions는 이미 `runLifecycleTask()`로 FSM lifecycle을 직접 사용한다.
- startup에서 `syncHeaderHeight`, `syncPopupBounds`, old showSlotBorders sync, help popup, sidebar install, lifecycle wrapper, layout resizer 호출 제거.
- startup의 core renderer/model 초기화(`applyDashboardZoom`, default CSV, slot controller, `makeSlots`, `applySlotStyle`, `appFSM.ready`)는 유지.
- old `projectName` input write 제거.

## 이유
old header/aside/layout markup을 물리적으로 제거하려면 startup이 해당 DOM을 요구하지 않아야 한다. Mantine sidebar와 lifecycle이 이미 동일 역할을 수행하므로 별도 compatibility bridge는 필요하지 않다.

## Source of truth
sidebar UI state는 Mantine AppShell local UI state, lifecycle은 `appFSM`, project name은 project model이다.

## EFSM/core 영향
FFPX/FFSX/Plotly/schema와 project/domain 알고리즘은 변경하지 않는다.

## 검증
workflow 전체 검증.

## 롤백
patch revert 가능. persistent migration 없음.

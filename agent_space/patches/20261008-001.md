# 20261008-001 — GUI selection and explicit image connection

## 목적과 변경 내용
- 그래프 편집기의 CSV 읽기 projection은 현재 선택된 에셋 CSV를 우선 사용한다. 기존 그래프 오브젝트의 csvId는 데이터 참조로 보존한다.
- 프로젝트 트리에서 이미지 클릭은 선택만 한다. 이미지 슬롯에서 '선택 이미지 추가' 명령 또는 기존 드롭 연결 경로로만 슬롯에 연결한다.
- 원본 JSON(비편집) 모드에서는 오브젝트 추가 버튼을 비활성화한다.
- source-code revision 9의 fingerprint를 기록하고, 브라우저·산출물 검증 전까지 stale로 표시한다.

## 선택 이유
Source Script의 assets.selectImage는 runtime selection이고 assets.connectToSlot은 별개 명령이다. graphs.graphEditorAdd는 실제 선택 CSV id를 입력받는다. 첫 오브젝트의 csvId를 사용자 현재 선택보다 우선시하는 읽기 모델은 이 의미를 위반한다. 새 상태 변수를 만들지 않고 기존 authority를 사용한다.

## 기각한 대안
- UI 전용 selectedCsv useState: 선택 source of truth를 중복 소유한다.
- 이미지 선택 시 자동 슬롯 연결 유지: 선택과 mutation 의미가 혼합된다.
- 새 이미지 전용 연결 코어 구현: 기존 assets.connectToSlot이 있으므로 중복이다.
- 기존 오브젝트의 csvId를 선택 변경 시 자동 갱신: 단순 선택이 데이터 참조를 의도치 않게 변경한다.

## 관련 미변경 범위 및 후속 작업
- 빈 CSV 생성 복구와 빈 chart 유지 가능성, 파일 가져오기 중 연결 정책, SLOT_SELECT 토글, 파일명 충돌 모달 닫기 규칙은 이번 패치에 포함하지 않았다.
- 그래프 오브젝트에 저장된 csvId는 그대로 유지되며 명시적인 오브젝트 수정/추가 경로만 그래프 모델을 변경한다.
- Source Script 및 PlusCal의 기존 선택/연결 분리 계약을 새로운 의미 없이 구현으로 교정한다.
- 브라우저와 FFPX round-trip 통합 검증은 미실시. current로 표시하지 않으며 build artifact도 갱신하지 않았다.

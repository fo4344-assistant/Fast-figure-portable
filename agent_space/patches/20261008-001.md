# 20261008-001 — UI asset selection and explicit image connection

## Purpose and changes
- Define a single selected CSV through assetSelection/assetPath; graph object csvId remains a reference, not competing selection.
- Make image asset click select only. Image slot content changes on explicit add command or drop.
- Disable adding graph objects to imported non-editable charts.
- Correct image add command to provide the actual slot object to existing connectToSlot API.

## Direction and rationale
Found mismatch in current JavaScript implementation; returned to Source Script and translated the same rules into the existing pseudocode documentation before source implementation. No additional selection state, DOM bridge, API name, or domain representation.

## Alternatives rejected
- Fallback to existing graph object CSV: overrides current selection.
- Automatic image slot connection on asset click: conflates selection and mutation.
- New duplicate local selection: violates authoritative state ownership.
- Passing slot.id: existing core connectToSlot accepts slot object.

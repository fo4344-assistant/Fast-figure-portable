# 20260914-012 Legacy generic UI event cutover

## 목적
Mantine이 이미 소유하는 README, 프로젝트 import/export/name, layout/label/caption/print overlay의 legacy DOM 이벤트 설치를 중단하고, 프로젝트 재렌더 경로에서 삭제 예정인 legacy control을 더 이상 동기화하지 않도록 한다. 다음 패치에서 실제 legacy markup을 삭제하기 위한 마지막 코드 측 cutover이다.

## 변경
- native README dialog의 toggle/close/cancel/backdrop/close 이벤트 wiring을 제거한다.
- legacy projectName 및 FFPX import/export DOM wiring을 제거한다. Mantine project controls와 기존 `downloadProject`/`importProject` 기능 경계는 유지한다.
- `renderProjectObject()`에서 `syncProjectControlsFromObject`, table preview, label preview, legacy caption control 동기화를 호출하지 않는다. project model → dashboard/render/FSM 경로만 유지한다.
- legacy label/caption installer 호출과 slot-caption legacy button wiring을 제거한다. helper 정의는 이번 단계에서는 남겨 rollback과 후속 dead-code 정리를 단순하게 한다.
- legacy print/layout toolbar wiring, legacy overlay Escape/outside-click/pointerdown ownership, legacy caption DOM input/name wiring을 제거한다.
- dashboard/Plotly/FFPX/FFSX/project model/FSM 알고리즘은 변경하지 않는다.

## 이유
삭제 예정 markup에 load-time handler가 남아 있거나 프로젝트 import 후 legacy control write가 수행되면 markup 삭제 직후 null DOM 접근으로 초기화/불러오기가 깨진다. Mantine이 이미 같은 UI 기능을 소유하므로 두 번째 generic UI owner를 유지할 이유가 없다.

## 기각안
- 삭제할 element를 빈 hidden placeholder로 남기는 방식: Mantine → legacy DOM 의존을 유지하므로 기각한다.
- 모든 legacy helper를 동시에 삭제하는 방식: 현재 graph renderer/compatibility helper와 결합된 함수가 있어 실제 markup 삭제와 무관한 범위까지 커진다. 이번에는 active ownership만 끊고 dead-code/CSS는 후속 정리한다.

## Source of truth
- project/layout/labels/captions/appearance: `activeProject` + `projectObjects`
- UI 상태/overlay/lifecycle: `appFSM`
- generic controls: `fast-figure-ui.js` Mantine components
- dashboard/Plotly renderer: 기존 `fast-figure.js` renderer

## EFSM/core 영향
상태 정의, transition, write-lock, FFPX/FFSX schema와 도메인 mutation은 변경하지 않는다. legacy DOM event producer만 제거한다.

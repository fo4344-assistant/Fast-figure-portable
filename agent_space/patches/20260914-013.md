# 20260914-013 Legacy shell markup deletion

## 목적
Mantine 전환이 완료되어 더 이상 active owner가 아닌 legacy shell markup을 실제 HTML에서 제거한다. 삭제 직전 복구 지점은 `e6165770847ffcce78845b6f89ef7afe1242962c` (`Apply agent patch 20260914-012`)로 확인했다.

## 삭제 범위
- legacy 상단 header/toolbar (`layoutToggle`, `labelToggle`, `captionToggle`, `printToggle`, `targetInfo`)
- legacy project fieldset (`projectName`, FFPX import/export button/input)
- legacy UI palette controls
- legacy debug controls/log element
- legacy README sidebar button과 native dialog wrapper/close button
- legacy sidebar resize/collapse handle

README의 canonical `template#readmeContent` 자체는 Mantine README overlay가 사용하므로 보존한다. Dashboard/Plotly renderer와 graph compatibility controls도 보존한다.

## 이유
20260914-012에서 위 markup을 향한 load-time event ownership과 project-render 동기화가 제거되었다. 남겨 두면 동일 기능의 비활성 DOM 사본만 유지되어 Mantine 단일 ownership 원칙과 최소복잡도 원칙을 어긴다.

## 기각안
- `hidden` 처리만 유지: DOM identifier와 legacy CSS/구조 부채를 계속 남기므로 기각한다.
- aside 전체 및 graph controls 동시 삭제: `configFromForm`, `readAxis`, graph editor compatibility 경로가 아직 일부 control을 읽으므로 범위를 넘는다.
- README template까지 삭제: Mantine overlay의 canonical content source이므로 보존한다.

## Source of truth
- generic shell/project/palette/debug/README UI: `fast-figure-ui.js` Mantine components
- README content: `template#readmeContent`
- graph/domain state: `activeProject`, `projectObjects`, `appFSM`
- dashboard renderer: 기존 `fast-figure.js`

## EFSM/core 영향
없음. 상태 정의, transition, FFPX/FFSX schema, renderer 알고리즘을 변경하지 않고 이미 owner를 잃은 markup만 삭제한다.

## 삭제 전 복구 지점 확인
삭제 patch 작성 전에 GitHub `main`을 직접 조회하여 `e6165770847ffcce78845b6f89ef7afe1242962c`가 `Apply agent patch 20260914-012`로 존재하고 부모 커밋 `0e2ab6b6138ff95c9674b548b35a53d68140f0f3`를 갖는 것을 확인했다. 따라서 이 삭제 이전 상태는 독립 Git 커밋으로 복구 가능하다.

## 검증
workflow의 `git apply --check`, JavaScript syntax check, portable build, split/portable `file://` Chromium smoke를 모두 통과해야 한다.

## 롤백
문제가 생기면 `e6165770847ffcce78845b6f89ef7afe1242962c`를 기준으로 삭제 이전 markup 상태로 되돌릴 수 있다.

# 패치 설명

## 목적과 변경 내용

사용자의 지적에 따라 `agent_space/plans/plan-032.md`의 작업 범위를 바로잡는다. Source Script 52를 고정된 번역 기준으로 두고 R01~R20의 차이를 pseudocode에서 수정한다. 계획에 잘못 추가했던 Source Script 수정 분기와 별도 닫힘 선행 단계를 제거한다. Source Script의 파일과 계층 기록은 보존한다.

## 선택한 방향과 이유

사용자 요구는 Source Script → pseudocode 번역이다. 번역 대상과 완료 근거를 이 방향에 맞춘다. 의미를 유일하게 읽을 수 없는 항목은 위치와 해석 차이를 기록하여 확인을 요청한다. 확인 없이 상위 의미를 수정하는 범위 확장은 제외한다.

## 실제 diff와 유지 범위

- 비교 기준 tree: `999c7844ba8832f934fb01a6aad282b3112895c2`. HEAD `959f154dfbec5441945593b5a36740e9347de316`에 수정 전 미커밋 Plan032를 포함한 native Git tree다.
- 동명 `.patch`는 해당 tree에서 계획 수정과 이 설명 문서 추가의 실제 native Git diff다. patch 자체는 포함하지 않는다.
- 앞서 작성한 review와 016·017 패치 쌍을 보존한다. 일반 Git index는 변경하지 않는다.
- Source Script·pseudocode·source code·metadata는 수정하지 않았다. 테스트·빌드·checker·커밋·푸시도 수행하지 않았다.

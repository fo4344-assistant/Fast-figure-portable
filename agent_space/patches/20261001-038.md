# 20261001-038 — TLA Slot Core TLC timeout 연장

## 검사 결과

verification-model r6에서:

- PlusCal translation: 성공
- SANY parsing/semantic processing: 성공
- TLC state exploration: 실제 시작
- invariant violation: timeout 전까지 없음
- 약 15분 시점:
  - generated states: 9,372,348
  - distinct states: 6,985,221
  - queue: 2,420,191

workflow가 `timeout-minutes: 15`에 도달해 TLC process가 강제 취소되었다.

이 결과는 검증 실패나 counterexample이 아니라 CI 실행시간 제한에 의한 중단이다.

## 변경 내용

`.github/workflows/tla-slot-core.yml`의 job timeout만:

```text
15 minutes -> 45 minutes
```

로 연장한다.

verification code, cfg, Source Script, version fingerprint는 변경하지 않는다.

## 선택 이유

현재 TLC가 이미 정상 상태공간 탐색 단계에 진입했고
같은 bounded model을 계속 탐색하는 작업이다.

검증 범위를 줄이거나 모델을 바꾸면 직전 탐색과 다른 검사가 되므로,
먼저 동일 모델이 완주할 수 있도록 실행시간 제한만 완화한다.

## 고려했지만 선택하지 않은 방향

### state-space bound 축소

선택하지 않았다.

현재는 모델 오류가 아니라 timeout만 확인되었으므로
검증 강도를 낮출 근거가 없다.

### TLC depth 제한

선택하지 않았다.

현재 목표는 bounded model 전체 탐색이다.

### verification code 변경

선택하지 않았다.

timeout 문제는 Source Script 또는 verification translation 의미와 무관하다.

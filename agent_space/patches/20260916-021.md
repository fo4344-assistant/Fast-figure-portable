# 20260916-021 — native graph editor CSS removal

## 목적과 변경 내용

`20260916-020`에서 제거한 native graph editor markup만을 위한 CSS를 `Fast-figure.html`에서 제거한다.

삭제 범위는 다음과 같다.

- `#buildBox` 내부 details 계층 스타일
- `.axis-choice` 및 그 select 배치 규칙
- `.graph-objects`와 `.graph-object*` object-list 스타일
- centralized palette selector에 남은 `.graph-objects` 항목
- centralized palette block의 `.graph-object.selected` 잔여 규칙

## 선택 이유

해당 selector의 유일한 markup consumer가 `20260916-020`에서 제거되었고, current JS/Mantine graph editor는 이 class/ID를 사용하지 않는다. 따라서 이 규칙들은 기능 renderer나 logic EFSM이 아니라 legacy frontend presentation의 잔여물이다.

## 선택하지 않은 방향

- 전역 `input/select/button`, `.row`, `.colors`, `.color` 스타일은 이번 패치에서 제거하지 않는다. 다른 legacy 또는 renderer 표면의 소비 여부를 별도 확인해야 한다.
- `.layout-panel`, dashboard/slot/Plotly renderer CSS는 유지한다.
- graph model, EFSM event, `graphEditor*` command에는 변경을 가하지 않는다.

## 전제 / 후속 작업 / 누락

- native CSV preview markup/CSS와 `fileName`/`status` fallback은 별도 ownership 단위로 후속 감사한다.
- rollback은 이 패치를 되돌리면 CSS만 복구되며 project/domain state에는 영향이 없다.

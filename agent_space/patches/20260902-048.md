# 20260902-048 — Mantine graph palette file sidebar wiring

## 목적

`20260902-047`에서 정의한 palette save/load component를 inactive Mantine sidebar staging에 연결한다.

## 변경 범위

- `FastFigureSidebarStaging()`에서 `fastFigureUiBridge.readGraphPalette()` 호출
- graph-object add control과 graph-object 목록 사이에 `FastFigureGraphPaletteFileStaging({ graphPalette })` 렌더
- palette read model이 `null`이면 component를 렌더하지 않음
- 버전 `1.1.87-alpha` → `1.1.88-alpha`

## 이유

palette 파일 UI에 필요한 경계가 이미 각각 분리되어 검증됐다.

- canonical export colors: `046`
- file component: `047`
- parser: `044/045`
- palette mutation: `039`
- JSON download helper: 기존 `downloadJsonFile()`

따라서 sidebar wiring은 새 기능 규칙 없이 component를 조합하는 UI 작업만 수행한다.

## source of truth

React local palette state를 추가하지 않는다. sidebar는 매 render마다 bridge read model을 사용한다.

## EFSM / core 영향

없음. staging UI wiring만 변경한다. legacy active UI는 유지된다. Plotly renderer, graph-object schema, EFSM event를 수정하지 않는다.

## 위치 선택

순서를 다음과 같이 둔다.

1. graph object 추가
2. palette 파일 저장/불러오기
3. graph object 목록 + 기본 색상 reset
4. 선택 object 상세 설정

palette는 목록 전체에 적용되는 action이므로 개별 object 상세 form보다 앞에 배치한다.

## rollback

sidebar의 `graphPalette` read 한 줄과 component render block, 버전 문자열 두 곳만 제거하면 된다. `046/047` 정의는 inactive 상태로 남길 수 있다.

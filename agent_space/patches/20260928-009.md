# 20260928-009

## 목적과 변경 내용

icon-only action 역할의 버튼을 Mantine `ActionIcon`으로 통일한다.

대상:

- project asset row 작업 메뉴 `···`
- project folder 작업 메뉴 `···`
- graph object 삭제 `×`

세 위치 모두 일반 `Button` 대신 `ActionIcon`을 사용하고 `size="sm"`, `variant="subtle"` 역할 규칙을 공유한다.

## 선택 이유

텍스트 action과 icon-only action은 UI 의미가 다르다. 기존처럼 둘 다 Button으로 만들고 각 위치에서 size를 조정하면 같은 기능 역할이 조금씩 다른 geometry를 갖게 된다.

Mantine은 icon-only action 전용 `ActionIcon`을 제공하므로 이를 직접 사용한다. 별도 square-button CSS나 wrapper는 만들지 않는다.

## 선택하지 않은 방향

- Button에 width/height를 직접 지정하지 않는다.
- `IconButton` 같은 Fast Figure 전용 wrapper를 만들지 않는다.
- tree row 자체의 text Button은 icon-only 역할이 아니므로 변경하지 않는다.

## 검증

- GitHub-generated diff 사용
- Actions `git apply --check`
- `git diff --check`
- JS syntax
- portable build
- split/portable `file://` smoke
- 세 icon-only action이 모두 ActionIcon인지 재확인

## 롤백

역적용하면 세 action이 다시 compact Button으로 돌아간다. 기능 command/EFSM/domain state는 변경하지 않는다.

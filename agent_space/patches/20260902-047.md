# 20260902-047 — Mantine graph palette file component definition

## 목적

Mantine graph UI에서 legacy palette 파일 save/load와 동일한 동작을 수행할 수 있는 component를 정의한다. 이 패치에서는 component를 sidebar에 연결하지 않아 active 동작은 바뀌지 않는다.

## 변경 범위

`FastFigureGraphPaletteFileStaging({ graphPalette })` 추가.

### 저장

- `graphPalette.colors`를 `{ colors: [...] }` 구조로 저장
- 기존 `downloadJsonFile()` 재사용
- 기존 파일명 규칙 `chart-palette-<ISO timestamp>.json` 유지
- 기존 `graphPalette:save` debug event 유지

### 불러오기

- visible UI는 Mantine `Button`
- 실제 browser file picker는 숨겨진 native `<input type="file">`을 I/O adapter로 사용
- accept 규칙 유지: `.json,application/json`
- 파일 text는 `parseGraphPaletteText()`로 검증
- 적용은 `fastFigureUiBridge.setGraphObjectColors(colors, chartId)`만 사용
- 기존 성공 status/debug 및 실패 status/debug 문구 유지
- 처리 후 file input value를 비워 동일 파일 재선택 가능성 유지
- read-only chart에서는 load 버튼만 비활성화하고 save는 허용

## 이유

Mantine `FileButton` 존재/버전에 의존하는 새 API를 추측하지 않고, 현재 브라우저 file input semantics를 그대로 보존하면서 visible button 규칙만 Mantine으로 통일한다.

저장 데이터는 `046`의 canonical palette read model을 사용하므로 graph-object 목록 snapshot의 표시용 fallback에 의존하지 않는다.

## source of truth

- export colors: `selectedGraphPaletteModel()` / `readGraphPalette()`
- file parser: `parseGraphPaletteText()`
- palette mutation: `setGraphObjectColorsFromPalette()` / bridge `setGraphObjectColors()`
- download helper: `downloadJsonFile()`

component 내부에 persistent palette state를 만들지 않는다. `useRef`는 숨겨진 file input DOM handle일 뿐 데이터 source가 아니다.

## EFSM / core 영향

없음. component 정의만 추가하며 기존 graph-object EFSM과 mutation command를 재사용한다. Plotly renderer, trace 생성, chart schema는 수정하지 않는다.

## 기각안

### Mantine `FileButton` 직접 도입

기각. 현재 bundled Mantine runtime에서 해당 API를 별도로 확인하지 않은 상태에서 새 component identifier를 추측하지 않는다.

### native visible file input 사용

기각. visible UI 규칙이 다시 custom/browser default UI에 분산된다. native input은 hidden I/O adapter로만 둔다.

### component 내부 React palette state

기각. canonical graph colors와 별도 authority가 생긴다.

## rollback

`FastFigureGraphPaletteFileStaging` 함수와 버전 문자열 두 곳만 제거하면 된다. 이 패치는 sidebar에 아직 연결되지 않으므로 legacy/active UI에는 영향이 없다.

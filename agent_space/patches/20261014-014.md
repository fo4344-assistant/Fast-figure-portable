# 20261014-014 — Repair PlusCal control flow in verification r19

## 목적

plan-015 verification r18에서 push-trigger TLA workflow가 PlusCal translation 단계에서 실패했다. 두 오류는 모델 의미가 아니라 main loop에서 procedure call을 연속 배치한 control-flow 문법 문제였다.

## 변경

- `FastFigureInteractionCore.tla`: 빈 CSV 생성과 interface selection reconciliation을 `CreateEmptyCsvAndReconcile` wrapper procedure로 묶고 main loop에서는 단일 call만 수행한다.
- `FastFigureSlotCore.tla`: reset/swap/grid/merge/split project operation과 interface reconciliation을 각각 wrapper procedure로 묶는다.
- project state transition, precondition, invariant, reconciliation 순서는 유지한다.
- verification revision을 r19로 올리고 새 fingerprint를 기록한다.
- TLC는 실제 push-trigger workflow 성공 전까지 `pending`으로 유지한다.

## 실패 원인

- Interaction Core: PlusCal translator `Missing label` at line 322.
- Slot Core: `Statement follows call or return inside a with statement` at line 626.

## 기각한 방향

- reconciliation 호출 제거: 두 FSM의 commit 후 interface reconciliation 검증 의미가 사라진다.
- main loop에 임의 label만 추가: Slot Core의 with/call 제약을 해결하지 못하고 두 모델의 구조도 불일치한다.
- workflow 결과를 무시하고 `tlc: passed`로 기록: 실제 translator가 실패했으므로 허용하지 않는다.

## 검증

이 커밋의 push가 TLA workflow를 다시 트리거한다. 성공 결과 확인 후 별도 validation review와 `tlc: passed` 갱신을 수행한다.

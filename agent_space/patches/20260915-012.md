# 20260915-012 — Remove native annotation common CSS selectors

## Purpose
Recover from the pre-application failures of `20260915-010` and `20260915-011` by reducing the CSS cleanup to a small selector-level unit. This patch removes only common native annotation selector membership and rules, leaving native caption-specific and label-specific CSS for later patches.

## Failed-attempt recovery
- `20260915-010` and `20260915-011` remain as audit history.
- Both failed at `git apply --check` before application source changed.
- No rollback is required.
- This patch is rebuilt against current `main` and intentionally avoids reconstructing the larger caption CSS block.

## Exact changes
- Remove `.annotation-panel` from the shared fixed-popup selector while preserving `.layout-panel` and `.print-panel`.
- Remove `.annotation-panel > *` from shared popup child sizing.
- Remove `.annotation-controls` from shared heading styles and delete its standalone alignment rule.
- Remove `.annotation-controls strong` from the shared heading text rule.
- Remove `.annotation-controls button` from the shared heading button rule.
- Remove `.annotation-hint`.

Native caption selectors such as `.caption-heading`, `.caption-popup`, `.caption-settings`, and native label selectors remain temporarily and will be removed separately.

## Why this direction
The source cleanup is structurally simple, but prior broad hand-written CSS hunks failed before application. Reducing each retry to an exact small ownership subset minimizes patch fragility while preserving the same final Mantine ownership goal.

## Rejected alternatives
- Retry either failed patch unchanged: rejected because both were already rejected by `git apply --check`.
- Delete caption and label CSS together: rejected until the common selector cleanup has passed independently.
- Remove `.layout-panel`, `.print-panel`, or `.popup-heading`: rejected because those belong to separate not-yet-completed ownership areas.

## Source of truth
No state or model changes. This patch only removes unused native annotation presentation rules.

## EFSM/core impact
None. No JavaScript, state machine, project schema, persistence, renderer, or export behavior is changed.

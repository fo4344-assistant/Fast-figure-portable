# Plan027 — SSoT 세부 절차와 세 계층 직접 대응

## 목적·근거

사용자 구현 지시에 따라 슬롯별 사용 에셋 표시, grid 단일 차원 편집, debug toggle의 부족한 절차를 Source Script에서 먼저 보완하고 pseudocode → source code로 옮겼다. 기존 SSoT로 정해지는 내용을 사용자 선호 결정으로 되돌리지 않았다. 이전 Source Script 45의 closure/current 기록은 이 세 절차의 누락을 해결한 증거가 아니므로 새 revision은 closure=open/status=stale로 기록했다.

## 실제 변경·선택 이유

- **에셋 표시:** 기존 `layout.readState.visibleSlots`에 같은 current project의 slot→image 또는 editable chart→실제 CSV 합성 결과 `assetDisplay`를 공급한다. 순서/중복 제거, 빈 슬롯, embedded graph, 참조 없는 graph를 명시했다. read는 metadata만 새로 만들고 immutable copy로 반환한다. canonical `assets.readTree`와 분리하되 기존 공식 조회를 확장해 별도 chart 관리 API나 store를 만들지 않았다.
- **반환/소비자:** `assets.readTree`를 기존 canonical directory/CSV/image node sequence에 맞췄다. 트리 UI와 CSV 선택 후보의 실제 두 호출자를 함께 이관했다. `/slots`는 Backend가 종합한 표시만 소비한다. 행별 참조 수는 기존 공식 deletion-target read에서 얻으며 slot 표시의 중복 제거 결과로 대체하지 않는다. CSV 행 수의 기존 header fallback 표시도 유지한다. 읽기용 component-local index를 새 public 평면 묶음이나 authority로 취급하지 않는다.
- **grid:** 입력 이벤트에서 공식 current layout을 읽어 변경하지 않은 차원과 invalid 입력 fallback을 구성하고 같은 동기 경로에서 기존 `setGrid(rows, cols)`를 호출한다. 중간 await/외부 callback/다른 command는 없다. 과거 render값, 새 grid mirror, resize 계약 변경이나 불필요한 동기화 장치를 기각했다. 기존 Backend 검증·재확인·한 번 commit과 selection clear는 유지한다.
- **debug:** runtime owner의 pure `readDebugEnabled()` → 반전 → 기존 bool setter를 연결했다. telemetry는 label/pressed 표시만 담당한다. 새 toggle API·debug store·영속 project field는 만들지 않았다.
- **기록:** 현재 계획/메모의 정식 계층명을 Source Script → pseudocode → source code로 맞추고 실제 반영 결과를 표시했다. PlusCal은 pseudocode의 구현 언어다. 과거 기록·정책·AGENT·업로드 스크립트·배포물은 수정하지 않았다.

- pseudocode **26**: `sha256:4589e59d50c88005bc3b9a942be675a22b10a8543a55934ccc9897b2a537aaab`

- 세 계층 status=stale, 실제 fingerprint에 derived_from을 연결했다. optional verification model/TLC 이력은 유지한다. 기존 유틸리티의 hash 함수만 사용했고 version checker main은 실행하지 않았다.
- `20261114-014.patch`는 native `git diff` 원문이다. HEAD `ae45be706abd50673b4ef9c52fd29b93bf47b22d`에 이전 승인된 메모·Plan027 작성 상태를 포함한 tree `b297d9e3c7205811194c3a362faf6b2b3938c45b`를 반영 전 기준으로 사용했다. 이전 013 기록과 계획 전체를 중복 추가하지 않는 **17파일, 357추가/83삭제**의 증분이다. 현재 실제 수정이 반영된 임시 Git index만 사용·제거했으며 기본 index/branch/HEAD는 바꾸지 않았다. 별도 snapshot/diff 스크립트는 만들지 않았다.

## 확인·미확인

관련 중요 문서의 잘린 구간을 이어 전체를 확인하고, 변경 전체와 실제 조회·명령·표시 호출자/반환/분기를 정적으로 대조했다. `git diff --check`는 whitespace 오류 없이 끝났으며 LF/CRLF 안내만 있었다. 정적 대조 중 새 `assetDisplay`의 중첩 값도 기존 immutable read 계약을 따르도록 연결했다.

이 세 항목의 알려진 잔여 구현이나 별도 사용자 선호 결정은 확인되지 않았다. 테스트·app·build·version checker·TLC·브라우저·Actions를 실행하지 않았으므로 실행 성공이나 전체 프로젝트 closure/current는 주장하지 않는다. 삭제된 테스트는 복원하지 않았고 commit/push도 하지 않았다.

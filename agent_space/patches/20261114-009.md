# 모듈 반환값 소비 마무리

기존 public 반환 계약을 UI 호출자에 연결했다.

- graph palette: 반환 chart의 대상 id를 확인한 뒤 적용 status/log를 남긴다.
- UI palette reset: 미commit의 false를 palette draft로 펼치지 않는다.
- move: 미commit의 null을 후속 처리에서 역참조하지 않는다.
- directory 생성: NoValue를 마지막 directory 경로로 저장하지 않는다.

근거는 `application/public_api/graphs.pcal`의 palette 반환, `application/public_api/layout_annotations.pcal`의 appearance false 반환, `application/public_api/assets.pcal`의 move/directory NoValue 반환이다. public 반환 형식이나 기존 대화창 종료 동작은 바꾸지 않았다.

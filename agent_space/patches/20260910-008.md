# 20260910-008 — Print target entry patch matcher recovery

## 목적
20260910-003~007에서 기능 설계와 무관한 unified diff 적용 실패가 반복되어, 현재 `main`의 정확한 함수 선언 한 줄만 교체해 patch matcher를 복구한다. 이 변경은 별도 설계 단계가 아니라 동일 print/export Mantine ownership 작업의 기계적 적용 복구다.

## 변경
- `exportDashboardTarget()` 선언을 `exportDashboardTarget(options = null)`로 변경한다.
- 함수 본문과 동작은 이 패치에서 변경하지 않는다.

## 선택 이유
현재 blob에서 가장 작은 동일 길이 교체로 `git apply` 경로 자체를 검증할 수 있다. 성공 즉시 후속 변경에서 같은 함수의 DOM 입력 의존 제거와 Mantine Print Modal 연결을 계속한다.

## 기각안
- 기능 설계를 다시 분해하거나 별도 abstraction을 만드는 것: 문제 원인이 architecture가 아니므로 기각.
- application source를 직접 수정하는 것: 프로젝트 patch 규칙에 반하므로 기각.

## Source of truth / EFSM 영향
없다. 함수의 optional parameter 선언만 추가하며 아직 사용하지 않는다.

## WIP
`1.1.31-wip` 포팅 중의 기계적 patch recovery 단계다. 이 상태 자체를 완성본으로 취급하지 않는다.

## 검증
workflow 전체를 통과해야 한다.

## Rollback

# 20260902-066 — Layout Modal에 dashboard zoom controls 연결

## 목적

`20260902-065`에서 정상 적용된 `FastFigureDashboardZoomStaging()`을 Layout Modal에 연결한다.

`20260902-064`는 `layoutMap` 블록 전체를 context로 사용해 current main과 불일치했으므로, 이번 patch는 안정적인 `id: "layoutMap"` anchor 앞에 component 한 줄만 삽입한다.

## 변경 내용

- `layoutMap` preview 바로 앞에 `FastFigureDashboardZoomStaging` 렌더
- 기존 Layout form, preview, merge/split, apply action은 변경하지 않음

## 배치

Layout Modal 내부 순서는 다음이 된다.

1. layout numeric/style controls
2. dashboard zoom/lock/reset
3. layoutMap preview
4. merge/split/apply

Zoom을 조절하면 실제 dashboard renderer가 즉시 바뀌므로 preview와 함께 같은 작업 맥락에서 사용할 수 있다.

## 영향 범위

UI wiring 한 줄만 변경한다. 파일/EFSM/domain 의미에는 영향이 없다.

## 검증

- `git apply --check`
- `git diff --check`
- JavaScript `node --check`

## rollback

이 patch만 되돌리면 Layout Modal 연결만 제거되고 `063/065` command/component는 유지된다.

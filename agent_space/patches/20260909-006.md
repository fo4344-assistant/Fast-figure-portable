# 20260909-006 — 005 graph/data ownership patch 형식 교정

## 목적

`20260909-005`의 구현 내용을 변경하지 않고 unified diff hunk header를 실제 body line count에 맞춰 교정해 적용한다. `005`는 `git apply --check`에서 `corrupt patch`로 중단되어 application source에는 적용되지 않았다.

## 변경 내용

`005`와 동일하게 `fast-figure.js`, `fast-figure-ui.js`를 대상으로 한다.

- graph object 값 기반 command 도입
- CSV 선택/header line 값 기반 command 도입
- imported Plotly editable 전환 command 추출
- Mantine `FastFigureGraphDataEditor` 추가
- CSV preview, header line, editable toggle, object add/select/drag reorder/delete/color, object CSV/X/Y/axis/type/legend/line/marker/bar 설정을 Mantine에서 직접 제공

## 005와의 차이

기능 코드의 의도와 내용은 동일하다. 차이는 patch header의 old/new hunk count와 후속 hunk new-line offset을 실제 patch body에 맞춘 것뿐이다.

`005` 실패 원인은 JavaScript나 EFSM 설계가 아니라 업로드 과정에서 generated diff를 축약하면서 hunk count를 갱신하지 않은 것이었다.

## Source of truth / EFSM

`20260909-005.md`와 동일하다.

- project CSV와 `headerLines`
- `chart.editor.objects`
- `chart.editor.editable`
- 기존 appFSM selection/workspace

외에 별도 영속 상태를 추가하지 않는다. Plotly renderer와 FFPX/FFSX 의미를 변경하지 않는다.

## 선택하지 않은 방향

실패한 `005`를 덮어쓰지 않는다. 실패 기록과 원인을 보존하고 새로운 순번으로 교정한다.

기능을 다시 여러 소패치로 분해하지 않는다. 사용자가 지적한 중간 작업 반복을 피하기 위해 graph/data ownership 단위를 그대로 유지한다.

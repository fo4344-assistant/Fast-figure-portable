## 요구와 선택 이유

사용자는 정의되지 않은 “지정 필드”나 “control”로 처리를 생략한 설명, 기존 정의를 중복 나열한 집합, 자연어 알고리즘을 Python 분기로 대신한 작성 방식을 지적했다.

기존 인자인 values와 기존 chart 설정 구조를 사용하면 입력 자체에서 변경 항목과 새 값을 확인할 수 있다. 기존 공식 읽기·명령 경로를 연결하여 선택 소유자와 Backend 검증 책임을 유지한다. 설명에는 실제 정의된 인자, 필드와 메서드를 사용한다.

# 20260902-056 — Label preview renderer / draft drag 계산 경계 분리

## 목적

`review-006.md`에서 확인한 Label staging의 핵심 누락인 실제 slot 비율 preview와 drag interaction을 Mantine로 이식하기 위한 기능 경계를 준비한다.

기존 `renderLabelPreview()`는 다음 책임이 섞여 있다.

- 실제 slot reference geometry 계산
- label text/font/position preview 렌더
- legacy X/Y native input `.value` 동기화

Mantine controlled draft가 이 함수를 그대로 호출하면 preview renderer가 React input DOM을 직접 수정하게 된다. 따라서 preview 계산/렌더와 legacy form 동기화를 분리한다.

## 변경 내용

- `renderLabelPreviewFromValues(values, syncControls = false)` 추가
  - canonical label settings에 explicit draft values를 overlay한다.
  - 기존 `labelPreviewGeometry()` / 실제 slot reference geometry를 재사용한다.
  - 기존 identifier 규칙을 재사용해 format/parentheses draft를 preview한다.
  - font family/font size/X/Y를 draft 기준으로 그린다.
  - `syncControls=true`일 때만 legacy `labelPositionX/Y` DOM input을 동기화한다.
- 기존 `renderLabelPreview()`는 `renderLabelPreviewFromValues(activeProject.labelSettings, true)` wrapper로 유지한다.
  - legacy UI 동작은 유지된다.
- `labelPreviewPositionFromPointer(clientX, clientY, offsetX, offsetY)` 추가
  - 기존 `labelPreviewGeometry()`와 `constrainLabelPreviewPosition()`을 재사용해 pointer 좌표를 실제 slot 기준 X/Y px로 변환한다.
  - domain state를 수정하지 않는다.
- bridge에 다음을 추가한다.
  - `renderLabelPreview(values)` — Mantine draft preview 전용, legacy form DOM sync 없음
  - `labelPreviewPosition(...)` — pointer 위치 계산

## source of truth

이 patch는 label persisted state를 수정하지 않는다.

- canonical label state: 기존 `activeProject.labelSettings`
- Mantine draft: 후속 component에서만 commit 전 임시값
- preview DOM: renderer output일 뿐 source of truth가 아님

## 기존 기능 보존

다음 계산은 새로 구현하지 않고 기존 함수를 재사용한다.

- dashboard reference width
- selected slot geometry
- slot aspect/size
- label element actual size에 따른 drag boundary
- x/y pixel coordinate convention

따라서 과거 수정에서 맞춘 “실제 slot 대비 preview label 크기/위치 비율”을 유지한다.

## 기각한 대안

### React에서 slot geometry를 별도 계산

기각한다. geometry source가 둘이 된다.

### legacy input ID를 Mantine NumberInput에도 붙여 기존 renderLabelPreview 사용

기각한다. imperative `.value` write와 React controlled value가 충돌한다.

### drag 중 domain state를 직접 수정

후속 Mantine component에서는 사용하지 않는다. Modal draft 수명주기와 cancel 가능성을 유지하기 위해 pointer drag는 draft만 갱신하고 Apply에서 기존 command로 commit한다.

## 파일/EFSM 영향

- 파일 schema 변경 없음
- EFSM event/action 변경 없음
- label persisted 의미 변경 없음

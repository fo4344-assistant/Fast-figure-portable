# 20260911-024 — FSM legacy UI hook removal

## 목적
legacy HTML 제거 전에 FSM 정의에 남은 마지막 generic-UI 역방향 동기화를 제거한다. 특히 overlay update가 old label/caption/layout DOM을 다시 쓰는 경로를 끊어 Mantine overlay가 단일 UI owner가 되게 한다.

## 변경
- no-op `syncProjectWorkspaceState`, `enterOverlayState`, `exitOverlayState` helper를 제거한다.
- project workspace의 no-op entry/update hook을 제거한다.
- overlay states의 legacy entry/exit hook을 제거한다.
- layout overlay의 `renderLayout()/syncLayoutMapSize()` update를 제거한다.
- label/caption overlay의 legacy control sync update를 제거한다.
- empty `syncAssetSelectionState` hook과 assetSelection state의 entry/update 연결을 제거한다.

## 유지
- graph/image workspace의 model-level transient selection 동기화는 유지한다.
- overlay state/event transition 자체와 `appFSM.publish()` 구독 경로는 유지한다. Mantine은 이를 통해 다시 렌더링된다.
- renderer, project model, FFPX/FFSX/Plotly 계층은 변경하지 않는다.

## 근거
기존 UI 호환성은 보존 대상이 아니다. legacy DOM update hook을 남기면 old markup 삭제 뒤 Mantine 조작이 DOM null 오류로 이어질 수 있다.

## 검증
workflow patch check, JS syntax, portable build, split/portable smoke.

## 롤백
이 패치를 되돌리면 legacy FSM UI hooks가 복구된다.

# 20260928-013

## 목적과 변경 내용

Mantine shell 안에 마지막으로 남아 있던 일반 UI용 raw `<pre>` debug log surface를 Mantine component로 교체한다.

변경 전 debug log는 직접 다음 geometry/styling을 소유했다.

- max height 220px
- overflow auto
- margin/padding
- border
- radius
- font size

변경 후:

- scroll lifecycle: Mantine `ScrollArea`
- code/log surface: Mantine `Code block`
- 내용 특성상 필요한 `white-space: pre-wrap`, `overflow-wrap: anywhere`만 local style로 유지

## 선택 이유

Mantine 도입 목적은 일반 GUI element의 크기·padding·border·radius·scroll 동작을 Fast Figure CSS/inline style로 반복 구현하지 않는 것이다.

debug log는 Plotly/dashboard 같은 기능 renderer가 아니라 일반 UI이므로 Mantine primitive가 소유하는 것이 맞다.

## 유지하는 raw DOM

현재 React source의 raw `div` 3개는 다음 기능 surface다.

- label preview host
- draggable label preview object
- layout preview grid

이들은 UI chrome이 아니라 실제 geometry/drag preview renderer이므로 이번 단계에서 Mantine Box로 의미 없이 포장하지 않는다.

## 선택하지 않은 방향

- debug log 전용 CSS class를 추가하지 않는다.
- `AppDebugLog` 같은 wrapper component를 만들지 않는다.
- border/radius/font size를 Code에 다시 직접 지정하지 않는다.
- renderer preview surface는 변경하지 않는다.

## 롤백

역적용하면 debug log만 이전 raw `pre` 구현으로 돌아간다. debug telemetry, EFSM, domain state에는 영향이 없다.

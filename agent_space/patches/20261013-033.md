# 20261013-033 — Translate Source Script r18 to PlusCal pseudocode r4

## 목적과 변경 내용

closed Source Script r18의 변경 의미를 기존 module hierarchy를 유지한 채 PlusCal pseudocode에 직접 번역한다.

- `pseudocode/api_ui.pcal`: project tree selection/move, tree move와 slot connection precondition 분리, settings overlay resize local state, Layout preview rendered-width projection을 추가.
- `pseudocode/assets_files.pcal`: trash membership과 tree move eligibility 분리, entering-trash detach와 leaving-trash non-restore를 명시.
- `pseudocode/renderer_runtime.pcal`: slot swap commit 뒤 reconciled selection을 읽고 dashboard를 즉시 render하는 순서를 명시.
- `development-versions.json`: pseudocode를 r4/current로 올리고 r18 fingerprint에서 파생됨을 기록.
- translation review `review-20261013-012-pluscal-r18.md` 추가.

## 선택 이유

Source Script의 user-visible 의미와 mutation/reference 경계를 Source Code가 다시 해석하지 않도록 실행 순서와 branch를 한 단계 구체화했다. Mantine/DOM API는 pseudocode에 넣지 않고 저수준 구현으로 남겼다.

## 고려했지만 선택하지 않은 방향

- Mantine Tree API 이름을 pseudocode procedure로 직접 모델링: library 선택을 논리 명세로 승격하므로 기각.
- trash move와 slot connection을 하나의 draggable boolean으로 모델링: 서로 다른 precondition을 잃으므로 기각.
- leaving trash에서 reference restore action 추가: Source Script에 없는 의미이므로 기각.
- preview width를 별도 pseudocode state로 유지: r18이 제거한 중복 의미를 다시 만드는 것이므로 기각.
- overlay resize를 project/layout mutation으로 처리: UI-local state 경계를 위반하므로 기각.

## 관련 변경과 후속

- Source Script r18은 `review-20261013-011-sourcescript-closure-r18.md`에서 closed.
- verification-model r11과 source-code r13은 이 패치 후에도 stale이다.
- 다음 단계는 r4 pseudocode에서 필요한 state/reference 변화만 verification model에 반영하고 TLC를 실행하는 것이다.

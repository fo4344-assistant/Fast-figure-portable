# 20260916-023 — dead native CSV projection markup removal

## 목적과 변경 내용

native data fieldset 안에 남아 있으나 current JavaScript/Mantine에서 더 이상 사용하지 않는 CSV selection/header-lines projection과 table preview markup을 제거한다.

삭제 대상:

- `#csvSelectionPanel`
- `#headerLinesLabel`
- `#headerLines`
- `#tableWrap`
- `#preview`

`#fileName`과 `#status`는 이번 패치에서 유지한다.

## 선택 이유

`20260916-019`에서 global `rows/columns`, `loadData()`, `preview()` 경로가 제거된 이후 current `fast-figure.js`와 `fast-figure-ui.js`에는 `csvSelectionPanel`, `tableWrap` 또는 native `headerLines` DOM 접근이 남아 있지 않다. CSV header-line 편집은 Mantine graph editor가 `graphEditorHeaderLines()` functional command를 사용한다.

따라서 해당 markup은 project CSV SoT나 graph command API가 아니라 더 이상 소비되지 않는 legacy frontend projection이다.

## 선택하지 않은 방향

- `fileName/status`까지 함께 제거하지 않는다. 이 둘은 current core utility가 아직 optional DOM fallback으로 쓰고 있어 별도 ownership 변경이 필요하다.
- `<aside>` 전체를 제거하지 않는다. Mantine bootstrap root visibility를 먼저 확인해야 한다.
- CSV model/headerLines domain field나 `graphEditorHeaderLines()`는 변경하지 않는다.

## 전제 / 후속 작업 / 누락

- table/preview 및 asset-selection 전용 CSS는 markup 제거 후 별도 패치에서 제거한다.
- rollback은 이 패치만 되돌리면 markup이 복구되며 project/schema에는 영향이 없다.

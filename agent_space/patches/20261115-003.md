# 20261115-003

## 목적과 변경 내용

사용자가 기존 계획의 축약 표현과 불명확한 설명을 지적하고 재작성을 요청했다. 이에 `agent_space/plans/plan-028.md` 전체를 다시 작성했다. 프로그램을 고치는 작업은 수행하지 않았다.

새 계획은 실제로 고장 난 두 사용자 동작을 먼저 설명한다. 이어서 내부 저장 객체에는 선택 슬롯 식별자가 없지만 외부 읽기 함수의 결과에는 있다는 차이와, 화면이 잘못된 경로를 읽어 값 없는 인자를 전달하는 과정을 설명한다.

그 다음 관련 Source Script 다섯 파일에서 무엇을 추가하고 고칠지 각각 적었다. 외부 읽기 결과의 구성과 변경 알림 순서, Application의 상태 읽기 통로, 화면 구독, 객체 추가, 파일 불러오기, 선택 없음과 슬롯 0, 처리 도중 선택 변경과 실패 처리를 순서 있는 문장으로 풀었다. pseudocode와 source code의 대응 파일, 작업 순서, 실제 재시험 절차와 완료 조건도 구분했다.

## 이 방향을 선택한 이유

용어만 나열하거나 처리 단계를 화살표로 줄이면 사용자는 실제 수정 내용을 판단할 수 없다. 증상, 원인, 수정 후 동작, 파일별 수정안, 작업 순서, 확인 방법 순서로 읽을 수 있도록 구성했다. 함수와 필드의 실제 이름은 보존하되 그 이름이 가리키는 역할과 값을 한국어 문장으로 설명했다.

## 선택하지 않은 다른 방향

- 기존 계획에 용어 설명 몇 줄만 추가하기: 처리 순서와 책임을 이해하기 어렵다는 지적을 해결하지 못한다.
- 고장 난 두 함수 호출만 고치겠다고 적기: 상태 읽기와 구독의 차이, 같은 상태를 쓰는 다른 입력 처리, 반복 화면 갱신 문제를 빠뜨린다.
- 이번에 구현까지 진행하기: 사용자는 계획 재작성을 요청했으며 프로그램 수정은 요청하지 않았다.
- 기존 계획과 별개의 새 계획 번호 만들기: 같은 계획의 재작성 요청이므로 `plan-028.md`를 대체한다.

## 실제 패치의 기준과 포함 범위

이 패치는 재작성 직전의 계획 문서를 포함한 Git tree `90018b4b18bd9b48363efc91d2b92cf558503a93`와 실제 수정 파일을 비교해 생성한다. 그 tree는 현재 HEAD `9e58bdf0381b62bb59068a44ca78d75be6edcaed`에 기존 미커밋 `plan-028.md`만 포함한 비교 기준이다. 임시 Git index를 사용하며 일반 index와 branch를 변경하지 않는다.

패치에는 계획 문서의 재작성 diff와 본 설명 문서를 포함한다. 패치 자신은 자기참조를 피하려고 제외한다. 기존 `20261115-002.patch/.md`는 처음 작성한 계획의 기록으로 보존하며 덮어쓰지 않는다. 이번 패치는 그 다음 변경이다. 임시 index는 생성 후 삭제한다.

선행 실필드 결과 문서, 증거 파일과 `20261115-001.patch/.md`는 그대로 둔다. Source Script, pseudocode, source code, 버전 정보, 배포본, 정책, index 문서, Git 업로드 도구는 바꾸지 않았다. 브라우저 재시험, build, checker, Actions, commit과 push도 하지 않았다. 계획에 적힌 구현과 재시험은 별도 실행 지시 후의 후속 작업이다.

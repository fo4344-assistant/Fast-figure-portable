# 20260910-002 — Mantine annotation WIP 구현

## 목적
WIP 단계에서 레이블과 캡션 UI를 별도 선행 정리 작업 없이 Mantine overlay로 먼저 구현한다. 완전한 legacy 제거와 popup interaction parity는 후속 통합 단계로 미룬다.

## 변경
- Mantine `Textarea`를 사용 가능하게 추가한다.
- `FastFigureLabelOverlay`를 추가한다.
  - 표시 토글, 식별자 형식, 괄호, row/column-major, font family, font size, X/Y px, 위치 초기화.
  - 현재 layout/slot geometry를 사용한 WIP preview를 제공한다.
  - project `labelSettings`를 직접 authority로 사용하고 기존 label/dashboard renderer 및 FSM notify를 재사용한다.
- `FastFigureCaptionOverlay`를 추가한다.
  - 전체 caption 표시, slot caption mode, slot caption insertion.
  - global/slot caption text 편집, caption name, bold, font family, size, line-height.
  - 기존 `CAPTION_TEXT_INPUT`, `SLOT_CAPTION_MODE_CHANGED`, `SLOT_CAPTIONS_INSERTED` FSM event와 dashboard caption renderer를 재사용한다.
- shell에서 label/caption/layout Mantine overlays를 함께 render한다.

## 선택 이유
레이블과 캡션은 같은 annotation ownership 영역이다. 이전처럼 renderer-neutral helper, popup abstraction, content editor를 각각 별도 패치로 나누지 않고 WIP 상태에서 기능 surface를 먼저 채운다.

## 기각안
- label command 추출 → preview 분리 → Modal 구현을 각각 별도 패치로 진행: 중간 작업을 늘리므로 기각.
- caption text editor만 먼저 이전: annotation ownership을 불필요하게 분할하므로 기각.
- legacy popup DOM을 Mantine 내부로 복제: 장기 bridge가 되므로 기각.

## Source of truth / EFSM 영향
- 레이블 영속 상태: `activeProject.labelSettings`, `activeProject.labelsEnabled`.
- 캡션 영속 상태: `activeProject.caption*` 및 slot caption field.
- 기존 ProjectObject/FFPX schema/UI-FSM/functional EFSM은 변경하지 않는다.
- React local state를 annotation 영속 authority로 사용하지 않는다.

## WIP 제한
legacy annotation popup과 global outside-click handler가 아직 공존하므로 modal interaction, drag preview, focus behavior의 최종 parity는 보장하지 않는다. 이 버전은 `1.1.31-wip`이며 해당 미완성 상태를 허용한다. 이후 통합 단계에서 legacy popup 제거와 pointer-drag/focus parity를 마감한다.

## 검증
workflow의 git apply, JS syntax, portable build, split/portable file smoke를 통과해야 한다. UI interaction parity는 WIP 후속 통합 검증에서 수행한다.

## Rollback
이 패치를 역적용하면 Mantine label/caption overlays와 `Textarea` import만 제거된다. project schema/EFSM/data migration은 없다.

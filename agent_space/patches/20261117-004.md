# Plan036 Source Script 수정

## 목적

공통 조작 크기·정렬, 접기 계층, 대시보드/미리보기의 공통 틀, 빈 행·열 입력 복원, 오브젝트 이동 뒤 선택 유지, 그래프 제목이 포함된 목록 표시를 Source Script에 반영했다.

## 변경 이유와 선택

- 같은 역할의 조작 크기는 기존 theme/default props, 입력 행 배치는 기존 UI 구성 절차에 모았다. 별도 UI 설정 저장소나 공통 컴포넌트 계층은 추가하지 않았다.
- 기하 계산은 기존 Backend `dashboardGeometry`를 사용한다. Application이 현재 세션과 layout에서 너비를 전달하고 실제 화면·미리보기는 `renderDashboardFrame`으로 같은 틀을 구성한다. 미리보기의 독립 grid 복제와 전체 Plotly renderer 호출은 배제했다.
- move 결과의 전체 순번 대응을 기존 참조 보정에 연결했다. UI에서 이동 선택을 추측하거나 object id·이름 비교를 새로 도입하지 않았다.
- 빈 입력 복원과 접기는 UI-local 처리다. 목록 제목은 같은 공식 조회의 표시 값이다. project 저장 필드는 유지했다.

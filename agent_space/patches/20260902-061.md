# 20260902-061 — Dashboard Capture bridge 연결

## 목적

`20260902-060`에서 정상 적용된 `captureDashboardTargetFromValues()`를 Mantine Print UI가 기존 bridge 규칙으로 호출할 수 있도록 연결한다.

## 변경 내용

- `fastFigureUiBridge.captureTarget(values, statusTarget)` 추가
- 구현은 `captureDashboardTargetFromValues(values, statusTarget)`에 그대로 위임

## 영향 범위

UI adapter 한 메서드만 추가한다.

- export/capture renderer 변경 없음
- EFSM/domain 변경 없음
- 파일 schema 변경 없음
- Mantine button은 후속 patch에서 연결

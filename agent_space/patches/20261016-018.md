# 20261016-018 — 정책 재독 후 Source r34 검토 기록

## 목적·이유

사용자가 요구한 정책 재독 → 검토 → 적절한 위치의 문서 기록 순서를 따른다. `agent_space/AGENT.md`, `agent_space/policies/policies.md`, `agent_space/policies/development-policy.md` v0.2.6 전체를 재독한 뒤 Source r34의 API 반환과 command/reconciliation/선택 경로를 정적으로 대조했다. 독립 검토 결과이므로 `agent_space/reviews/review-20261016-014-policy-first-source-r34.md`에 기록했다.

## 변경과 판단

- P2 명세 불일치 3건: 기본 image import 경로 `/assets/image` 대 `/assets/images`, connect의 선택 비변경 약속 대 SELECT_SLOT의 asset clear, 빈 CSV 생성 command의 선택 owner 서술 충돌.
- P2 미정의 경로 1건: CSV cascade reference 삭제 후 범위 내 숫자 index가 다른 graph object를 선택할 수 있는 반례. 실제 clear/remap hint 생성 규칙이 없어 Source 완결성 부족으로 분류했으며 실행 버그를 확정하지 않았다.
- 이전 r34 반환 검토의 connect asset 선택 비변경 주장을 그대로 승인하지 않았다. 근거 경로와 문서의 한계를 새 검토에 명시했다. 과거 검토 기록은 소급 삭제/수정하지 않았다.
- Source current/open 및 하위 stale 유지가 타당하다. 이번 문서는 새 의미/계약 원천이나 수정 완료 선언이 아니다.

## 선택하지 않은 대안

- 검토와 함께 Source를 즉시 수정: 요청은 정책 우선 검토와 기록이며, 특히 cascade 선택 정책은 먼저 의미를 결정해야 하므로 포함하지 않았다.
- 기존 반환표만 재확인: 반환 직전/직후의 상태 전이가 불일치할 수 있어 command와 후속 선택까지 추적했다.
- lower 코드의 현재 동작으로 판정 대체: Source 자체의 계약 간 대조가 우선이며 하위 구현이 open Source의 의미를 대신 정할 수 없다.
- 새 query/selection registry 또는 legacy alias: 기존 단일 owner와 공식 경로 안에서 해결할 수 있는 문제이며 이번에는 새 계약을 만들지 않았다.
- Source closed 선언 또는 PlusCal/Source Code 재개: 논리적 완결성·목적 적합성·중복/통합 검토 근거가 부족하다.

## 실제 누적 patch 범위·게시 방식

- 변경 기준점: `34b300a7afdfb577eb5a3555d61f2406c2bc6486`.
- 검토 문서 반영의 의미상 종료점: `9cddf54c9f5678ad648767d883c401bf857e0403`.
- 동명 `.patch`는 `git diff --binary 기준점 종료점`의 실제 결과다. 검토 문서 1개 추가, 114줄이며 자기 참조를 피하기 위해 이 패치 쌍 자체는 포함하지 않는다.
- 각 GitHub Contents API 쓰기 전에 main HEAD와 대상 blob SHA를 재확인한다. 신규 문서는 대상 없음(404) 및 현재 tree의 경로 미존재를 확인한다. UTF-8/LF 내용으로 순차 게시한다.
- 검토 문서 commit 이후 실제 diff를 생성하고 별도 commit들로 패치 쌍을 게시한다. 따라서 문서·패치·설명 전체가 하나의 atomic commit으로 게시되었다거나 동일 commit 내부에서 자기 diff까지 기록되었다고 주장하지 않는다.

## 확인과 미포함

- 기준점→종료점 `git diff --check` 통과.
- 종료점 tree의 격리된 임시 index에서 생성 patch의 reverse cached apply check 통과. 실제 working index/Source는 변경하지 않았으며 임시 index는 제거했다.
- 위 확인은 파일/diff 정합성 확인이지 Source/application 실행이나 의미 검증 통과가 아니다.
- 수동 Actions dispatch, 로컬 Source import/application/test/checker/build/TLC 실행 없음. 기록 push로 자동 workflow가 시작될 수 있으나 그 결과를 이번 정적 검토 근거로 주장하지 않는다.
- 정책·Source·PlusCal·model·하위 코드·metadata·test·build·dist 변경 없음. 관련 helpers/임시 자료는 현재 작업 경로 아래에서만 다뤘다.
- Source r34 current/open, closure_review null, fingerprint `sha256:024c9de52803c2743ab65742753e94b09dd15fdaa1f3f1d40f34567c648478ac`와 PlusCal r11/model r26/source-code r36 stale을 그대로 유지한다.

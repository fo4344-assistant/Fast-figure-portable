# 20260831-013

## 목적

React/Mantine runtime vendoring에서 발생한 third-party bundle의 줄 끝 공백 검증 실패만 분리해 수정한다.

## 변경 내용

- 기존 v3 builder를 그대로 재사용하는 one-shot v4 workflow를 추가한다.
- v4는 v3의 실행 스크립트를 읽고 `git diff --check`만 `git diff --check --ignore-space-at-eol`로 치환한다.
- runtime 결과 patch 순번은 `20260831-014`로 변경한다.
- 애플리케이션 소스용 기존 HTML patch workflow의 엄격한 `git diff --check`는 변경하지 않는다.

## 이 방향을 선택한 이유

실패한 항목은 esbuild가 만든 vendored React/Mantine runtime 내부의 trailing whitespace였다. 해당 generated third-party block 때문에 애플리케이션 소스의 일반 검증까지 완화할 필요는 없다. 따라서 이번 one-shot vendoring 작업에서만 줄 끝 공백을 무시하고 conflict marker 등 나머지 검사는 유지한다.

또한 같은 vendoring 스크립트를 다시 복사하지 않고 v3의 검증 명령과 결과 순번만 치환해 실행하므로 중복 구현을 늘리지 않는다.

## 고려했지만 선택하지 않은 방향

- 기존 HTML patch workflow의 `git diff --check`를 완화하지 않는다.
- vendored bundle 전체를 임의로 재포맷하지 않는다.
- 실패한 Actions run을 rerun하지 않는다.

## 후속 작업

runtime vendoring 성공 후 실패/일회성 vendor workflow들을 별도 cleanup 커밋에서 제거한다.

## 패치에 포함되지 않은 변경사항

이 patch와 설명 파일 자체는 재귀적으로 diff에 포함하지 않는다.

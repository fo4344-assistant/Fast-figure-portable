# 20261013-027 — Record pseudocode policy-alignment plan

## 목적

사용자 지시에 따라 pseudocode를 archived/non-authoritative로 취급한 현재 메타데이터를 상위 정책 v0.2.6과 정렬하기 전에 실행 계획을 기록한다.

## 변경

- `agent_space/plans/plan-011.md` 추가.

application source, Source Script, pseudocode 의미 파일, verification model, version metadata는 이 패치에서 변경하지 않는다.

## 선택 이유

이번 변경은 개발 계층의 권위와 lineage 검사 규칙을 바로잡는 작업이므로 구현 전에 정책 기준, 변경 범위, 비변경 범위와 검증 순서를 명시한다.

## 기각한 방향

- pseudocode를 verification 보조 산출물로 유지하지 않는다. 상위 정책은 pseudocode를 Source Script 전체 번역 계층으로 명시한다.
- 정책 원문을 현재 메타데이터에 맞춰 수정하지 않는다. 정책이 상위 원천이므로 하위 메타데이터와 checker를 수정한다.
- application source를 함께 수정하지 않는다. 현재 발견된 문제는 구현 의미가 아니라 계층 관리와 상태 문서의 불일치다.

## 후속

plan-011에 따라 계층 메타데이터, checker, README를 수정하고 hosted version check 후 build를 수행한다.

# 20260922-009

## 목적과 변경 내용

native `#debugLog` DOM이 제거된 뒤에도 남아 있던 debug telemetry의 legacy DOM projection을 제거한다.

- `clearDebugOutput()`에서 `$("debugLog")` text clear를 제거한다.
- `debugLog()`에서 `#debugLog` text/scroll projection을 제거한다.
- debug line의 실제 runtime state는 기존 `uiTelemetryState.debugLines`와 `publishUiTelemetry()`에 그대로 유지한다.

## 선택 이유

현재 HTML에는 `id="debugLog"` element가 없고 Mantine `FastFigureStatusDebug`는 telemetry를 구독한다. 따라서 DOM projection은 기능을 제공하지 않는 legacy branch이며 core가 제거된 UI element를 계속 인식하게 만든다.

## 선택하지 않은 방향

- `#debugLog` element를 다시 만들지 않는다.
- optional chaining으로 DOM projection을 보존하지 않는다.
- 별도 debug buffer를 추가하지 않는다. 기존 telemetry state가 debug 표시의 유일한 runtime source다.

## 전제와 후속 작업

- HTML 전체에서 `id="debugLog"`가 0회임을 확인했다.
- Mantine debug UI는 `useUiTelemetry()`를 통해 같은 `debugLines`를 사용한다.
- save/clear/debugEnabled 동작은 변경하지 않는다.

## 롤백

역적용하면 존재할 경우 `#debugLog` DOM에도 telemetry를 중복 투영하는 branch가 복원된다. project/domain state에는 영향이 없다.

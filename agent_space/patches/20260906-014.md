# 20260906-014 — workspace domain / legacy presentation wrapper 분리

## 목적

현재 active workspace wrapper는 `20260906-009` 이후 domain helper를 먼저 호출하지만, 같은 함수 안에서 legacy DOM presentation까지 계속 수행한다.

이번 패치는 project/graph/image workspace와 graph exit에서 legacy presentation 부분을 별도 helper로 추출해, wrapper 구조를 `domain synchronization → legacy presentation`으로 명시한다. EFSM callback과 transition은 아직 바꾸지 않는다.

## 변경 내용

- 앱 버전 `1.1.117-alpha` → `1.1.118-alpha`
- `syncLegacyProjectWorkspacePresentation()` 추가
- `syncLegacyGraphWorkspacePresentation()` 추가
- `syncLegacyImageWorkspacePresentation()` 추가
- `exitLegacyGraphWorkspacePresentation()` 추가
- 기존 active wrapper는 기존 domain helper를 호출한 뒤 반환 model과 `objects`만 presentation helper에 전달

## source of truth

새 helper는 별도 상태를 소유하지 않는다. `availability`, `slot`, `selection`, `objects`는 호출 범위 안의 transient 값으로만 전달하고 저장하지 않는다.

project/slot/chart/CSV/image의 source of truth와 `appFSM.state`는 변경하지 않는다.

## 의미 보존

### project workspace

기존 target text, file name/preview, availability UI, image control, asset tree, label/caption controls, native panel visibility 동작을 그대로 presentation helper로 이동한다.

### graph workspace

`syncGraphWorkspaceDomainState()`가 slot/availability/chart selection을 결정한다. chart selection이 필요한 경우에만 기존 `syncLegacyGraphEditorSelection(selection)`을 presentation 단계에서 실행한다. chart가 없는 slot의 기존 preview/buildBox 정리도 유지한다.

### image workspace

active image 정규화는 domain helper에 남고, file name/preview/image controls/tree/caption 표시만 presentation helper로 이동한다.

### graph exit

`selectedObjectIndex = null`은 기존 `exitGraphWorkspaceDomainState()`가 계속 담당하고, `buildBox` 숨김만 legacy presentation helper가 담당한다.

## Mantine 전환과의 관계

이 패치 후 active wrapper 자체가 legacy UI와 domain을 결합하는 마지막 adapter가 된다. 후속 cutover에서는 `APP_STATE_DEFINITIONS.workspace`의 callback을 domain helper에 직접 연결하고 legacy presentation helper를 호출하지 않는 방향을 검토할 수 있다.

React/Mantine shell mount는 이번 패치에 포함하지 않는다.

## EFSM / core / format 영향

- workspace state 이름 변경 없음
- transition target 변경 없음
- event/action 변경 없음
- chart/data/image mutation 변경 없음
- FFPX/FFSX schema 변경 없음
- renderer 동작 변경 없음

## 선택하지 않은 방향

### APP_STATE_DEFINITIONS를 즉시 domain helper로 교체

현재 active owner가 아직 legacy UI이므로 presentation callback이 사라져 화면 갱신이 중단된다. React shell mount와 같은 cutover 단계에서 수행해야 한다.

### presentation helper에서 domain 상태를 다시 읽기

전달된 transient 값을 무시하고 다시 source of truth를 읽으면 callback 사이 의미가 갈릴 수 있다. domain helper가 산출한 같은 값만 한 번 전달한다.

### 새 UI owner flag 도입

아직 실제 owner 전환을 하지 않으므로 불필요한 상태를 추가하지 않는다.

## 회귀 위험

낮음.

기존 문장을 별도 함수로 이동하고 같은 순서로 즉시 호출하며, domain helper와 presentation의 실행 순서는 유지한다.

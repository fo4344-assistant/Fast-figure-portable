# 20260906-007 — built-in README source 위치 설명 정리 재적용

## 목적

실패한 `20260906-006`의 built-in README 문구 교정을 현재 split HTML의 정확한 줄과 주변 context를 기준으로 재적용한다.

`006`은 실행 코드 문제가 아니라 첫 zero-context hunk의 시작 위치가 현재 source와 맞지 않아 `git apply --check`에서 중단됐으며 실제 HTML에는 반영되지 않았다.

## 변경 내용

- React / ReactDOM 개발 source 위치와 portable embed 관계 설명
- Mantine 개발 source 위치와 portable embed 관계 설명
- Iconoir 개발 source 위치와 portable embed 관계 설명
- Plotly 개발 source 위치와 portable embed 관계 설명

## patch 안정성

각 hunk에 앞뒤의 실제 현재 HTML context를 포함했다. React/Mantine/Iconoir 문구에서 늘어나는 줄 수를 후속 hunk의 new-file 시작 위치에도 누적 반영했다.

## 영향

문서 문구만 변경한다. 앱 버전, EFSM, renderer, 파일 포맷, build logic, JavaScript는 변경하지 않는다.

## 검증

기존 workflow의 `git apply --check`, JavaScript syntax check, portable build, split/portable `file://` smoke test, `git diff --check`를 모두 다시 통과해야 한다.

# 20260915-006 — Split annotation cleanup: remove obsolete state-to-native projections

## Purpose
Resume the annotation cleanup from failed patch 20260915-005 using smaller, independently checkable hunks. Patch 005 failed at `git apply --check` before changing source.

## Failed-attempt recovery
- `20260915-005.patch` and its explanation remain as audit history.
- No source rollback is required because the workflow stopped before application.
- This patch intentionally covers only the small projection/call-site subset of 005; native label editor function deletion and caption API simplification are deferred to following patches.

## Exact changes
- Remove `syncLabelControlsFromObject` and `syncCaptionControlsFromObject`, which only write project annotation state into removed native annotation controls.
- Remove the corresponding two calls from the legacy project-control synchronizer.
- Remove the inert `renderDashboard()` hook for the absent `labelPreview` DOM.
- Remove native annotation button writeback from `setAnnotationEnabled`; authoritative annotation state mutation, dashboard render, debug log, and EFSM notification remain unchanged.

## Rationale
These are self-contained state-to-deleted-DOM projections. Removing them first reduces the surface area of the subsequent native label/caption helper deletion and avoids another large multi-hunk failure.

## Rejected alternatives
- Retry 005 unchanged: rejected because the workflow already rejected it before application.
- Restore native annotation controls: rejected because Mantine owns the editor UI.
- Change annotation state or renderer behavior: rejected because these hunks only remove obsolete UI projection.

## Source of truth
`activeProject.annotations`, compatibility accessors, and existing EFSM events remain authoritative. Actual figure labels/captions continue through `renderDashboard()` and `syncDashboardCaption()`.

# 20260908-003 — Mantine blank-image insertion

## 목적

`review-010-mantine-ui-inventory.md`의 Image/Data 영역에 포함된 `빈 이미지 삽입` 기능을 Mantine image editor에서 직접 사용할 수 있게 한다.

현재 기능은 legacy `#insertEmptyImage.onclick` handler 안에 프로젝트 이미지 생성과 `SLOT_IMAGE_IMPORTED` 전이가 inline되어 있다. Mantine 버튼이 legacy 버튼을 클릭하지 않도록 실제 기능 부분만 기존 이름·전이·renderer 의미를 보존한 command로 추출한다.

## 변경 내용

### `fast-figure.js`

- legacy onclick body를 `insertEmptyImageIntoSelectedSlot()` 함수로 추출한다.
- 함수는 기존과 동일하게 선택된 image slot을 검사한다.
- 동일한 1600×900 빈 SVG를 `buildProjectImageModel()`로 생성한다.
- 기존 `appFSM.send("SLOT_IMAGE_IMPORTED", ...)` 경로를 그대로 사용한다.
- 기존 `setFileName()`, `updateFileAvailability()`, `renderDashboard()`, status 호출을 유지한다.
- 성공 시 생성된 image model을 반환한다.
- legacy `#insertEmptyImage.onclick`은 이 command를 직접 사용한다.

### `fast-figure-ui.js`

- `FastFigureImageEditor`에 `빈 이미지 삽입` Mantine `Button`을 추가한다.
- 버튼은 `insertEmptyImageIntoSelectedSlot()`을 직접 호출한다.
- lifecycle이 `ready`가 아니면 비활성화한다.

## Source of truth / EFSM 영향

없음.

- image model authority: 기존 `activeProject.images`
- slot content authority: 기존 slot/project model
- 전이: 기존 `SLOT_IMAGE_IMPORTED`
- renderer: 기존 `renderDashboard()`
- 새 React state 없음
- FFPX/FFSX schema 변경 없음

## 선택 이유

기능이 legacy handler에 inline되어 있어 Mantine에서 재사용할 직접 command가 없으므로 `plan-006`의 helper 추출 허용 조건에 해당한다. 새 adapter/state 계층을 만들 필요 없이 handler body를 이름 있는 기능 함수로 승격하는 것이 최소 복잡도다.

## 기각한 대안

### Mantine에서 `document.getElementById("insertEmptyImage").click()`

legacy DOM을 내부 API로 사용하므로 기각한다.

### Mantine component에 SVG 생성과 `SLOT_IMAGE_IMPORTED` 로직 복제

동일 기능을 두 군데 구현하게 되므로 기각한다.

### 새 EFSM event 추가

기존 `SLOT_IMAGE_IMPORTED`가 필요한 기능 전이를 이미 표현하므로 기각한다.

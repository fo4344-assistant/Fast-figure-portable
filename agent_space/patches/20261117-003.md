# 변경 목적

Plan034의 중복 실행을 줄인다. WF80의 FFPX 저장·재열기는 WF50·WF51과 겹치므로 실행 제외로 표시하고, 로그 정리와 브라우저 종료는 공통 절차로 유지한다. WF36은 WF35의 행 변경과 겹치지 않도록 기존 3행을 유지한 열 변경으로 한정한다. split, 입력 형식, 오류 종류 등 목적이 다른 과정은 유지한다.

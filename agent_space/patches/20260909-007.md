# 20260909-007 — Graph/data editor 직접 Mantine ownership

## 목적

`20260909-005`와 `006`은 application source 적용 전에 unified diff 형식 오류로 중단되었다. 이번 패치는 기능 범위를 축소하지 않고 구현 코드를 더 간결한 값 기반 command 집합으로 다시 작성해 graph/data editor ownership을 실제로 이전한다.

## 변경 파일

- `fast-figure.js`
- `fast-figure-ui.js`

## 구현 범위

한 패치에서 다음을 함께 이전한다.

- project CSV 선택
- CSV header line 수
- 30행 데이터 preview
- imported Plotly original/editable 전환
- graph object 추가/선택/drag reorder/삭제
- graph object 색상
- object CSV
- X/Y column
- X/Y axis side
- graph type
- legend name
- line width/dash
- marker symbol/size
- bar opacity/border width

## Core command

`fast-figure.js`에 UI 독립적인 다음 함수들을 추가한다.

- `graphEditorChart()`
- `graphEditorCommit()`
- `graphEditorSelectCsv()`
- `graphEditorSelectObject()`
- `graphEditorObjectValues()`
- `graphEditorAdd()`
- `graphEditorMove()`
- `graphEditorDelete()`
- `graphEditorHeaderLines()`
- `graphEditorSetEditable()`

기존 `GRAPH_OBJECTS_REPLACED`, `SELECT_GRAPH_OBJECT`, `CLEAR_GRAPH_OBJECT`, `SLOT_DATA_CONNECTED`, `SELECT_ASSET`와 기존 project/chart/CSV 객체를 그대로 사용한다.

## Mantine ownership

`FastFigureGraphDataEditor`가 `slot.graph` workspace에서 project/chart state를 직접 읽고 위 command를 호출한다. legacy input `.value`나 `.click()`을 Mantine callback에서 사용하지 않는다.

React local state는 drag 중인 object index만 가진다. CSV, header, chart object, editable 등의 영속 값은 기존 project model과 appFSM이 authority다.

## Legacy projection

기존 legacy UI가 아직 전체 cutover 전까지 존재하므로 `graphEditorHeaderLines()`는 현재 CSV일 때 legacy header input/table preview를 한 방향으로 갱신한다. Mantine UI는 이 DOM projection을 읽지 않는다.

기존 `#headerLines.onchange`와 `#editorEditable.onclick`도 동일한 값 기반 command를 호출하도록 바뀐다.

## 보존한 의미

- header line: 0..CSV row count
- line width: 0.1..20
- marker size: 1..40
- bar opacity: 0.05..1
- bar border: 0..10
- graph type: scatter / markers / lines+markers / bar / hidden
- X axis: bottom/top
- Y axis: left/right
- Plotly JSON → editable 변환 시 기존 conversion rows/fallback CSV 생성 의미
- Plotly renderer, FFPX/FFSX, project VFS/validation 의미

## 선택하지 않은 방향

- header/editable/object를 다시 별도 migration patch로 나누지 않는다.
- React 전용 graph store를 만들지 않는다.
- Mantine에서 legacy `configFromForm()` 또는 DOM 값을 읽지 않는다.
- legacy graph-object DOM을 clone하지 않는다.

## 005/006과의 관계

`005`와 `006`은 모두 `git apply --check`에서 실패했으므로 application source에 영향이 없다. 실패 기록은 그대로 보존한다. `007`은 같은 ownership 목표를 더 간결한 구현으로 대체한다.

## 후속 범위

Graph editor에서 아직 남는 전역 legend/title/zero-line/font와 네 axis 상세 설정은 같은 ownership 방향으로 이어서 이전한다. 이번 패치는 그 전제 작업용 bridge가 아니라 CSV/object/editable 사용자 기능 자체를 실제 Mantine에서 사용할 수 있게 하는 변경이다.

# 20260914-018 — Remove legacy print panel markup

## Purpose
Remove the native legacy print/export popup after Mantine ownership and legacy event detachment.

## Exact changes
- Delete `section#printPanel` and its legacy format/DPI/size/action controls from `Fast-figure.html`.
- Preserve the dashboard, dashboard caption, export functions, project export settings, and Mantine print UI.

## Rationale
The native print popup no longer owns export interaction. Mantine passes export options through the UI-independent export command path, so the obsolete popup can be removed without removing export logic.

## Rejected alternatives
- Keep hidden print controls as compatibility inputs: rejected because the active Mantine export path supplies options explicitly.
- Delete export rendering logic with the panel: rejected because export is core functionality, not legacy UI.

## Source of truth
Project/export model state and Mantine-provided export options remain authoritative.

## EFSM/core impact
None intended. Markup deletion only.

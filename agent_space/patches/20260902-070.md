# 20260902-070 — Mantine graph file actions component 정의

## 목적

`review-007`에서 확인한 graph slot 파일/편집 모드 기능을 inactive Mantine sidebar staging에서 사용할 수 있는 하나의 component로 이식한다.

이번 패치는 component 정의만 추가하고 sidebar에는 아직 연결하지 않는다.

## 변경 내용

- 앱 버전 `1.1.101-alpha` → `1.1.102-alpha`
- `FastFigureGraphFileActionsStaging({ graphFileActions })` 추가
- visible UI는 Mantine `Button`, `Group`, `Stack`, `Text` 사용
- 제공 기능:
  - FFSX 내보내기 → 기존 `downloadSlotFfsx()` 재사용
  - Plotly JSON 내보내기 → 기존 `downloadPlotlyJson()` 재사용
  - FFSX / Plotly JSON 불러오기 → 기존 `importSlotFile(file, slot)` 재사용
  - 원본 JSON / 편집 가능 전환 → `069` bridge의 `setGraphEditorEditable()` 재사용
- 파일 picker는 숨겨진 native `input[type=file]`을 browser I/O adapter로만 사용
- accept 범위는 `.ffsx`, `.json`, JSON MIME, Fast Figure slot MIME을 포함
- import 오류 시 기존 `refreshCsvControls()`, status/debug 의미 유지

## stale target guard

component snapshot은 source of truth가 아니므로 각 action 실행 시 `readGraphFileActions()`를 다시 읽는다.

snapshot의 `slotId/chartId`와 현재 선택 대상이 다르면 실행하지 않고 상태 메시지를 표시한다.

import는 file chooser가 열린 동안 selection이 바뀔 수 있으므로 file change 시점에도 현재 selected slot ID를 다시 검증한다.

## 파일 의미 보존

새 export/import 구현을 만들지 않는다.

- FFSX schema/build/read/validation: 기존 함수 그대로 사용
- Plotly JSON figure 생성: 기존 `chartFigure()` 경로 그대로 사용
- imported Plotly 변환: 기존 `importSlotFile()` / `parsePlotlyToEditor()` 경로 그대로 사용

따라서 `plan-005`의 파일 roundtrip 호환 범위를 UI migration 때문에 변경하지 않는다.

## source of truth

- selected slot/chart: 기존 project/FSM selection
- editable: `chart.editor.editable`
- file contents: browser `File` 객체가 단일 import interaction 동안만 존재
- component 내부 persistent graph/file state 없음

`useRef`는 숨겨진 file input DOM handle일 뿐 데이터 authority가 아니다.

## 기각안

### legacy 버튼 `.click()` 재사용

기각. legacy DOM을 기능 API로 남기게 된다.

### FFSX/Plotly import/export를 React에서 재작성

기각. 파일 의미와 validation source가 이중화된다.

### Mantine FileButton 추측 사용

기각. 현재 bundled runtime API를 별도 검증하지 않은 상태에서는 hidden native input adapter가 더 좁고 안전하다.

## 회귀 위험

낮음~중간. component는 inactive staging에 정의만 되고 아직 호출되지 않는다.

검증:

- `git apply --check`
- `git diff --check`
- application JavaScript `node --check`
- 새 file schema/renderer/conversion code 없음
- stale selection guard 존재
- import 실패 후 동일 파일 재선택 가능하도록 input value reset

## rollback

`FastFigureGraphFileActionsStaging`과 버전 문자열 두 곳만 제거하면 된다. `067/069`의 공통 command/read 경계는 독립적으로 유지 가능하다.

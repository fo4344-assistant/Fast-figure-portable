# 20260922-001

## 목적과 변경 내용

Mantine shell을 실제 active UI로 cutover하면서, 20260916-032에서 native aside를 제거한 뒤 남은 legacy 3-column `.app` 배치 때문에 dashboard renderer가 첫 열에 자동 배치될 수 있는 문제를 함께 수정한다.

- `#ff-react-bootstrap-root`의 `hidden` 속성을 제거한다.
- React root는 fixed overlay로 두고 자체 pointer event는 끈다.
- Mantine `AppShell.Header`와 `AppShell.Navbar`만 pointer event를 받게 한다.
- 기존 dashboard renderer를 담은 `.app`은 Mantine navbar 폭만큼 첫 grid column을 예약하고 `main`을 두 번째 column에 둔다.
- Mantine navbar 폭/접힘 상태를 frontend-local `useEffect`에서 `.app --sidebar-width` presentation 값으로 투영한다.
- navbar 변경 시 Plotly resize를 예약한다.
- 전역 `main` CSS를 `.app > main`으로 좁혀 Mantine `AppShell.Main`과 legacy renderer CSS가 섞이지 않게 한다.

## 선택 이유

Fast Figure의 dashboard/Plotly/slot/image surface는 기존 기능 renderer이므로 React가 그 DOM ownership까지 가져가도록 재구현하지 않는다. 대신 Mantine은 generic shell만 소유하고 기존 renderer surface는 sibling 영역으로 유지한다. 이 방식은 single-shell cutover를 수행하면서 domain renderer를 보존한다.

navbar 폭은 UI presentation state다. `--sidebar-width`는 backend/domain state가 아니며 `.app` 레이아웃에만 사용된다. 다른 기능 로직이나 API에서 이 값을 읽지 않는다.

## 선택하지 않은 방향

### `hidden`만 제거

Mantine `AppShell.Main`은 기본적으로 viewport 높이를 차지하므로 React root를 일반 document flow에 그대로 노출하면 기존 dashboard가 아래로 밀릴 수 있다. 따라서 사용하지 않는다.

### dashboard DOM을 React root 안으로 이동

기존 renderer DOM을 React-managed subtree로 강제로 옮기거나 React가 직접 dashboard markup을 소유하게 하면 renderer ownership까지 동시에 바뀐다. Mantine shell cutover 범위를 넘어가므로 사용하지 않는다.

### 새 shell bridge/state 생성

navbar 상태를 별도 전역 객체나 backend state로 복제하지 않는다. React local state에서 renderer layout CSS 값만 갱신한다.

## 전제와 후속 작업

- `FastFigureShell`의 navbar 초기 폭은 370px이며 기존 renderer offset 기본값과 동일하다.
- 이 패치는 old sidebar CSS 전체를 제거하지 않는다. active shell cutover가 확인된 뒤 dead CSS로 별도 정리할 수 있다.
- 다음 ownership 작업에서는 `selectedObjectIndex`와 `appFSM.state.graphObjectIndex` 중복을 제거한다.
- 이후 layout 선택 상태를 frontend-local state로 옮기고 backend merge/split command에는 slot id 목록을 명시적으로 전달한다.

## 롤백

이 패치만 역적용하면 React root는 다시 hidden staging 상태가 되고 `.app`은 이전 legacy grid 배치로 돌아간다. project schema, FFPX/FFSX, domain model에는 변경이 없다.

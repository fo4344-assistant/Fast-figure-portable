# 20260906-006 — built-in README source 위치 설명 정리

## 목적

`20260906-001`의 JavaScript source split과 `20260906-005`의 portable build 복구 이후에도 built-in README의 third-party 설명 일부가 여전히 “현재 HTML 안에 직접 포함된다”고 적혀 있다.

개발 source와 generated portable HTML의 차이를 정확히 설명하도록 문구만 수정한다.

## 변경 내용

- React / ReactDOM: 개발 source에서는 `vendor/fast-figure-ui-runtime.js`, portable build에서는 generated HTML 내부에 embed된다고 명시
- Mantine: 같은 runtime 파일과 portable embed 관계를 명시
- Iconoir: 개발 source에서는 `fast-figure.js`, portable build에서는 generated HTML에 embed된다고 명시
- Plotly: 개발 source에서는 `vendor/plotly.min.js`, portable build에서는 generated HTML에 embed된다고 명시

## 선택 이유

runtime 내용, 실행 순서, EFSM, 파일 포맷은 이미 `001`/`005`에서 검증됐다. 남은 문제는 문서상의 위치 설명뿐이므로 코드나 build logic을 다시 건드리지 않는다.

## 고려했지만 선택하지 않은 방향

- third-party 설명 섹션 전체 재작성: 현재 라이선스와 버전 정보는 맞으므로 불필요하다.
- 앱 버전 추가 증가: 실행 코드나 포맷 변화가 없는 설명 교정만이므로 이번 patch에서는 유지한다.

## 검증

- `git apply --check`
- `git diff --check`
- 기존 JavaScript syntax check
- portable build
- split/portable `file://` smoke test가 모두 기존대로 통과해야 한다.

## rollback

이 patch를 역적용하면 설명 문구만 이전 상태로 돌아간다.

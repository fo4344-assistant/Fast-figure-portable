# 20260915-013 — Remove native annotation common CSS with generated exact hunks

## Purpose
Recover from the pre-application failures of `20260915-010`, `20260915-011`, and `20260915-012` by applying the same small common-annotation CSS cleanup with hunk headers generated from the exact current `Fast-figure.html` source rather than hand-counted.

## Failed-attempt recovery
- `20260915-010`, `20260915-011`, and `20260915-012` remain as audit history.
- All three failed at `git apply --check` before application source changed, so no rollback is required.
- Inspection showed that the intended source text was present, but the broad retry hunks used manually reconstructed hunk ranges/counts. This patch is regenerated from the exact current source excerpt and uses automatically calculated unified-diff hunk counts/positions.
- Before queueing, the generated patch was checked with `git apply --check` against a synthetic file preserving the exact current source lines and their repository line positions.

## Exact changes
- Remove `.annotation-panel` from the shared fixed-popup selector while preserving `.layout-panel` and `.print-panel`.
- Remove `.annotation-panel > *` from shared popup child sizing.
- Remove `.annotation-controls` from the shared heading selector.
- Remove the standalone `.annotation-controls` alignment rule.
- Remove `.annotation-controls strong` from the shared heading text selector.
- Remove `.annotation-controls button` from the shared heading-button selector.
- Remove `.annotation-hint`.

Native caption-specific selectors and native label-specific selectors remain for following patches.

## Why this direction
The native annotation editor DOM and JavaScript ownership have already been removed, but repeated manually reconstructed CSS patches failed before application. The code intent was not the problem; patch construction was. Generating the diff from exact current text eliminates manual hunk-count errors while retaining a small, independently rollbackable ownership unit.

## Rejected alternatives
- Retry `010`, `011`, or `012` unchanged: rejected because each was already rejected by the workflow.
- Directly edit `Fast-figure.html` through the GitHub contents API: rejected because project policy requires application source changes to be represented and applied through paired diff patches.
- Remove caption and label CSS in the same retry: rejected to keep this recovery patch small and isolate any further mismatch.
- Remove `.layout-panel`, `.print-panel`, `.popup-heading`, or actual dashboard caption/slot-label styles: rejected because they belong to separate live or not-yet-audited ownership areas.

## Source of truth
No state ownership changes. This patch only removes unused native annotation presentation rules.

None. No JavaScript, UI-FSM/EFSM transition, project model, persistence, renderer geometry, or export behavior is changed.

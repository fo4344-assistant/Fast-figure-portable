# 20260902-050 — React shell workspace host staging 재적용

## 목적

`20260902-049`의 설계를 더 작은 범위로 재적용한다. `049`는 `window.FastFigureReactShell` export object의 현재 context가 달라 `git apply --check`에서 실패했고 HTML에는 반영되지 않았다.

## 변경 내용

- 앱 버전을 `1.1.89-alpha`로 올린다.
- `FastFigureWorkspaceStaging()`을 추가한다.
- `graphArea`, `dashboard`, `dashboardCaption`, `captionPrefix`, `captionText` host contract를 React shell 내부에 준비한다.
- `FastFigureShellStaging()`의 placeholder main을 해당 workspace component로 교체한다.
- `049`와 달리 `window.FastFigureReactShell` export object는 수정하지 않는다.

## 이유

`FastFigureWorkspaceStaging`은 shell 내부 구현 세부사항이고 외부 호출자가 직접 사용할 필요가 없다. 따라서 외부 export를 추가하지 않는 편이 최소 구현이며 current export context와의 불필요한 결합도 피한다.

## 변경하지 않는 영역

- Plotly/slot/image renderer
- graph/caption domain 의미
- 파일 import/export
- legacy active shell
- React root mount

## rollback

이 patch만 되돌리면 staging shell은 다시 placeholder main을 사용한다. domain/file state에는 영향이 없다.

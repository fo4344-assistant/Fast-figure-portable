# 20260916-026 — orphan native README dialog CSS removal

## 목적과 변경 내용

Mantine `FastFigureReadmeOverlay`로 README overlay ownership이 이전된 뒤 남아 있는 native `#readmeDialog` 전용 CSS를 제거한다.

변경 내용:
- `#readmeDialog` box/panel style 제거
- `#readmeDialog::backdrop` 기본 style 제거
- centralized palette의 `#readmeDialog::backdrop` override 제거
- Mantine overlay가 재사용하는 `.readme-content`는 유지

## 선택 이유

current HTML에는 `readmeDialog` element가 없고 current JavaScript에도 `readmeDialog` 참조가 없다. README 본문은 `<template id="readmeContent">`와 Mantine Modal이 소유하므로 `#readmeDialog` selector들은 더 이상 consumer가 없는 legacy frontend CSS다.

## 선택하지 않은 방향

- README template/content 자체는 제거하지 않는다.
- `.readme-content` typography/layout은 Mantine overlay에서도 사용하므로 유지한다.
- Mantine Modal lifecycle, logic EFSM, ProjectObject, renderer는 변경하지 않는다.

## 전제 / 후속 작업 / 누락

- 이 패치는 frontend CSS ownership 정리만 수행한다.
- rollback은 이 패치를 되돌리면 native README dialog selector들이 그대로 복구된다.

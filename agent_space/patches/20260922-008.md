# 20260922-008

## 목적과 변경 내용

호출되지 않는 legacy project-control DOM projection `syncProjectControlsFromObject()`를 제거한다.

이 함수는 제거된 native controls인 `#projectName`, `#gridRows`, `#gridCols`, `#dashboardReferenceWidth`, `#slotGap`, `#dashboardOuterMargin`, `#slotRadius`, `#dashboardAspect` 및 palette controls에 project 값을 다시 투영하는 코드만 가지고 있으며 현재 호출 지점이 없다.

## 선택 이유

Mantine cutover 이후 backend/core가 제거된 native form controls를 알고 있을 이유가 없다. 호출이 없는 dead projection을 남기면 이후 실수로 다시 bridge처럼 사용할 가능성이 생기므로 제거한다.

## 선택하지 않은 방향

- 제거된 controls를 다시 만들지 않는다.
- optional chaining으로 DOM write를 보존하지 않는다.
- Mantine 쪽에 같은 projection 함수를 복제하지 않는다. frontend는 각 SoT API snapshot을 읽는다.

## 전제와 후속 작업

- 현재 source 전체에서 `syncProjectControlsFromObject()` 호출은 정의 자체 외 0회임을 확인했다.
- project/layout/appearance의 실제 state 및 renderer 적용 함수는 변경하지 않는다.
- 남은 legacy DOM helper와 CSS는 사용 여부를 계속 횡단 감사한다.

## 롤백

역적용하면 호출되지 않는 legacy DOM projection 함수만 복원된다. project schema와 기능 state에는 영향이 없다.

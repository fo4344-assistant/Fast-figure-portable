# 20260901-015

## 목적

`20260901-014`에서 분리한 values 기반 export 계약을 사용하는 Mantine Print staging component를 준비한다. 현재 활성 overlay host는 아직 바꾸지 않아 UI cutover와 준비 코드를 분리한다.

## 변경 내용

- 애플리케이션과 built-in README 버전을 `1.1.45-alpha`로 올린다.
- `fastFigureUiBridge.exportTarget(values, statusTarget)`를 추가한다.
- `FastFigurePrintModalStaging`을 추가한다.
- 가로/세로/DPI는 Mantine `NumberInput`, 형식은 Mantine `Select`, 실행은 Mantine `Button`을 사용한다.
- 현재 실제 export 엔진과 동일하게 PNG/JPEG만 제공한다.
- 세로 값은 빈 문자열이면 기존 자동 높이 의미를 유지한다.
- export 상태 메시지는 작은 `textContent` setter adapter를 통해 React state로 받는다.
- 기존 export 함수가 반환한 정규화된 고정 높이는 필요할 때 staging draft에 반영한다.
- staging component를 `window.FastFigureMantineStaging`에 노출한다.

## 이 방향을 선택한 이유

Mantine UI가 canvas/Plotly/export 구현을 직접 알지 않고 bridge만 호출하도록 유지해야 renderer 책임이 React form으로 역류하지 않는다. 또한 status 전달을 단일 setter adapter로 제한하면 별도 이벤트 시스템을 추가하지 않고 기존 export 메시지를 그대로 재사용할 수 있다.

## 선택하지 않은 방향

- 아직 `FastFigureOverlayHostStaging`의 print 항목을 교체하지 않는다.
- legacy print panel을 제거하지 않는다.
- 지원 형식이나 export 한도를 확장하지 않는다.
- 전체 shell cutover를 수행하지 않는다.

## 검증 항목

- `git apply --check`
- `git diff --check`
- 메인 JavaScript `node --check`
- APP_BUILD와 built-in README 버전 일치
- Print staging에서 legacy print DOM ID 미사용
- bridge를 통한 기존 export renderer 재사용
- PNG/JPEG, 자동 세로, DPI 36–1200 계약 유지

## 패치에 포함되지 않은 변경사항

이 `.patch`와 설명 `.md` 자체는 재귀적인 diff에 포함하지 않는다. 실제 HTML 수정은 제한된 patch workflow가 검증 후 적용한다.

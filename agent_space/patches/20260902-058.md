# 20260902-058 — 독립 Mantine Label preview component 이식

## 목적

`20260902-057`은 Label Modal의 초기 state/effect context가 현재 main과 달라 apply-check 단계에서 실패했다. HTML에는 반영되지 않았다.

현재 component 내부 구조를 불필요하게 재작성하지 않고 preview 기능만 안정적으로 이식하기 위해 독립 component로 분리한다.

## 변경 내용

- `FastFigureLabelPreviewStaging({ draft, setDraft })` 추가
  - transient pointer drag state는 `useRef`에만 저장
  - draft 변화 후 `fastFigureUiBridge.renderLabelPreview(draft)` 호출
  - 기존 preview host class/id contract 사용
  - pointer move는 `fastFigureUiBridge.labelPreviewPosition(...)`으로 실제 slot geometry 기준 위치 계산
  - 결과를 parent draft x/y에 반영
- 기존 `FastFigureLabelModalStaging`에는 `레이블 형식` Select 앞에 preview component 한 줄만 삽입
- parent의 draft 생성/apply/reset lifecycle은 변경하지 않음

## 설계 이유

Label preview는 재사용 가능한 UI surface이며 parent form state와 분리된 pointer lifecycle을 갖는다. 별도 component로 두면 parent Modal의 현재 구현 변화와 결합을 줄일 수 있다.

## source of truth / EFSM

- preview drag: React draft만 변경
- persisted label settings: 기존 domain state
- commit: 기존 Label apply command
- 새 EFSM event 없음

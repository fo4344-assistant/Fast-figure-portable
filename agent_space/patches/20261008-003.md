# 20261008-003 — Graph object selection ordering

## Purpose
After a consistent CSV-selection transition clears graph-object selection, selecting an object must select its referenced CSV first and then set SELECT_GRAPH_OBJECT. Otherwise the second action clears the first selection.

## Decision
Preserve one FSM selected asset source and existing event names; reorder the two operations only. Object csvId is still authoritative data reference. No duplicate state.

## Rejected
Remove graph-object clear from CSV selection: reintroduces inconsistent entry-point semantics. Add special-case flag: adds needless alternate branch.

## Omissions

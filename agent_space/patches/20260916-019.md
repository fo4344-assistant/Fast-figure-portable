# 20260916-019

## 목적과 변경 내용

`20260916-018`에서 native graph object-list가 제거된 뒤 완전히 무호출이 된 legacy CSV preview/data-buffer ownership을 제거한다.

이번 패치는 다음만 제거한다.

- global `rows`
- global `columns`
- `loadData(data, name, { showGraphControls })`
  - native `xCol`/`yCol` select와 `buildBox`를 채우던 legacy data-form projection
- `clearPreview()`
- `preview()`
  - native `tableWrap`/`preview` 테이블을 렌더링하던 CSV preview UI

## current-source 확인

`20260916-018` 적용 후 current source를 다시 검색했다.

- `loadData()`는 정의 외 호출이 없다.
- global `rows`/`columns`는 `loadData()`와 `preview()`에서만 사용된다.
- `preview()`는 `loadData()`에서만 호출된다.
- `clearPreview()`는 `preview()`에서만 호출된다.

따라서 이 값과 함수들은 active graph/domain path와 분리된 하나의 legacy native CSV-preview ownership이다.

`graphEditorObjectValues()` 내부에도 이름이 `columns`인 지역 변수가 있지만, 이는 각 CSV의 `columnDefinitions()`에서 즉시 계산하는 operation-local `Set`이며 이번에 제거하는 global `columns`와 별개다.

## source of truth 경계

CSV 데이터의 권위 상태는 `activeProject.csvFiles` / `ProjectObject`의 project CSV model에 있다. 선택 상태는 `SELECT_ASSET` / `appFSM.state.assetPath`가 소유한다.

제거되는 global `rows`/`columns`는 native graph form/preview를 위해 CSV model을 별도로 복사·가공해 두던 UI buffer다. active Mantine graph editor는 선택된 project CSV에서 직접 `columnDefinitions(activeCsv.rows, activeCsv.headerLines)`를 계산하므로 이 global buffer가 필요하지 않다.

## 보존하는 기능/core

이번 패치는 다음을 수정하지 않는다.

- project CSV `csv.rows`, `csv.headerLines`, `bytesBase64`
- `activeProject` / `ProjectObject`
- `selectedProjectCsv()` / `getProjectCsv()` / project VFS
- `columnDefinitions(table, headerLines)`
- `dataRows(table, headerLines)`
- `graphDataSelection()`
- `graphEditor*` functional commands
- logic EFSM 및 asset/graph events
- CSV import/export, FFPX/FFSX persistence
- `traces()` / `tracesSingle()` / `layout()` / Plotly renderer
- Mantine graph data editor의 CSV table/column UI

즉 CSV domain data나 functional renderer를 제거하지 않고 native preview projection만 제거한다.

## 고려했지만 선택하지 않은 방향

### global `rows`/`columns`를 project CSV SoT에 다시 연결

선택하지 않았다. active Mantine path는 이미 project CSV를 직접 읽으며 별도 shared projection이 필요 없다. 다시 동기화하면 review-011의 SoT 규칙을 어긴다.

### `columnDefinitions()` / `dataRows()`까지 제거

선택하지 않았다. 두 함수는 active Mantine editor와 graph trace/core 계산에서 사용된다. native preview 함수와 별개다.

### native preview markup/CSS까지 함께 제거

선택하지 않았다. 이번 패치는 JS ownership과 global buffer 제거에 한정한다. `tableWrap`, `preview`, `buildBox`, native graph form markup/CSS는 JS reference audit 후 별도 패치에서 제거한다.

### `selectedGraphObjectGuard()` 같은 무호출 logic helper 정리

선택하지 않았다. UI cleanup과 logic-level dead-code audit를 섞지 않는다.

# 20261013-003 — Stabilize dashboard file-drop listener lifetime

## Layer classification
Source Script r15 and PlusCal already define dashboard external drop semantics. This is a Source Code implementation defect only.

## Problem
FastFigureDashboardFileDrop installs its DOM drop listener in a React effect that depends on choosePlan. choosePlan was recreated on every render, so the effect repeatedly removed and re-added the dashboard listener. A drop delivered during that render/effect gap could be lost. The branch-triggered regression exposed this as nondeterministic collision-modal test behavior.

## Change
Import React.useCallback and memoize choosePlan with stable dependencies. The dashboard drop effect now remains attached across ordinary application re-renders.

## Design impact
No Source Script, PlusCal, project state, import-plan, or lifecycle semantics change.

# 20260831-015

## 목적
React/Mantine production runtime을 `Fast-figure.html` 내부에 vendoring하고 기존 UI를 변경하지 않은 상태에서 하나의 `MantineProvider` bootstrap 경계를 만든다.

## 변경 내용
- React/ReactDOM 19.2.8과 `@mantine/core`/`@mantine/hooks` 9.5.2를 단일 HTML 안에 번들했다.
- Mantine core CSS와 비가시 bootstrap root를 추가했다.
- 애플리케이션 버전을 1.1.30-alpha로 올렸다.
- built-in README와 top-level LICENSE에 React/Mantine MIT 고지를 추가했다.
- 기존 toolbar/sidebar/overlay DOM은 변경하지 않았다.

## 이 방향을 선택한 이유
Dependency/bootstrap 문제와 실제 UI migration 문제를 분리하여 회귀 원인을 좁히기 위해서다.

## 고려했지만 선택하지 않은 방향
- CDN runtime은 portable/offline 요구와 충돌하므로 사용하지 않았다.
- toolbar/modal을 동시에 교체하지 않았다.
- `@mantine/modals`는 사용하지 않는다. overlay 상태는 EFSM이 소유한다.

## 검증
- inline IIFE runtime/bootstrap
- 외부 module/script runtime 의존성 부재
- 버전 일치와 LICENSE 고지
- main JavaScript `node --check`
- `git diff --check`

## 패치에 포함되지 않은 변경사항
이 설명 파일과 patch 기록 파일 자체는 재귀적으로 diff에 포함하지 않는다.

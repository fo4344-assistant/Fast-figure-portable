# 20261013-012 — Define r17 UI interaction and empty-CSV semantics

## 목적과 변경 내용

Source Script r17에서 다음 의미를 구체적으로 확정한다.

- visible slot click은 content type보다 현재 selection 상태를 먼저 판정한다.
- 미선택 graph/image/empty slot은 같은 slot-surface selection 규칙을 사용한다.
- 이미 선택된 content slot 본문은 content interaction을 유지하고 bookmark는 기존 toggle을 사용한다.
- dashboard background는 기존 SELECT_SLOT none 경로로 selected slot을 해제한다.
- trash CSV/image의 일반 selection 비활성화와 row action Menu 접근을 분리한다.
- 빈 CSV 삽입은 역사적으로 사용된 정확한 CSV template을 일반 asset으로 생성하고 기존 CSV selection 경로를 사용한다.
- 빈 CSV는 protected/default asset이 아니며 생성 시 graph object를 자동 만들지 않는다.
- Layout/Label/Caption/Print outer Modal width는 네 component의 개별 size가 아니라 하나의 공통 Mantine maximum-size owner를 사용하며, 그 maximum은 현재 Mantine maximum token보다 넓어야 한다.

Source Script revision은 r17, fingerprint는 `sha256:2fec6d0c59f9b29a3d1d824ced75db46787fb566dd81373b07812db03b357664`로 갱신하고 closure review를 추가한다.

## 변경을 발생시킨 요구와 발견

현재 renderer Source Script와 Source Code는 chart/image content 존재 여부를 먼저 검사하여 미선택 content slot 본문을 selection 진입점에서 제외하고 있었다. 따라서 이미 선택이 풀린 content slot을 본문 클릭으로 다시 선택할 수 없는 상태가 발생한다.

trash tree UI는 trash 여부 하나로 selection과 Menu target까지 동시에 비활성화하고 있다. 두 interaction은 동일한 권한이 아니다.

zero-object chart 설계에서 protected default CSV를 제거한 뒤 사용자 명령으로 일반 빈 CSV를 생성하는 entry point가 복구되지 않았다. 과거 구현에서 사용하던 template은 `빈 CSV.csv`, `[["X","Y"],["",""]]`, `text/csv`, `headerLines=1`이었다.

네 설정 overlay는 Mantine으로 통합되어 있으면서 outer size를 lg/xl로 개별 소유하고 있어 공통 UI 규칙 중앙화 목적과 맞지 않는다.

## 알고리즘 의미와 책임 경계

slot selection authority는 기존 selectedSlotId/ApplicationStateMachine에 그대로 둔다. renderer controller는 click context를 판정해 기존 SELECT_SLOT command를 호출할 뿐 별도 selection state를 만들지 않는다.

빈 CSV asset 생성은 assets_files의 일반 CSV creation 경로를 사용하고, 현재 CSV selection은 기존 appFSM assetSelection/assetPath 경로를 사용한다. graph object 생성은 graphs.addObject의 기존 경로를 유지한다.

trash row Menu의 opened/enabled 여부는 UI interaction projection이며 project state가 아니다.

설정 Modal width는 Mantine generic UI ownership이며 persistent project state가 아니다.

## 선택한 방향

selection branch는 `visible slot 여부 → 현재 selected 여부 → selected일 때만 content interaction 여부` 순서로 명시했다. 이는 미선택 content slot도 다시 선택 가능하게 하면서 이미 선택된 Plotly/image interaction을 유지한다.

빈 CSV는 보호된 singleton이 아니라 매번 일반 CSV asset으로 생성하도록 했다. 현재 zero-object chart와 일반 asset 규칙을 유지하면서 필요한 template data entry point만 복구할 수 있다.

## 고려했지만 선택하지 않은 방향

- graph/image slot별로 별도 selection 예외를 추가하지 않았다. 같은 slot selection 의미가 content type에 따라 다시 분기하기 때문이다.
- document 전역 click을 deselection으로 사용하지 않았다. dashboard 밖의 toolbar/sidebar/Modal interaction까지 selection 의미에 섞이기 때문이다.
- trash asset을 다시 일반 selectable asset으로 바꾸지 않았다. Menu 접근 문제와 asset selection/slot connection 권한은 별개다.
- original-location restore state를 추가하지 않았다. 이번 요구에 그런 persistent 의미가 없고 현재 project model에 원래 path authority가 없다.
- protected default CSV와 `isDefaultEmpty`를 되살리지 않았다. r16의 zero-object chart 및 일반 CSV 규칙과 충돌하고 과거의 삭제/이동/FFSX 예외를 다시 만든다.
- 빈 CSV 생성과 graph object 생성을 하나의 새 mutation으로 합치지 않았다. 기존 CSV selection + graphs.addObject 경로를 재사용할 수 있다.
- 네 Modal에 같은 px 또는 같은 token을 각각 반복 지정하지 않았다. 공통 sizing ownership이라는 목적을 다시 깨뜨린다.

## 닫힘 판정 영향

이 revision에서 추가하거나 수정한 사용자 관찰 가능한 의미는 각 branch, mutation owner, non-owner를 명시했으며 별도의 unresolved design choice를 남기지 않는다. `agent_space/reviews/review-20261013-006-sourcescript-closure-r17.md`에서 r17을 closed로 판정한다.

## 하위 단계 전파 범위

verification-model에는 slot selection/deselection과 empty-CSV persistent mutation/selection 경로 중 검증 대상 의미를 번역해야 한다. UI-only Menu availability 및 concrete Modal width 값은 persistent state로 만들지 않는다.

Source Code에는 r17 verification/TLC gate 통과 후 renderer click dispatch, trash Menu target, empty CSV public command/UI, common Modal maximum, layout preview actual-width geometry를 반영해야 한다.

## 후속/누락 사항

이 patch는 Source Script와 lineage/closure만 변경한다. verification-model, TLC 결과, application Source Code, browser regression, distribution은 아직 변경하지 않는다.

## rollback

이 patch를 되돌릴 때는 다섯 Source Script 파일, `development-versions.json`, r17 closure review를 함께 r16 상태로 복원한다. 하위 verification/source-code 변경이 이후 r17을 기준으로 만들어졌다면 그 하위 변경도 해당 lineage에 맞춰 별도로 되돌려야 한다.

# 20261001-008 — Source Script 정책·변경 기록·복구 계획 추가

## 목적과 변경 내용

사용자가 제공한 Source Script 작성 정책 v0.1.1을 프로젝트의 정책 경로에 원문 그대로 추가하고, Source Script 수정에도 application source와 같은 diff/설명 기록 원칙을 명시적으로 적용한다.

추가:

- `agent_space/policies/source-script-policy.md`
- `agent_space/policies/policies.md`
- `agent_space/plans/plan-007.md`

수정:

- `agent_space/AGENT.md`
- `scripts/check-development-layer-versions.py`

application source와 `sourcescript/` 자체는 이번 patch에서 수정하지 않는다.

## 정책 원문 처리

업로드된 `source-script_policy.md`의 v0.1.1 내용을 프로젝트 고유 결정과 섞지 않고 `agent_space/policies/source-script-policy.md`에 그대로 보존한다.

`AGENT.md`는 이 문서를 상위 정책 원천으로 참조하고, 정책 원문은 사용자 명시 없이 수정하지 않는다는 연결 규칙만 둔다.

## Source Script 변경 기록

기존 `agent_space/patches/`가 이미 모든 변경의 diff와 이유를 기록하는 유일한 경로이므로 Source Script 전용 이력 폴더를 추가하지 않는다.

대신 Source Script 변경 시 다음을 명시적으로 요구한다.

- 새 patch/md 쌍
- 실제 `sourcescript/` diff 포함
- revision/fingerprint 변경 포함
- 변경 원인과 의미 변화
- 선택 이유와 기각 대안
- 닫힘 판정 영향
- 하위 단계 전파 범위
- 하위 단계에서 되돌아온 경우 기존 닫힘 판정이 놓친 원인

version checker에도 Source Script가 변경된 commit에서 새 patch pair가 존재하고 실제 Source Script diff를 포함하는지 확인하는 검사를 추가한다.

## plan-007

review-013의 발견 사항을 실행 가능한 순서로 재구성했다.

우선 의미 충돌을 해결한다.

- grid 축소 content 보존
- chart ownership/cardinality
- caption ownership
- label preview/commit
- export settings persistence

그 다음 project/file/graph/export/FSM/API 알고리즘 누락을 보완하고, 마지막으로 `editing`, detach/reset, asset reference cascade, `layoutMapWidth` 등의 중복 구조를 통합 또는 제거한다.

Source Script가 다시 닫히기 전에는 pseudocode와 application source를 수정하지 않는다.

## 선택 이유

Source Script 변경 기록을 별도 체계로 만들면 application source patch history와 같은 변경에 대해 두 이력 원천이 생긴다. 기존 patch 체계를 확장하면 같은 diff/설명 규칙을 그대로 유지하면서 이력 원천을 하나로 둘 수 있다.

정책 원문과 프로젝트 해결 계획도 분리했다. 정책은 일반 원칙이고, Fast Figure의 chart/grid/caption 등의 구체 해법은 plan-007에 둔다.

## 고려했지만 선택하지 않은 방향

### Source Script 전용 history 디렉터리

선택하지 않았다. 기존 `agent_space/patches/`와 역할이 중복되고 어느 기록이 authoritative한지 다시 판정해야 한다.

### 업로드 정책 문서에 Fast Figure 전용 diff 규칙을 직접 추가

선택하지 않았다. 사용자가 제공한 정책 원문은 일반 정책이며 프로젝트 고유 파일 경로와 patch naming은 `AGENT.md`의 프로젝트 작업 규칙으로 두는 편이 정책/구현 결정을 분리한다.

### review-013만 후속 계획으로 사용

선택하지 않았다. review는 문제와 판정을 기록하는 문서이고 실제 적용 순서, 권고 해결 규칙, phase별 완료 조건과 중단 조건은 plan 역할에 해당한다.

### 발견 즉시 Source Script 수정

선택하지 않았다. 이번 변경은 정책과 계획을 먼저 고정하는 단계다. 실제 Source Script 변경은 plan-007 순서에 따라 다음 revision부터 별도 patch pair로 진행한다.

## 버전 영향

이번 변경에서는 `sourcescript/`가 바뀌지 않으므로 Source Script revision/fingerprint는 변경하지 않는다.

현재 상태는 그대로 유지한다.

- Source Script r1: current, not yet closed
- pseudocode r0: missing
- source code r0: stale / pre-version-chain

# 20260928-018

## 목적과 변경 내용

Mantine shell 이행 뒤 남은 미사용 Iconoir DOM 초기화 코드를 제거한다. `fast-figure.js`의 glyph 사전·SVG 조립 함수·`.iconoir-mount[data-iconoir]` 초기화 루프와 `Fast-figure.html`의 `.iconoir` 스타일이 대상이다.

현재 활성 HTML과 React UI에는 `.iconoir-mount[data-iconoir]` 요소가 없고, 다른 application source에서 glyph 사전과 두 함수를 호출하지 않는다. README의 제3자 고지는 이번 실행 코드 패치 대상이 아니다.

## 선택 이유

이 초기화 코드는 삭제된 legacy toolbar/sidebar 아이콘의 DOM을 찾도록 설계됐다. 현재는 빈 결과에 대해 실행될 뿐이며 Mantine UI의 아이콘이나 기능 renderer의 SVG를 만들지 않는다. 정리 범위가 코드·CSS의 단일 소유권 단위로 닫혀 있다.

## 고려했지만 선택하지 않은 방향

- **아이콘 사전과 초기화 루프를 미래의 UI 아이콘용으로 보관:** 현재 mount 요소와 호출처가 없어 유지할 실행 계약이 없다. 재사용 가능성만으로 legacy DOM 초기화 경로를 남기는 것은 WIP 정리 목적에 맞지 않는다.
- **glyph 사전을 `fast-figure-ui.js`로 옮겨 React 아이콘으로 포팅:** 지금 표시할 해당 아이콘이 없으므로 새 UI 동작 없이 코드만 이동한다. 실제 아이콘 요구가 생기면 그 사용처와 함께 도입하는 편이 범위가 명확하다.

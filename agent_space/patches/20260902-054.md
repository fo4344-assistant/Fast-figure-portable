# 20260902-054 — Mantine Caption 슬롯별 캡션 추가 버튼 연결

## 목적

`20260902-053`에서 추가한 DOM-free `insertSlotCaptions()` bridge를 Mantine Caption Modal에 연결한다.

## 변경 내용

- Caption Modal 하단 action group에 `슬롯별 캡션 추가` Button을 추가한다.
- 버튼은 `fastFigureUiBridge.insertSlotCaptions()`만 호출한다.
- command 실행 후 기존 `readDraft()`를 다시 호출해 canonical caption editor state를 Modal draft에 반영한다.
- 기존 `캡션 적용` Button은 유지한다.

## 설계 이유

`20260902-052`에서는 Caption component 내부 draft mapping까지 함께 정리하려다 current context 불일치가 발생했다. 이 패치에서는 기능 이식에 필요한 최소 UI wiring만 수행한다.

별도 React/domain 상태를 추가하지 않고 기존 read helper를 재사용한다.

## 파일/EFSM 영향

- 새 EFSM event 없음
- 기존 `SLOT_CAPTIONS_INSERTED` 재사용
- caption schema 및 FFPX/FFSX 의미 변경 없음

## 회귀 확인

- `git apply --check`
- `git diff --check`
- JavaScript `node --check`
- staging inactive 상태에서 legacy active UI 영향 없음

## rollback

이 patch만 되돌리면 Mantine button wiring만 제거되고 `053` command와 기존 Caption domain 기능은 유지된다.

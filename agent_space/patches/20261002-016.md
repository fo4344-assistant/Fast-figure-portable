# 20261002-016 — graph font regression scope correction

## 목적과 변경 내용

source code r8의 graph font selector 회귀 검사 19번을
실제 요구인 "기존 custom font를 가진 graph editor를 다시 열었을 때 값이 보존되는가"에 맞게 수정한다.

변경:

- `agent_space/tests/browser-regression.js`
  - custom graph font를 API로 설정한 직후 authoritative settings에 저장되었는지 확인
  - selected slot을 해제했다가 다시 선택해 graph workspace/editor를 재구성
  - 재구성된 Select에서 `기존: <font>`가 표시되는지 확인
- `agent_space/reviews/review-026-source-code-r8-font-selectors.md`
  - 위 검증 절차를 정확히 기록

application source와 `development-versions.json`은 변경하지 않는다.

## 이 방향을 선택한 이유

초기 19번 검사는 이미 mount된 graph editor에 외부 API mutation을 넣은 뒤
같은 tick의 UI 갱신까지 요구했다.

그러나 2.5 회귀의 핵심은 historical/imported custom font family가 editor를 열 때
predefined 목록에 없다는 이유로 손실되지 않는지 여부다.

따라서 먼저 model 저장을 검증하고 editor를 실제로 재구성한 뒤
custom option projection을 확인하는 것이 요구와 직접 대응한다.

## 고려했지만 선택하지 않은 다른 방향

### source code를 바로 변경

annotation selector와 동일한 `fontSelectData` helper를 graph도 사용하고 있으며,
실패 로그만으로 source helper가 잘못됐다고 결론낼 근거가 없다.
먼저 검사의 대상과 타이밍을 실제 요구에 맞췄다.

### 단순 sleep 시간을 늘림

비결정적인 timing 의존성을 추가할 뿐 historical value 보존이라는 조건을 더 정확히 검증하지 못한다.

### graph API mutation 직후의 live UI 갱신을 별도 요구로 추가

현재 review-022의 5번 문제에는 그러한 요구가 없다.
추가 요구를 암묵적으로 source 의미로 확대하지 않는다.

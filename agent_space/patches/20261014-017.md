# 20261014-017 — Refresh verification lineage for pseudocode r6

## 변경

- `FastFigureInteractionCore.tla`의 abstraction 설명을 pseudocode r6에 맞게 갱신한다.
- Layout local selection과 dashboard projection invalidation은 project authority를 추가하지 않는 UI/runtime-local effect로 모델 밖에 둔다.
- removed-reference count는 기존 entering-trash transition에서 결정적으로 파생되는 result metadata로 명시하고 별도 state variable을 추가하지 않는다.
- verification revision을 r17로 올리고 Source Script r20 / pseudocode r6 lineage를 기록한다.
- TLC 상태는 push-trigger workflow가 실제 통과하기 전까지 `pending`으로 둔다.

## 선택 이유

현재 interaction model은 이미 entering trash reference detach, leaving trash non-restore, trash direct slot connection 금지를 상태공간에서 검증한다. 결과 count를 독립 상태로 추가하면 같은 사실을 중복 표현하므로 최소 복잡도와 single source of truth에 맞지 않는다.

## 기각한 방향

- removed reference count를 새 verification state로 추가: 기존 transition에서 완전히 유도 가능해 상태공간만 증가한다.
- Layout selection과 renderer scheduling을 project model에 포함: persistent project invariant가 아닌 UI-local effect다.
- 이전 r16 TLC 결과를 새 lineage의 passed로 재사용: push-trigger TLC를 다시 실행하므로 pending으로 기록한다.

## 후속

이 push로 TLA/TLC workflow와 development-layer version check가 트리거된다. 실제 통과 결과를 확인한 뒤 validation review를 추가하고 `tlc: passed`로 전환한다.

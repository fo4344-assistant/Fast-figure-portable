# 20261014-017 — Route declared persistent settings through project EFSM r26

## 목적

plan-015 J1 WIP를 확장해 Source Script r21의 `PROJECT_COMMANDS`에 이미 선언된 persistent mutation을 실제 `projectEFSM`으로 수렴시킨다.

## 변경

- `PROJECT_NAME_CHANGED`: project name commit.
- `LABEL_SETTINGS_CHANGED`: label enabled/settings candidate commit.
- `LABEL_POSITION_CHANGED`: persistent label x/y commit.
- `APPEARANCE_CHANGED`: UI palette candidate commit.
- `EXPORT_SETTINGS_CHANGED`: persistent export settings commit.
- 대응 public API 함수는 activeProject를 직접 쓰지 않고 appFSM compatibility facade → projectEFSM 경로를 사용한다.
- commit 뒤 renderer/notify는 기존 UI API 위치에서 수행해 projectEFSM이 DOM/UI를 직접 변경하지 않게 한다.

## 범위

- Source Code는 여전히 `stale`이다.
- caption name/nameBold/settings, image display settings, merge/split 등 Source Script의 command 표현을 더 명확히 해야 하는 persistent 경로는 후속 WIP에서 다룬다.
- TLC r19 pending 상태를 우회하지 않는다.

## 검증

push-trigger JS syntax, browser regression, distribution build, development-layer version check 결과를 확인한다.

# 20261001-005 — Source Script 구현 기본값 표현 정리

## 목적과 변경 내용

20261001-004의 1차 Source Script를 개발 정책의 작성 표기법에 맞춰 다시 점검했다.

일부 함수 signature에 현재 JavaScript 구현의 literal default argument를 그대로 옮긴 부분을 제거한다.

대상에는 `requireSlots=False`, `directory=False`, `choice="rename"`, CSV/image 생성 함수의 id/MIME/header default, `direction="fsm-to-model"`, `notify=True` 등이 포함된다.

Source Script에는 입력 식별자와 의미를 남기고, 현재 구현에서의 기본 동작은 기존 docstring 처리 설명과 구현 원천에서 추적한다.

## 선택 이유

Source Script의 Python 문법은 최종 Python 호출 규약이나 현재 JavaScript signature를 복제하기 위한 것이 아니다.

실제 literal default를 signature에 그대로 보존하면 pseudocode 이전 단계에서 대상 구현의 호출 표현을 과도하게 고정한다. 함수 경계와 데이터 의미만 유지해도 현재 책임과 처리 규칙을 보존할 수 있다.

## 고려했지만 선택하지 않은 방향

### 구현과 동일한 default argument 유지

현재 코드와의 기계적 1:1 대응은 쉬워지지만 Source Script가 두 번째 source code에 가까워진다.

### 범위 숫자와 VFS path 같은 확정 규칙도 제거

선택하지 않았다. 이는 단순 호출 문법이 아니라 validation, 참조 무결성, 파일 의미에 필요한 확정 규칙이며 descriptive string과 처리 설명에 남긴다.

## 범위와 후속 작업

application source는 변경하지 않는다.

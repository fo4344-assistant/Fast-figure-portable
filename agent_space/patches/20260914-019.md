# 20260914-019 — Remove dead legacy layout DOM helpers

## Purpose
Remove JavaScript that only managed the native layout panel removed by patches 015–018.

## Exact changes
- Delete `syncPopupBounds`, `syncLayoutMapSize`, `installLayoutResizer`, and `renderLayout` from `fast-figure.js`.
- Remove their remaining call sites from dashboard/project rendering and the Mantine shell/layout overlay.
- Stop `applySlotStyle` from attempting optional writes to the removed `layoutMap`; retain dashboard and caption geometry updates.
- Preserve project layout state, grid/slot algorithms, `dashboardGeometry`, `gridSlotGeometry`, zoom logic, merge/split commands, and export rendering.

## Rationale
These helpers only projected state into DOM that no longer exists. Mantine's layout overlay renders its own React preview from project state, while the actual dashboard is still updated by the core renderer.

## Rejected alternatives
- Leave the helpers as harmless no-ops: rejected because they preserve a false dependency on deleted legacy UI.
- Fold dashboard geometry into Mantine: rejected because geometry is core/rendering logic shared by dashboard and export.

## Source of truth
`activeProject.layout`, `layoutSelected`, and existing EFSM/project commands remain authoritative.

## EFSM/core impact
No domain behavior change intended. Only obsolete DOM projection and calls are removed.

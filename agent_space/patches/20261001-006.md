# 20261001-006 — Source Script closure 감사 기록

## 목적과 변경 내용

현재 `sourcescript/`가 pseudocode 단계로 내려갈 만큼 닫혀 있는지 세 기준으로 검토한 결과를 `agent_space/reviews/review-013-sourcescript-closure.md`에 기록한다.

검토 기준:

- 알고리즘의 논리적 완결성
- Fast Figure 프로젝트 목적과의 일치
- 중복 제거, 통합 또는 확장 필요성

결론은 현재 Source Script가 아직 닫혀 있지 않다는 것이다.

## 주요 발견

- grid 축소에서 Source Script 설명과 현재 구현이 불일치하며 content가 orphan될 수 있다.
- valid state가 chart shared reference를 허용할 수 있는데 slot reset은 다른 slot의 reference를 확인하지 않고 chart를 제거한다.
- slot.content에는 caption이 포함되지만 merge와 swap이 caption을 서로 다르게 취급한다.
- label preview/commit 의미가 아직 확정되지 않았다.
- project initialization/import normalization, file parsing, Plotly conversion, FFPX typed XML, FFSX apply/remap, graph axis schema, export geometry, FSM mutation contract, FastFigureApi method contract가 Source Script에 충분히 닫혀 있지 않다.
- editing, layoutMapWidth, asset reference cascade 등은 통합/제거 검토가 필요하다.

## 선택 이유

현재 단계에서 pseudocode를 작성하면 누락된 의미를 pseudocode가 새로 결정하게 된다.

개발 정책의 단계 경계를 지키려면 source code를 먼저 수정하거나 pseudocode에서 빈칸을 채우지 않고 Source Script에서 의미 충돌과 누락을 먼저 닫아야 한다.

## 고려했지만 선택하지 않은 방향

### 현재 구현을 그대로 정답으로 간주하고 Source Script만 더 상세화

선택하지 않았다. grid 축소와 shared chart reset처럼 현재 구현 내부 규칙 자체가 충돌하는 사례가 확인되었다.

### 바로 source code 수정

선택하지 않았다. chart cardinality, caption ownership, label preview, export settings persistence 등은 먼저 Source Script 단계에서 의미를 확정해야 한다.

### 현재 Source Script 상태에서 pseudocode 병행

선택하지 않았다. pseudocode가 새로운 설계 결정을 담당하게 된다.

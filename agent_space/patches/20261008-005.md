# 20261008-005 — Initial PlusCal selection translation

## Purpose
Start the required PlusCal pseudocode layer using the already defined selection event ordering in Source Script application_fsm.py.

## Scope
pseudocode/application_fsm.pcal represents a bounded module of the existing FSM: CSV selection, graph-object selection, image selection, clear operations. It uses one authoritative asset-selection pair, and graphObjectIndex only. It never writes chart object csvId or slot imageId.

## Translation and responsibility
- ClearObjectForCsv precedes SelectCsvAsset in both UI entry points.
- Object selection resolves ObjectCsv[index] as a reference input, applies the same CSV choice, and finally selects index.
- Image selection does not execute a slot mutation.
- Constant collections model externally validated VFS/chart references; they are not additional application authority.

## Not claimed
This is a partial language-neutral pseudocode, not yet a complete translation of application_fsm.py or the source modules. It does not cover connection commit, failure handling, lifecycle or project replacement. No TLC verification or code-generation claim. Existing markdown pseudocode is historical reference only.

## Rejected alternatives
Creating a second editor CSV selection state or storing a copy of each object's CSV as user selection. Both contradict the single runtime selection contract.

# 20260911-018 — audit Mantine ownership cutover

## 목적
legacy UI markup을 제거할 수 있도록 `auditApp()`이 old controls/panels를 필수 UI로 간주하는 검사를 제거한다.

## 변경
- audit의 required DOM 검사를 `dashboard`, `dashboardCaption`, `graphArea`, `readmeContent`로 한정한다.
- legacy layout/label/caption/print panel visibility, old toggle highlight, dashboard popup CSS class, legacy README dialog open 여부 검사를 제거한다.

## 근거
generic UI ownership은 Mantine으로 이전됐고, core가 직접 요구하는 DOM은 renderer/content root뿐이다. old UI의 존재 여부를 audit invariant로 유지하면 single-Mantine cutover를 방해한다.

## WIP
기존 `REQUIRED_CONTROL_IDS` 상수 정의는 이번 패치에서 즉시 삭제하지 않는다. audit 참조를 먼저 끊은 뒤 다음 dead-code 패치에서 제거한다.

## 제외
프로젝트/FFPX/FFSX/Plotly 검증과 FSM/model invariant 검사는 유지한다.

## 검증
workflow patch check, JS syntax, portable build, split/portable smoke.

## 롤백
이 패치를 되돌리면 audit가 다시 legacy UI DOM 동기화를 요구한다.

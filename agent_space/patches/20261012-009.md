# 20261012-009 — Rewrite core r13 pseudocode in valid PlusCal P-syntax

## Purpose
Remove non-PlusCal constructs from the first-pass pseudocode and align the critical FSM/renderer/UI modules with the syntax style already used by repository verification models.

## Corrections
- Replace JavaScript-style try/catch with PlusCal nondeterministic success/failure lifecycle branches.
- Remove labels from with-statement bodies and avoid reassignment of bound with identifiers.
- Use procedure local variables for resolved references/candidates.
- Add explicit SetSelectedSlot, SwapSlotContents, and PrepareDashboardFileDrop procedures matching Source Script function responsibility.
- Preserve candidate-first mutation and UI-local/project-authority separation.

## Basis
PlusCal procedure bodies begin with labels; with bodies cannot contain labeled statements. The repository's existing verification PlusCal/TLA files use the same P-syntax conventions.

## Rejected
Keeping C-like pseudocode that is not legal PlusCal merely because its intent is understandable; changing Source Script semantics to simplify syntax.

## Remaining
Other .pcal modules still need the same syntax pass. This patch does not claim successful PlusCal translation/tool execution or TLC verification.

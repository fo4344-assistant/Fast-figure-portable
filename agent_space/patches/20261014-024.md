- FastFigureSlotCore에서 project mutation과 selectedSlotId reconciliation을 분리한다.
- swap은 project commit에서 selection을 직접 변경하지 않고 result hint를 남긴 뒤 별도 interface reconciliation이 처리한다.
- grid/merge/split 후 interface reconciliation 경계를 모델링하고 pending 동안만 transient invalid selection을 허용한다.

## 선택 이유

새 Source Script의 핵심은 같은 observable command를 두 state machine transition으로 분리하는 것이다. 따라서 기존 결과 invariant만 재사용하면 owner isolation을 검증하지 못한다. 실제 project commit과 interface reconciliation 사이의 불변 관계를 executable model에 넣는다.

## 기각한 방향

- EFSM/UI-FSM 분리를 문서 assertion만으로 처리하고 executable model은 그대로 유지.
- selectedSlotId를 ProjectObject field로 넣어 swap과 함께 원자 commit.
- interface reconciliation을 renderer 단계에서 대신 수행.
- 두 authority를 복사해 equality invariant로 동기화.

# 20261002-017 — graph font remount regression boundary

## 목적과 변경 내용

20261002-016에서 graph workspace 재구성을 검증하기 위해 slot을 해제 후 재선택하도록 했지만,
두 event를 같은 동기 tick에 연속 실행해 React가 중간 project workspace를 실제로 렌더하지 못했다.

`api.slots.select(null)` 뒤에 한 번의 event-loop render boundary를 두고,
그 다음 기존 slot을 다시 선택하도록 browser regression 19번만 수정한다.

application source와 source-code revision/fingerprint는 변경하지 않는다.

## 이 방향을 선택한 이유

검사의 목적은 custom graph font를 저장한 뒤 graph editor를 새로 구성했을 때
`기존: ...` option이 재생성되는지 확인하는 것이다.

두 selection command를 React render 전에 모두 실행하면 최종 snapshot만 관찰될 수 있어
component unmount/remount를 보장하지 않는다.

따라서 source를 변경하지 않고 검사에서 실제 재구성 조건을 먼저 성립시킨다.

## 고려했지만 선택하지 않은 다른 방향

### 임의로 긴 sleep 추가

필요한 것은 시간 지연 자체가 아니라 두 workspace state 사이의 render boundary다.
0ms event-loop boundary로 목적을 명시적으로 표현한다.

### graph Select에 key를 추가해 강제 remount

현재 실패만으로 실제 UI에 그러한 workaround가 필요하다는 근거가 없다.
테스트가 먼저 의도한 상태 전이를 정확히 수행해야 한다.

## 검증

browser regression 19번이 inline/split artifact 모두에서 통과해야 한다.

# 20260911-023 — legacy required-control contract removal

## 목적
020에서 audit가 renderer/content root만 직접 검사하도록 바뀌었으므로, old UI control ID 전체를 나열하던 `REQUIRED_CONTROL_IDS` 계약을 제거한다.

## 변경
- 121줄의 `REQUIRED_CONTROL_IDS` 상수 전체 제거.

## 근거
기존 header/sidebar/graph form/overlay/debug controls는 더 이상 UI compatibility target이 아니다. dead 목록을 유지하면 single-Mantine ownership과 코드 의미가 불일치한다.

## 유지
- renderer root 존재 검사는 `auditApp()`에 직접 유지된다.
- model/FSM/file-format 검증은 유지된다.
- FFPX/FFSX/Plotly 계층은 변경하지 않는다.

## 검증
workflow patch check, JS syntax, portable build, split/portable smoke.

## 롤백
이 패치만 되돌리면 dead constant 정의만 복구된다.

# 20261015-004 — Plan 016 PlusCal system boundary translation (WIP)

## 목적과 변경 내용

닫힌 Source Script r25의 Backend / Application boundary / Frontend / Portable build 의미 hierarchy를 `pseudocode/system.pcal`의 system initialization에 반영하기 시작한다.

- 기존 모든 책임을 direct sibling으로 보는 오래된 설명을 새 hierarchy로 변경했다.
- Frontend renderer의 `activeProject` 직접 읽기를 없애고, Application boundary의 Backend renderer read projection과 Frontend state projection을 전달하도록 했다.
- slot controller에 Application public action surface를 제공하도록 표현했다.
- lifecycle ready 전환은 renderer의 직접 FSM 호출 대신 Application-boundary event로 전달하도록 표현했다.

## 방향 선택 근거

System-level initialization에서 Backend state의 유일한 권위는 유지하면서 renderer에 immutable read projection을 전달해야 한다. 기존 direct `RenderDashboardFrom(activeProject)`는 plan-016의 계층 경계를 위반하므로 제거했다.

## 고려했지만 선택하지 않은 방향

- Renderer에 Backend `activeProject`를 read-only로 넘기는 방식: direct dependency이므로 기각.
- Frontend용 별도 ProjectObject store 생성: 중복 authority이므로 기각.
- Portable build를 Backend/Frontend 자식으로 편입: Source Script r25 hierarchy와 달라 기각.
- 이번 한 파일 변경을 전체 PlusCal r11 완료로 간주: 나머지 module 번역과 검증이 끝나지 않아 기각.

# 20261001-011 — Source Script r2 project invariant 정규화

## 변경 원인

plan-008 Phase 1에 따라 current source code의 특수 상태를 Source Script 규칙으로 승격하지 않고 project-level invariant를 먼저 정규화한다.

## 의미 변경

- editable chart의 zero-object 상태를 유효한 empty graph로 정의
- protected/default CSV를 project invariant에서 제거
- chart는 정확히 하나의 slot이 소유하는 1:1 topology로 정의
- slot caption을 graph/image renderable content와 분리된 annotation으로 정의
- UI caption placeholder는 authoritative state에 저장하지 않음
- export settings를 persistent project state로 추가
- project initialization이 default CSV 없이 valid state를 직접 생성하도록 정의
- source code를 권위 원천이 아니라 검증 자료로 재분류

## 선택 이유

빈 graph를 직접 표현하면 default CSV의 보호/삭제/충돌/remap 예외가 필요하지 않다.
chart ownership을 1:1로 정하면 current FFPX의 slot-local chart document 구조와 reference topology가 일치한다.
caption은 현재 storage grouping이 아니라 의미에 따라 annotation으로 분리하는 편이 operation semantics를 별도로 검토할 수 있다.
README가 export settings를 persistent project state로 명시하므로 구현 누락을 이유로 계약을 제거하지 않는다.

## 기각한 대안

- default CSV 유지: 동일 기능을 더 많은 특수 규칙으로 표현하므로 기각
- shared chart clone normalization: malformed topology를 자동으로 다른 identity로 바꾸므로 기각
- caption을 현재 slot.content 전체와 동일시: placeholder 저장이 semantic ownership을 왜곡하므로 기각
- export settings 비영속화: README/FFPX 공개 계약을 구현 현황에 맞춰 축소하므로 기각

## 닫힘 판정 영향

project state의 empty state, chart topology, export persistence는 닫혔다.
다만 caption의 swap/merge/split/reset 이동 규칙, editing, layoutMapWidth는 아직 미확정/검토 항목이므로 Source Script closure는 open 상태다.

## 하위 단계 전파 범위

- default CSV와 관련 예외 제거
- zero-object chart 지원
- whole-project validator에 chart 1:1 ownership 추가
- persistent export settings 저장/복원
- slot caption placeholder를 UI projection으로 이동
- malformed shared/orphan chart 거부

현재 pseudocode/source code는 수정하지 않는다.

# 20261001-020 — Source Script r11 caption file 책임 중복 제거

## 변경 원인

r10 closure review에서 FFPX document responsibility를 교차 검토했다.

r5에서 slot caption의 authoritative owner를 slot object로 확정했고
`slots/slot-<id>.xml`도 이미 slot-local caption을 저장한다고 명시했지만,
`caption/caption.xml` 설명에 여전히 global/slot caption configuration이라는 이전 책임이 남아 있었다.

## 의미 변경

- `caption/caption.xml`은 project-level global caption configuration만 담당한다.
- slot-local caption은 각 `slots/slot-<id>.xml`에만 저장한다.

새 caption 기능이나 데이터는 추가하지 않는다.

## 선택 이유

같은 slot caption을 global caption document와 slot document가 동시에 책임지면
어느 문서가 authoritative한지와 roundtrip conflict 해결 규칙을 추가로 만들어야 한다.

slot-local property는 slot document에, project-global property는 caption document에 둠으로써
ownership과 file-format responsibility를 동일하게 맞춘다.

## 기존 안을 채택하지 않은 기록

### caption/caption.xml에도 slot caption을 복제

채택하지 않는다.

중복 serialized authority가 생기며 두 값이 다를 때 우선순위를 별도로 정해야 한다.
사용자가 확정한 slot-local ownership에도 맞지 않는다.

## 닫힘 판정 영향

FFPX caption document responsibility의 마지막 중복 표현을 제거했다.
r11은 전체 closure review 전까지 current/open이다.

## 하위 단계 전파 범위

FFPX writer/reader에서:

- global caption은 caption/caption.xml
- slot caption은 slot-<id>.xml

로 단일 책임을 유지해야 한다.

# 20261014-027 — Include project-command ownership in bounded Slot Core TLC

## 원인

`verification/FastFigureSlotCore.cfg`에는 `ProjectCommandOwnershipInvariantSpec`가 등록되어 있었지만,
push-trigger workflow는 `.github/tlc/FastFigureSlotCore2x2.cfg`를 사용한다.
따라서 기존 Slot Core run은 새 ownership invariant를 실제로 검사하지 않았다.

## 변경

- bounded 2x2 TLC config에 `INVARIANT ProjectCommandOwnershipInvariantSpec`를 추가한다.
- verification TLA/CFG 의미 파일 자체는 변경하지 않으므로 verification revision/fingerprint/lineage는 유지한다.
- 이 push 이후 새 Slot Core TLC run의 결과만 r23 validation 근거로 사용한다.

## 선택 이유

검증하려는 property는 이미 current verification model에 정의되어 있다.
누락된 실행 harness의 invariant 선택만 보완하는 것이 최소 변경이다.

## 기각

- 기존 run을 그대로 passed로 인정: ownership invariant가 실행되지 않았다.
- verification model에 동일 invariant를 중복 정의: 같은 property를 복제한다.
- workflow에 별도 ad-hoc assertion을 추가: TLC config가 invariant 선택의 자연스러운 위치다.

# 20261016-006

## 목적과 변경 이유

사용자의 명시적 요청에 따라 `agent_space/policies/source-script-policy.md`를 `agent_space/policies/development-policy.md`로 이름 변경한다. 정책 본문과 v0.2.6의 의미는 변경하지 않는다.

현재 정책 원천을 가리키는 `agent_space/AGENT.md`, 정책 색인, 활성 `plan-016.md`의 링크와 development-layer-version workflow의 정책 변경 감시 경로를 함께 갱신한다. 정책을 둘 이상의 경로에 계속 복제해 두는 방식은 중복 원천이 되므로 배제했다.

## 실제 누적 patch

- 시작 HEAD: `427bdddd6d691c4ccbfbb7eeb2d4af461d233c06`.
- 종료 HEAD: `1bff48b9d3adf9ae547fa78b8f2392a6bb74b9e3`.
- 생성 명령: `git diff --find-renames --binary 427bdddd6d691c4ccbfbb7eeb2d4af461d233c06 1bff48b9d3adf9ae547fa78b8f2392a6bb74b9e3`.
- GitHub Contents API로 새 경로 생성 → 현재 링크 변경 → 이전 경로 삭제를 순차 수행했다. 각 write 직전 HEAD와 대상 blob SHA/새 경로 부재를 확인했다. 삭제 전 새/이전 파일의 remote blob SHA가 정확히 동일함을 확인했다. Git diff도 본문 변경 없는 100% rename으로 인식한다.
- 파일별 commit이므로 rename/link 갱신은 atomic하지 않았다. 일시적인 두 경로는 이전 경로 삭제로 해소했다. 실제 누적 patch가 rollback 범위이며, 이 patch/설명 쌍 자체는 종료 HEAD 이후 별도로 기록한다.

## 제외와 검증 범위

- 과거 plan/review/patch의 당시 정책 경로 기록과 Source Script의 기존 provenance 주석은 소급 변경하지 않았다. 기존 `source-script-policy.md` 경로 기록은 이름 변경 전의 동일한 정책을 가리키며 현재 경로는 `development-policy.md`이다.
- Source Script 의미, PlusCal, application source 및 development layer fingerprint/revision은 변경하지 않았다. 파일명 변경을 이유로 의미 계층을 불필요하게 개정하는 대안은 배제했다.
- 확인한 사항은 remote blob 동일성, 최종 Git rename diff, 현재 링크와 workflow 경로다. 애플리케이션 테스트·빌드·TLC를 실행하거나 통과했다고 주장하지 않는다. 정책/워크플로 파일의 정상 commit에 따른 자동 CI는 별개이며, 이를 위해 빈 commit 또는 무관한 변경을 만들지 않았다.

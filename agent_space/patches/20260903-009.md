# 20260903-009 — DOM-free workspace callback 단독 준비

## 상태

`20260903-007`은 hunk count 오류, `008`은 current workspace context 불일치로 실패했으며 둘 다 HTML에는 적용되지 않았다.

현재 GitHub connector가 대형 `Fast-figure.html`의 해당 line range를 반환하지 않아 active workspace wrapper 본문을 추측해서 계속 수정하지 않는다.

## 목적

Mantine shell cutover에서 사용할 DOM-free workspace callback을 **기존 legacy wrapper를 수정하지 않고** 독립적으로 준비한다.

## 변경 내용

- 앱 버전 `1.1.107-alpha` → `1.1.108-alpha`
- `syncProjectWorkspaceDomainState()` 추가
  - workspace availability / README-close policy
  - active CSV 정규화
  - active image 정규화
- `syncGraphWorkspaceDomainState()` 추가
  - selected slot 확인
  - availability policy
  - chart 변경 시 `selectChartForEditing()`
  - active CSV 정규화
- `syncImageWorkspaceDomainState()` 추가
  - selected slot 확인
  - availability policy
  - selected image → `activeImageId` 정규화
- `exitGraphWorkspaceDomainState()` 추가
  - selected graph object transient reset

이번 patch에서는 기존 `syncProjectWorkspaceState`, `syncGraphWorkspaceState`, `syncImageWorkspaceState`, `exitGraphWorkspaceState`를 전혀 수정하지 않는다.

## 이 방향을 선택한 이유

현재 active legacy UI를 유지하는 동안 새 helper가 호출되지 않아도 된다. 중요한 것은 cutover 시 EFSM callback이 native DOM을 요구하지 않는 경로를 미리 확보하는 것이다.

현재 source context를 정확히 얻지 못하는 상황에서 오래된 wrapper 본문을 추측 패치하는 것보다, 이미 검증된 domain helper들을 안정적인 application-code anchor 근처에 독립 정의하는 편이 회귀 위험과 patch 실패 가능성이 훨씬 낮다.

## 고려했지만 선택하지 않은 방향

### legacy wrapper를 계속 추측해서 수정

기각. `005/008`의 context mismatch가 반복됐다.

### helper와 wrapper가 잠시 같은 로직을 갖는 문제 때문에 helper 추가 자체를 미룸

기각. helper는 현재 호출되지 않는 cutover staging 경계이며 영속 상태를 복제하지 않는다. 실제 ownership 전환 시 legacy wrapper가 제거되므로 장기 duplicate authority가 아니다.

### React effect에서 동일 작업 구현

기각. workspace EFSM과 React lifecycle이 같은 transient/domain 의미를 중복 소유하게 된다.

## source of truth

새 helper는 기존 `appFSM.state`, project model, `editing`, `activeCsvId`, `activeImageId`, `selectedObjectIndex`만 변경/조회한다. 별도 state나 cache를 만들지 않는다.

## 회귀 위험

매우 낮음. 함수 정의만 추가하고 기존 active call graph를 바꾸지 않는다.

## 검증

- `git apply --check`
- `git diff --check`
- application JavaScript `node --check`
- helper 내부 native DOM `$()`/`document` 접근 없음
- file schema / Plotly renderer / EFSM definitions 변경 없음

## rollback

네 helper와 버전 문자열만 제거한다.

## 후속

lifecycle/overlay도 동일하게 domain-only helper를 먼저 준비한다. 그 뒤 실제 cutover patch에서 React shell mount, EFSM callback 전환, legacy renderer 제거를 하나의 일관된 ownership 변경으로 수행한다.

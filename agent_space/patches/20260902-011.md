# 20260902-011 — Mantine graph 축 sidebar 연결 재시도

## 배경

`20260902-010`은 `Check and apply patch` 단계에서 실패했다. 009가 이미 성공적으로 적용되어 공통 축 컴포넌트와 JavaScript 구문은 검증되었으므로 010의 실패 기록은 그대로 보존한다.

010은 sidebar Mantine destructuring을 단일 행 hunk로 교체했으며, 009의 대규모 삽입으로 이동한 실제 줄 위치에 지나치게 의존했다. 011은 동일 기능을 주변 문맥이 포함된 unified diff로 다시 표현한다.

## 목적

009의 `FastFigureGraphAxisStaging`을 inactive Mantine sidebar에 연결한다. 기능 의미는 010과 동일하며 새로운 domain/EFSM 변경은 없다.

앱 버전은 현재 `1.1.59-alpha`에서 `1.1.60-alpha`로 올린다.

## 변경 범위

- `FastFigureSidebarStaging`의 Mantine destructuring에 `Accordion` 추가
- 기존 `그래프 전역 설정` 뒤에 `그래프 축 설정` Accordion 추가
- xBottom/xTop/yLeft/yRight를 같은 공통 컴포넌트로 `.map()` 렌더링

## 010과의 차이

코드 의미는 동일하다. 패치 위치 식별만 다음처럼 강화한다.

- Mantine destructuring hunk에 `if (!runtime)`, `let { React, MantineCore }`, `slot`, `workspace` 주변 문맥 포함
- 축 block 삽입 hunk에 기존 graph global staging의 종료부와 `선택` section 시작부 문맥 포함

## source of truth

축 persisted source는 selected chart의 `editor.globalSettings.axes` 하나뿐이다. Accordion은 표시/접기 상태만 담당하고 축 상태를 복제하지 않는다.

## Core/EFSM 판정

변경하지 않는다.

- graph/domain 데이터 구조
- graph object EFSM
- action/event/guard
- Plotly renderer
- 축 계산 알고리즘
- import/export
- 활성 legacy UI

## rollback

1. 그래프 축 Accordion block 제거
2. sidebar destructuring의 `Accordion` 제거
3. 앱 버전을 `1.1.59-alpha`로 복원

009는 독립적으로 유지 또는 롤백 가능하다.

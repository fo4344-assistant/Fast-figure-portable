# 20260901-009 — Annotation visibility와 Label reset 계약 분리

## 목적

`plan-003.md` Commit B에서 Label staging을 구성하기 전에 남아 있는 두 mutation 경계를 DOM에서 분리합니다. 대상은 label/caption 표시 토글과 label 위치 초기화입니다. 기존 EFSM event 이름과 legacy UI 동작은 유지합니다.

## 변경 내용

- 애플리케이션 버전을 `1.1.39-alpha`로 갱신합니다.
- `applyAnnotationVisibilityFromValues(kind, enabled)`를 추가합니다.
  - `label`과 `caption`만 허용합니다.
  - project annotation enabled 상태를 갱신합니다.
  - 기존 dashboard render, debug log, `ANNOTATION_VISIBILITY_CHANGED` notify를 유지합니다.
  - DOM button 상태는 변경하지 않습니다.
- 기존 `setAnnotationEnabled(kind, enabled)`는 위 mutation을 호출한 뒤 legacy toggle UI만 동기화하는 adapter로 축소합니다.
- Label position mutation의 공통 부분을 `commitLabelPosition(values, event, debugEvent)`로 모읍니다.
- `applyLabelPositionFromValues(values)`는 공통 helper를 이용해 기존 `LABEL_POSITION_CHANGED` event를 유지합니다.
- `resetLabelPositionFromValues()`는 `{x: 0, y: 0}`을 같은 경로에 전달하되 기존 `LABEL_POSITION_RESET` event와 `annotation:label-position-reset` log를 유지합니다.
- legacy `labelPositionReset` handler는 직접 mutation하지 않고 `resetLabelPositionFromValues()`를 호출합니다.
- `fastFigureUiBridge`에 `setAnnotationEnabled(kind, enabled)`와 `resetLabelPosition()`을 노출합니다.

## 구현 원칙

표시 여부의 project/domain mutation과 legacy button의 `dataset/class/aria` 동기화를 분리합니다. 따라서 Mantine staging은 legacy DOM button을 건드리지 않고 project 상태와 EFSM notify 경로만 사용할 수 있습니다.

Label position의 일반 변경과 reset은 renderer side effect가 동일하므로 이를 하나의 내부 helper로 통합하되, event와 debug 의미는 기존대로 구분합니다. 같은 자유도와 동작을 유지하면서 중복 구현을 줄이는 방향입니다.

## 변경하지 않는 항목

- label preview drag renderer
- pointer capture와 drag constraint
- label format/order/font renderer
- caption 설정 mutation
- 활성 UI ownership

## 검증 기준

- patch target은 `Fast-figure.html` 하나뿐이어야 합니다.
- `git apply --check`, `git diff --check`, main inline JavaScript `node --check`를 통과해야 합니다.
- legacy label/caption toggle은 이전과 동일하게 button 표시와 project 상태를 함께 갱신해야 합니다.
- bridge visibility 경로는 DOM ID/class/dataset을 참조하지 않아야 합니다.
- label reset은 여전히 `LABEL_POSITION_RESET`, 일반 position 변경은 `LABEL_POSITION_CHANGED`를 발생시켜야 합니다.

## 후속 작업

다음 커밋에서 `FastFigureLabelModalStaging`을 추가합니다. 일반 form control은 Mantine가 소유하고, label preview/drag는 domain renderer로 유지하는 경계를 따릅니다.

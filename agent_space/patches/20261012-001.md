# 20261012-001 — Close Source Script interaction ownership gaps

## Purpose
Resolve open logical-structure findings before Source Script r13 closure: selection failure atomicity, bookmark click/drag ownership, dashboard file-drop responsibility, and module hierarchy.

## Changes
- Resolve all CSV/image/object references before any runtime selection mutation; failed resolution preserves prior selection.
- Content-slot body does not select a graph/image slot. Bookmark click selects/toggles; bookmark drag moves slot-local payload. Empty slot surface remains selectable because it has no graph/image interaction.
- External file drop is split into target/runtime preparation, frontend collision/lifecycle orchestration, and assets.importToSlot persistent commit.
- system.py is the semantic root with the eight responsibility modules as siblings; imports among siblings do not imply hierarchy.
- Resolved decisions are recorded in system.py; no duplicate authority or new runtime state is introduced.

## Rejected alternatives
- Clear selection before validating the requested CSV/object/image.
- Use graph/image body click for non-selected content slots.
- Treat bookmark drag as a selection transition.
- Let prepareFileDrop or finishFileDrop commit asset/domain state.
- Infer module parent/child structure from imports.

## Downstream
This patch changes Source Script only. PlusCal pseudocode and JavaScript implementation must be updated only after the r13 closure review confirms these decisions.

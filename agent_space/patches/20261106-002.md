## 선택 이유·기각 대안

Source Adapter와 PlusCal InvalidRequestBeforeTask/OneOuterTaskBinding을 그대로 따른다. 특정 UI만 방어하면 direct API 호출의 불일치가 남는다. 빈 입력을 public task 전에 반환하는 최적화는 public busy 규칙을 우회한다. child helper마다 lifecycle을 추가하면 중첩/self-rejection을 만든다. 새 task manager, cache, rollback, 광범위한 리팩터링은 기존 명세를 옮기는 데 필요하지 않다. 테스트 확장 자체를 목적 삼지 않고 기존 책임 경계 사례만 보강했다.

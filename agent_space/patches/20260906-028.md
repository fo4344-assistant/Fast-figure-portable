# 20260906-028

## 목적

새 폴더 생성 기능을 축소하지 않고 기존 `window.prompt` UI를 Mantine 입력 Modal로 교체할 수 있는 공통 text-input dialog 경계를 추가합니다.

## 변경 내용

- 재사용 가능한 `FastFigureTextInputModalStaging`을 추가합니다.
  - Mantine `Modal`, `TextInput`, `Button`, `Group`, `Stack`, `Text`를 사용합니다.
  - 입력 draft는 Modal 내부 React local state에만 보관하며 project/model의 source of truth가 되지 않습니다.
  - Enter 제출, 취소, Escape/outside-click/focus lifecycle은 Mantine에 맡깁니다.
- 폴더 생성을 다음 세 책임으로 분리합니다.
  - `createAssetDirectoryInputModel()`: parent와 UI descriptor 계산
  - `createAssetDirectoryFromValue()`: 기존 FSM command 실행
  - `createAssetDirectory()`: 현재 legacy UI가 남아 있는 동안만 사용하는 `window.prompt` adapter
- Mantine sidebar의 직접 `새 폴더` 버튼과 asset action menu의 `create-directory` 작업은 모두 같은 input descriptor/command를 사용합니다.
- 앱 빌드를 `1.1.132-alpha`로 올립니다.

## 기능 보존

기존 폴더 생성 기능의 다음 의미를 그대로 유지합니다.

- 선택 디렉터리가 `/assets` 계층이 아니면 `/assets`를 parent로 사용합니다.
- 기본 입력값은 `New Folder`입니다.
- 이름/path 정규화와 중복 검사는 기존 `PROJECT_DIRECTORY_CREATED` FSM action을 그대로 사용합니다.
- 성공 시 생성된 디렉터리를 선택하고 기존 성공 status를 표시합니다.
- 오류 시 기존 `폴더 생성 오류: ...` status를 표시합니다.
- 사용자는 입력 Modal을 취소할 수 있으며 이때 model/FSM mutation은 없습니다.

FFPX/FFSX schema, VFS 규칙, EFSM transition 정의는 변경하지 않습니다.

## 선택 이유

`window.prompt`를 삭제만 하면 폴더 이름을 지정하는 편집 자유도가 사라지므로 기능 축소입니다. 반대로 Mantine text-input dialog라는 상위 UI로 통합하면 같은 입력 기능을 유지하면서 크기, focus, Escape, outside-click, 버튼 배치 규칙을 공통화할 수 있습니다.

또한 이름 정규화와 경로 검증을 React에 복제하지 않고 기존 FSM action에 맡겨 source of truth를 하나로 유지합니다.

## 고려했지만 선택하지 않은 방향

### 고정 이름으로 즉시 폴더 생성

기존 이름 지정 기능을 제거하므로 기각했습니다.

### legacy prompt를 Mantine 버튼에서 그대로 호출

UI lifecycle이 브라우저 native dialog에 남아 Mantine 전환 목적을 달성하지 못하므로 기각했습니다.

### React에서 이름/path validation 재구현

FSM validation과 이중 source가 되므로 기각했습니다.

### 폴더 생성 전용 bespoke popup 작성

다른 문자열 입력 작업과 규칙을 공유하기 어렵고 Mantine 사용 목적에 반하므로 범용 text-input Modal로 구성합니다.

## 위험 요소

- asset action menu에서 dialog를 연 뒤 선택이 바뀌어도 최초 parent가 바뀌지 않도록 dialog descriptor에 parent/context를 함께 고정합니다.
- domain command 오류가 발생해도 기존처럼 status로 전달하며, 입력 dialog 자체는 제출 후 닫힙니다.

## 후속 작업

공통 confirmation Modal에 슬롯 초기화와 참조 중 자산 삭제를 연결하고, 남은 native `window.confirm`/`window.alert`/`window.prompt` 경로를 기능별로 Mantine generic dialog로 이관합니다. 대응 legacy UI는 기능 이관이 완료된 순서대로 제거합니다.

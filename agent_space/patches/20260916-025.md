# 20260916-025 — legacy help-popup ownership removal

## 목적과 변경 내용

삭제된 native form의 도움말 버튼을 위해 남아 있던 legacy help-popup JavaScript와 CSS를 하나의 ownership 단위로 제거한다.

변경 내용:
- 무호출 `installHelpPopups()` 제거
- `.help` 및 `.help-popup` CSS 제거
- centralized palette selector의 `.help/.help-popup` 항목 제거
- `.help-popup` shadow override 제거

## 선택 이유

current HTML에서 `.help` markup consumer가 사라졌고 `installHelpPopups()` 역시 정의 외 호출이 없다. 이 경로는 UI 설명 popup lifecycle을 직접 소유하던 legacy frontend 구현이며 backend/core, logic EFSM, renderer와 무관하다.

JavaScript와 CSS를 따로 남기면 더 이상 존재하지 않는 UI lifecycle의 잔여 ownership이 남으므로 같은 패치에서 닫는다.

## 선택하지 않은 방향

- Mantine에 별도 compatibility help bridge를 만들지 않는다.
- `.hidden`, status/debug, readme, dashboard/layout CSS는 변경하지 않는다.
- logic EFSM, ProjectObject, functional commands에는 변경을 가하지 않는다.

## 전제 / 후속 작업 / 누락

- 앞으로 도움말 UI가 필요하면 Mantine component가 자체 UI lifecycle로 구현하되 domain SoT와 분리해야 한다.
- rollback은 이 패치를 되돌리면 help-popup implementation과 CSS가 함께 복구된다.

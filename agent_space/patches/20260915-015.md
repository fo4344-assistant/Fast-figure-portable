# 20260915-015 — Remove native label editor and preview CSS

## Purpose
Continue the validated annotation cleanup after `20260915-014` by removing CSS used only by the deleted native label editor and its native preview surface.

## Exact changes
Remove native-only label editor/preview selectors from `Fast-figure.html`, including:

- `.label-settings`
- `.label-setting-fields`
- `.label-preview`
- `.label-preview-slot`
- `.label-preview-slot::after`
- `.label-preview-label`
- `.label-preview-label.dragging`
- `.label-format-setting`
- `.label-position-readout`
- `.label-position-reset`

Preserve the following:

- active Mantine `FastFigureLabelOverlay` rendering and interaction
- actual dashboard `.slot-label` rendering
- layout controls and layout geometry styles following the removed block
- print/export styles preceding the removed block

## Patch construction
The patch was generated from the exact current `Fast-figure.html` excerpt after `20260915-014`, with unified-diff hunk counts/positions calculated automatically rather than manually reconstructed. The generated patch was checked with `git apply --check` against a synthetic file preserving the current source lines and repository line positions before queueing.

## Why this direction
`20260915-008` removed the dead native label editor JavaScript and the active editor/preview is Mantine-owned. The corresponding native markup is absent. These CSS rules therefore have no live owner and retaining them would obscure later legacy audits.

## Rejected alternatives
- Remove actual dashboard `.slot-label` styles: rejected because they render figure output rather than editor chrome.
- Remove layout or print/export CSS in the same patch: rejected because those are separate ownership areas and require their own audits.
- Keep native preview CSS as compatibility styling: rejected because there is no corresponding live native preview DOM and compatibility styling would preserve a false ownership boundary.

## Source of truth
No state ownership changes. `activeProject.annotations.labels` remains authoritative; Mantine owns label editing/preview UI; `renderDashboard()` owns actual figure labels.

## EFSM/core impact
None intended. No JavaScript, UI-FSM/EFSM transition, project schema, persistence, renderer geometry, or export behavior is changed.

## Validation
Use the standard Fast Figure patch workflow: patch check/apply, JavaScript syntax checks, portable HTML build, split/portable Chromium `file://` smoke tests, then inspect CSS to confirm native label editor/preview selectors are gone while actual `.slot-label`, layout, and print/export styles remain.

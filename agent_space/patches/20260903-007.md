# 20260903-007 — workspace domain sync / legacy presentation 분리

## 목적

`006`에서 `updateFileAvailability(model)` 입력 경계를 준비했다. 이번 patch는 project / graph / image workspace entry에서 domain/transient synchronization과 legacy native UI synchronization을 명시적으로 분리한다.

아직 `APP_STATE_DEFINITIONS`의 entry/update callback은 기존 `sync*WorkspaceState()` wrapper를 사용하므로 active legacy UI의 동작은 바뀌지 않는다.

## 변경 내용

- 앱 버전 `1.1.107-alpha` → `1.1.108-alpha`
- `syncProjectWorkspaceDomainState()` 추가
  - availability/README-close policy 실행
  - active CSV 정규화
  - active image 정규화
- `syncGraphWorkspaceDomainState()` 추가
  - selected slot 확인
  - availability/README-close policy 실행
  - chart 변경 시 `selectChartForEditing()` 호출
  - active CSV 정규화
- `syncImageWorkspaceDomainState()` 추가
  - selected slot 확인
  - availability/README-close policy 실행
  - selected slot의 image를 `activeImageId`로 정규화
- `exitGraphWorkspaceDomainState()` 추가
  - `selectedObjectIndex = null`만 담당
- 기존 `syncProjectWorkspaceState`, `syncGraphWorkspaceState`, `syncImageWorkspaceState`, `exitGraphWorkspaceState`는 domain 결과를 받아 native presentation을 수행

## 의미 보존

### project workspace
기존 `updateFileAvailability()`, `refreshCsvControls()`, `refreshImageControls()`에서 수행하던 domain 의미는 먼저 domain helper에서 실행한다. legacy button/menu/preview/tree/form synchronization은 wrapper에 남긴다.

### graph workspace
기존 `editChart(slot.chart)`는 `001/002`에서 selection과 presentation으로 이미 분리됐다. 이번에는 workspace domain helper가 `selectChartForEditing()`을 호출하고 wrapper가 `syncLegacyGraphEditorSelection()`을 호출한다. 호출 순서는 기존 의미와 동일하다.

### image workspace
active image selection은 domain helper가 처리하고 native `insertEmptyImage` disabled 표시는 wrapper가 처리한다.

### graph exit
selected graph-object transient reset은 domain helper로 이동하고 native `buildBox` 숨김은 wrapper에 남긴다.

## 이 방향을 선택한 이유

Mantine cutover 시 EFSM workspace callback은 DOM-free helper만 사용해야 한다. 그러나 현재 active legacy UI를 유지하는 동안에는 native form/tree/preview도 계속 갱신되어야 한다. 두 책임을 분리한 wrapper 구조가 가장 작은 단계적 전환이다.

## 고려했지만 선택하지 않은 방향

- 지금 바로 EFSM callback을 domain helper로 교체하지 않는다. legacy active UI가 갱신되지 않게 된다.
- React effect가 workspace transient state를 별도로 계산하지 않는다. EFSM과 React lifecycle이 이중 owner가 된다.
- `if (mantineMounted)` 같은 구현 분기를 workspace callback에 넣지 않는다.

## source of truth

- workspace/slot/overlay: `appFSM.state`
- chart/CSV/image: project model
- editing/activeCsvId/activeImageId/selectedObjectIndex: 기존 transient state
- 반환되는 helper object는 한 callback 실행 동안만 쓰는 임시값이며 authority가 아니다.

## 회귀 위험

중간 수준. 함수 내부 책임을 이동하지만 기존 wrapper 외부 동작은 유지되어야 한다.

## 후속

lifecycle/overlay entry를 같은 방식으로 domain policy와 legacy renderer로 분리한다. 그 뒤 active React shell mount와 EFSM callback ownership 전환을 준비한다.

# 20260902-030 — graph object 목록 command patch hunk metadata 교정

## 배경

`20260902-029`는 GitHub Actions의 `git apply --check`에서 다음 오류로 중단되었다.

```text
error: corrupt patch at agent_space/patches/20260902-029.patch:30
```

HTML에는 적용되지 않았고 JavaScript 검사와 commit에도 도달하지 않았다.

원인은 bridge hunk가 `selectGraphObject`부터 `applyGraphObject`까지 실제 기존 6줄 / 신규 15줄인데 `-9,+18`로 잘못 기록된 것이다.

두 번째 graph-object command insertion hunk는 기존 6줄 / 신규 69줄로 재확인했다.

## 목적

`029`과 동일한 구현을 유지하고 unified-diff metadata만 교정해 적용한다.

## 변경 내용

`029.md`와 동일하다.

- 앱 버전 `1.1.72-alpha` → `1.1.73-alpha`
- DOM-free color/delete/reorder command 추가
- bridge에 세 command 노출
- existing `replaceGraphObjects()` / selection EFSM 재사용
- active legacy handler는 아직 변경하지 않음

## 교정한 hunk

```text
기존 잘못된 값: @@ ... 9 ... 18 @@
교정값:          @@ ... 6 ... 15 @@
```

command insertion hunk는:

```text
old = 6
new = 69
```

# 20260831-014

## 목적

vendored React/Mantine runtime 내부의 줄 끝 공백 때문에 엄격한 `git diff --check`가 실패하는 문제를 검증 우회 없이 해결한다.

## 변경 내용

- 기존 v3 builder를 재사용하는 one-shot v5 workflow를 추가한다.
- esbuild가 생성한 `runtime.js`를 HTML에 삽입하기 전에 각 줄의 trailing whitespace만 제거한다.
- 일반 `git diff --check`는 그대로 유지한다.
- runtime 결과 patch 순번은 `20260831-015`로 변경한다.

## 이 방향을 선택한 이유

v4에서 `git diff --check --ignore-space-at-eol`을 시도했지만 `--check`의 whitespace error 보고는 계속 발생했다. 따라서 검사 옵션을 완화하는 대신 실제 vendored block을 줄 끝 공백만 정규화하는 편이 명확하고 재현 가능하다.

정규화는 줄 끝의 공백만 제거하며 bundle의 토큰 순서와 실행 의미는 바꾸지 않는다. 이후 엄격한 `git diff --check`를 다시 수행하므로 같은 문제가 남으면 커밋되지 않는다.

## 고려했지만 선택하지 않은 방향

- 일반 HTML patch workflow의 검증을 완화하지 않는다.
- bundle 전체를 formatter로 재작성하지 않는다.
- 실패한 Actions run을 rerun하지 않는다.

## 후속 작업

runtime vendoring 성공 후 실패/일회성 vendor workflow들을 별도 cleanup 커밋에서 제거한다.

## 패치에 포함되지 않은 변경사항

이 patch와 설명 파일 자체는 재귀적으로 diff에 포함하지 않는다.

## 선택 이유와 대안

대화에서 수정한 예시를 별도 파일로 보관하여 이후 Source Script 작성 시 직접 참조할 수 있게 했다. 개발 정책 본문에 예시를 삽입하는 방식은 사용자가 지정한 examples 경로와 별도의 변경이므로 선택하지 않았다. 실행 가능한 치수 계산 구현으로 바꾸는 방식은 자연어 알고리즘을 사용하는 이번 예시의 작성 목적과 달라 선택하지 않았다.

동명 patch는 기준 HEAD `9e58bdf0381b62bb59068a44ca78d75be6edcaed`에 대한 새 예시와 이 설명 문서의 실제 native Git diff다. 일반 index는 유지하고 임시 index로 두 파일만 기록한다.

# 20260916-024 — native CSV projection CSS removal

## 목적과 변경 내용

`20260916-023`에서 제거된 native CSV selection/table preview markup에만 대응하던 CSS를 제거한다.

삭제 범위:
- `.asset-selection-panel`, `.asset-selection-title`
- `.table-wrap`, `.preview-more td`
- 제거된 preview table에만 쓰이던 `table`, `th`, `td` 규칙
- centralized palette block의 `.preview-more td` 잔여 selector

## 선택 이유

current source에서 해당 class/table markup의 active consumer가 사라졌고, CSV header-line 편집과 graph data 선택은 Mantine graph editor + backend functional command 경로로 처리된다. 이 CSS는 domain renderer나 EFSM 상태가 아니라 삭제된 native presentation의 잔여물이다.

## 선택하지 않은 방향

- `.status`, `.file-name`, `.file-picker`는 아직 native fallback consumer가 있어 유지한다.
- global input/button 또는 dashboard/layout renderer CSS는 변경하지 않는다.
- CSV model, headerLines domain field, `graphEditorHeaderLines()`는 변경하지 않는다.

## 전제 / 후속 작업 / 누락

- `fileName/status` fallback ownership과 React bootstrap visibility는 별도 감사한다.
- rollback은 이 패치를 되돌리면 CSS만 복구되며 project/schema에는 영향이 없다.

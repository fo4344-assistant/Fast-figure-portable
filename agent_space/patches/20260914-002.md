# 20260914-002 — renderer-safe legacy DOM cutover

## 목적
20260914-001이 unified-diff line count 오류로 적용되지 않았으므로, 동일 방향을 작은 정확한 hunk로 나눠 먼저 active renderer 경로의 legacy DOM 의존을 제거한다.

## 변경
- `syncDashboardZoomDisplay()`가 old zoom slider/reset button에 값을 쓰지 않고 현재 배율만 계산하도록 변경한다.
- `syncSlotContentTypeUi()`를 제거하고 `updateFileAvailability()`에서 old sidebar panel/readme button DOM 접근을 제거한다. CSV/image runtime 선택 갱신과 README overlay close는 유지한다.
- old `applyGrid` 및 `showSlotBorders` click handler를 제거한다. Mantine layout overlay가 기존 command 경계를 직접 사용한다.

## 이유
이 세 경로는 `renderDashboard()` 및 초기 실행 중 반복 호출되므로, legacy markup을 제거하기 전에 반드시 DOM-independent해야 한다.

## 기각한 대안
old element가 없을 때 optional chaining만 추가하는 방식은 legacy UI 계약을 남기므로 사용하지 않는다.

## Source of truth
layout/project state와 overlay state는 기존 `activeProject` 및 `appFSM`이다.

## EFSM/core 영향
project schema, FFPX/FFSX/Plotly, slot/layout 알고리즘은 변경하지 않는다.

## 검증
workflow 전체 검증을 통과해야 한다.

## 롤백
이 patch만 revert하면 해당 legacy DOM sync/handler가 복원된다. 데이터 migration은 없다.

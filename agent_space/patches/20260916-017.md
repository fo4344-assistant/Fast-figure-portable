# 20260916-017

## 목적과 변경 내용

legacy native graph form에 남아 있지만 current source에서 더 이상 호출되지 않는 UI helper를 제거한다.

이번 패치는 다음 함수만 제거한다.

- `refreshColumnControls()`
  - legacy `rows`/`columns` buffer와 native `xCol`/`yCol` select를 동기화하던 projection helper
- `syncEditableUi(chart)`
  - native `editorEditable` 버튼 및 `#buildBox` 내부 control disabled 상태를 동기화하던 UI helper
- `bindGraphNumberInputs(ids, apply)`
- `bindGraphTextInputs(ids, apply)`
  - native graph form input의 change/Enter 처리를 설치하던 binding helper

모든 함수는 current source에서 정의 외 호출이 없음을 확인했다.

## 선택 이유

`20260916-016` 이후 active Mantine graph editor는 `graphEditor*` functional command 및 logic EFSM event를 사용한다. 위 네 helper는 이 경로에 포함되지 않으며 native DOM control에만 결합되어 있다.

한편 `loadData()`/`preview()`와 native object-list renderer는 아직 서로 참조하는 별도 legacy ownership 단위다. 이번 패치에서 그것까지 함께 제거하지 않고, 먼저 완전한 무호출 helper만 정리해 다음 단계의 호출 폐쇄를 더 명확하게 만든다.

## ownership 분류

### 제거 대상

- UI component/projection: `refreshColumnControls`, `syncEditableUi`
- native UI event binding: `bindGraphNumberInputs`, `bindGraphTextInputs`

### 보존 대상

- logic EFSM / application transitions
- `graphEditor*` backend/core functional commands
- `GRAPH_OBJECTS_REPLACED`, `SELECT_GRAPH_OBJECT`, `CLEAR_GRAPH_OBJECT`, `SELECT_ASSET`, `SLOT_DATA_CONNECTED`, `CHART_LAYOUT_CHANGED` 등 logic events
- `activeProject` / `ProjectObject` / chart/CSV SoT
- Plotly renderer 및 `traces`, `layout`, `chartFigure`, `renderDashboard`
- `rows` / `columns` / `loadData` / `preview` — 다음 native CSV-preview ownership 패치 전까지 유지
- `populateObjectForm` / `selectGraphObject` / `saveGraphObjects` / `renderGraphObjects` / `updateTypeSpecificOptions` — 다음 native object-list ownership 패치 전까지 유지

즉 UI helper 제거를 logic EFSM/core cleanup과 섞지 않는다.

## active graph mutation boundary 재확인

`review-011-sot-api-boundary.md`에 따라 active Mantine graph mutation 경로를 다시 확인했다.

- object 변경은 `graphEditorCommit()`을 거쳐 `GRAPH_OBJECTS_REPLACED`로 진입한다.
- object 선택은 `SELECT_GRAPH_OBJECT` / `CLEAR_GRAPH_OBJECT`로 진입한다.
- CSV 선택은 `graphEditorSelectCsv()`가 `SELECT_ASSET`을 사용한다.
- 빈 슬롯 graph 생성은 `graphEditorAdd()`가 `SLOT_DATA_CONNECTED`를 사용한다.
- layout 변경은 `CHART_LAYOUT_CHANGED`를 사용한다.
- `graphEditorHeaderLines()`와 `graphEditorSetEditable()`은 `fast-figure.js` 내부 functional command이며 Mantine component의 직접 domain mutation이 아니다.

이번 패치는 이 command/event 경로를 수정하지 않는다.

## 고려했지만 선택하지 않은 방향

### native object-list와 CSV preview까지 한 번에 제거

선택하지 않았다. `selectGraphObject()`가 아직 `loadData()`/`populateObjectForm()`/`renderGraphObjects()`를 묶고 있어, 먼저 정의-only helper를 제거한 뒤 object-list와 CSV-preview를 순차적으로 닫는 편이 책임 경계와 rollback이 명확하다.

### `rows` / `columns`를 이번 패치에서 제거

선택하지 않았다. 현재 이 값은 legacy `loadData()`/`preview()`가 사용한다. 해당 UI 체인을 제거하기 전에 전역만 먼저 없애면 dead legacy code가 즉시 깨진 형태로 남는다.

### `graphEditorHeaderLines()` 또는 `graphEditorSetEditable()` 제거/EFSM화

선택하지 않았다. 두 함수는 active Mantine frontend가 호출하는 backend/core command다. native UI helper와 같은 ownership으로 취급하지 않는다.

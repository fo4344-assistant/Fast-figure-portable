# 20260914-008 — legacy layout/palette wiring removal

## 목적
20260914-007 이후 인접한 legacy zoom/layout/palette wiring을 하나의 연속 hunk로 제거해 Mantine 단일 ownership을 확정한다.

## 변경
- old dashboard zoom slider/reset handlers 제거.
- old layout numeric/aspect handlers, merge/split button handlers 제거.
- `uiPaletteFromControls()` 제거.
- `applyUiPalette()`가 `activeProject.appearance.uiPalette`만 읽도록 변경하고 old color inputs 역동기화 제거.
- old palette apply/reset handlers 제거.
- `applyUiPaletteValues()`는 그대로 유지한다.

## 이유
Mantine layout/palette가 이미 command/model API를 직접 사용하며, legacy controls는 더 이상 source of truth가 아니다.

## Source of truth
layout은 project layout/slotStyle, palette는 project appearance.uiPalette, zoom은 runtime state다.

## EFSM/core 영향
FFPX/FFSX/Plotly, schema, layout 및 merge/split 알고리즘은 변경하지 않는다.

## 검증
workflow 전체 검증.

## 롤백
patch revert 가능. persistent migration 없음.

## WIP
sidebar/debug/lifecycle startup wiring과 legacy HTML/CSS가 남아 있으며 다음 cutover 대상이다.

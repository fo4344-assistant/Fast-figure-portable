# 20261002-009 — Mantine primary color follows UI palette

## 목적과 변경 내용

일반 Mantine Button/ActionIcon이 project appearance의 `uiColor`와 별도의
Mantine 기본 blue를 사용하는 문제를 수정한다.

`activeProject.appearance.uiPalette.uiColor`을 generic Mantine primary UI의
단일 색상 원천으로 유지한다.

## Source Script 우선 검토

수정 전에 Source Script를 먼저 확인했다.

`sourcescript/api_ui.py`의 `FastFigureApp`은 이미 다음을 요구한다.

- persistent appearance palette를 FastFigureApi에서 읽는다.
- palette를 Mantine CSS variable로 투영한다.
- UI color luminance에서 primary contrast text를 계산한다.

따라서 이번 현상은 Source Script 수준에서 색상 의미가 빠진 문제가 아니라,
하위 Mantine 구현이 theme의 기본 `primaryColor=blue`를 별도로 사용한 불일치다.

Source Script와 verification-model은 수정하지 않았다.

## 구현 원인

기존 `FastFigureApp`은 다음 global CSS variable을 `palette.uiColor`에서 만들고 있었다.

- `--mantine-primary-color-filled`
- `--mantine-primary-color-filled-hover`
- `--mantine-primary-color-light`
- `--mantine-primary-color-light-hover`
- `--mantine-primary-color-light-color`

그러나 Mantine Button과 ActionIcon의 component vars resolver는
theme의 `primaryColor` 기본값인 `blue`에서
`--button-bg`, `--button-hover`, `--ai-bg` 등을 계산한다.

그래서 global primary palette와 실제 button color가 분리되었다.

## 선택한 수정 방향

현재 `palette.uiColor`을 값으로 가지는 Mantine custom color `ffui`를
`FastFigureApp` render에서 만들고 provider theme의 `primaryColor`로 지정한다.

또한 Mantine component resolver가 참조하는 `--mantine-color-ffui-*` variable은
기존 palette 기반 `--mantine-primary-color-*` variable에 연결한다.

이 구조에서는 별도의 button color 영속 상태나 독립 palette를 만들지 않는다.

## 고려했지만 선택하지 않은 방향

### 각 Button에 color prop을 반복 지정

모든 호출부에 색 지정이 분산되고 새 버튼이 추가될 때 누락될 수 있어 선택하지 않았다.

### Button/ActionIcon vars에서 variant별 색을 직접 재구현

Mantine variant resolver와 중복되는 별도 색상 규칙이 생기므로 선택하지 않았다.

### Source Script에 새 버튼 색 규칙 추가

Source Script에 이미 appearance palette의 Mantine projection 책임이 있으므로
동일 의미를 더 좁은 Button 규칙으로 중복 정의하지 않았다.

### CSS에서 Mantine 내부 hash class를 직접 override

vendored Mantine 버전의 내부 class hash에 결합되므로 선택하지 않았다.

## 회귀 검사

browser regression에 다음 검사를 추가했다.

- filled Mantine Button이 존재하는지 확인
- 현재 `appearance.uiColor`의 computed RGB와
  filled Button의 computed background color가 동일한지 확인

regression target source code revision도 r4로 갱신했다.

## rollback

`--mantine-color-ffui-*` alias를 제거하고,
browser regression r4 검사 및 source-code r4 metadata를 r3 상태로 되돌리면 된다.

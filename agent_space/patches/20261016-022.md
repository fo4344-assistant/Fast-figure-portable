# 20261016-022 — 공통 settings 데이터와 annotation 계산 r36

## 목적·변경

사용자의 설정 파일 형식/분리 복잡도 지적 및 caption·reference-width export 요구를 Plan 020에 따라 반영했다. `sourcescript/backend/settings.json` 하나에 label/caption 기본값과 필요한 caption reference 값을 데이터로만 둔다. 기본값 해석·current Project authority는 기존 Backend annotation/project-state가 유지하고, 번호/group/append와 geometry 계산은 기존 owner 안에서 연결한다.

- caption은 전체 visible anchor 기준 label order를 사용한다. 인접 동일 문자열/뒤따르는 empty를 range로 묶고 시작 empty는 label만 표시해 global text 끝에 공백 구분으로 append한다.
- target export는 layout referenceWidth 기준 dashboard/caption 높이를 목표 pixel width/referenceWidth 비율로 scaling한다. auto total은 ceil, explicit total은 caption 영역을 뺀 grid 유효성을 검사한다. DPI를 pixel width에 다시 곱하지 않는다.
- checker의 file collection/fingerprint/변경 감지/patch marker/revision 범위에 공통 JSON을 포함한다. Source36 current/open, lower stale 유지.

## 위치·이유·기각 대안

기존 Backend 디렉터리에 공통 JSON 파일 하나만 둔다. 설정별 파일/새 Python package/import/loader/registry를 만드는 비용을 정당화하지 못한 점을 바로잡는다. 계산 문장을 config에 넣거나 값 목록을 renderer/Python에 중복 정의하지 않는다. 현재 사용자 설정은 Backend Project이며 JSON과 양방향 동기화하지 않는다.

미게시 `sourcescript/backend/settings/annotations.py`·전용 디렉터리·관련 import는 제거했다. 원격 게시 이력이 없어 diff의 삭제 항목은 아니며, 제안만 했던 annotation-settings.json도 생성하지 않았다. 기존 layout_annotations.py를 새 설정 모듈로 간주해 삭제하는 대안은 기존 계산 책임을 없애므로 기각했다. Plan019의 설정 방식은 Plan020이 대체한다.

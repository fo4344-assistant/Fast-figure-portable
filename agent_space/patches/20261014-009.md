# 20261014-009 — Diagnose settings Modal resize regression

## 목적과 변경 내용

settings Modal resize의 반복 실패 위치를 구현 변경 없이 browser regression에서 단계별로 구분한다.

test 29에 다음 확인을 추가한다.

1. mousedown 직후 `document.body.style.cursor === "ns-resize"`인지 확인하여 React resize start handler가 실행됐는지 검증.
2. mousemove 직후 `Modal.Content.style.height`가 px 값으로 바뀌었는지 확인하여 resize projection이 실행됐는지 검증.
3. 기존 최종 bounding-height 변화 검증은 유지.

## 선택 이유

이전 실행에서는 최종 box height만 검사하여 event handler 미실행, 계산 미실행, CSS layout clamp를 구분할 수 없었다. 기능 의미를 더 바꾸기 전에 실패 계층을 정확히 특정하기 위한 최소 진단이다.

## 변경하지 않은 범위

- application source 없음.
- Source Script/pseudocode/verification 없음.
- source-code revision/fingerprint 없음.
- production runtime behavior 없음.

## 후속

hosted regression 결과의 최초 실패 assertion을 기준으로 product code 또는 test simulation 중 실제 문제가 있는 계층만 수정한다.

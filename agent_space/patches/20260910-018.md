# 20260910-018 — Legacy asset menu dead-code removal

## 목적
017에서 legacy asset explorer의 활성 interaction wiring을 끊은 뒤 호출되지 않게 된 action-menu 계열과 native-confirm 휴지통 wrapper를 제거한다. 동시에 `updateFileAvailability()`가 더 이상 비활성 legacy asset controls를 동기화하지 않도록 정리해 Mantine PROJECT DATA를 generic asset UI의 단일 소유자로 만든다.

## 변경 내용
- `ASSET_TREE_ACTION_SCHEMA`, `ASSET_TREE_ACTION_HANDLERS`, `renderAssetTreeActionMenu()`, `syncAssetTreeActionMenu()`를 제거한다.
- legacy `emptyProjectTrash()` wrapper를 제거한다. Mantine tree의 휴지통 비우기는 기존 `PROJECT_TRASH_EMPTIED` event와 자체 Modal을 직접 사용한다.
- `updateFileAvailability()`에서 legacy `assetDownload`/`deleteSelectedAsset` disabled 상태 동기화와 action-menu 동기화를 제거한다.
- `updateFileAvailability()`의 실제 남은 역할인 slot-dependent legacy workspace visibility/readme-close 처리는 그대로 유지한다.
- project tree snapshot/renderer, project VFS, Mantine이 사용하는 selection/download/import commands는 변경하지 않는다.

## Source of truth 및 EFSM 영향
Persistent authority는 `activeProject`, `projectVfs`, `appFSM` 그대로다. 이 패치는 generic UI dead code만 삭제하며 `PROJECT_TRASH_EMPTIED`, project asset reference cleanup, validation과 lifecycle semantics를 수정하지 않는다.

## 기각안
- legacy action menu를 disabled 상태로 계속 렌더링: 실행 경로는 없어도 상태 동기화와 DOM authority 흔적이 남으므로 기각.
- `updateFileAvailability()` 전체 제거: graph/image/workspace legacy renderer가 아직 호출하므로 범위가 과도하다.
- project tree snapshot/renderer까지 동시 제거: 별도 호출관계 확인 없이 제거하면 cutover와 renderer 정리를 한 rollback 단위에 섞게 된다.

## 검증
Workflow의 patch check, diff check, JavaScript syntax, portable build, split/portable `file://` smoke를 통과해야 한다. Mantine asset selection, item menu download/move/trash, folder create/empty trash, drag/drop 및 slot selection 뒤 asset selection이 안정적으로 유지되는지 확인한다.

## 롤백
이 패치만 revert하면 017의 legacy interaction wiring은 여전히 비활성인 상태에서 legacy action-menu/dead wrapper 코드만 복원된다. 따라서 기능 cutover와 dead-code deletion을 독립적으로 되돌릴 수 있다.

## 후속
legacy tree DnD policy/execution/install 함수와 native-confirm 삭제/새폴더 wrappers의 남은 참조를 제거한다. 그 뒤 `Fast-figure.html`의 legacy explorer markup 및 `REQUIRED_CONTROL_IDS`를 Mantine ownership 기준으로 정리한다.

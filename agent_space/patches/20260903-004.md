# 20260903-004 — workspace EFSM entry domain / legacy presentation 분리

## 목적

React/Mantine shell cutover의 핵심 blocker인 workspace EFSM entry의 native DOM 의존성을 제거할 준비를 한다.

현재 `syncProjectWorkspaceState`, `syncGraphWorkspaceState`, `syncImageWorkspaceState`는 domain/transient selection 정리와 legacy sidebar/form synchronization을 한 callback에서 수행한다.

이번 패치는 각 workspace에 DOM-free domain sync 함수를 추가하고, 기존 callback은 그 결과를 받아 legacy presentation을 수행하는 wrapper로 유지한다. 아직 `APP_STATE_DEFINITIONS`의 entry/update callback은 바꾸지 않으므로 active legacy UI 동작은 유지된다.

## 변경 내용

- 앱 버전 `1.1.106-alpha` → `1.1.107-alpha`
- `updateFileAvailability(model)`이 이미 계산/정책 적용된 model을 받을 수 있게 변경
- `syncProjectWorkspaceDomainState()` 추가
  - workspace availability policy 적용
  - active CSV 정규화
  - active image 정규화
- `syncGraphWorkspaceDomainState()` 추가
  - selected slot 확인
  - workspace availability policy 적용
  - chart가 바뀌었으면 `selectChartForEditing()` 호출
  - active CSV 정규화
  - legacy form을 건드리지 않고 `{ slot, availability, selection }` 반환
- `syncImageWorkspaceDomainState()` 추가
  - selected slot 확인
  - workspace availability policy 적용
  - slot image 기준 active image 정규화
- `exitGraphWorkspaceDomainState()` 추가
  - 기존 `selectedObjectIndex = null` 의미를 legacy `buildBox` 숨김과 분리
- 기존 `sync*WorkspaceState()` wrapper는 domain 결과를 받아 현재 native UI를 동일하게 동기화

## 기능 의미 보존

### project workspace

기존과 동일하게:
- active CSV/image transient state를 정규화
- README-close policy 유지
- legacy target/file/preview/tree/label/caption/native boxes를 동기화

### graph workspace

기존 `editChart(slot.chart)` 호출은 내부적으로 이미 `selectChartForEditing()` + `syncLegacyGraphEditorSelection()`으로 분리돼 있다. 이번 patch는 동일 순서를 workspace wrapper에서 명시적으로 수행한다.

### image workspace

기존 `refreshImageControls(slot.imageId)`의 active image mutation은 domain helper로 이동하고, native button disabled 표시는 wrapper에 남긴다.

## 이 방향을 선택한 이유

cutover 때 EFSM callback을 통째로 삭제하면 transient selection/README overlay 정책까지 사라지고, 그대로 유지하면 제거된 native DOM ID를 계속 조회한다.

따라서 callback을 domain sync와 presentation adapter 두 단계로 나누고, 지금은 wrapper를 계속 사용한다. 이후 cutover patch에서는 `APP_STATE_DEFINITIONS.workspace.*.entry/update`를 domain callback으로 바꾸고 legacy wrapper를 제거할 수 있다.

## 고려했지만 선택하지 않은 방향

### 지금 바로 APP_STATE_DEFINITIONS를 domain callback으로 변경

기각. 아직 active UI가 legacy라 native sidebar/form이 workspace 전이에 따라 갱신되지 않게 된다.

### React effect에서 workspace domain state를 재구성

기각. EFSM transition semantics와 React lifecycle이 이중 owner가 된다.

### 기존 wrapper 내부에 `if (mantine)` 분기 추가

기각. UI implementation 선택이 domain transition callback 내부에 남는다.

## source of truth / EFSM

- selected slot/workspace/overlay: `appFSM.state`
- chart/image/CSV: project domain model
- editing chart / active CSV / active image / selected object: 기존 transient state
- React snapshot은 여전히 read-only invalidation/presentation 입력

## 회귀 위험

중간 수준. workspace 진입/업데이트 경로를 재구성하지만 기존 wrapper가 동일 presentation 작업을 수행한다.

확인 항목:
- project workspace 진입 시 기존 sidebar 상태 유지
- graph slot 전환 시 chart form이 기존과 동일하게 채워짐
- 빈 graph slot 선택 시 preview/build box 의미 유지
- image slot 선택 시 active image와 image controls 유지
- graph workspace exit 시 selected graph object 해제 유지
- README overlay + slot selection 자동 close 유지
- JavaScript syntax 정상

## rollback

새 domain helper를 제거하고 기존 `sync*WorkspaceState()` inline body를 복원하면 된다. `001`~`003` helper는 독립 유지 가능하다.

## 후속

다음은 lifecycle/overlay entry의 domain policy와 legacy popup renderer를 같은 방식으로 분리한다. 그 뒤 React shell mount → domain-only EFSM callbacks → legacy markup removal의 cutover patch를 설계한다.

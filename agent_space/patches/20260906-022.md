# 20260906-022 — asset selection domain/presentation split

## 목적

Mantine asset tree가 legacy form DOM을 통하지 않고 CSV/image asset selection을 수행할 수 있도록 선택 command와 legacy presentation synchronization을 분리한다.

## 이유

`20260906-021`에서 asset tree 자체는 Mantine component로 재구성했지만 bridge의 `selectAssetPath()`가 여전히 `selectCsvFromTree()` / `selectImageFromTree()`를 호출했다. 두 함수는 selection/domain mutation과 함께 `#headerLines`, `loadData`, `setFileName`, `renderProjectDataTree` 등 legacy DOM presentation을 직접 실행한다.

이 상태에서는 Mantine owner cutover 후 legacy form 제거가 불가능하다.

## 변경

- `selectCsvAsset(path)` 추가.
  - VFS resolve, asset/graph-object selection, active CSV/runtime data normalization, UI-store invalidation을 수행한다.
  - legacy form DOM을 읽거나 쓰지 않는다.
- `syncLegacyCsvAssetSelection(selection)` 추가.
  - 기존 `#headerLines`, native graph controls/data preview, filename, legacy asset tree 갱신만 담당한다.
- `selectCsvFromTree(path)`는 domain command + legacy presentation adapter wrapper가 된다.
- `selectImageAsset(path)` 추가.
  - VFS resolve, image selection, image-slot link, dashboard renderer, UI-store invalidation을 담당한다.
  - legacy sidebar DOM을 직접 갱신하지 않는다.
- `syncLegacyImageAssetSelection(selection)`과 legacy wrapper를 분리한다.
- Mantine bridge `selectAssetPath()`는 CSV/image에서 DOM-free command를 직접 호출한다.
- 앱 빌드 `1.1.125-alpha` → `1.1.126-alpha`.

## 보존

- asset selection EFSM 의미와 VFS path 규칙.
- image slot link 의미.
- CSV 선택 시 기존 graph slot의 chart data를 자동 교체하지 않는 동작.
- active legacy UI에서는 wrapper가 기존 native presentation을 계속 갱신한다.
- FFPX/FFSX schema/roundtrip 의미.

## 기각안

- Mantine asset tree가 기존 native button을 `.click()`하는 방식: legacy control 소유가 계속 필요하므로 기각.
- React local state에 CSV/image selection을 복제하는 방식: EFSM/project source of truth와 이중화되므로 기각.

## 회귀 위험

- CSV 선택 시 기존 `loadData()`가 함께 수행하던 `rows/columns` runtime 갱신을 DOM-free command가 직접 수행한다. `dataTable`/`columnDefinitions`의 기존 경로를 그대로 사용한다.
- legacy wrapper가 중복으로 같은 runtime data를 재생성하지만 현재 active legacy UI 동작 보존을 위한 과도기 adapter이며 owner cutover 후 제거 대상이다.

## 다음 단계

1. asset drag/drop을 Mantine tree target에 연결하되 기존 VFS drop policy/execute command를 재사용한다.
2. status/palette/debug 등 남은 generic sidebar UI를 Mantine으로 이식한다.
3. active owner cutover 후 legacy asset/sidebar handler 및 markup을 제거한다.

# 20260922-003

## 목적과 변경 내용

`SLOTS_RESET` backend action에 남아 있던 제거된 native file input `#file` 접근을 제거한다.

현재 HTML에는 `id="file"` element가 없지만 `applySlotsResetAction()`이 `$("file").value = ""`를 실행하고 있어 slot reset 시 null 접근으로 실패할 수 있다.

이 패치는 해당 한 줄만 제거한다.

## 선택 이유

파일 input은 Mantine frontend local input으로 이미 이동했으며 backend reset action이 UI DOM을 직접 초기화해서는 안 된다. 제거된 DOM을 다시 만들거나 hidden input bridge를 추가하지 않고 stale projection 자체를 삭제한다.

## 선택하지 않은 방향

- `#file` hidden input을 복원하지 않는다. 최종 구조와 반대되는 legacy bridge가 된다.
- optional chaining으로 `$("file")?.value`를 남기지 않는다. backend가 frontend input을 알고 있는 구조 자체가 불필요하다.
- slot/domain reset 의미는 변경하지 않는다.

## 전제와 후속 작업

- Mantine file input은 사용 후 자체 `input.value = ""` 처리 경로를 가진다.
- 다음 패치에서 graph object selection의 authoritative state를 `appFSM.state.graphObjectIndex`로 통합한다.

## 롤백

역적용 시 stale native file input 접근 한 줄만 복원된다. project/domain 데이터에는 영향이 없다.

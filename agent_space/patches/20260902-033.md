# 20260902-033 — Mantine graph object 목록 sidebar wiring

## 목적

`20260902-032`에서 준비한 `FastFigureGraphObjectListStaging`을 inactive Mantine sidebar에 연결한다.

## 변경 내용

- 앱 버전 `1.1.75-alpha` → `1.1.76-alpha`
- sidebar render 시 `fastFigureUiBridge.readGraphObjects()` snapshot을 읽음
- graph-object 상세 form 앞에 `FastFigureGraphObjectListStaging` 렌더
- 선택된 object가 있으면 기존 `FastFigureGraphObjectStaging` 상세 form도 계속 렌더

## UI 흐름

```text
readGraphObjects()
→ Mantine list
→ selectGraphObject(index, chartId)
→ existing graphObject EFSM
→ external-store invalidation
→ readGraphObjects() / readGraphObject() 재조회
→ selected row + detail form 갱신
```

색상/삭제/reorder도 동일하게 bridge command → canonical model mutation → snapshot 재조회 흐름을 따른다.

## source of truth

React sidebar는 `graphObjects` snapshot과 `graphObject` snapshot을 같은 render cycle에 읽지만 둘 다 비권위 read model이다.

- list source: chart `editor.objects`
- detail source: selected index로 찾은 같은 canonical object
- selection source: graphObject EFSM / selectedObjectIndex

두 snapshot을 서로 동기화하거나 한쪽을 다른 기능의 source로 사용하지 않는다.

## commit timing / interaction

- row click/Enter/Space: selection 즉시
- color: Mantine ColorInput change 즉시
- delete: click 즉시
- reorder: drop 시 commit
- detail form: 기존 017/018 timing 유지

## 변경하지 않는 영역

- active legacy UI
- add object
- palette
- EFSM event/action
- graph renderer
- Plotly/trace code
- 인라인 Plotly library
- import/export

## 회귀 위험

낮음. shell은 아직 inactive staging이다.

검사:

- graph slot에서 list snapshot이 있을 때만 목록 표시
- selection 후 detail form snapshot 갱신
- image/no-chart에서 목록 미표시
- React local persistent objects/selection state 없음
- legacy DOM 참조 없음
- Plotly/trace diff 없음

## rollback

- sidebar의 `graphObjects` read 제거
- list component render 제거
- 앱 버전을 `1.1.75-alpha`로 복원

`032` component와 이전 command/read model은 독립 유지 가능하다.

## 후속

graph object의 **추가** 경로는 기존 `addGraphObject()`가 새 chart 생성과 existing chart object append를 서로 다른 경로로 처리하므로 별도 검토한다. 현재 `SLOT_DATA_CONNECTED`, `CHART_MODEL_REPLACED`, active CSV 의미를 확인한 뒤 DOM-free command를 설계한다.

## Plotly 범위

이번 패치는 sidebar staging의 read/render wiring만 변경한다. 인라인 Plotly library는 읽거나 수정하지 않는다.

# 20260916-022 — native graph editor CSS removal retry

## 목적과 변경 내용

`20260916-021`이 application source 적용 전에 `git apply --check`에서 실패했으므로, 동일한 CSS ownership cleanup을 current source 기준의 올바른 unified-diff hunk count로 다시 기록한다.

삭제 범위는 `#buildBox` 계층 규칙, `.axis-choice`, `.graph-objects/.graph-object*`, centralized palette의 graph-object 잔여 selector뿐이다.

## 선택 이유

`20260916-020`에서 해당 markup은 제거되었고 현재 JS/Mantine에서도 이 selector들을 사용하지 않는다. `021` 실패는 source 변경이 아니라 patch 형식의 첫 hunk count 오류였으므로 application rollback은 필요 없다.

## 선택하지 않은 방향

- 실패한 `021` 파일을 수정하거나 재사용하지 않는다. 실패 기록을 audit history로 보존한다.
- 전역 input/button/row/color/layout/dashboard 스타일은 함께 제거하지 않는다.
- logic EFSM, ProjectObject, graph functional command/renderer는 변경하지 않는다.

## 전제 / 후속 작업 / 누락

- `021`은 source를 변경하지 않았다.
- native CSV preview markup/CSS와 status/fileName fallback은 후속 ownership 단위로 분리한다.
- rollback은 이 패치만 되돌리면 된다.

# 20261014-026 — Repair batch-import PlusCal symbol collision in verification r23

## 원인
Interaction Core의 main `with allowCommit` 변수와 `ImportAssetBatch(allowCommit)` procedure parameter가 PlusCal translator에서 중복 symbol로 생성되었다. translation은 끝났지만 SANY semantic analysis가 multiply-defined symbol로 실패했다.

## 변경
main 쪽 nondeterministic 선택 변수만 `batchCommitChoice`로 변경한다. procedure parameter, 상태 전이, atomicity assertion, command ownership 의미는 변경하지 않는다.

## 기각
batch atomicity transition 제거 또는 parameter를 전역 상태로 승격하면 검증 의미를 줄이거나 불필요한 상태를 만든다.

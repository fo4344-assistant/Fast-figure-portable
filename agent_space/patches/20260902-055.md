# 20260902-055 — 슬롯별 캡션 버튼 wiring 재시도

## 목적

`20260902-054`는 기능/context 문제가 아니라 unified diff hunk count 오류(`old 4 / new 15`를 `new 14`로 기록)로 `git apply --check`에서 실패했다. HTML에는 반영되지 않았다.

동일한 Mantine Caption button wiring을 hunk count만 교정해 재시도한다.

## 변경 내용

- Caption Modal action group에 `슬롯별 캡션 추가` Mantine Button 추가
- `fastFigureUiBridge.insertSlotCaptions()` 호출
- 실행 후 기존 `readDraft()`로 canonical caption editor 값을 다시 읽어 local draft 갱신
- 기존 `캡션 적용` Button 유지

## 영향 범위

UI staging wiring만 변경한다. EFSM/domain/file schema는 `053` 상태를 그대로 사용한다.

## 검증

- `git apply --check`
- `git diff --check`
- JavaScript `node --check`

## rollback

이 patch만 되돌리면 Mantine button만 제거된다.

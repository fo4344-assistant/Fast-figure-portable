# 20260906-030

## 목적

CSV/이미지 자산 삭제의 기존 기능과 cascade 의미를 그대로 유지하면서, 참조 중 자산의 `window.confirm`을 이미 도입한 Mantine 공통 confirmation Modal로 이관합니다.

## 변경 내용

- 자산 삭제용 DOM-free read model을 추가합니다.
  - 선택된 CSV/이미지 종류, ID, 이름, 참조 수를 계산합니다.
  - 참조가 있을 때만 기존 문구와 동일한 confirmation descriptor를 제공합니다.
- CSV 삭제를 confirmation과 실제 command로 분리합니다.
  - 참조 그래프 오브젝트 제거는 기존 `GRAPH_OBJECTS_REPLACED` 경로를 그대로 사용합니다.
  - 기본 빈 CSV 삭제 금지 규칙을 유지합니다.
- 이미지 삭제도 confirmation과 실제 command로 분리합니다.
  - 참조 슬롯 초기화는 기존 `SLOTS_RESET` 경로를 그대로 사용합니다.
- Mantine sidebar의 `에셋 삭제` 버튼은 다음 규칙을 사용합니다.
  - 참조 없음: 기존처럼 즉시 삭제
  - 참조 있음: 공통 Mantine confirmation 표시 후 삭제
- legacy 버튼/코드 경로는 현재 owner가 남아 있는 동안 임시 `window.confirm` adapter를 사용하지만 Mantine 경로에서는 호출하지 않습니다.
- 앱 빌드를 `1.1.134-alpha`로 올립니다.

## 기능 보존

### CSV

- 기본 빈 CSV는 삭제할 수 없습니다.
- 참조가 없으면 추가 확인 없이 즉시 삭제합니다.
- 참조가 있으면 기존과 동일하게 그래프 오브젝트 개수를 경고합니다.
- 확인 후 해당 CSV를 참조하는 모든 그래프 오브젝트를 제거합니다.
- `selectedObjectIndex`를 초기화합니다.
- CSV를 삭제하고 asset selection을 지운 뒤 dashboard를 다시 렌더링합니다.
- 기존 성공 status 문구를 유지합니다.

### 이미지

- 참조가 없으면 추가 확인 없이 즉시 삭제합니다.
- 참조가 있으면 기존과 동일하게 이미지 슬롯 개수를 경고합니다.
- 확인 후 참조 슬롯을 `SLOTS_RESET`으로 초기화합니다.
- 이미지를 삭제하고 asset selection을 지운 뒤 dashboard를 다시 렌더링합니다.
- 기존 성공 status 문구를 유지합니다.

FFPX/FFSX schema, project/VFS 의미, EFSM transition 정의는 변경하지 않습니다.

## 선택 이유

Mantine 전환은 삭제 기능이나 안전 확인을 없애는 작업이 아닙니다. 서로 다른 domain cascade는 그대로 두고 generic confirmation lifecycle만 공통 Mantine Modal로 올리는 것이 기능 보존과 UI 규칙 통합을 동시에 만족합니다.

## 고려했지만 선택하지 않은 방향

### 모든 자산 삭제에 확인창 추가

현재 참조 없는 자산은 즉시 삭제됩니다. 모든 삭제에 확인을 추가하면 사용자-visible semantics가 바뀌므로 선택하지 않았습니다.

### 참조 중 자산 삭제 금지

기존 cascade 삭제 기능을 축소하므로 기각했습니다.

### CSV와 이미지 cascade를 하나의 generic delete algorithm으로 합치기

CSV는 graph object, 이미지는 slot이라는 서로 다른 domain 관계를 가지므로 억지 통합은 책임 경계를 흐립니다. UI confirmation만 공통화합니다.

### Mantine 버튼에서 기존 `deleteSelectedAsset()` 직접 호출

참조가 있을 때 내부 `window.confirm`으로 빠져 Mantine single-owner 목표를 방해하므로 기각했습니다.

## 위험 요소

- Modal을 연 뒤 selection이 달라진 경우 다른 자산을 삭제하지 않도록 kind/ID를 descriptor에 고정합니다.
- 확인 시점에는 현재 모델의 참조를 다시 계산하여 실제 cascade가 누락되지 않도록 합니다.
- legacy adapter는 최종 구조가 아니며 해당 legacy UI 제거 시 같이 삭제합니다.

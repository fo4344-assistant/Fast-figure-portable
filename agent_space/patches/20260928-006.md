# 20260928-006

## 목적과 변경 내용

실패한 `20260928-005`의 GUI CSS 정리 목적을 현재 main에 다시 적용한다.

`20260928-005`는 `git apply --check`에서 `Fast-figure.html:9356` hunk가 적용되지 않아 application source를 전혀 변경하지 않았다. 원인은 반복되는 CSS 문맥에서 자체 생성한 unified diff hunk context가 부정확했던 transport 문제였다.

이번 patch는 같은 설계 목적을 유지하되 다음 방식으로 생성했다.

1. 현재 main의 실제 `Fast-figure.html`에서 최종 candidate를 만든다.
2. candidate 전체 파일을 Git blob/tree/임시 commit으로 생성한다.
3. GitHub가 그 commit에 대해 계산한 실제 unified diff를 patch 본문으로 사용한다.
4. 사람이 hunk line/count/context를 다시 계산하지 않는다.

추가로 candidate 검토 중 빠져 있던 dead selector `details.palette[open] summary`도 함께 제거하고, 제거된 CSS variable 자리의 불필요한 빈 줄을 남기지 않는다.

## 제거 범위

- old header/toolbar
- old aside/sidebar resize/collapse controls
- native fieldset/details/palette form layout
- native `input/select/button/label` geometry
- old row/button helpers
- old setting toggle/hint
- old README wrapper button sizing
- old layout popup/heading/layout controls
- old ratio controls
- old dashboard zoom controls
- old layout resize handle
- old layout map/slot UI
- old icon-only sizing
- old generic disabled/light-button palette overrides
- 위 legacy UI에서만 쓰던 toolbar/popup/icon numeric CSS variables

## 유지 범위

- Mantine shell과 sibling renderer를 연결하는 `.app`, `.app > main`, `--sidebar-width`
- dashboard/slot/Plotly/image/caption/label renderer CSS
- slot drag/select surface
- graph area
- React root host

global `body`의 14px font override는 제거하고 같은 renderer font를 `.app > main`으로 이동하여 Mantine GUI typography와 renderer typography의 책임을 분리한다.

## 20260928-005와의 관계

`005`는 실패 기록으로 수정하거나 덮어쓰지 않는다. 이 patch는 transport 방식까지 교정한 후속 temporal patch다.

## 검증

- candidate 생성 후 남은 custom stylesheet에서 `header/aside/button/input/select/label/fieldset/legend/.toolbar/.layout-panel/.layout-controls/.sidebar-/.dashboard-zoom/.layout-map/.layout-slot` 계열 generic selector가 0개임을 확인했다.
- GitHub 생성 diff를 그대로 사용한다.
- Actions에서 `git apply --check`, `git diff --check`, JS syntax, portable build, split/portable `file://` smoke를 수행한다.
- 적용 후 custom style 크기와 남은 selector를 다시 검사한다.

## 롤백

역적용하면 제거된 legacy GUI CSS만 복원된다. EFSM, project/domain model, renderer 알고리즘, FFPX/FFSX 의미는 변경하지 않는다.

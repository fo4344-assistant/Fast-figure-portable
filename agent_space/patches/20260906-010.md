# 20260906-010 — CSV header command / legacy form synchronization 분리

## 목적

Mantine cutover 전 bridge 횡단 감사에서 확인된 CSV header command의 legacy DOM 의존성을 제거한다.

현재 Mantine sidebar의 CSV header `NumberInput`은 `fastFigureUiBridge.applyCsvHeader()`를 호출하지만, 이 bridge는 `applyCsvHeaderLinesFromValue()`로 연결되어 있다. 해당 함수는 CSV model 변경과 graph rebuild뿐 아니라 `#headerLines` native input 갱신과 `refreshColumnControls()`까지 수행한다.

따라서 legacy sidebar DOM을 제거한 뒤에는 Mantine callback이 제거된 native control을 요구하게 된다.

## 변경 내용

- 앱 버전 `1.1.113-alpha` → `1.1.114-alpha`
- `applyCsvHeaderLinesToModel(value, csvId)` 추가
  - active CSV 검증
  - header line 수 정규화
  - `csv.headerLines` 갱신
  - 해당 CSV를 사용하는 editable graph rebuild
  - dashboard domain renderer 갱신
  - debug log 및 React external-store invalidation
  - `{ csvId, headerLines }` snapshot 반환
- 기존 `applyCsvHeaderLinesFromValue()`는 legacy adapter로 축소
  - `applyCsvHeaderLinesToModel()` 호출
  - `#headerLines` native input 반영
  - `refreshColumnControls()` 수행
- `fastFigureUiBridge.applyCsvHeader()`는 DOM-free `applyCsvHeaderLinesToModel()`을 직접 사용

## source of truth

CSV header의 지속 의미는 계속 `csv.headerLines` 하나만 source of truth로 사용한다.

Mantine `NumberInput`의 value는 `selectedCsvHeaderModel()` snapshot에서 읽고, 변경 시 model command를 호출한다. legacy native input 값은 active legacy UI가 표시를 위해 사용하는 adapter 값일 뿐 authority가 아니다.

## renderer 경계

`renderDashboard()`는 제거하지 않는다. 이는 legacy 일반 UI가 아니라 Plotly/slot domain renderer 갱신이므로 Mantine shell에서도 필요하다.

반대로 `#headerLines`와 `refreshColumnControls()`는 legacy graph/sidebar form presentation이므로 bridge command에서 분리한다.

## EFSM / 파일 의미

- EFSM transition/state 의미 변경 없음
- CSV row/header 해석 의미 변경 없음
- graph rebuild 조건 변경 없음
- FFPX/FFSX/Plotly schema 및 roundtrip 의미 변경 없음
- 새로운 state/cache 없음

## 선택하지 않은 방향

### bridge에서 legacy DOM 존재 여부를 검사

`if ($("headerLines"))` 같은 compatibility 분기를 넣으면 Mantine command가 계속 legacy 구현에 결합되므로 선택하지 않는다.

### React local state만 변경

CSV model과 source of truth가 갈라지므로 선택하지 않는다.

### refreshColumnControls 전체를 즉시 제거

현재 active legacy sidebar에서 X/Y column select와 preview 동기화에 사용하므로 cutover 전에는 유지한다.

## 회귀 위험

낮음~중간.

model mutation 순서와 graph rebuild/render는 유지하며 legacy onchange는 기존 adapter를 계속 사용한다. Mantine 경로만 legacy form synchronization을 우회한다.

## rollback

- bridge를 `applyCsvHeaderLinesFromValue()`로 복원
- `applyCsvHeaderLinesToModel()` 내용을 기존 legacy 함수에 다시 inline
- 앱 버전을 `1.1.113-alpha`로 복원

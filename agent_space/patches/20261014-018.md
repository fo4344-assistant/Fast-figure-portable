# 20261014-018 — Restore pre-TLC Source Code after policy-order violation

## 목적과 원인

plan-015 verification r19의 TLC가 아직 `pending`인데 r25/r26 Source Code WIP를 먼저 push했다.
`AGENT.md`와 `source-script-policy.md`의 개발 계층 순서 및 현재 프로젝트의 TLC gate를 위반한 진행이었다.

하위 구현 중 Source Script command coverage 누락도 발견되었으므로, Source Code를 계속 확장하지 않고
마지막 pre-TLC 상태인 r24 구현으로 되돌린다.

## 변경

- `fast-figure.js`를 r25/r26 도입 전 상태로 복원한다.
- `development-versions.json`의 Source Code metadata를 r24 상태로 복원한다.
- Source Script r21 / pseudocode r7 / verification r19 자체는 이 rollback에서 수정하지 않는다.

## 선택 이유

정책상 Source Script 의미 문제가 발견되면 Source Script로 돌아가 다시 닫은 뒤 PlusCal과 verification을 순서대로 전파해야 한다.
TLC가 `passed`가 되기 전에 Source Code를 계속 수정하는 것은 허용되지 않는다.

## 기각한 방향

- r26을 유지한 채 Source Script만 사후 보정: 하위 구현이 상위 의미보다 먼저 존재하게 되어 계층 권위가 역전된다.
- r25/r26을 별도 WIP authority로 유지: 동일 기능의 두 권위 계보를 만들고 정책상 허용되지 않는 Source Code 선행 상태를 보존한다.
- git history rewrite: 이미 push된 감사 기록을 숨기므로 사용하지 않는다.

## 후속

다음 변경은 Source Script command coverage와 책임 경계를 보정하고 새 revision으로 다시 닫는 작업이다.
그 후 pseudocode → verification/TLC → Source Code 순서를 다시 따른다.

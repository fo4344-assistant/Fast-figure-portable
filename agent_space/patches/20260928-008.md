# 20260928-008

## 목적과 변경 내용

React/Mantine shell 안에 남아 있던 generic raw `div/span` UI element를 Mantine primitive로 교체한다.

변경 내용:

- asset row 이름/meta `span` → `Text component="span"`
- README content host `div` → `Box`
- layout preview resize separator `div` → `Box`
- toolbar flex wrapper `div` → `Box`
- sidebar resize separator `div` → `Box`

resize separator의 pointer handler는 기능 보존을 위해 유지하되 position/width/height 같은 geometry는 Mantine Box props로 전달한다.

## 선택 이유

Mantine 전환의 목적은 일반 GUI element와 styling lifecycle을 직접 HTML/CSS로 반복 구현하지 않는 것이다.

이 단계의 대상들은 domain renderer가 아니라 React shell 내부의 generic GUI container/text/interaction surface이므로 Mantine primitive가 소유하는 것이 일관적이다.

## 유지하는 직접 style

다음 값은 component별 기능 특성이라 공통 theme로 올리지 않는다.

- resize handle cursor/touchAction
- README HTML content 자체
- renderer preview geometry

공통 control 높이/radius/modal lifecycle은 이미 `fastFigureTheme`가 소유한다.

## 선택하지 않은 방향

### Box를 감싼 AppBox wrapper 추가

Mantine Box 자체로 충분하므로 별도 wrapper를 만들지 않는다.

### resize 기능 제거

sidebar/layout preview resizing은 기존 사용자 기능이므로 유지한다.

### renderer DOM을 React/Mantine으로 재작성

dashboard/slot/Plotly 기능 renderer는 이번 GUI primitive 정리 범위가 아니다.

## 후속 작업

다음 단계에서 Mantine component 자체에 남은 반복 size/style props를 감사한다. 의도된 역할 차이(`xs` compact row action 등)는 유지하되, 같은 역할인데 각 위치에서 반복되는 geometry는 theme/default props 또는 Mantine layout props로 통합한다.

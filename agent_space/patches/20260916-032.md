# 20260916-032 — native data/status aside ownership removal

## 목적과 변경 내용

Mantine shell이 이미 소유하고 있는 status 표시와 asset UI 뒤에 남은 native data aside를 제거하고, status 전달 경로를 telemetry 하나로 통일한다.

변경 내용:
- `status()`의 `#status` DOM text projection 제거
- `status()`는 `uiTelemetryState` publish만 수행하도록 단순화
- native data aside의 `#fileName`/`#status` markup 제거
- 더 이상 consumer가 없는 `.file-picker`, `.data-action-button`, `.file-name`, `.status` CSS 제거
- centralized palette/disabled selector에서 해당 legacy selector 제거

## 선택 이유

Mantine `FastFigureStatusDebug`는 `useUiTelemetry()`를 통해 `telemetry.status`를 직접 구독한다. 따라서 `status()`가 같은 문자열을 native `#status`에도 쓰는 것은 동일 UI 의미의 중복 projection이다.

또한 `20260916-031`에서 `setFileName()`과 모든 호출이 제거되어 native `#fileName`은 정적 orphan markup이 되었다. data aside에는 이 두 legacy 출력 외 기능이 남지 않았으므로 markup과 전용 CSS를 같은 ownership 단위에서 제거하는 것이 적절하다.

## 선택하지 않은 방향

- native status DOM과 Mantine telemetry를 계속 병행 동기화하지 않는다.
- telemetry 값을 별도 cache/read model로 복제하지 않는다.
- `status()` 호출자, debug telemetry, app FSM, project/domain state는 변경하지 않는다.
- `.app` wrapper나 readme/dashboard renderer 구조는 이번 patch에서 제거하지 않는다.

## 전제 / 후속 작업 / 누락

- Mantine status UI가 `uiTelemetryState.status`를 구독함을 확인했다.
- native data aside 제거 후 남은 legacy shell/CSS와 frontend↔backend command/API 경계를 다시 감사한다.
- rollback은 이 patch를 되돌리면 native aside, CSS, status DOM projection이 함께 복구된다.

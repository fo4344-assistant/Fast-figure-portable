# 20261013-021 — Allow GitHub-hosted Actions for plan-009 continuation

## 목적

사용자의 새 지시에 따라 plan-009의 GitHub Actions 금지 조건이 self-hosted 서버 비가동을 피하기 위한 운영 조건이었음을 명시하고, self-hosted를 사용하지 않는 범위에서 GitHub-hosted runner를 허용한다.

## 변경

- `agent_space/plans/plan-010.md`를 추가한다.
- plan-009의 기능 범위와 계층 순서는 변경하지 않는다.
- self-hosted runner는 사용하지 않는다.
- 저장소에 이미 설정된 `ubuntu-latest` hosted workflow는 Source Code 회귀, development-layer version 검사, distribution build에 사용할 수 있다.

## 선택 이유

기존 계획을 직접 덮어쓰면 당시 실행 조건과 변경 이유가 사라진다. plans 정책에 따라 후속 계획으로 관계를 기록한다.

## 기각한 방향

- plan-009의 "GitHub Actions는 사용하지 않는다" 문장만 수정: 변경 맥락이 사라지므로 사용하지 않는다.
- self-hosted runner 재활성화: 사용자가 서버를 꺼 둔 상태라고 명시했으므로 사용하지 않는다.

## 후속 작업

plan-009의 Source Code 구현을 r17/r11 lineage에서 진행한다.

# 20261013-023 — Correct empty CSV regression block placement

## 발견

20261013-022 구현 commit의 실제 diff를 다시 검토하는 과정에서 새 `run(27)` empty CSV regression block이 테스트 본문의 끝이 아니라 공용 `run()` helper의 `try` 내부에 잘못 삽입된 것을 확인했다.

애플리케이션 Source Code r13의 의미 변경에는 영향이 없지만 이 상태에서는 regression harness 자체가 재귀적으로 `run(27)`을 호출하는 잘못된 구조가 된다.

또한 20261013-022.patch에는 의도한 테스트 위치만 기록되어 있었으므로 실제 commit과 기록 사이의 배치 차이가 생겼다. 이 패치는 그 차이를 숨기지 않고 별도 교정 기록으로 남긴다.

## 변경

- `agent_space/tests/browser-regression.js`의 `run(27)` block을 공용 `run()` helper 밖으로 제거한다.
- 기존 `run(26)` collision regression 뒤, 최상위 regression sequence의 마지막 항목으로 이동한다.
- 테스트 내용과 r17/r11/r13 기대 의미는 바꾸지 않는다.

## Source of Truth / 계층

- application Source Code 파일은 변경하지 않는다.
- source-code fingerprint와 revision r13은 변경하지 않는다.
- Source Script r17 및 verification-model r11도 변경하지 않는다.

## 선택 이유

테스트 helper 자체를 수정하거나 재귀 실행을 예외 처리하는 대신, 원래 의도한 top-level regression sequence 위치로 block을 이동하는 것이 최소 변경이다.

## rollback

이 패치를 되돌리면 regression harness가 잘못된 재귀 구조로 돌아가므로 독립적으로 rollback하지 않는다.

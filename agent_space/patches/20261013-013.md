# 20261013-013 — Translate r17 interaction changes to PlusCal

## 목적

Source Script r17에서 확정된 slot selection, dashboard deselection, ordinary empty CSV creation/selection, trash row Menu availability, common settings-overlay maximum 의미를 기존 PlusCal pseudocode 책임에 직접 번역한다.

## 변경 내용

- `application_fsm.pcal`: NoSelection과 visible-slot resolution을 명시적으로 분리한다.
- `renderer_runtime.pcal`: content-first 분기를 제거하고 selection-state-first SlotSurfaceClick과 DashboardBackgroundClick을 추가한다.
- `assets_files.pcal`: protected 상태 없는 일반 `빈 CSV.csv` 생성 절차를 추가한다.
- `api_ui.pcal`: empty CSV 생성 후 기존 CSV selection, trash Menu 접근, 네 설정 overlay의 공통 maximum-size 의미를 추가한다.
- `graphs.pcal`: graph object 추가가 current selected CSV를 사용한다는 계약을 명시한다.
- archived pseudocode fingerprint/revision/derived_from metadata를 실제 변경에 맞춰 갱신한다.

## 선택 이유

r17의 새 의미를 Source Code에서 직접 재해석하지 않고 Source Script의 처리 순서와 책임 경계를 PlusCal에 그대로 옮기기 위함이다.

## 고려했지만 선택하지 않은 방향

- graph/image별 selection procedure를 만들지 않았다.
- empty CSV와 graph object 생성을 하나의 procedure로 합치지 않았다.
- trash Menu opened state를 project state로 만들지 않았다.
- concrete Modal px 값을 PlusCal state로 만들지 않았다.
- archived pseudocode fingerprint를 이전 값으로 남기지 않았다.

## 검증 상태

이 patch는 의미 번역만 기록한다. 현재 실행 환경에는 `tla2tools.jar`가 없고 외부 다운로드가 불가능하므로 official PlusCal translator/SANY/TLC 실행을 주장하지 않는다.

canonical verification-model은 계속 stale이며 Source Code 수정 gate는 아직 열리지 않는다.

## 후속 작업

r17 selection/deselection과 empty-CSV mutation/reference 의미를 canonical `verification/` 모델에 반영하고 TLC를 실행해야 한다.

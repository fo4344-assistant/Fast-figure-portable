# Plan047 — 작업 완료 경로에서 UI 요소 직접 갱신

- 근거: `agent_space/plans/plan-047.md`. 기준 커밋: `55ff1b0faaa85747bccb8a5d2091a64a68375446`.
- Frontend FSM은 선택·참조 보정·작업 상태의 결과를 호출자에게 반환한다. Application은 각 전이와 명령 완료 경로에서 영향을 받은 요소의 표시 함수를 직접 호출한다. UI mount가 표시 함수를 제공하고, 각 요소의 표시값과 미확정 입력은 그 요소에서 관리한다. 명령에 필요한 현재 값은 기존 API로 읽는다.
- 자산 트리와 슬롯 연결 행의 조회를 분리했다. 참조 수가 바뀐 자산 정보는 기존 Backend 반영 결과에 남겼다. 같은 그래프 식별자가 기록되는 선 굵기 변경과 CSV 연결 변경을 `chartIds`만으로 구별할 수 없기 때문이다. CSV 선택은 처음 확인한 대상 메타데이터를 반환한다. 열린 CSV 표의 조회 제한 및 같은 열 조회 결과 재사용을 유지했다. 배율 변경은 기존 대시보드에 CSS 배율을 적용하고 입력에 확정값을 표시한다.
- 공통 변경 정보를 보내 화면마다 읽을지 판정하는 방법은 조회 조건을 여러 곳에 흩어 놓으므로 제거했다. 화면 전체를 다시 구성하는 방법은 영향받지 않은 자산·그래프·미리보기 조회까지 실행할 수 있어 제외했다.
- Source Script 59의 변경과 지문을 기록했다. 닫힘은 보류한다. 특히 여러 표시 함수가 함께 호출되는 공유 CSV 교체·프로젝트 교체에서 첫 표시와 명령 완료가 같은 조회를 반복하지 않는지, 연결 행의 배치·이름 변경을 기존 반영 결과만으로 어디까지 구분할 수 있는지 추가 대조가 필요하다.
- 닫힘 이후 전파 범위: Frontend 상태 전이와 UI 갱신 연결, Application의 명령 완료·배율·CSV 선택 절차, 초기화와 renderer 호출. 이번 패치는 pseudocode와 source code를 변경하지 않는다.

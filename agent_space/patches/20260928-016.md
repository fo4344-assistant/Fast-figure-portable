# 20260928-016

## 목적과 변경 내용

README Modal 본문의 스크롤 동작을 Mantine `ScrollArea.Autosize`가 소유하도록 변경한다. 기존 Modal `styles.body`의 `maxHeight: "75vh"`와 `overflowY: "auto"`를 제거하고, 동일한 높이 상한을 `ScrollArea.Autosize`의 `mah`에 지정한다. README 내용 생성과 Modal 열기·닫기 이벤트는 변경하지 않는다.

## 선택 이유

README 길이에 맞게 영역이 커지되 화면 높이를 넘으면 내부가 스크롤되는 동작이 필요하다. 현재 vendored Mantine runtime에서 `ScrollArea.Autosize`와 `mah` 스타일 속성이 실제로 제공됨을 확인했다. 팝업 스크롤은 일반 UI 동작이므로 Mantine component에 맡긴다.

## 고려했지만 선택하지 않은 방향

- **Modal의 `styles.body`를 유지:** 변경량은 없지만 스크롤과 높이 제한을 사용자 정의 CSS로 계속 소유한다. 현재 일반 UI 스크롤의 Mantine 통합 목적에 맞지 않는다.
- **일반 `ScrollArea`에 고정 높이 `h: "75vh"` 지정:** 짧은 README에서도 팝업 본문이 고정 높이를 차지한다. 내용 길이에 따라 늘어나는 기존 동작에는 `Autosize`가 더 적합하다.

## 롤백과 후속 작업

역적용하면 README 본문의 이전 Modal inline scroll 설정으로 돌아간다. domain/EFSM, README 문서 내용, 파일 형식에는 영향이 없다. 후속으로 남은 generic UI와 기능 renderer의 스타일 소유권을 구분해 검토한다.

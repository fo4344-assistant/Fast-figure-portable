# 20260901-025 — Mantine 이미지 슬롯 설정 staging 경계

## 목적과 변경 내용

`plan-003.md`의 Commit B를 이어서 inactive `FastFigureSidebarStaging`에 이미지 슬롯의 세부 설정을 준비한다.

- 이미지 슬롯에서 Mantine `Select`로 `contain`, `cover`, `manual` 맞춤 방식을 선택한다.
- 수동 방식에서는 Mantine `NumberInput`으로 크기 비율과 X/Y 위치를 변경한다.
- 이미지가 없는 이미지 슬롯에는 기존과 같은 빈 SVG 이미지를 삽입하는 Mantine 버튼을 제공한다.
- 현재 이미지 설정을 DOM 없이 읽는 `selectedImageSettingsModel()`을 추가한다.
- 기존 DOM 입력 전용 쓰기 로직을 `applyImageSettingsFromValues(values)`로 분리하고 legacy와 staging이 함께 사용한다.
- 빈 이미지 삽입도 `insertEmptySlotImage()`로 추출해 양쪽 UI가 같은 도메인 명령을 사용한다.
- 앱 버전을 `1.1.54-alpha`로 올린다.

## source of truth 검토

새로운 영속 상태나 React local state를 추가하지 않는다.

- 이미지 맞춤 방식, 크기, 위치의 source of truth는 기존 project image model의 `image.settings`다.
- `selectedImageSettingsModel()`은 현재 선택 슬롯이 참조하는 이미지 설정을 렌더 시 복사해 고정한 일회성 selector 결과다. 저장하거나 다른 기능이 참조하지 않는다.
- Mantine control은 selector 값을 직접 표시하고 변경 때마다 기존 image model 쓰기 경계로 값을 전달한다.
- 빈 이미지의 저장과 슬롯 연결은 기존 `SLOT_IMAGE_IMPORTED` EFSM event가 계속 담당한다.
- 변경 알림은 기존 `appFSM.notify("images", "IMAGE_SETTINGS_CHANGED")` 경로를 유지한다.

## 이 방향을 선택한 이유

기존 `applyImageSettings()`은 DOM 입력값 읽기와 image model 변경을 한 함수에 묶고 있었다. 실제 변경 의미는 안정적으로 동작하고 있으므로 DOM 읽기만 adapter에 남기고 값 기반 함수로 분리하면 legacy와 Mantine가 동일한 검증, renderer 갱신, EFSM 알림을 재사용할 수 있다.

이미지 설정은 CSV 헤더 설정과 달리 하나의 image model과 하나의 알림 경계 안에서 완결된다. 따라서 독립 패치로 검토하기 적합하다.

## 고려했지만 선택하지 않은 방향

### React local state에 이미지 설정 draft 저장

선택하지 않았다. 기존 UI는 변경 즉시 image model과 슬롯 이미지를 갱신한다. 별도 draft를 만들면 같은 설정의 두 번째 권위 상태와 commit/cancel 의미가 추가된다.

### Mantine callback에서 image model 직접 변경

선택하지 않았다. legacy와 staging의 검증 범위 및 갱신 순서가 달라지고 bridge가 도메인 내부 구조를 알아야 한다.

### 이미지 설정과 CSV 헤더 줄 수를 한 패치에서 전환

선택하지 않았다. CSV 헤더 변경은 열 선택 갱신과 해당 CSV를 참조하는 편집 가능 그래프 전체 재구축을 포함한다. 이미지 설정 경계와 책임이 다르므로 별도 후속 패치로 남긴다.

### legacy DOM renderer 제거

선택하지 않았다. Commit C의 단일 shell cutover 전에는 활성 UI가 legacy 한 벌이어야 하므로 기존 control과 event binding을 유지한다.

## 호환성과 동작 보존

- 맞춤 방식과 수동 설정의 허용 범위는 기존과 동일하다.
- 수동 크기 비율은 1–1000%, X/Y 위치는 -100–200%로 제한한다.
- `contain`과 `cover`에서는 기존 수동 수치를 보존하고 렌더 방식만 바꾼다.
- 빈 이미지는 기존과 동일한 1600×900 투명 SVG model을 생성한다.
- 설정 변경 뒤 기존 slot image element 동기화, debug log, images 알림을 유지한다.
- staging shell은 계속 비활성 상태다.

## 후속 작업 / 범위 밖

- CSV 헤더 줄 수와 그래프 재구축 명령의 DOM-독립 경계는 후속 Commit B 패치에서 다룬다.
- 이미지 preview surface 자체는 domain renderer이므로 현재 패치에서 React로 재작성하지 않는다.
- legacy `imageBox`, `imageSelectionPanel`, input과 handler 제거는 Commit C/D까지 보류한다.
- asset tree 본체와 나머지 sidebar 그래프 설정도 아직 전환되지 않았다.

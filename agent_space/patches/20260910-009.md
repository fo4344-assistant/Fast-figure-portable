# 20260910-009 — Print target export value entry 좌표 교정

## 목적
20260910-008까지 반복된 적용 실패의 원인을 확정했다. `fetch_file(start_line=9340)` 결과의 첫 줄이 실제 `exportDashboardTarget()` 선언이었는데 이전 작업 요약의 9345를 실제 line number로 사용한 것이 원인이었다. 동일 구현을 실제 line 9340 기준으로 적용한다.

## 변경
- `exportDashboardTarget(options = null)`로 확장한다.
- 이 패치에서는 함수 선언만 먼저 정확한 좌표에 적용한다. 즉시 이어지는 같은 WIP 작업에서 본문의 값 기반 입력과 Mantine Print Modal을 연결한다.

## 선택 이유
기능 설계 문제가 아니라 잘못된 patch line 좌표 문제이므로 architecture를 변경하거나 추가 abstraction을 만들지 않는다.

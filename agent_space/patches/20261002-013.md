# 20261002-013 — label preview line-height parity

## 목적과 변경 내용

`review-022-mantine-ui-regression-qa.md`의 4번 문제인
레이블 위치 preview에서 글자가 아래로 밀려 보이는 문제를 수정한다.

변경:

- `fast-figure-ui.js`
  - label preview typography에 `lineHeight: 1.2` 추가
- `agent_space/tests/browser-regression.js`
  - regression target r7
  - preview/dashboard label의 computed line-height/font-size 비율 비교
- `development-versions.json`
  - source-code r7 metadata 반영을 의도함
  - 초기 커밋의 revision field 오적용은 아래 정정 기록과 20261002-014에서 보정
- `agent_space/reviews/review-025-source-code-r7-label-preview.md`
  - 변경 경계와 검증 기록

## 이 방향을 선택한 이유

실제 dashboard label은 이미 line-height 1.2를 사용한다.
preview만 Mantine/body 기본 line-height를 상속해 같은 font/padding 설정에서도
line box 높이가 달랐다.

따라서 새 geometry 계산이나 위치 보정값을 넣지 않고 실제 renderer와 같은
typography ratio를 투영하는 것이 가장 작은 수정이다.

## 고려했지만 선택하지 않은 다른 방향

### preview Y 위치에 보정 offset 추가

증상만 이동시키고 line box 자체는 계속 달라져 drag bounding box도 불일치한다.

### padding 값을 줄여 시각적으로 맞춤

실제 renderer와 preview의 padding 의미가 달라져 specification의 projection parity와 어긋난다.

### dashboard label line-height를 preview 기본값에 맞춤

현재 실제 출력 geometry를 불필요하게 바꾸며 구 reference 동작도 변경한다.

## Source Script / verification 판정

- Source Script r12 변경 없음
- verification-model r6 변경 없음
- TLC 상태 변경 없음

이번 수정은 renderer-level typography projection이다.

## 메타데이터 오류 및 후속 정정

초기 013 커밋 `4f31d421de09d4e2347dc5965f98a8e8218d82cd`에서
자동 문자열 치환이 첫 번째 `"revision": 6`에 적용되어
verification-model revision이 6에서 7로 잘못 바뀌고 source-code revision은 6에 남았다.

애플리케이션 source, source-code fingerprint, validation review 내용은 r7 변경과 일치한다.
이 기록 파일은 20261002-014에서 당시 실제 diff를 반영하도록 정정하며,
같은 보정 패치에서 verification-model을 r6로 복원하고 source-code revision을 r7로 맞춘다.

## 검증

실제 DOM에서 dashboard label과 preview label의 computed
`line-height / font-size` 비율을 직접 비교한다.

검사 후 label visibility와 overlay 상태를 원래 상태로 복원하여
이후 regression에 영향을 남기지 않는다.

## rollback

`lineHeight: 1.2`와 r7 regression/review/version metadata를 제거하고 r6로 복원하면 된다.
persistent data 변경은 없다.

## 후속 작업

label 문제군의 다음 기능 문제인 font-size transient editing은 별도 입력/validation 패치로 남긴다.

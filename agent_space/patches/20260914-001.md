# 20260914-001 — active legacy layout/palette DOM cutover

## 목적
Mantine이 이미 소유하는 layout, dashboard zoom, UI palette 경로에서 legacy HTML control이 실행에 필요한 상태가 되지 않도록 한다. 다음 단계의 legacy markup 삭제 전에 `renderDashboard()`와 layout/palette command가 old input/button ID 없이 동작하도록 만드는 cutover다.

## 변경
- `syncDashboardZoomDisplay()`를 old `dashboardZoom` slider와 `dashboardZoomReset` button을 쓰지 않는 계산 함수로 축소한다.
- `syncSlotContentTypeUi()`를 제거하고 `updateFileAvailability()`는 project/model 상태 갱신과 README overlay close만 수행한다.
- old `applyGrid`/`showSlotBorders` event wiring을 제거한다.
- `setDashboardZoomLocked()`에서 old slider/button 상태 쓰기를 제거한다.
- old dashboard zoom slider/reset, layout numeric input, aspect reset, merge/split button event wiring을 제거한다. Mantine overlay는 기존 command 함수(`makeSlots`, `applyDashboardZoom`, `setDashboardZoomLocked`, `mergeSelected`, `splitSelected`)를 직접 사용한다.
- `uiPaletteFromControls()`와 old palette input/button wiring을 제거한다.
- `applyUiPalette()`는 persistent project palette만 source of truth로 사용하고 legacy color input에 값을 역동기화하지 않는다. `applyUiPaletteValues()` API는 유지한다.

## 이유
legacy markup을 삭제하기 전에 active render path에 남은 DOM write/read를 끊어야 한다. 특히 `renderDashboard()` → `updateFileAvailability()`와 resize path → `syncDashboardZoomDisplay()`가 old control을 직접 요구하면 markup 삭제 직후 null-reference가 발생한다. 이 patch는 UI ownership만 정리하고 layout/project/EFSM 의미는 바꾸지 않는다.

## 기각한 대안
- legacy element가 없을 때만 optional chaining으로 무시하는 방식: old UI 계약과 handler가 코드에 계속 남아 single-Mantine ownership이 불명확해져 기각했다.
- hidden compatibility controls를 유지하는 방식: Mantine → hidden legacy DOM이라는 bridge를 장기화하므로 기각했다.

## Source of truth
- layout/zoom persistent 값: `activeProject.layout` / `activeProject.layout.slotStyle` 및 기존 zoom runtime state.
- UI palette: `activeProject.appearance.uiPalette`.
- overlay visibility: `appFSM.state.overlay`.

## EFSM/core 영향
FFPX/FFSX/Plotly serialization, project schema, domain actions, slot merge/split 알고리즘은 변경하지 않는다. 기존 command 경계와 renderer를 그대로 사용한다.

## 검증
workflow의 `git apply --check`, JS syntax, portable build, split/portable Chromium smoke를 모두 통과해야 한다.

## 롤백
이 patch 하나를 revert하면 legacy layout/palette controls와 양방향 DOM sync를 복구할 수 있다. persistent data migration은 없다.

# 20261013-016 — Fix r17 interaction TLA+ sequence notation

## 원인

GitHub Actions run `38356450583`, job `verify-interaction-core`에서 PlusCal translation은 성공했지만 SANY parse가 실패했다.

실패 위치:

```text
Encountered "|->" at line 35, column 6 and token "1"
```

원인은 `SlotContentType`과 `SlotHasContent`를 숫자 key record처럼 작성한 것이다. TLA+ record field syntax는 이 숫자 field 표기를 허용하지 않는다.

## 변경

`SlotIds = 1..3`으로 이미 정해져 있으므로 두 lookup을 1-based sequence로 표현한다.

```text
SlotContentType == <<"graph", "image", "graph">>
SlotHasContent == <<TRUE, TRUE, FALSE>>
```

기존 `SlotContentType[slotId]`, `SlotHasContent[slotId]` 접근 의미는 그대로 유지된다.

## 계층 기록

canonical verification 파일이 바뀌므로 verification-model revision을 r8로 올리고 fingerprint를 갱신한다.

TLC는 아직 다시 통과하지 않았으므로:

```text
status = stale
tlc = pending
validation_review = null
```

을 유지한다.

## 후속

이 push로 `TLA Slot Core` workflow를 다시 실행하고 interaction job의 PlusCal translation, SANY parse, TLC 순서로 결과를 확인한다.

# 20261013-029 — Record Mantine Tree and overlay resize repair plan

## 목적

사용자가 요청한 tree drag 복구, trash resource interaction 복구, bookmark swap 즉시 반영, 설정 overlay resize 및 Layout preview 종횡비 복원을 구현 전에 계획으로 고정한다.

## 변경

- agent_space/plans/plan-012.md 추가.

이 패치에서는 application source, Source Script, pseudocode, verification model을 변경하지 않는다.

## 선택 이유

- Mantine 9.5.2 Tree가 hierarchy/selection/DnD primitive를 이미 제공하므로 커스텀 재귀 tree를 계속 보수하는 것보다 패키지 기능을 사용하는 편이 단순하다.
- trash 진입의 reference detach와 tree resource availability는 다른 의미이므로 분리한다.
- 지난 Layout 수정은 기존 resize handle을 previewWidth 조절로 잘못 해석했으므로 overlay resize와 preview geometry를 분리한다.

## 기각한 방향

- Button/Group 구조에 drag handler만 임시 추가: tree 기능을 계속 중복 구현하게 된다.
- trash reference detach 제거: 의도된 기능이므로 유지한다.
- preview 아래 세로 handle로 width 변경: 사용자가 지적한 왜곡 원인이므로 제거한다.
- Mantine Tree moved data를 project authority로 사용: VFS 단일 진실 원천 원칙에 위배된다.

# 20260911-020 — audit required DOM cutover

## 목적
Mantine이 generic UI를 소유하므로 `auditApp()`이 legacy controls를 필수 DOM으로 요구하지 않도록 한다.

## 변경
- `auditApp()`의 `missingControls` 검사를 `dashboard`, `dashboardCaption`, `graphArea`, `readmeContent` 네 renderer/content root로 한정한다.

## 근거
현재 core가 DOM 존재 자체를 전제로 해야 하는 것은 dashboard/chart renderer root와 README content authority뿐이다. legacy form/button/panel은 Mantine 전환 후 필수 invariant가 아니다.

## 제외
- `REQUIRED_CONTROL_IDS` 상수 정의 자체는 아직 삭제하지 않는다. audit 참조를 먼저 끊은 뒤 dead-code 정리에서 제거한다.
- overlay audit 블록도 이번 패치에서는 건드리지 않는다.
- FFPX/FFSX/Plotly와 model/renderer logic은 변경하지 않는다.

## 이전 실패
018/019는 malformed unified diff 때문에 `git apply` 전 단계에서 실패했고 애플리케이션 소스에는 반영되지 않았다.

## 검증
workflow patch check, JS syntax, portable build, split/portable smoke.

## 롤백
이 패치를 되돌리면 audit가 다시 `REQUIRED_CONTROL_IDS` 전체를 필수 DOM으로 검사한다.

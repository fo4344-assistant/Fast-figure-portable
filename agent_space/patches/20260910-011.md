# 20260910-011 — Mantine print/export overlay

## 목적
20260910-010에서 설정 크기 export의 값 기반 entry가 적용된 데 이어, 현재 화면 capture도 legacy print DOM에서 분리하고 Mantine Print Modal을 실제 shell에 장착한다. 이 패치로 print/export의 Mantine 기능 경로를 WIP 기준으로 완성한다.

## 변경
- `exportDashboard(capture, options)`가 `{ dpi, format, onStatus }`를 선택적으로 받도록 확장한다.
- options가 있는 capture 경로는 legacy `#printDpi/#printFormat/#printStatus`를 사용하지 않고 전달된 값으로 동작한다.
- options가 없는 legacy 경로는 기존 동작을 유지한다.
- `FastFigurePrintOverlay`를 추가한다.
- PNG/JPEG 선택, DPI 36–1200, 폭 100–20000, 세로 100–20000 또는 빈 값 자동 높이를 제공한다.
- `PRINT_EXPORT` lifecycle을 통해 `exportDashboardTarget(options)`을 직접 호출한다.
- `CAPTURE_EXPORT` lifecycle을 통해 `exportDashboard(true, options)`을 직접 호출한다.
- 출력 진행/검증 메시지는 React local state에만 둔다.
- shell 및 `FastFigureMantineUi` export에 Print overlay를 장착한다.

## 선택 이유
출력 계산 및 렌더링 알고리즘을 유지한 채 UI 값 전달 경계만 독립화하여 Mantine과 legacy가 동일 renderer를 사용한다. Mantine에서 legacy input 값을 쓰거나 legacy button을 클릭하는 bridge는 만들지 않는다.

## 기각안
- Mantine에서 `#print*` 값을 설정하고 legacy handler 실행: DOM bridge이므로 기각.
- React에서 export 알고리즘 복제: 기능 source of truth가 둘로 갈라지므로 기각.
- 최종 legacy panel 제거까지 기다린 뒤 구현: WIP 구현 우선 정책에 반하므로 기각.

## Source of truth / EFSM 영향
project/layout/chart/image/annotation 데이터는 기존 model이 source of truth다. print 설정은 일회성 UI 값이며 영속 상태가 아니다. 기존 export renderer와 `PRINT_EXPORT`/`CAPTURE_EXPORT` lifecycle을 유지한다. FFPX schema는 변경하지 않는다.

## WIP 제한
legacy print panel과 handler는 아직 공존한다. focus/outside-click 및 legacy markup 제거는 통합 cutover에서 수행한다.

## 검증
workflow의 git apply, JavaScript syntax, portable build, split/portable file smoke를 모두 통과해야 한다.

## Rollback
역적용하면 Mantine Print Modal과 capture options 경계가 제거되고 010의 target export options entry 및 기존 legacy print UI는 남는다.

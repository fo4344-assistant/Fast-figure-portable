# 20261001-034 — PlusCal P-syntax 통일

## 검사 결과

첫 `TLA Slot Core` workflow에서 PlusCal translator가 다음 오류로 중단했다.

```text
Expected "{" but found "begin"
line 379, column 1
```

원인은 verification code가:

- algorithm header/Main loop는 C-syntax
- procedure/body는 P-syntax

를 혼합한 것이었다.

이는 Source Script 의미나 알고리즘 문제가 아니라 verification code 문법 번역 오류다.

## 변경 내용

verification code 전체 스타일을 P-syntax 쪽으로 맞췄다.

- `--algorithm FastFigureSlotCore {` → `--algorithm FastFigureSlotCore`
- Main의 while/either/with block을 P-syntax `do/end ...` 구조로 변환
- procedure 이름, 호출 관계, branch, candidate/commit 순서는 변경하지 않음
- TLC harness action 종류도 변경하지 않음

## 선택 이유

현재 procedure와 if/return 구조가 이미 P-syntax로 작성되어 있었기 때문에,
Main만 P-syntax로 맞추는 것이 최소 변경이다.

## Source Script 영향

없음.

Source Script r12는 변경하지 않는다.
이 patch는 verification code의 문법만 수정한다.

# 20260915-008 — Remove dead native label editor implementation

## Purpose
Continue the post-cutover legacy cleanup from `20260915-006` by removing the native label-editor implementation that is no longer connected to any active DOM or Mantine callback.

## Exact changes
Remove the following native-only functions from `fast-figure.js`:

- `finiteLabelPosition`
- `labelPreviewGeometry`
- `constrainLabelPreviewPosition`
- `renderLabelPreview`
- `applyLabelSettings`
- `applyLabelPosition`
- `installLabelSettings`

No Mantine component, annotation project state, EFSM event, dashboard label renderer, slot geometry helper, export path, or caption code is changed in this patch.

## Why this direction
`20260915-004` already detached the active Mantine label overlay from `renderLabelPreview()`, and `20260915-006` removed the remaining state-to-native-label-control projections. The corresponding native markup is absent from `Fast-figure.html`, while `FastFigureLabelOverlay` owns the active editor and preview interaction. The remaining functions therefore represent a second, dead UI ownership path that only dereferences removed native controls.

Removing the whole native label-editor ownership unit is simpler and safer than preserving isolated helpers whose only consumers are inside the same dead unit.

## Rejected alternatives
- Keep the functions as dormant compatibility code: rejected because they reference removed DOM identifiers and preserve a false second UI owner.
- Restore hidden native label controls: rejected because that would reintroduce duplicate UI state and forbidden Mantine-to-legacy coupling.
- Move or rewrite the actual dashboard label renderer: rejected because actual figure rendering remains a core renderer responsibility and is not part of the native editor cleanup.
- Combine caption cleanup in the same patch: rejected to keep the ownership unit small after the failed large `20260915-005` patch.

## Source of truth
`activeProject.annotations.labels` and its existing compatibility accessors remain authoritative. Mantine owns label editing and preview UI. `renderDashboard()` continues to own actual labels drawn on the figure.

## EFSM/core impact
None intended. Existing annotation visibility/state transitions and Mantine-emitted label notifications are unchanged. No schema, persistence, FFPX/FFSX, layout geometry, dashboard label order/format, or export behavior is changed.

## Validation
Use the standard Fast Figure patch workflow:

1. `git apply --check` and `git diff --check`
2. JavaScript syntax checks
3. portable HTML build
4. split and portable Chromium `file://` smoke tests
5. source inspection confirming there are no executable references to the removed native label-editor functions

## Rollback
Revert commit `Apply agent patch 20260915-008`.

Because this patch only deletes a dead native editor ownership unit, rollback does not require project-data migration. If the native label editor is intentionally restored later, its markup and ownership rules must be restored coherently rather than reintroducing hidden controls.

## Follow-up
Simplify the caption settings API to be DOM-independent and remove `installCaptionSettings` / `installAnnotationPopup` in a separate patch. After annotation JavaScript ownership is clean, remove CSS used only by the deleted native annotation editor, then continue with print/export fallback DOM cleanup.

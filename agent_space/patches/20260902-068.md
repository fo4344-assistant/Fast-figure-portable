# 20260902-068 — graph slot file/action read + bridge 경계

## 목적

`067`에서 graph editable 전환을 DOM-free command로 분리했으므로, Mantine graph file actions component가 selected slot/chart 상태를 legacy DOM 없이 읽고 command를 호출할 수 있는 최소 bridge를 준비한다.

## 변경 내용

- 앱 버전 `1.1.100-alpha` → `1.1.101-alpha`
- `selectedGraphFileActionsModel(slot)` 추가
  - selected slot이 없으면 `null`
  - `slotId`
  - `chartId`
  - `canExport`
  - `canToggleEditable`
  - `editable`
- UI bridge에 `readGraphFileActions()` 추가
- UI bridge에 `setGraphEditorEditable(editable, chartId)` 추가
  - `067`의 `setGraphEditorEditableFromValue()` 재사용

## read 순수성

read model은 selected slot과 chart/editor를 읽어 immutable snapshot만 반환한다.

- chart/editor를 normalize하지 않음
- DOM을 읽지 않음
- file contents/chart clone을 snapshot에 넣지 않음
- project/domain state를 변경하지 않음

## 파일 기능 의미

selected slot이 있으면 import 대상이 될 수 있으므로 chart가 없는 slot에서도 model은 `null`이 아니다.

반면 FFSX/Plotly export와 editable toggle은 chart가 있어야 하므로 `canExport` / `canToggleEditable`로 구분한다.

## source of truth

- selected slot: 기존 selection/domain
- chart: `slot.chart`가 가리키는 project chart
- editable: `chart.editor.editable`
- React snapshot은 presentation 입력일 뿐 권위 상태가 아니다.

## 변경하지 않는 영역

- FFSX/Plotly import/export implementation
- file schema/validation
- Plotly conversion
- graph renderer
- graph object EFSM
- active legacy UI

## 후속

다음 패치에서 Mantine graph file actions component를 정의한다. export는 기존 `downloadSlotFfsx()` / `downloadPlotlyJson()`, import는 기존 `importSlotFile(file, slot)`, editable은 이번 bridge를 사용한다.

## rollback

read model과 bridge method 두 개, 버전 변경만 제거하면 된다. `067`은 독립 유지 가능하다.

# 명시 경로 삭제 대상·휴지통 조회 연결

`contract.pcal`의 query 경로에 맞춰 `assets.readDeletionTarget(path)`가 전달받은 경로와 Backend 반환값을 그대로 사용하도록 했다. 선택 상태를 몰래 재조회하고 결과를 축약하던 부분을 제거했다. UI는 선택 경로를 명시하고, 확인창에 받은 target에서 kind/id/path만 삭제 명령에 전달한다.

`project_state.pcal`의 `BuildVfsRead`에 적힌 디렉터리→CSV→image 순서와 canonical parent 연결로 VFS 트리를 구성하여 `assets.readTrash`에서 trash 하위 트리의 immutable copy를 반환한다. 공개 readTrash는 이 Backend query를 호출한다. 기존 확인창의 비어 있음·참조 수 표시는 UI가 하위 트리를 순회하고 명시 경로 삭제 대상 조회의 referenceCount를 합산해 유지한다. readTree의 기존 표시 형식 변경은 포함하지 않는다.

# 20260831-016

## 목적

Mantine UI 이관 전에 공통 control 규격을 `MantineProvider` theme 한 곳에 정의한다. 이후 toolbar/sidebar/modal을 이관할 때 버튼 높이, padding, 입력 높이, radius를 개별 컴포넌트마다 다시 지정하지 않도록 한다.

## 변경 내용

- `fastFigureTheme`를 `createTheme()`로 정의한다.
- Fast Figure의 기존 UI 기준을 초기 Mantine theme에 유지한다.
  - font: `system-ui, "Segoe UI", sans-serif`
  - 공통 control 높이: 38px
  - 기본 font size: 14px
  - 기본 radius: 6px
- `Button`에 `ff` 기본 size를 정의한다.
  - `--button-height: 38px`
  - `--button-padding-x: 12px`
  - `--button-fz: 14px`
- `ActionIcon`에 `ff` 기본 size를 정의하고 `--ai-size: 38px`를 사용한다.
- 공통 `Input`에 `ff` 기본 size를 정의한다.
  - `--input-height: 38px`
  - `--input-fz: 14px`
  - `--input-radius: 6px`
- `Input` default props는 Mantine의 TextInput/NumberInput/Select 등 Input 기반 컴포넌트가 공유하도록 한다.
- `MantineProvider`에 `theme: fastFigureTheme`를 연결한다.
- 애플리케이션 버전을 `1.1.31-alpha`로 올리고 built-in README 버전을 맞춘다.
- 실제 toolbar/sidebar/modal DOM은 아직 교체하지 않는다.

## 이 방향을 선택한 이유

Mantine 도입의 가장 중요한 목적은 UI 공통규칙을 여러 CSS selector와 개별 control에서 다시 구현하지 않는 것이다. Mantine가 제공하는 component default props와 CSS variable resolver를 사용하면 이후 개별 UI는 별도 높이/padding 값을 반복하지 않고 같은 규격을 상속할 수 있다.

현재 38px, 14px, 6px 기준은 기존 Fast Figure geometry를 유지하기 위한 migration baseline이다. 이번 단계에서 시각 디자인 자체를 바꾸지 않아 다음 toolbar 이관 시 회귀 원인을 좁힌다.

## 공식 API 확인

Mantine 9 계열에서 다음을 확인했다.

- `theme.components`의 `extend({ defaultProps, vars })`로 공통 default props와 component CSS variables를 정의할 수 있다.
- Button custom size는 `--button-height`, `--button-padding-x`, `--button-fz`를 사용할 수 있다.
- ActionIcon은 `--ai-size`를 사용한다.
- Input은 `--input-height`, `--input-fz`, `--input-radius`를 사용하고 `Input` default props는 TextInput, NumberInput, Select 등 Input 기반 컴포넌트에 공유된다.

## 고려했지만 선택하지 않은 방향

- 기존 `.toolbar button`, `.icon-only` 등의 CSS를 지금 제거하지 않는다. 아직 해당 DOM이 legacy control을 사용하므로 toolbar 이관 커밋과 함께 제거해야 회귀 범위가 명확하다.
- 각 Mantine control에 `size="ff"`를 반복 지정하지 않는다. default props가 그 중복을 없애기 위해 존재한다.
- `AppButton`, `AppInput` 같은 단순 style wrapper를 만들지 않는다.
- primary color와 전체 palette를 이번 단계에서 재설계하지 않는다. 이번 커밋의 책임은 공통 geometry와 typography baseline이다.

# 드롭 거부 경로와 portable 종료 조건 번역

- `frontend/mantine_ui.pcal`의 `DashboardExternalFileDrop`: 준비가 거부되면 즉시 반환한다. 준비 검사를 `try/finally` 앞으로 옮겨 이때 `finishFileDrop()`이 실행되지 않도록 했다. 승인된 import의 finally는 유지한다.
- `portable_build/portable_build.pcal`의 `VerifyNoExternalScriptDependency`: 알려진 세 태그만 재확인하던 코드를 최종 HTML 전체의 외부 script 검사로 바꿨다. HTMLParser로 실제 script의 src 속성을 확인하여 inline JavaScript 내부 문자열을 태그로 오인하지 않는다. 외부 script가 남으면 출력 파일 기록 전에 중단한다.

Mantine·system·portable build 절차를 순서대로 대조했다. system 시작 절차에는 변경이 필요한 차이가 없었다.

Git 기준 `cf561e9011f5a5f6c020c380d434b27a25074c97` 이후 세 파일 변경을 `git diff`로 기록했다. code151/stale, fingerprint는 기존 버전 도구의 계산 함수로 갱신했다.

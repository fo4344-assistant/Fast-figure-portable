# 20260911-013 — workspace/lifecycle legacy DOM cutover

## 목적
Mantine UI 구현이 완료된 뒤에도 `ApplicationStateMachine`의 workspace/lifecycle entry/update가 기존 sidebar/form DOM을 직접 갱신하고 있다. 기존 UI 호환성은 유지 대상이 아니므로 이 역방향 동기화를 제거하고, FSM은 모델 상태와 lifecycle 의미만 유지한다.

## 변경
- `syncAssetSelectionState()`에서 legacy file-action availability 갱신을 제거한다.
- project workspace의 `targetInfo`, file name, preview, CSV/image control, label/caption form 동기화를 제거한다.
- graph workspace는 선택 chart의 `activateChartModel()`만 유지한다. legacy target/preview/form 갱신은 제거한다.
- image workspace는 `refreshImageControls(slot.imageId)`만 유지해 transient active image selection을 모델 수준에서 맞춘다.
- lifecycle entry는 `body`의 busy/aria-busy 상태와 error logging만 유지하고 legacy import/export/print control disabled 동기화를 제거한다.

## 근거
Mantine component는 `appFSM.subscribe()`와 project/model source of truth를 직접 사용한다. 따라서 FSM transition 때 기존 DOM form을 다시 쓰는 것은 중복 UI ownership이며 향후 old markup 제거를 방해한다. 반면 graph의 `activateChartModel()`과 image active-id 갱신은 editor의 transient model selection에 해당하므로 유지한다.

## 제외
- FFPX/FFSX/Plotly parser, serializer, import/export는 수정하지 않는다.
- renderer와 dashboard DOM은 수정하지 않는다.
- legacy helper 정의 자체는 이번 패치에서 일괄 삭제하지 않는다. 실행 경로를 먼저 끊은 뒤 참조 검사 후 제거한다.

## 검증
workflow의 `git apply --check`, `git diff --check`, JavaScript syntax, portable build, split/portable Chromium smoke를 사용한다.

## 롤백
이 패치 하나를 되돌리면 기존 workspace/lifecycle DOM 동기화가 복구된다.

# 20260915-010 — Remove orphaned native annotation editor CSS

## Purpose
Complete the annotation editor ownership cleanup after `20260915-008` and `20260915-009` by removing CSS that only styled deleted native label/caption editor DOM.

## Exact changes
- Remove `.annotation-panel` from shared legacy popup panel selectors while preserving `.layout-panel` and `.print-panel` styling.
- Remove `.annotation-controls`, `.annotation-hint`, and native caption editor selectors such as `.caption-popup`, `.caption-heading`, `.caption-actions`, `.caption-settings`, and `.caption-toggle-setting`.
- Preserve `.popup-heading` rules still used by other legacy UI pending later cleanup.
- Remove native label editor/preview selectors such as `.label-settings`, `.label-setting-fields`, `.label-preview`, `.label-preview-slot`, `.label-preview-label`, `.label-format-setting`, `.label-position-readout`, and `.label-position-reset`.
- Remove annotation-only palette/theme overrides for `.label-preview::after`, `.annotation-panel`, and `.label-preview-label`.
- Preserve actual figure renderer selectors including `.dashboard-caption`, `.caption-prefix`, `.caption-body`, `.caption-section`, `.caption-edit-region`, and `.slot-label`.

## Why this direction
The native annotation editor markup is already absent, the native annotation JavaScript ownership paths were removed in `008`/`009`, and the active editors are Mantine components. Retaining these selectors no longer supports any live DOM and obscures the remaining legacy surface.

This patch deliberately removes only annotation-editor CSS. Layout, print/export, dashboard caption, and slot-label rendering styles remain separate ownership units.

## Rejected alternatives
- Remove all legacy popup/layout/print CSS together: rejected because those ownership areas are cleaned in later steps and still contain live or not-yet-audited paths.
- Remove dashboard caption or slot-label CSS because the editor moved to Mantine: rejected because those selectors style actual figure output, not editor chrome.
- Keep orphan CSS until final cleanup: rejected because annotation ownership is now fully cut over and removing it now makes later legacy audits more precise.

## Source of truth
No state source changes. This patch only removes unused presentation rules. Project annotation state and actual dashboard renderers remain authoritative as before.

## EFSM/core impact
None. No JavaScript, project model, state machine, file format, renderer geometry, or export behavior is intentionally changed.

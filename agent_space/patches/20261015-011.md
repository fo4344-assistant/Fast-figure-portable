# 20261015-011 — Slot Core TLC 실행 시간 제한 수정

## 목적과 변경 내용
Plan 016의 verification r26에 대한 TLC 검증을 완료하기 위해 기존 GitHub Actions Slot Core job의 시간 제한을 45분에서 180분으로 변경했다.

- 대상: `.github/workflows/tla-slot-core.yml`
- 변경: `jobs.verify-slot-core.timeout-minutes: 45 → 180`
- Interaction Core 및 Boundary Core job은 변경하지 않았다.
- verification model, Source Script, PlusCal, application source 및 lineage는 변경하지 않았다.

## 선택한 방향과 이유
run `38703609264`에서 Interaction Core와 Boundary Core는 통과했지만 Slot Core는 45분 제한으로 취소되었다. 검증 의미나 상태공간을 축소하지 않고 실제 탐색 시간을 확보하기 위해 해당 job의 시간 제한만 연장했다.

## 검토했으나 선택하지 않은 방향
- 동일 제한으로 재실행: 같은 제한에 다시 도달할 수 있어 근본 원인을 해결하지 못한다.
- 검증 모델의 핵심 상태전이 제거: 정책상 검증 범위를 임의 축소할 수 없다.
- 모든 job의 제한 연장: 성공한 두 job에는 불필요하다.
- 별도 workflow 추가: 기존 canonical workflow와 중복된다.

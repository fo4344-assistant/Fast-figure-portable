# 20261014-032 — Restore project data-tree projection after batch import refactor

## 원인

r25에서 `importProjectFilesToDirectory`를 candidate-first 구현으로 교체할 때 종료 anchor를
`projectDataTreeObjects`로 잡으면서 그 사이에 있던 `projectDataTreeSnapshot`까지 실수로 제거했다.

이 함수는 Mantine project tree와 overlay가 사용하는 read-only projection이다.
삭제 이후 project tree를 읽는 React component가 정상 렌더되지 않아 layout/label/caption/tree 계열 regression이 연쇄 실패했다.

## 변경

`projectDataTreeSnapshot`을 기존 의미 그대로 복원한다.

## 범위와 원칙

EFSM 책임, persistent mutation, batch import 알고리즘은 변경하지 않는다.
회귀 원인이 패치 범위 오류이므로 새 추상화나 우회 구현을 추가하지 않는다.

# 20261115-014 — Plan031 Source Script 참조 연결 적용

## 요구와 범위

사용자의 수정 시작·계속 지시에 따라 Plan031의 여덟 수정 대상과 두 추가 후보를 적용·판정했다. Source Script의 명령·함수·조회·이벤트·허용값·원형·설정 범위·라벨 계산의 원천과 소비자를 연결한다.

## 변경 이유와 방법

- PROJECT_COMMANDS에 실제 담당 함수 참조를 두고 send가 한 번 선택한다. 네 helper의 Args는 등록 원천을 참조한다. 실제 담당 34개와 후보 계산·재확인·재시도·단일 반영·결과 계산은 유지한다.
- 미사용 PUBLIC_PROJECT_MUTATION_ROUTES를 제거하고 공개 함수의 실제 명령 전달을 유지했다. PUBLIC_API_METHODS는 기존 공개 집합을 실제 함수와 Backend 조회 등록값에 연결한다.
- Application이 Frontend 이벤트 등록값과 세 Backend 참조 판정 함수를 연결한다. 실제 사용처가 없는 interface-intent 등록·설명은 제거했다. Backend의 Frontend import는 추가하지 않았다.
- 기존 Backend 설정의 grid 범위를 공식 layout.readState의 gridLimits로 전달한다. 이미지 범위·graph enum·imageSettings 원형의 소비자는 공통 정의를 참조한다. 설정 값과 기본값은 유지한다.
- formatSlotLabel을 실제 번호와 예시가 함께 사용한다. FFPX/FFSX 문서 구조는 각 파일 형식의 역할로 유지하고 writer/reader에 연결했다. 미사용 system 목록은 제거하고 실제 portable build 입력인 SCRIPTS는 유지했다.
- 계산은 담당 함수의 처리에 두었다. 변수 정의에는 자료형·원형·값의 의미를 적고 함수 참조·등록 자료에 절차 문장을 추가하지 않았다.

# 20261013-031 — Source Script r18 interaction semantics

## 목적과 변경 내용

plan-013의 사용자 관찰 가능 의미를 Source Script에 먼저 반영한다.

- project data tree의 tree move 가능 여부와 slot connection 가능 여부를 분리한다.
- trash CSV/image row는 선택 가능하고, fixed directory가 아닌 trash descendant는 일반 directory로 이동해 복구할 수 있게 명세한다.
- non-trash → trash 이동의 reference detach는 유지하고, trash → normal 이동은 과거 reference를 자동 복원하지 않게 명세한다.
- bookmark slot swap commit 직후 current project/selection 기준 dashboard projection refresh를 명시한다.
- Layout/Label/Caption/Print settings overlay의 하단 세로 resize는 overlay UI-local height만 변경하도록 명세한다.
- Layout preview는 actual rendered width 하나를 geometry 기준으로 사용하고 configured aspect를 유지하며 preview 전용 size-drag 의미를 제거한다.

`development-versions.json`의 Source Script를 r18/open으로 올리고 새 fingerprint를 기록한다. 아직 번역되지 않은 pseudocode, verification-model, source-code는 stale로 전환하고 TLC는 pending으로 되돌린다.

## 변경을 발생시킨 요구와 발견 사항

- Mantine 전환 후 project resource row의 실제 drag surface가 깨져 기존 resource → slot drag 사용성이 사라졌다.
- trash resource가 disabled되고 move source에서도 제외되어 UI에서 복구할 수 없었다.
- bookmark slot swap은 domain state를 바꾸지만 renderer refresh가 없어 다른 selection trigger 전까지 이전 위치처럼 보였다.
- 지난 Layout 수정이 아래쪽 세로 handle을 previewWidth 변경기로 해석하여 popup resize와 preview geometry 책임을 혼합했고, rendered aspect가 어긋날 수 있었다.

## 알고리즘 의미와 책임 경계

- VFS/project state는 계속 유일한 persistent authority다. tree projection과 overlay height는 authority가 아니다.
- tree move와 asset-to-slot connection은 서로 다른 precondition을 사용하지만 실제 mutation은 기존 public command에 수렴한다.
- entering-trash만 reference detach를 발생시키고 leaving-trash는 reference history를 복구하지 않는다.
- swap 후 render는 projection 갱신이며 domain mutation을 반복하지 않는다.
- settings overlay height는 component-local UI state이고 project serialization 대상이 아니다.
- Layout preview geometry는 actual rendered width에서 단방향으로 파생한다.

## 선택 이유

일반 정책의 단일 권위, 계산/상태 변경 분리, 최소 복잡도 원칙에 따라 기존 VFS/move/connect/swap authority를 확장하고 UI-local projection만 분리했다. 새 restore state, drag state authority, preview-size domain state를 추가하지 않았다.

## 고려했지만 선택하지 않은 방향

- trash reference detach 제거: 사용자가 의도된 기능이라고 명시했고 reference 무결성 의미도 유지해야 하므로 기각했다.
- trash asset을 slot에 직접 연결 허용: trash의 연결 해제 의미와 충돌하므로 기각했다.
- original-location restore history 추가: 요구되지 않았고 새로운 persistent authority가 필요하므로 기각했다.
- Mantine Tree의 local moved data를 project authority로 사용: VFS와 이중 source of truth가 되므로 기각했다.
- overlay resize를 Layout preview width 조절로 재사용: 현재 회귀의 원인이므로 기각했다.
- swap 시 별도 임시 DOM patch: renderer projection과 domain state의 이중 동기화를 만들 수 있어 기각했다.

## 닫힘 판정에 미치는 영향

r18은 이 패치에서 `open` 상태다. 변경 의미의 논리적 완결성, 프로젝트 목적 부합, 중복/통합 여부를 별도 closure review에서 검토한 뒤에만 `closed`로 전환한다.

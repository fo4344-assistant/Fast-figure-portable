# 20260906-005 — portable build 기능 우선 적용

## 목적

`002`~`004`에서 build 기능과 built-in README의 여러 떨어진 문구 수정을 한 patch에 묶으면서 후속 HTML hunk가 current context에 적용되지 않았다. 실제 source에는 해당 시도들이 반영되지 않았다.

이번 patch는 portable 계약 복구에 필요한 기능을 먼저 적용하고, 떨어져 있는 third-party 설명 교정은 후속 patch로 분리한다.

## 변경 내용

- 앱 버전 `1.1.110-alpha` → `1.1.111-alpha`
- `scripts/build-portable.py` 추가
- top-level README에 split development source와 portable build 절차 기록
- built-in README의 About/Distribution 영역만 source/portable 구조에 맞게 수정
- React/Mantine/Iconoir/Plotly 개별 설명 문구는 이번 patch에서 건드리지 않음

## 이유

build와 `file://` 실행 가능 여부를 먼저 검증해야 source split이 portable 요구와 양립하는지 판정할 수 있다. 서로 멀리 떨어진 문서 hunk를 기능 patch와 묶을 이유가 없다.

## 검증

- `git apply --check`
- 세 external JS `node --check`
- `scripts/build-portable.py` 실행
- split source `file://` headless Chrome smoke
- generated portable HTML `file://` headless Chrome smoke
- Plotly/FastFigureUiRuntime/FastFigureReactShell/appFSM 존재 및 lifecycle `ready`
- `git diff --check`

## 후속 작업

성공 후 built-in README의 React/Mantine/Iconoir/Plotly source 위치 설명을 별도 최소 patch로 수정한다.

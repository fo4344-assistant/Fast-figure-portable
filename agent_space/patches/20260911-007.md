# 20260911-007 — Remove legacy graph header/global/axis wiring

## Purpose

Complete the active execution cutover for the legacy sidebar graph controls. `20260911-005` removed the graph-object editor entrypoints and `20260911-006` removed palette and FFSX/Plotly DOM entrypoints. This patch removes the remaining header-line, global graph-setting, axis-field, graph lifecycle-wrapper, and graph startup wiring.

## Exact changes

### `fast-figure.js`
- Remove legacy `#headerLines` onchange wiring; Mantine calls `graphEditorHeaderLines()` directly.
- Remove old showLegend/showTitle/showZeroLine button handlers.
- Remove delegated `.axis-fields` change, Enter-key, and setting-toggle handlers.
- Remove graph-only lifecycle-wrapper entries for slot import, palette import, FFSX export and Plotly export. Preserve project import/export and print lifecycle wrappers still used by remaining legacy surfaces.
- Stop startup synchronization/installation of graph-only toggle state, `axisFields()`, `graphColorInputs()`, and `syncEditableUi(null)`.
- Preserve all graph model commands, Plotly rendering, data parsing, graph settings normalization, FFSX/Plotly format functions, and Mantine controls.

## Rationale

These listeners no longer represent supported UI behavior. Leaving them active keeps a second DOM presentation authority even when the controls are visually obsolete. The Mantine graph editor already owns these interactions through UI-independent commands and project-model state.

## Source of truth

- Graph persistent state: project chart model and `appFSM`.
- Graph presentation/edit controls: Mantine.
- File compatibility and rendering: existing non-React functions, unchanged.

## EFSM / core impact

None. No FSM transition, graph schema, chart renderer, parser, serializer, or project-state rule is changed.

## File-format compatibility

FFPX, FFSX, Plotly JSON, CSV and image formats are unchanged.

## Rejected alternatives

- Keep the old delegated axis listeners because they are harmless when hidden: rejected because hidden compatibility is explicitly unnecessary and complicates ownership.
- Route Mantine through old DOM events: rejected because that would recreate a UI bridge.

## Validation

Repository CI must pass patch application, JavaScript syntax, portable build, and split/portable Chromium `file://` smoke tests.

## Rollback

Revert the application commit for this patch. No persisted data migration is involved.

## Follow-up

Decouple the remaining data-selection/runtime helpers from graph DOM defaults, remove dead graph form readers/renderers/helpers, then delete `#buildBox` and graph-only CSS/markup. After that, inventory the non-graph legacy surfaces against the Mantine migration plan.

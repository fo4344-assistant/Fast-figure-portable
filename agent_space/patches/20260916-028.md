# 20260916-028 — orphan native palette-row CSS removal

## 목적과 변경 내용

Mantine palette UI로 전환된 뒤 consumer가 사라진 native `.colors` / `.color` presentation CSS를 제거한다.

변경 내용:
- `aside .colors` width-normalization selector 제거
- `.colors` grid style 제거
- `.color`, `.color input`, `.color code` style 제거

## 선택 이유

current HTML에는 `.colors` 또는 `.color` class를 가진 markup이 없고, current application JavaScript와 Mantine UI도 해당 class를 생성하지 않는다. 실제 palette 기능은 Mantine component와 project appearance state가 담당하므로 이 CSS는 기능 semantics나 renderer가 아닌 legacy frontend presentation 잔여물이다.

## 선택하지 않은 방향

- project UI palette state와 `applyUiPalette`는 유지한다.
- Mantine ColorInput/palette action은 변경하지 않는다.
- generic `.row`, input/select/button CSS는 다른 legacy 영역의 consumer가 남아 있어 이번 패치에서 제거하지 않는다.
- logic EFSM, ProjectObject, API/router에는 변경을 가하지 않는다.

## 전제 / 후속 작업 / 누락

- 이후 generic legacy shell CSS는 실제 consumer가 닫힌 ownership 단위별로 계속 제거한다.
- rollback은 이 패치를 되돌리면 native palette-row CSS가 그대로 복구된다.

## 이유와 기각한 방향

기존 정책·Source와 사용자 설명으로 정해지는 SSoT를 표시값과 동등한 선택지로 제시한 종전 분류를 바로잡는다. UI projection을 authority로 되쓰는 방향, 전용 API나 새 mirror를 필수 해법으로 도입하는 방향, 슬롯 resize 알고리즘을 다시 설계하는 방향은 채택하지 않았다. Source의 부족한 절차를 건너뛰고 코드부터 수정하거나 현재 표시 기능을 제거하는 방향도 제외했다.

## 실제 기록과 범위

- 기준 HEAD: `ae45be706abd50673b4ef9c52fd29b93bf47b22d`.
- patch는 tracked 메모의 `git diff HEAD`와 신규 계획의 native `git diff --no-index`를 합친 실제 두 파일 변경이다. 74 insertions / 8 deletions이며 patch/설명 자체는 재귀 포함하지 않는다. 별도 snapshot/diff 도구는 만들지 않았다.

- tracked 메모의 `git diff --check`에서 whitespace 오류는 없었다. 신규 계획 diff에는 LF/CRLF 안내가 있었다. 테스트·app·build·checker·TLC·브라우저·Actions·commit·push는 실행하지 않았다.

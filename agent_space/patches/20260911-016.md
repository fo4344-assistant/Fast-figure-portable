# 20260911-016 — overlay entry/exit cutover correction

## 목적

## 변경
- `enterOverlayState()`를 no-op으로 전환한다.
- `exitOverlayState()`를 no-op으로 전환한다.
- 앞의 `setOverlayDomState()` 종료와 뒤의 `enterLifecycleState()` 시작을 patch context로 사용한다.

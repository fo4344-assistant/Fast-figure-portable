# 20260903-006 — updateFileAvailability model 입력 경계

## 상태

`20260903-005`는 `git apply --check`에서 `Fast-figure.html:16955` context mismatch로 실패했고 HTML에는 적용되지 않았다. `003`이 적용한 실제 current code는 다시 확인했다.

## 목적

workspace domain/presentation 분리 전에 `updateFileAvailability()`가 이미 계산되고 정책 적용된 availability model을 받을 수 있도록 최소 변경한다.

## 변경 내용

- 앱 버전 `1.1.106-alpha` → `1.1.107-alpha`
- `updateFileAvailability(model = applyWorkspaceAvailabilityPolicy())`
- 전달된 model이 있으면 다시 availability 계산/README-close policy를 수행하지 않고 그대로 legacy button/menu 표시만 갱신
- 인자를 주지 않는 기존 호출은 현재와 동일하게 `applyWorkspaceAvailabilityPolicy()`를 수행

## 이유

이후 workspace domain sync가 availability policy를 먼저 수행하고 legacy presentation wrapper가 같은 결과를 소비하려면, UI adapter가 policy를 두 번 실행하지 않는 입력 경계가 필요하다.

## 선택하지 않은 방향

- workspace wrapper에서 policy를 두 번 호출하는 방식은 불필요한 중복 transition 가능성이 있어 선택하지 않는다.
- availability model을 React state로 저장하지 않는다. model은 한 transition 안의 임시값이다.

## 검증

- 기존 무인자 호출 동작 동일
- model 전달 호출은 DOM 표시만 수행
- `git apply --check`
- `git diff --check`
- JavaScript syntax

## rollback

함수 인자를 제거하고 기존 내부 `applyWorkspaceAvailabilityPolicy()` 호출로 복원한 뒤 버전을 `1.1.106-alpha`로 되돌리면 된다.

## 후속

`007`에서 workspace domain sync와 legacy wrapper를 분리한다.

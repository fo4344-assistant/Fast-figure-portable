# 20260906-037

## 목적

`20260906-036`으로 pre-Mantine application JavaScript와 Plotly가 외부 파일로 분리되었으므로, 기존 `Fast-figure.html` 단일 파일 전용 patch workflow를 현재 split-source 구조에 맞게 갱신한다. 또한 `036`에만 사용한 일회성 source-split workflow를 제거한다.

## 문제

복구된 기존 `.github/workflows/apply-fast-figure-patch.yml`은:

- patch target을 `Fast-figure.html` 하나로 제한하고
- 마지막 inline script를 추출해 syntax check하며
- `Fast-figure.html`만 commit한다.

따라서 `fast-figure.js`가 application source가 된 현재 구조에서는 이후 정상적인 source patch를 적용할 수 없다.

반대로 backup branch의 최신 workflow를 그대로 가져오면 아직 main에 존재하지 않는 `vendor/fast-figure-ui-runtime.js`, `FastFigureUiRuntime`, `FastFigureReactShell`을 smoke test에서 요구하므로 pre-Mantine 단계에 맞지 않는다.

## 변경 내용

`apply-fast-figure-patch.yml`을 현재 split source에 맞게 최소 갱신한다.

허용 source target:

- `Fast-figure.html`
- `fast-figure.js`
- `vendor/plotly.min.js`
- `README.md`
- `scripts/build-portable.py`

검증:

- paired `.md` 존재
- exactly one changed `.patch`
- `git apply --check`
- `git diff --check`
- `node --check fast-figure.js`
- Plotly가 변경될 경우 `node --check vendor/plotly.min.js`
- `scripts/build-portable.py`로 portable HTML 생성
- split/portable 양쪽 `file://` smoke
  - `Plotly` 존재
  - `appFSM` 존재
  - lifecycle `ready`

commit은 실제 변경된 허용 source target과 patch record만 포함한다.

`split-pre-mantine-source.yml`은 `036` 완료 후 다시 실행할 이유가 없으므로 제거한다.

## 선택 이유

Mantine runtime 도입 전에는 현재 존재하는 source만 검증해야 한다. 후대 workflow를 그대로 가져오지 않고 pre-Mantine split 상태에 맞춘 최소 검증만 두면 이후 React/Mantine runtime을 별도 patch로 추가할 때 검증 조건도 해당 patch에서 명시적으로 확장할 수 있다.

## 선택하지 않은 방향

### 기존 HTML-only workflow 유지

application logic patch가 `fast-figure.js`에 적용되지 못하므로 불가능하다.

### backup 최신 workflow 그대로 복구

Mantine runtime/shell을 이미 존재한다고 가정하므로 현재 단계와 맞지 않는다.

### 일회성 split workflow 유지

특정 `036.md` 변경에만 반응하는 완료된 migration 도구이며 장기 인프라가 아니다.

## 기능/EFSM/project 영향

없음. 애플리케이션 source를 수정하지 않는다.

## rollback

이 변경의 diff를 reverse apply하면 HTML-only patch workflow와 `036` 일회성 split workflow 상태로 돌아간다. 애플리케이션 source에는 영향이 없다.

## 후속 작업

workflow 갱신 후 기존 migration patch의 독립 버그 수정 여부를 whitelist audit하고, 필요한 수정만 split `fast-figure.js`에 새 patch로 재작성한다.

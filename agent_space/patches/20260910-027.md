# 20260910-027 — Remove dead legacy asset-tree CSS

## Purpose

Delete CSS that only styled the legacy project-data tree and toolbar removed by `20260910-026`.

Legacy UI compatibility is not retained. FFPX/FFSX and other file-format compatibility are unrelated and untouched.

## Exact changes

### `Fast-figure.html`

Remove selectors dedicated to the deleted legacy asset explorer:

- `.asset-tree-shell`
- `.asset-tree-toolbar*`
- `.asset-tree-toolbar-icon`
- `.asset-tree`
- `.asset-tree-list`
- `.asset-tree-row*`
- `.asset-tree-directory*`
- `.asset-tree-button*`
- `.asset-tree-twistie*`
- `.asset-tree-icon`
- `.asset-tree-label`
- `.asset-tree-action-menu*`
- legacy explorer drop-state selectors
- `.asset-tree-item`
- `.asset-tree-meta`
- `.asset-tree-empty`

Keep generic Iconoir and icon-only button styles because other active controls still use them. Keep `.asset-selection-panel` styles because those legacy panels have not yet been removed in this patch.

## Source of truth

The project data tree is rendered by `FastFigureProjectDataTree` using Mantine/React. It does not use the removed `.asset-tree-*` DOM or CSS.

## File-format compatibility

No JavaScript, FFPX/FFSX reader/writer, package layout, version, or model serialization code changes.

## EFSM / core impact

None. CSS-only dead-code removal.

## Rationale

After `20260910-026`, no markup or renderer creates these classes. Retaining the stylesheet would only preserve obsolete legacy UI implementation details and obscure which UI system owns the tree.

## Rejected alternatives

- Keep CSS for possible fallback: rejected because legacy UI compatibility is not a requirement.
- Rewrite these rules for Mantine: rejected because Mantine owns its own component styling and the selectors do not target the active React tree.
- Remove generic `.iconoir` / `.icon-only` styles in the same patch: rejected because they remain shared by unrelated active controls.

## Validation

Repository CI must pass patch application, JavaScript syntax checks, portable build, and split/portable Chromium `file://` smoke tests.

## Rollback

Revert the application commit for `20260910-027` to restore the obsolete styles. No project or file-format data is affected.

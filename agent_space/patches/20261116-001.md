# pseudocode → source code 검토와 Plan033

## 목적과 요청

사용자가 Source Script와 pseudocode를 기준으로 source code의 번역 불일치를 조사하고, review를 작성한 다음 수정 계획을 작성하도록 요청했다. 이번 변경은 두 문서와 이 설명으로 한정한다.

## 실제 변경

- `agent_space/reviews/review-20261116-001-pseudocode-source-code.md`: 현재 15개 논리 모듈의 source code와 고정 Source Script 52/pseudocode 27을 정적으로 대조한 19개 항목(P1 5개, P2 14개), 정확한 경로·행·입력·결과·영향을 기록했다.
- `agent_space/plans/plan-033.md`: Backend 소유·정규화·읽기, 실제 참조 결과, 자산 가져오기, FSM/공개 선택, UI 현재 읽기, 캡션의 순서로 수정 대상·절차·소비자·대조 입력·완료·중단 조건을 작성했다.
- Source Script와 pseudocode는 고정 기준이고 향후 수정 대상은 source code다. 이번 작업에서 구현·버전·상태는 변경하지 않았다.

## 판단과 대안

기존 graph rebuild와 manual 이미지 0, debug 소유 값, grid 선택 정리 등 이미 대응하는 경로는 보존 대상으로 기록했다. 내부 assetNodes 이름의 일관된 변환과 현재 동기 가져오기 코드의 문장 순서만으로는 별도 결함을 확정하지 않았다. 선택 상태의 별도 store나 캐시, 상위 계층 변경, 34개 command의 일괄 재구조화는 계획에 추가하지 않았다.

## 패치 근거와 확인 범위

- 비교 기준은 `9991697cf25c29ceb051c91779dc506331d6a7ba`다. 세 파일은 이 기준에 없는 새 문서다.
- 동명 `.patch`는 각 새 파일에 대한 실제 `git diff --no-index --binary --full-index -- /dev/null <파일>` 결과를 결합한다. 패치 파일 자체는 payload에서 제외한다.
- 중요한 본문은 전체를 구간별로 읽었고, 잘린 코드 출력은 해당 구간을 복구했다. review와 plan도 끝까지 다시 읽었다.
- 확인은 정적 본문·분기·반환·참조 관계 및 native 패치 대조다. 앱·테스트·빌드·브라우저·TLC·checker 본체·Actions를 실행하지 않았다. 커밋·푸시도 수행하지 않았다.
- Source Script/pseudocode/source code/설정/계층 메타데이터/정책/AGENT/배포물은 유지한다. 구현 승인은 별도로 받는다.

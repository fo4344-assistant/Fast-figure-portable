# 20260902-046 — graph palette export read model

## 목적

Mantine palette save/load UI가 legacy DOM이나 표시용 graph-object snapshot fallback에 의존하지 않고, 기존 `graphPalette()`와 동일한 의미의 canonical palette를 읽을 수 있게 한다.

## 변경 범위

- `selectedGraphPaletteModel(slot = getSelectedSlot())` 추가
- 반환값:
  - `slotId`
  - `chartId`
  - `editable`
  - frozen `colors`
- `colors` 의미는 기존 `graphPalette()`와 동일하게 유지한다.
  - `chart.editor.objects[].color`의 truthy 값만 순서대로 추출
  - 하나도 없으면 `DEFAULT_COLORS` 전체를 fallback으로 제공
- bridge에 `readGraphPalette()` 추가
- 버전 `1.1.85-alpha` → `1.1.86-alpha`

## 이유

`selectedGraphObjectsModel()`의 `item.color`는 UI 표시를 위해 누락된 object color에 `DEFAULT_COLORS[index]` fallback을 제공한다. 이를 그대로 palette export에 사용하면 legacy `graphPalette()`와 다른 파일이 만들어질 수 있다.

따라서 palette export는 표시 모델을 재사용하지 않고 canonical `chart.editor.objects`에서 기존 export 의미를 그대로 파생하는 별도 pure read model이 필요하다.

## source of truth

- canonical graph colors: `chart.editor.objects[].color`
- fallback palette: `DEFAULT_COLORS`
- export read model: `selectedGraphPaletteModel()`

새 persistent state는 없다.

## read purity

- `ensureGraphObjects()`를 호출하지 않는다.
- chart/editor/object를 수정하지 않는다.
- legacy DOM을 읽지 않는다.
- 반환 배열/객체만 freeze한다.

## EFSM / core 영향

없음. read-only adapter 추가다. graph mutation event, chart schema, Plotly renderer, import/export package 형식은 수정하지 않는다.

## 기각안

### `readGraphObjects().objects.map(item => item.color)` 사용

기각. 목록 snapshot의 color는 표시용 fallback이 포함돼 기존 `graphPalette()` semantics와 다를 수 있다.

### `graphPalette()`를 bridge에서 직접 호출

기각. 이 함수는 암묵적 `editing` 전역에 의존한다. selected slot/chart identity를 명시적으로 확인하는 read model이 stale UI 방어와 책임 경계에 더 적합하다.

## rollback

`selectedGraphPaletteModel()`과 bridge `readGraphPalette()` 및 버전 변경만 제거하면 된다. 기존 legacy palette 기능에는 영향이 없다.

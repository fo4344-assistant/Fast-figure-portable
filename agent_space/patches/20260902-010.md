# 20260902-010 — Mantine graph 축 staging sidebar 연결

## 선행 조건

`20260902-009`가 적용되어 `FastFigureGraphAxisStaging` 공통 컴포넌트와 `1.1.59-alpha`가 현재 소스에 존재한다.

## 목적

009에서 추가한 공통 축 컴포넌트를 inactive Mantine sidebar의 graph layout 영역에 연결한다. 축 네 개는 Mantine `Accordion`으로 묶고, 각 항목은 같은 `FastFigureGraphAxisStaging`을 `axisKey`만 바꾸어 재사용한다.

앱 버전은 `1.1.59-alpha`에서 `1.1.60-alpha`로 올린다.

## 변경 내용

`FastFigureSidebarStaging`의 Mantine destructuring에 `Accordion`을 추가한다.

기존 `그래프 전역 설정` 다음, 선택 영역 이전에 `그래프 축 설정`을 추가한다.

- `xBottom` — 아래 X축
- `xTop` — 위 X축
- `yLeft` — 왼쪽 Y축
- `yRight` — 오른쪽 Y축

`Accordion`은 표시/접기 lifecycle만 담당하며 축 설정을 소유하지 않는다.

## source of truth

새 sidebar block은 이미 읽어온 `chartLayout` snapshot을 공통 축 컴포넌트에 전달할 뿐이다. persisted source는 selected chart의 `editor.globalSettings.axes` 하나뿐이며 쓰기 경로도 009/007에서 확인한 기존 `applyChartLayout → applyGraphLayoutSettings → CHART_LAYOUT_CHANGED` 경로뿐이다.

## Mantine/Core 분류

이 패치는 presentation wiring만 변경한다.

변경하지 않는다.

- graph/domain 데이터 구조
- graph object EFSM
- graph action/event/guard
- Plotly renderer
- 축 계산 알고리즘
- import/export
- 활성 legacy UI

## 최소복잡도

축 네 개의 JSX를 복제하지 않고 `[axisKey, label]` 데이터 네 개를 `.map()`하여 하나의 공통 컴포넌트로 렌더링한다. 별도 axis 상태 저장소나 wrapper framework는 추가하지 않는다.

## rollback

1. `그래프 축 설정` Accordion block 제거
2. sidebar Mantine destructuring의 `Accordion` 제거
3. 앱 버전을 `1.1.59-alpha`로 복원

009의 공통 컴포넌트는 inactive 상태로 독립 유지하거나 별도로 롤백할 수 있다.

## 검증

# 20260915-011 — Retry native caption/annotation CSS cleanup in a smaller unit

## Purpose
Recover from the pre-application failure of `20260915-010` by removing only the orphaned native caption/annotation editor CSS in a smaller, exact current-source patch. Native label editor CSS is deliberately deferred to a following patch.

## Failed-attempt recovery
- `20260915-010.patch` and its explanation remain as audit history.
- Its workflow failed at `git apply --check` on `Fast-figure.html:9874` before changing application source.
- No source rollback is required.
- This patch does not retry `010` unchanged; it reduces the ownership unit and rebuilds the hunk against current `main`.

## Exact changes
- Remove `.annotation-panel` from the shared fixed-popup selector while preserving `.layout-panel` and `.print-panel`.
- Remove `.annotation-panel > *` from shared popup child sizing while preserving layout/print rules.
- Replace the obsolete `.annotation-controls` / `.caption-heading` / native caption editor CSS block with the retained `.popup-heading` rules needed by remaining legacy UI.
- Remove native-only selectors for `.annotation-hint`, `.caption-popup`, `.caption-heading`, `.caption-actions`, `.caption-settings`, and `.caption-toggle-setting`.

This patch intentionally does not remove label-editor CSS, print CSS, layout CSS, actual dashboard caption styles, slot-label styles, or palette/theme leftovers outside this local block.

## Why this direction
`20260915-009` removed the last native caption JavaScript ownership path and the active caption editor is Mantine-owned. These CSS selectors now style no live editor DOM. Splitting the failed broad CSS cleanup into caption/annotation and label stages reduces patch fragility and keeps each rollback unit easy to inspect.

## Rejected alternatives
- Retry `20260915-010` unchanged: rejected because its large multi-region patch already failed pre-application.
- Remove label CSS in this retry as well: deferred so this patch has one smaller contiguous ownership area.
- Remove `.popup-heading`: rejected because it is shared with remaining not-yet-audited legacy UI.
- Remove `.dashboard-caption`, `.caption-prefix`, `.caption-body`, `.caption-section`, or `.slot-label`: rejected because these style actual figure renderer output, not the deleted editor chrome.

## Source of truth
No state ownership changes. `activeProject` caption state remains authoritative; Mantine owns caption editing; `syncDashboardCaption()` owns actual dashboard caption rendering.

## EFSM/core impact
None. This is unused CSS removal only. No JavaScript, EFSM/UI-FSM transition, project schema, persistence, export geometry, or actual figure renderer behavior is intentionally changed.

## Validation
Use the standard Fast Figure patch workflow:

1. `git apply --check` and `git diff --check`
2. JavaScript syntax checks
3. portable HTML build
4. split and portable Chromium `file://` smoke tests
5. inspect `Fast-figure.html` to confirm the native caption/annotation editor selectors in this patch are gone while `.popup-heading`, print/layout styles, and actual dashboard caption styles remain

Revert commit `Apply agent patch 20260915-011`.

No data migration or state rollback is required.

# 20261015-012 — TLC 필수 gate 제거

## 목적과 변경 사항

2026-10-15 사용자 지시에 따라 TLC의 장시간 탐색 또는 미완료를 이유로 Plan 016 구현을 계속 보류하던 필수 gate를 제거한다.

- `agent_space/AGENT.md`: Fast Figure의 TLC 통과를 Source Code 구현 및 `current` 판정의 필수 요건으로 두던 규칙 제거. 필수 계층은 Source Script와 직접 번역한 PlusCal pseudocode로 유지.
- `agent_space/plans/plan-016.md`: §1.6, §23, §24, 검증 패치 범위 및 완료 조건의 필수 TLC 실행·통과 단계를 선택적 검증으로 수정.
- `verification/README.md`: TLC 미완료를 이유로 Source Code 완료 처리를 금지하던 설명 제거. 검증 상태 표기는 별도 보존.
- `development-versions.json`: `authority_rule`에서 TLC가 Source Code를 gate한다는 선언 제거. revision, fingerprint, `tlc: pending` 등 실제 lineage 이력은 변경하지 않음.

## 방향 선택 이유

상위 `agent_space/policies/source-script-policy.md` v0.2.6은 verification-model/TLC를 선택적 단계로 명시한다. `scripts/check-development-layer-versions.py`도 Source Code의 `current` 판정 시 TLC `passed`를 요구하지 않으며, Source Script 및 PlusCal lineage를 검사한다. 이에 반해 AGENT 및 Plan 016 문구가 TLC `passed`를 추가 필수 조건으로 요구해 작업을 막았다.

선택적 검증의 실행 결과와 필수 개발 계층의 완료 판정은 분리한다. 검증이 실제로 완료되지 않은 상태를 완료된 것으로 표시하지 않으며, Source Code 개발은 PlusCal에서 바로 진행할 수 있다.

## 고려했으나 선택하지 않은 방향

- 기존 Slot Core의 제한 시간만 연장하고 TLC 성공을 대기: 미완료 검증에 구현 작업이 계속 종속되므로 기각.
- TLC 모델·워크플로와 역사적 검증 기록 모두 삭제: 선택적 검증 능력 및 실제 작업 증거까지 파괴하므로 기각.
- 검증을 미실행 상태에서 `passed`로 기록: 실제 결과와 불일치하므로 기각.
- 개발 계층 전체를 건너뛰고 Source Code를 독립 설계: Source Script → PlusCal 우선순위가 유지되어야 하므로 기각.
- 정책 원문 v0.2.6을 수정: 이미 TLC를 선택 사항으로 규정하므로 변경 불필요.

## 실제 수정되지 않은 관련 부분과 후속 작업

- 기존 `verification-model.tlc: pending`은 과거 실행 결과와 구분하기 위한 실제 상태이므로 유지한다. 이 상태는 더 이상 Source Code 진행을 차단하지 않는다.
- `scripts/check-development-layer-versions.py`의 `passed` 분기 및 validation review 검사 역시 **`passed`라고 선언한 경우에만** 실행되는 무결성 검사로, 실제로 TLC 통과를 강제하는 조건이 아니다. 그래서 변경하지 않았다.
- 이전 Plan 015, 완료된 review 및 patch는 작업 이력이므로 수정하지 않았다.
- 기존 GitHub Actions run은 별도로 계속될 수 있지만 그 종료를 Source Code의 선행 조건으로 사용하지 않는다.
- Plan 016의 Source Code 구현은 별도 후속 작업이다. 이번 패치에서 application source는 변경하지 않았다.

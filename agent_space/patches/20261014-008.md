# 20261014-008 — Apply settings Modal height directly to owned content

## 목적과 변경 내용

settings Modal resize의 계산 결과를 React state를 거치지 않고 component가 직접 소유한 `Modal.Content` DOM projection에 적용한다.

- resize 전용 `height` React state 제거.
- 초기 height는 공통 `min(72dvh, 720px)` 유지.
- mousemove에서 계산한 clamped height를 `contentRef.current.style.height`에 직접 적용.
- drag lifetime과 listener cleanup은 r19의 공통 helper 구조를 유지.
- source-code revision r20, APP build `1.1.40-wip`.

## 실패 근거

r19까지 inline/split regression에서 test 29만 반복 실패했고 나머지 30개 test는 모두 통과했다.

이 시점에서 event transport, direct `Modal.Content` ref, explicit initial height까지 모두 적용했으므로 남은 변동 요소는 React state update를 거쳐 geometry를 반영하는 단계였다.

## 선택 이유

popup height는 project/domain state가 아니라 해당 component lifetime에만 의미가 있는 UI projection이다. resize handler가 소유한 `contentRef`에 직접 style을 적용하면 별도 synchronized state를 만들지 않고 하나의 실제 geometry만 유지한다.

이는 legacy DOM bridge가 아니라 현재 React component가 직접 생성하고 소유하는 DOM node에 대한 component-local interaction이다.

## 고려했지만 선택하지 않은 방향

- regression test 제거: 실제 요구 기능 검증을 잃으므로 기각.
- overlay별 height state 분산: 공통 helper의 목적에 반하므로 기각.

# 20261002-003 — 모듈 PlusCal 검증 방법/결과 문서 확장

## 목적

사용자 요청에 따라 기존 `agent_space/docs/slot-core-module-verification.md`를 단순 mapping/실행 기록에서,
왜 파일 경계 분해를 사용했는지, 실제로 어떤 상태를 유지/제거했는지, 공유 전역 상태를 어떤 입력 projection으로 바꿨는지,
실행 중 어떤 문제가 발견되고 어떻게 수정됐는지, 단일 모델과의 정량 비교가 무엇을 의미하는지까지 재현 가능한 수준으로 확장한다.

## 변경 내용

수정:

- `agent_space/docs/slot-core-module-verification.md`

추가:

- `agent_space/patches/20261002-003.patch`
- `agent_space/patches/20261002-003.md`

Source Script, canonical verification model, TLC execution model, workflow, application source는 변경하지 않는다.

## 문서에 추가한 핵심 내용

- 파일/import 구조를 1차 검증 경계로 선택한 이유
- 단순 파일 분리와 실제 state-product 분해의 차이
- 공유 authoritative state를 consumer input range로 projection하는 규칙
- `idsResolved`, visibility, `layoutAccepted` 입력의 역할
- layout의 `default/payload-a/payload-b` 추상화가 보존하는 의미
- Application FSM unit과 Layout unit 각각의 상태/알고리즘 범위
- canonical operation coverage mapping
- 동일 TLC/BFS/4-worker/2x2 조건
- workflow expression, PlusCal symbol collision, reset resolve branch 누락의 발견/수정 과정
- main 최종 결과와 test run 결과
- generated/distinct/time 감소율과 배수
- 왜 상태 수가 줄었는지에 대한 global product vs local walk 설명
- 현재 실험의 정확한 주장 범위와 미자동화된 한계
- 관련 파일과 GitHub Actions run 식별자

## 수치 기준

main 최종 modular run `36967409524`:

- Application FSM: 1,794,598 generated / 1,008,357 distinct / 8 s
- Layout: 100,797 generated / 60,285 distinct / 5 s
- 합계: 1,895,395 generated / 1,068,642 distinct / 13 s

baseline `36895823728`:

- 14,129,174 generated
- 8,114,209 distinct
- 510 s

비교:

- generated 86.59% 감소, 약 7.45배 작음
- distinct 86.83% 감소, 약 7.59배 작음
- main TLC time 합계 97.45% 감소, 약 39.23배 단축

test branch의 동일 상태공간 run은 12 s였으나 보수적으로 main 13 s를 문서 대표값으로 사용한다.

## 선택 이유

기존 문서는 mapping과 결과 수치는 있었지만,
왜 해당 projection이 sound한 경계 후보인지와 실제 구현 방법을 재구성하기에는 설명이 부족했다.

새 문서는 실험 결과뿐 아니라 경계 선택과 추상화 판단의 근거를 함께 기록해
향후 전체 PlusCal pseudocode의 파일 기반 검증 매핑을 만들 때 재사용할 수 있게 한다.

## 고려했지만 선택하지 않은 방향

### 별도 새 문서 추가

선택하지 않았다.
동일 실험에 대한 mapping 문서와 상세 방법 문서를 둘로 나누면 어느 쪽이 최신인지 관리해야 하므로
기존 `slot-core-module-verification.md`를 유일한 상세 문서로 확장했다.

### verification/ 또는 Source Script에 설명 추가

선택하지 않았다.
이번 변경은 의미/알고리즘 수정이 아니라 실행 실험의 방법과 결과 문서화이므로 authoritative 계층을 수정할 이유가 없다.

## rollback

이 패치를 되돌릴 때는 `agent_space/docs/slot-core-module-verification.md`를
20261002-002 시점의 짧은 mapping 문서로 되돌리고, 이 패치 쌍을 기록에서 제외한다.

# 20260902-053 — 슬롯별 캡션 추가 DOM-free command 분리

## 목적

`20260902-052`가 Caption component의 마지막 UI hunk context 불일치로 apply-check 단계에서 실패했다. 해당 실패 patch는 HTML에 반영되지 않았다.

이 재시도에서는 기능 경계를 먼저 안정적으로 적용하기 위해 DOM-free command와 bridge만 분리한다.

## 변경 내용

- `insertSlotCaptionsFromCurrentLayout()` 추가
  - `clearAllSlotSelections()` 재사용
  - 기존 `SLOT_CAPTIONS_INSERTED` event 재사용
  - 실제 caption text 변경 여부 판정
  - 기존 no-op status 메시지 유지
  - 기존 debug event와 삽입 길이 기록
  - 최신 `readCaptionEditorState()` 반환
- `fastFigureUiBridge.insertSlotCaptions()` 추가
- Mantine component wiring은 후속 patch로 분리

## EFSM / source of truth

새 event/action/state를 만들지 않는다. Caption persisted state와 insertion 의미는 기존 domain/EFSM이 계속 권위자다.

## 파일 호환성

FFPX/FFSX 및 caption schema를 변경하지 않는다.

## 검증

- `git apply --check`
- `git diff --check`
- JavaScript `node --check`

## rollback

이 patch만 되돌리면 adapter command만 제거되며 기존 legacy Caption 동작에는 영향이 없다.

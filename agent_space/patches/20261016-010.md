# 20261016-010 — Plan 017 Source Script 통합 / r27 OPEN

## 목적과 이유

사용자가 승인한 `agent_space/plans/plan-017.md`에 따라 Source Script r26 검토의 참조/ownership/selection/return 충돌을 기존 공통 경로에 통합한다. non-editable imported conversion object에 아직 없는 project CSV를 요구하지 않되 실제 project 참조와 chart 구조 검증은 유지한다. 하위 JS를 정답으로 소급 확정하거나 Plan 016 이전으로 rollback하는 작업이 아니다.

## 실제 변경

- `sourcescript/graphs.py`: 기존 `validateChartModel`의 representation 판정, conversionRows의 기존 의미 명시, 실제 CSV를 이미 가진 일반 chart 검증 유지, Backend 내부 graph candidate helper, post-commit chart/editable query 반환.
- `sourcescript/project_state.py`, `sourcescript/assets_files.py`: 같은 validator scope를 project/reference/package read/write/remap에서 사용. wrapper는 file/new input/choice만 보내며 current-state candidate는 Backend command에서 계산. 생성/import 성공 값은 실제 result id/path를 사용한 official query로 반환.
- `sourcescript/project_efsm.py`, `sourcescript/application_fsm.py`, `sourcescript/interface_fsm.py`: current authority 재확인, 단일 commit, 기존 result의 chart-scoped index hint producer와 reconciliation consumer 연결, hint 부재와 explicit clear 구분, 독립 current CSV 보존, 내부 tuple과 공개 반환 구분.
- `sourcescript/api_ui.py`, `sourcescript/layout_annotations_export.py`: 기존 move `from/to`, delete clear와 layout/annotation wrapper 입력/Backend candidate 책임 정렬. 새 result 타입/사후 선택 전이를 만들지 않음.
- `sourcescript/renderer_runtime.py`: 기존 renderer 안에 instance identity/generation에 따른 재사용/교체/purge/resize, stale completion 폐기와 image surface resource 수명 구체화. API 문법/scheduler primitive 고정 없음.
- `sourcescript/system.py`: 미정 항목을 빈 목록으로 두지 않고 D/E 잔여 작업을 기록.
- `development-versions.json`: Source Script r27/fingerprint 갱신, current/open 및 closure_review=null 유지. PlusCal/model/code stale 및 과거 derived_from 보존.
- `.github/workflows/development-layer-version.yml`: 기존 checker의 누적 검증에 쓸 선택적 dispatch `base_sha` 입력. push에는 기존 before SHA 사용.
- `agent_space/plans/plan-017.md`, `agent_space/reviews/review-20261016-005-plan017-r27-open.md`: 실제 경과, 정적 자기검토, 미정 범위/닫힘 제한 기록.

## 선택하지 않은 대안

- non-editable chart 전체 무검증: 실제 persistent 참조/구조 오류까지 숨기므로 제외.
- import 때 fake CSV 생성 또는 conversion 전용 두 번째 validator: deferred editable 전환 의미와 단일 검증 원천을 훼손하므로 제외.
- Application candidate 전달 예외, hint 후처리 전이, 새 성공 envelope/읽기 저장소: 중복 authority/경로가 생기므로 제외.
- 모든 read를 command화하거나 renderer가 Project에 역쓰기: query/mutation 경계를 훼손하므로 제외.
- JS 우선 수정 또는 placeholder를 닫힘으로 간주: 상위 원천이 아닌 하위 설계가 의미를 결정하게 되므로 제외.
- 애매한 palette/axis/trace 기본값을 임의 결정: 명세의 미정을 숨기므로 open으로 남김.

## 미포함 범위와 남은 작업

정책 개정, PlusCal/model/application JS/browser test/build/distribution 변경, TLC와 로컬 실행은 없다. graph trace/layout의 field별 계산/변환 제외 조건, reciprocal axis와 실제 기본값, 전체 public API 반환/실패/취소 및 복합 동작 trace는 미완료다. 이번 국소 통합만으로 closure를 올리거나 하위 구현을 재개하지 않는다. 상세는 위 r27 open review를 따른다.

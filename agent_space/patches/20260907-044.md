# 20260907-044 — Mantine selected asset download button

## Purpose

Continue the Mantine sidebar port with a non-destructive project-data action while preserving the existing asset-selection FSM, project VFS, asset model, and download implementation.

## Scope

This patch changes only `fast-figure-ui.js`.

It does not modify:

- `fast-figure.js`
- asset-selection FSM transitions
- `projectVfs`
- CSV/image project models
- `downloadProjectAsset()`
- delete/reset behavior
- asset-tree rendering or selection behavior

## Exact changes

1. Adds a Mantine `선택 에셋 다운로드` button to `FastFigureDataActions`.
2. The button is enabled only when:
   - lifecycle state is `ready`, and
   - `appFSM.state.assetSelection` is `csv` or `image`.
3. The button directly calls the existing `downloadProjectAsset()` function.
4. No legacy button `.click()` path is used.

## Why this direction

Asset download is already a complete non-destructive command whose default argument reads the selected asset path from `appFSM.state.assetPath`. Reusing that function directly lets Mantine replace only the generic button presentation without duplicating project VFS or binary download logic.

## Rejected alternatives

### Calling `#assetDownload.click()`

Rejected because legacy DOM must not become a compatibility API for Mantine.

### Reimplementing asset resolution/download inside React

Rejected because `projectVfs.resolve()`, asset validation, Blob creation, URL cleanup, and status reporting already belong to the existing functional implementation.

### Porting delete and folder operations in the same patch

Rejected because delete requires destructive confirmation behavior and folder creation currently depends on text-input prompting. Those belong to later Mantine Modal/Input migration steps.

## Rollback

Revert the single `fast-figure-ui.js` hunk from `20260907-044.patch`. No project data or FSM migration is required.

## Verification

The standard patch workflow must pass:

- `git apply --check`

- portable single-file build
- split `file://` smoke test
- portable `file://` smoke test

Manual parity checks for later cutover:

- no selected asset → download button disabled
- selected directory → download button disabled

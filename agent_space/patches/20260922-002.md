# 20260922-002

## 목적과 변경 내용

실패한 `20260922-001`의 Mantine shell cutover 의도를 current source에 다시 적용한다.

`20260922-001`은 application source에는 적용되지 않았고, `Fast-figure.html`의 인접한 두 diff hunk가 동일한 `</head>/<body>` context를 겹쳐 사용해 `git apply --check`에서 실패했다. 이 패치는 해당 두 hunk를 하나로 합친다.

기능 변경 의도는 동일하다.

- Mantine React root의 `hidden` 제거
- root를 fixed overlay로 유지하고 root 자체 pointer event 차단
- Mantine Header/Navbar만 pointer event 허용
- dashboard renderer `.app`을 navbar width + renderer main의 2-column 구조로 변경
- navbar width/collapse를 frontend-local `useEffect`에서 `.app --sidebar-width`로 반영
- navbar 변경 후 Plotly resize 예약
- generic `main` CSS를 `.app > main`으로 제한

## 선택 이유

`001`의 source 설계에는 문제가 없었고 failure는 patch serialization 문제였다. 실패 patch를 수정/덮어쓰지 않고 새 temporal ID로 재작성해 audit history를 유지한다.

## 선택하지 않은 방향

- 실패한 `001.patch`를 수정하지 않는다. 이미 실패 기록으로 남아 있으므로 immutable audit history로 보존한다.
- 겹친 hunk를 그대로 재시도하지 않는다.
- application source를 GitHub contents API로 직접 수정하지 않는다. 기존 patch workflow를 유지한다.

## 전제와 후속 작업

- `001`은 source 변경을 만들지 않았다.
- 이 패치 적용 뒤 `selectedObjectIndex` SoT 통합을 진행한다.
- 이후 layout selection을 frontend-local state로 옮긴다.

## 롤백

이 패치만 역적용하면 Mantine shell은 다시 hidden staging 상태가 되고 renderer layout은 이전 legacy grid 형태로 돌아간다. project/domain schema에는 영향이 없다.

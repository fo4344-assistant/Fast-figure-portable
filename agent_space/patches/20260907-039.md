# 20260907-039 — Mantine shell/toolbar 직접 구현 시작

## 목적

`plan-006`과 `review-010` inventory에 따라 migration bridge 없이 실제 React+Mantine UI 구현을 시작한다.

이번 단계는 active owner를 바꾸지 않는다. legacy UI는 계속 사용자에게 보이고, hidden `ff-react-bootstrap-root` 안에는 향후 cutover에 사용할 Mantine shell/toolbar를 실제로 렌더링한다.

## 변경 내용

- `fast-figure-ui.js` 신규 추가.
- 기존 `window.fastFigureUiRoot` 한 개만 사용.
- React `useSyncExternalStore`가 기존 `appFSM.subscribe()`와 `appFSM.state`를 직접 구독.
- `FastFigureToolbar` 구현:
  - 레이아웃
  - 레이블
  - 캡션
  - 프린트
  - target info
- 각 overlay button은 legacy DOM을 호출하지 않고 직접
  `appFSM.send("TOGGLE_OVERLAY", { overlay, source: "mantine" })`를 사용.
- toolbar active state는 `appFSM.state.overlay`에서 직접 읽음.
- target info는 `appFSM.state.workspace`와 기존 `getSelectedSlot()`에서 계산.
- `FastFigureShell`은 Mantine `AppShell`/`AppShell.Header`를 사용해 toolbar를 호스팅.
- 개발 HTML은 `fast-figure.js` 뒤에 `fast-figure-ui.js`를 로드.
- portable builder가 새 UI source도 inline.
- build version `1.1.30-alpha` → `1.1.31-alpha`.

## 하지 않는 것

- legacy toolbar 제거 또는 숨김
- legacy button `.click()` 사용
- legacy input `.value` 사용
- bridge/store/snapshot/read-model 추가
- UI FSM/EFSM/project model 수정
- overlay lifecycle 재설계
- sidebar/editor/modal 구현
- cutover

## 상태 경계

React가 별도 application state를 만들지 않는다.

```text
React render
  ← useSyncExternalStore
  ← appFSM.subscribe / appFSM.state

Mantine callback
  → appFSM.send(...)
```

`appFSM.notify()`가 model 변경 시 revision을 올리고 기존 listener를 호출하므로 React는 별도 migration store 없이 project/domain 변경에도 다시 렌더링할 수 있다.

## 기능 보존

현재 active UI는 legacy 한 벌이므로 사용자 동작은 변경되지 않는다. hidden Mantine toolbar는 동일 FSM event를 직접 사용해 향후 cutover 경로를 실제로 검증한다.

## rollback

이 patch를 reverse apply하면 `fast-figure-ui.js`와 그 script/build entry가 제거되고 version이 `1.1.30-alpha`로 돌아간다. React/Mantine runtime baseline `038`은 유지된다.

## 후속

`review-010` 순서대로 project/data/sidebar controls와 overlay contents를 같은 방식으로 구현한다. 실제 command가 legacy handler 안에 inline되어 있을 때만 UI 독립적인 값 기반 command를 추출한다.

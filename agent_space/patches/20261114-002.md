# Public API 명시 인자 binding 번역

목적: `pseudocode/application/public_api/contract.pcal`의 `InvokePublicWrapper`와 기존 public binding의 인자·helper 연결 차이를 갱신한다.

변경: graph mutation은 명세의 slotId/chartId를 기존 helper에 직접 전달한다. image settings도 명시적 slotId를 받는다. graph import의 공개 `(slotId, file)` 인자를 기존 file-first helper에 연결하고 importing lifecycle은 한 번만 실행한다. print save/capture는 statusSink를 전달한다. Mantine의 실제 호출자와 기존 회귀 호출을 같은 서명으로 변경하고 기존 사례170의 직접 binding·import 전달 조건을 보완했다.

이유: 선택을 재조회하는 convenience helper 대신 명세에 적힌 대상을 전달해야 한다. 기존 helper와 lifecycle은 재사용한다. 인자 형태를 추측하는 호환 분기나 domain helper 재작성은 명세에 없으므로 추가하지 않았다.

범위: 기존 WIP의 수정 전 텍스트 기준 5파일, 156 additions/142 deletions. 패치 71089 bytes, SHA-256 `fab27bda934648a26b3a8d8a070491375471323cfe3544f393bc40623e447a00`. 임시 저장소 파일은 만들지 않았다. 이 설명과 패치 자체는 diff에서 제외한다. Source/PlusCal·기존 plan/memo는 변경하지 않았다. sibling assets/tree/trash 등 다른 절차의 번역은 이 패치 범위가 아니다.

정적 확인: 현재 파일에 대한 patch reverse check와 whitespace 점검이 통과했다(기존 LF→CRLF 경고만). code149/stale, fingerprint `sha256:74d64c3bccb30edae96f516e09f6e2b5577b4993544f96f5b3afba42380dd476`; Source45/PlusCal25와 derived_from은 유지했다. 테스트·빌드·공식 checker·브라우저·Actions는 실행하지 않았다. 상위 로직 검증이나 전체 재작성은 수행하지 않았다.

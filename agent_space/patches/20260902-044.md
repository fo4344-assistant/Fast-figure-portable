# 20260902-044 — graph palette parser + save helper reuse

## 목적

`20260902-043`의 안전한 부분을 분리해 먼저 적용한다.

1. palette JSON/HEX 규칙을 순수 `parseGraphPaletteText(text)` helper로 정의한다.
2. legacy palette 저장이 중복 Blob/download 구현 대신 기존 `downloadJsonFile()`을 사용하게 한다.

load handler의 parser 전환은 이 패치에 포함하지 않는다.

## 043 실패 원인 및 분리 이유

`043`은 마지막 load-handler hunk의 unified-diff line-count 오류로 `git apply --check` 단계에서 `corrupt patch ...:57`로 실패했다. HTML에는 변경이 적용되지 않았다.

parser 추가와 save handler hunk는 patch parser가 그 위치까지 정상적으로 읽었으므로, `044`에서는 해당 두 책임만 분리해 적용하고 load 전환은 다음 패치로 미룬다.

## 변경 범위

- `parseGraphPaletteText(text)` 추가
  - 최상위 배열 또는 `{ colors: [...] }` 지원
  - `#RRGGBB` 형식만 유효 항목으로 인정
  - 기존 오류 문구 유지
- `saveGraphPalette`의 직접 `Blob`, `<a>`, `URL.createObjectURL/revokeObjectURL` 구현 제거
- 기존 `downloadJsonFile({ colors: graphPalette() }, filename)` 재사용
- 파일명 규칙 유지: `chart-palette-<ISO timestamp>.json`
- 버전 `1.1.83-alpha` → `1.1.84-alpha`

## source of truth

- palette 파일 검증 규칙: `parseGraphPaletteText()`
- JSON 다운로드 동작: 기존 `downloadJsonFile()`
- graph palette 값: 기존 `graphPalette()` / canonical graph objects

## EFSM / core 영향

없음. parser는 순수 helper이며 save는 파일 출력만 단순화한다. graph mutation, EFSM event, chart schema, Plotly renderer는 수정하지 않는다.

## 기각안

- `043` 전체를 다시 한 번에 재시도: 기각. 여러 위치를 동시에 수정해 실패 지점 추적 비용이 커진다.
- 새 download helper 추가: 기각. 기존 `downloadJsonFile()`이 같은 기능을 이미 제공한다.

## rollback

- `parseGraphPaletteText()` 제거
- save handler의 기존 Blob/download block 복원
- 버전 문자열 두 곳 복원

20260914-003이 overlapping unified-diff hunk 때문에 적용되지 않았으므로 같은 cutover를 비중첩 hunk로 교정해 적용한다.

## 변경
- `setDashboardZoomLocked()`의 legacy slider/button DOM write 제거.
- old dashboard zoom/reset, layout numeric/aspect, merge/split event wiring 제거.
- `uiPaletteFromControls()` 제거.
- `applyUiPalette()`를 project palette 단일 source로 전환하고 legacy color input 역동기화 제거.

## 이유

## 기각한 대안
hidden legacy controls 또는 optional DOM bridge 유지 방식은 single-Mantine ownership을 훼손하므로 사용하지 않는다.

## Source of truth
layout은 `activeProject.layout`/`slotStyle`, palette는 `activeProject.appearance.uiPalette`, zoom은 기존 runtime state다.

## EFSM/core 영향

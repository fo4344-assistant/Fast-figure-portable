# 20260911-006 — Remove legacy graph palette and file-action wiring

## Purpose

Remove the remaining legacy graph palette and FFSX/Plotly DOM action entrypoints after `20260911-005` disconnected the graph-object editor. Mantine already owns these controls. Legacy UI compatibility is not retained.

## Exact changes

### `fast-figure.js`
- Remove legacy graph palette reset/save/load button and hidden file-input handlers.
- Remove legacy FFSX/Plotly export/import button/input handlers and editable-toggle binding.
- Remove the legacy hidden `importSlotJsonFile` onchange path.
- Keep `downloadSlotFfsx()`, `downloadPlotlyJson()`, `importSlotFile()`, FFSX build/read functions, Plotly conversion, chart rendering, and all `graphEditor*` commands.

## Rationale

These handlers are duplicate presentation entrypoints. Mantine calls the same UI-independent functional commands and uses React-owned file inputs, so retaining hidden legacy controls would preserve an unnecessary second UI authority.

The remaining header/global/axis/startup graph wiring is removed immediately afterward as the same overall graph cutover; the patch boundary follows actual source blocks to avoid the context failures seen in `003`/`004`.

## Source of truth

- Persistent graph state: project chart model / `appFSM`.
- Generic graph controls: Mantine.
- FFSX and Plotly compatibility: existing UI-independent parser/serializer/import/export functions.

## EFSM / core impact

None. No event semantics, chart schema, renderer logic, or project mutation rules change.

## File-format compatibility

No FFPX, FFSX, Plotly JSON, CSV, image, parser, serializer, manifest, or package-version behavior changes.

## Rejected alternatives

- Keep hidden legacy controls wired: rejected because legacy UI compatibility is not required.
- Route Mantine through legacy button handlers: rejected because it recreates a DOM bridge.
- Move format code into React: rejected because file compatibility should remain UI-independent.

## Validation

Repository CI must pass patch application, JavaScript syntax, portable build, and split/portable Chromium `file://` smoke tests.

## Rollback

Revert this patch's application commit. No stored data migration is involved.

## Follow-up

Remove header/global/axis/lifecycle/startup graph wiring, then delete dead graph form readers/renderers/helpers and the complete `#buildBox` markup/CSS.

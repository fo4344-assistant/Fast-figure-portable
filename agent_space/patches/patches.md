# patches

코드 및 문서 변경을 재현 가능한 diff 패치로 보관하는 경로입니다.

모든 수정은 `.patch` 파일과 동일한 기본 이름의 `.md` 설명 파일을 한 쌍으로 기록합니다. 설명 파일에는 변경 목적, 적용 방향, 해당 방향을 선택한 이유, 다른 방향을 선택하지 않은 이유, 패치에 포함되지 않았지만 함께 발생한 변경사항을 기록합니다.

## 이름 규칙

패치 쌍의 기본 이름은 `YYYYMMDD-NNN` 형식을 사용합니다.

- `YYYYMMDD`: 기록 날짜
- `NNN`: 같은 날짜 안에서 `001`부터 증가하는 3자리 순번
- 파일 이름에는 변경 내용, 기능명, 모듈명, 구현 방식 등 의미 정보를 넣지 않습니다.
- 패치가 무엇을 변경했는지는 동명 `.md` 설명 파일에서 확인합니다.

예:

```text
20260831-001.patch
20260831-001.md
20260831-002.patch
20260831-002.md
```

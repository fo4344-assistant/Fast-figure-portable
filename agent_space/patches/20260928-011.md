# 20260928-011

## 목적과 변경 내용

Mantine Modal 공통 lifecycle default props가 비어 있는 회귀를 수정한다.

`20260928-004`에서 공통 Modal 규칙을 theme로 옮긴 직후 각 Modal의 반복 props를 제거하는 과정이 theme block 내부의 같은 문자열까지 함께 제거하여 다음 상태가 남았다.

```js
Modal: Modal.extend({
  defaultProps: {},
})
```

이번 patch는 공통 규칙을 theme에 정확히 복구한다.

- `centered: true`
- `closeOnClickOutside: true`
- `closeOnEscape: true`

개별 Modal에는 동일 props를 다시 추가하지 않는다.

## 선택 이유

이번 Mantine 전환의 핵심은 popup 동작을 각 위치에서 조금씩 다시 구현하지 않고 Mantine의 공통 lifecycle/default props가 한 곳에서 소유하도록 하는 것이다.

따라서 회귀를 개별 Modal props 복원으로 고치지 않고 theme의 단일 공통 규칙을 복구한다.

## 원인

`20260928-004` patch 생성 시 theme block을 추가한 뒤 source 전체에 대해 반복 `centered/closeOnClickOutside/closeOnEscape` 문자열을 제거하는 변환을 적용했다. 그 변환이 기존 Modal 사용처뿐 아니라 새 theme block까지 대상으로 삼았다.

## 선택하지 않은 방향

- 각 Modal에 세 props를 다시 반복하지 않는다.
- custom popup hook/lifecycle을 추가하지 않는다.
- Mantine default 동작에 암묵적으로 의존하지 않는다. Fast Figure의 공통 정책을 theme에 명시한다.

## 검증

- 수정 전 세 공통 props의 source count가 모두 0이고 empty Modal defaultProps block이 존재함을 확인했다.
- GitHub-generated diff 사용
- Actions `git apply --check`
- `git diff --check`
- JS syntax
- portable build
- split/portable `file://` smoke
- 적용 후 세 props가 theme block 한 곳에만 존재하는지 확인

## 롤백

역적용하면 Modal 공통 defaultProps가 다시 비어 있게 된다. domain/EFSM에는 영향이 없다.

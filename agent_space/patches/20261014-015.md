- 별도 `ProjectStateMachine`과 `projectEFSM` instance를 추가한다.
- persistent command는 `PROJECT_COMMAND_ACTIONS`를 통해 projectEFSM으로 route하고, commit 후 interfaceFSM의 `reconcileProjectResult`를 호출한다.
- 기존 UI 호출부를 즉시 전부 깨지 않기 위해 `appFSM`은 state machine이 아닌 compatibility routing facade로 남긴다.
- project action이 selectedSlotId 또는 interface machine state를 직접 변경하던 일부 경로를 selection hint/result로 전환한다.
- project load action에서 renderer/UI runtime rollback 결합을 제거하고, project commit 후 caller가 projection을 수행한다.
- grid candidate builder에서 selectedSlotId 변경과 renderer 호출을 제거한다.
- pending slot content type은 project mutation이 아니라 UI/runtime local state로 남긴다.

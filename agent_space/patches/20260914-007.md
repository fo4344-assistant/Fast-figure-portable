# 20260914-007 — dashboard zoom lock DOM cutover

## 목적
후속 legacy layout markup 제거를 위해 `setDashboardZoomLocked()`의 old slider/button DOM write를 먼저 분리 적용한다. 이전 006은 인접 hunk가 닫는 context를 공유해 적용되지 않았다.

## 변경
`setDashboardZoomLocked()`가 `dashboard` renderer root와 zoom runtime state만 사용하도록 하고 `dashboardZoom`, `dashboardZoomLock` control 상태 쓰기를 제거한다.

## 이유
Mantine layout overlay가 lock 상태를 자체 React state/FSM snapshot으로 렌더하므로 legacy control write는 중복 ownership이다.

## Source of truth
기존 dashboard zoom runtime state와 renderer root.

## EFSM/core 영향
없음. serialization/schema/layout 계산은 변경하지 않는다.

## 검증
workflow 전체 검증.

## 롤백
patch revert로 old control write 복구 가능.

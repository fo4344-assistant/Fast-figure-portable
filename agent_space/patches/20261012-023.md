## Source Code changes

### Slot bookmark interaction
- graph/image content-body click no longer selects a non-selected content slot.

- empty slot surface remains selectable.
- drag start keeps bookmark click suppression active.
- drop/dragend clears drag source but delays suppression release across the post-drag click opportunity.

- object reorder/color/delete controls are disabled when the chart is not editable.
- existing object selection itself remains available.

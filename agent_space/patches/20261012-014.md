# 20261012-014 — Define collision-modal dismissal before continuing PlusCal

## Source Script change trigger
During the r13 PlusCal fidelity pass, api_ui.useProjectAssetImportCollision had no defined outcome for closing the Modal without pressing rename/replace. The current lower implementation silently maps close to rename, so the missing Source Script meaning could not be filled at the pseudocode layer.

## Meaning added
- Only explicit rename/replace choices produce an import plan.
- Escape, outside click, close button, or component cleanup without an explicit choice is cancel.
- Cancel clears the UI-local pending resolver/collision state, returns no plan, and causes no project/domain mutation.

## Responsibility / authority
The rule stays in api_ui because it is Modal/resolver lifetime behavior. No new project state, import-plan authority, or asset mutation path is added. system.py records the resolved review item.

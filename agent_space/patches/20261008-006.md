# 20261008-006 — Distinguish CSV reference IDs from VFS selection paths

## Problem
The first PlusCal draft placed the object's csvId in assetSelection.path. The Source Script defines graphObject.csvId as a CSV identifier while appFSM.assetPath is a resolved VFS path.

## Fix
Use CsvPaths and ImagePaths as selection inputs and an ObjectCsvPath mapping which is obtained by resolving object.csvId against the authoritative CSV collection and VFS before selection. The mapping is an input projection, not a new authoritative state.

## Rejected
Treating numeric CSV IDs as VFS paths, or caching a second independently mutable selection.

## Scope
Only pseudocode representation changes; Source Script and implementation already resolve projectAssetPath(getProjectCsv(...)). Full PlusCal translation/validation still pending.

# 20260916-001 — Remove remaining native annotation palette/theme selectors

## Purpose
Complete the annotation ownership cleanup after `20260915-015` by removing the final centralized palette/theme selectors that still reference deleted native annotation editor/preview DOM.

## Exact changes
- Remove `.label-preview::after` from the shared subtle-color selector while preserving `.preview-more td` and the active dashboard zoom-lock selector.
- Remove `.annotation-panel` from the shared legacy panel palette override while preserving `.layout-panel` and `.print-panel` for their separate pending ownership audits.
- Remove the standalone `.label-preview-label` palette/background/shadow rule.

No actual dashboard label/caption selector, Mantine component style, layout style, print/export style, project state, renderer geometry, or JavaScript is changed.

## Why this direction
`20260915-008` removed the native label editor JavaScript, `20260915-009` removed native caption/annotation JavaScript ownership, and `20260915-013` through `015` removed the corresponding main editor CSS. Current-source inspection after `015` found exactly three remaining annotation-only selector fragments in the centralized palette block. Their DOM owners no longer exist, so keeping them would leave misleading dead presentation ownership.

This patch closes annotation CSS cleanup before starting the independent print/export ownership audit.

## Rejected alternatives
- Remove `.preview-more td` or dashboard zoom-lock styling together with `.label-preview::after`: rejected because those selectors still style live non-annotation UI.
- Remove `.layout-panel` or `.print-panel` from the shared palette override now: rejected because layout and print/export are separate ownership areas and must be audited before removal.
- Remove `.slot-label` or dashboard caption styles: rejected because they style actual figure output, not deleted editor chrome.
- Fold print/export cleanup into this patch: rejected to keep the annotation completion rollback boundary isolated.

## Source of truth
No source-of-truth change. `activeProject.annotations` remains authoritative for annotation state. Mantine owns annotation editing UI; existing dashboard renderers continue to own actual figure labels and captions.

## EFSM/core impact
None. No UI-FSM/EFSM transition, project model, persistence/schema, FFPX/FFSX meaning, export geometry, or renderer behavior is intentionally changed.

# 20261012-008 — Expand PlusCal function-level traceability

## Purpose
Correct the first-pass translation's overuse of unnamed helper calculations by giving Source Script read/calculation functions explicit PlusCal procedures.

## Added traceability
- project_state: project/registry reads, snapshot, slot non-default comparison.
- assets_files: path normalization, asset path, create CSV/image, move planning, unique path, descendants, tabular parse, reference collection, typed XML encode/decode, project-object construction.
- graphs: table/column/selection calculations, slot-data candidate, trace projection, axis/global normalization, chart validation, Plotly parse and editable conversion.
- layout_annotations_export: dashboard/grid geometry, image/label/caption reads, global caption text write, export-settings read.

## Reason
Policy requires inputs/outputs and meaningful calculation/data flow to remain directly traceable in the pseudocode layer; a helper name alone is insufficient for these Source Script responsibilities.

## Rejected
Leaving pure functions implicit because they do not mutate authority; moving them into unrelated modules for convenience.

## Remaining

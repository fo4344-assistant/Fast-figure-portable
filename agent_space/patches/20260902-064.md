# 20260902-064 — Mantine Layout dashboard zoom / lock / reset controls 이식

## 목적

`20260902-063`에서 분리한 dashboard zoom runtime command를 Layout Modal에 연결해 `review-006.md`의 Layout 기능 누락을 마무리한다.

## 변경 내용

- `FastFigureDashboardZoomStaging()` 추가
  - 현재 runtime 상태는 `readDashboardZoomModel()`에서 읽음
  - Mantine `Slider` 50~200%
  - 현재 zoom percent와 실제 dashboard width 표시
  - `현재 폭 고정` / `폭 고정 해제` Button
  - `100%` reset Button
- Slider `onChange`
  - `setDashboardZoomFromValue(value, false)` 호출
  - 기존 dashboard width/reference geometry를 즉시 갱신
  - local model은 command 반환 snapshot으로만 갱신
- Slider `onChangeEnd`
  - `setDashboardZoomFromValue(value, true)` 호출
  - 기존 `commitDashboardScale()` 경로 사용
- lock/reset도 `063` common command 사용
- Layout Modal에서 `layoutMap` preview 아래, merge/split/apply action 위에 배치

## source of truth

React local `model`은 control 표시를 위한 순간 snapshot이다.

권위 상태는 계속:
- `dashboardZoomIntent`
- `dashboardZoomLocked`
- `dashboardZoomLockedWidth`
- 실제 `#dashboard` geometry

UI model에서 별도 계산이나 persisted state를 만들지 않는다.

## popup/배치 판단

Zoom은 layout 설정 및 preview와 같은 작업 맥락에 있으므로 Layout Modal 내부에 둔다.

배치 순서:
1. layout numeric/style controls
2. `layoutMap` preview
3. dashboard zoom/lock/reset
4. merge/split + apply actions

이렇게 하면 설정/preview/작업 화면 scale control을 하나의 popup에서 접근할 수 있다.

## 파일/EFSM 영향

- 파일 schema 변경 없음
- 새 EFSM event 없음
- 기존 `DASHBOARD_SCALE_COMMITTED` notify 재사용

## 회귀 확인

- `git apply --check`

- staging inactive 상태에서 legacy active UI 영향 없음

## rollback

이 patch만 되돌리면 Mantine zoom controls만 제거되고 `063` common command와 legacy zoom UI는 유지된다.

# 20260916-007 — Remove standalone dead native graph UI helpers

## Purpose
Continue the graph compatibility-DOM cleanup after `20260916-006` by removing small native graph UI helpers that have no remaining executable caller, before deleting the larger native graph form ownership groups.

## Exact changes
Remove from `fast-figure.js`:
- `GRAPH_FONT_OPTIONS`, which only supplied options to the deleted native graph-font select;
- `fillGraphFontSelect`, whose only responsibility was populating that native select;
- `setGraphFontSelectValue`, whose only responsibility was projecting a saved font value into that native select;
- the empty `graphColorInputs()` compatibility stub.

No graph model, renderer, Mantine component, axis settings, palette state, import/export behavior, or state-machine transition is changed.

## Why this direction
Current `main` reference checks after `20260916-006` show `fillGraphFontSelect`, `setGraphFontSelectValue`, and `graphColorInputs` occur only at their definitions. `GRAPH_FONT_OPTIONS` is referenced only by `fillGraphFontSelect`. The active Mantine graph editor reads/writes `graphFontFamily` directly through project/chart state and `CHART_LAYOUT_CHANGED`, so these helpers no longer participate in the live UI path.

Removing these definition-only helpers separately keeps the next native graph form cleanup smaller and makes its call closure easier to audit.

## Rejected alternatives
- Keep the helpers as compatibility utilities: rejected because no live compatibility owner remains and retaining them falsely suggests native graph-form ownership.
- Move `GRAPH_FONT_OPTIONS` into the Mantine UI: rejected because the current Mantine graph-font field is a direct text input and does not use this legacy option list.
- Remove `graphPalette()` in this patch: deferred because it is still referenced by the yet-to-be-removed `configFromForm()` native form path; it should be removed with that closed ownership group rather than independently.
- Remove axis/form functions in the same patch: rejected to keep this first graph-helper cleanup small and independently rollbackable.

## Source of truth
No source-of-truth change. Chart/project state and `appFSM` remain authoritative. Mantine continues to own graph editing UI through the existing direct graph commands/events.

## EFSM/core impact
None. No UI-FSM/EFSM transition, chart object, Plotly renderer, project schema, FFPX/FFSX, Plotly JSON interchange, axis semantics, palette behavior, or persistence is changed.

## Validation
The repository workflow must pass:
1. `git apply --check` and `git diff --check`;
2. JavaScript syntax checks;
3. portable HTML build;
4. split and portable Chromium `file://` smoke tests;
5. source inspection confirming `GRAPH_FONT_OPTIONS`, `fillGraphFontSelect`, `setGraphFontSelectValue`, and `graphColorInputs` no longer occur;
6. confirmation that active `FastFigureGraphLayoutEditor`, `readGlobalSettings`, `normalizeGlobalSettings`, and `CHART_LAYOUT_CHANGED` paths remain unchanged.

## Rollback
Revert commit `Apply agent patch 20260916-007`.

No data migration or state rollback is required.

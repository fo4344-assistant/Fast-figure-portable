# 20260901-011 — Caption settings values/payload 계약 분리

## 목적

`plan-003.md` Commit B의 Caption 단계입니다. Caption 이름/이름 굵기/글꼴/글자 크기/행간 설정에서 native control 읽기와 실제 project mutation을 분리합니다. Caption 본문과 슬롯 모드는 이미 EFSM event 경로가 있으므로 중복 mutation API를 만들지 않습니다.

## 변경 내용

- 애플리케이션 버전을 `1.1.41-alpha`로 갱신합니다.
- `applyCaptionSettingsFromValues(values, notify)`를 추가합니다.
  - `name`, `nameBold`, `fontFamily`, `fontSize`, `lineHeight`를 DOM 없이 받습니다.
  - 기존 font size 범위 6~96과 fallback 14를 유지합니다.
  - 기존 line height 범위 0.8~4와 fallback 1.45를 유지합니다.
  - 기존 dashboard caption sync, debug log, `CAPTION_SETTINGS_CHANGED` notify를 유지합니다.
  - 적용 후 현재 `captions` project object 복사본을 반환합니다.
- 기존 `applyCaptionSettings(fromControls, notify)`는 legacy control 값을 payload로 만든 뒤 위 함수에 위임하고, 반환된 project 값을 native control에 동기화하는 adapter로 축소합니다.
- `fromControls=false` 경로는 mutation 없이 현재 project 상태를 dashboard/native control에 다시 반영하는 기존 의미를 유지합니다.
- `fastFigureUiBridge.applyCaptionSettings(values, notify)`를 추가합니다.

## 기존 EFSM 경로 재사용

Caption 본문은 기존 `CAPTION_TEXT_INPUT` event가 project mutation을 수행합니다. 슬롯별 캡션 모드는 `SLOT_CAPTION_MODE_CHANGED` event가 처리합니다. 따라서 이 둘을 위한 별도 bridge mutation 함수는 만들지 않고 staging에서 기존 `fastFigureUiBridge.send()`를 사용합니다.

표시 여부는 `20260901-009`의 `setAnnotationEnabled("caption", enabled)` DOM-free 경계를 재사용합니다.

## 상태 소유권

- 영속 caption 설정: `annotations.captions`
- 본문/슬롯 본문: 기존 caption domain/EFSM
- overlay 상태: 기존 EFSM
- legacy native control: 현재 활성 UI adapter

React staging은 이후 commit 전 임시 입력만 local state로 갖습니다.

## 검증 기준

- patch target은 `Fast-figure.html` 하나뿐이어야 합니다.
- `git apply --check`, `git diff --check`, main inline JavaScript `node --check`를 통과해야 합니다.
- `renderProjectObject()`의 `applyCaptionSettings(false, false)` 경로가 유지되어 project load 시 불필요한 mutation/notify가 없어야 합니다.
- legacy `installCaptionSettings()`와 change handler의 결과가 이전과 같아야 합니다.
- bridge settings 경로는 native Caption control ID를 참조하지 않아야 합니다.

## 후속 작업

다음 커밋에서 Caption의 일반 form과 본문 편집을 `FastFigureCaptionModalStaging`에 연결합니다. 본문 저장은 기존 `CAPTION_TEXT_INPUT`, 슬롯 모드는 `SLOT_CAPTION_MODE_CHANGED`, 표시 토글은 공통 annotation visibility 경로를 사용합니다.

## 선택 이유와 기각 대안

개발 소스의 실제 논리 모듈을 정식 ES module로 만들고 배포 시 하나의 classic script로 링크했다. 단순 텍스트 조각 이어붙이기는 숨은 전역 의존성을 지속시키므로 선택하지 않았다. 브라우저가 file://에서 원본 ESM을 직접 가져오도록 하는 방식은 기존 portable offline 사용을 깨뜨릴 수 있어 제외했다. 중복 Project/runtime 캐시, 전역 서비스 로케이터, 기존 monolith를 계속 editable source로 남기는 과도기 bridge도 도입하지 않았다. 거대한 전체 의미 재설계를 이 물리 전환에 끼워 넣지 않았으며 남은 ownership 위반은 명시한다.

빌드용 Node/esbuild 설치가 새로 필요하지만 배포 사용자에게는 Node/npm이나 네트워크가 필요 없다. linker는 기존 white-box probe의 classic lexical binding 접근을 유지하기 위해 tree shaking/minification을 하지 않는다. private-IIFE 경계나 새 window debug API가 생긴 것으로 설명하지 않는다.

# 20260901-008 — Label values/payload 계약 분리

## 목적

`plan-003.md` Commit B의 Label 단계입니다. 기존 Label 설정 함수가 native input/select/toggle을 직접 읽으면서 동시에 project mutation과 renderer side effect까지 수행하던 구조를 분리합니다. 현재 legacy UI 동작과 EFSM event 의미는 유지합니다.

## 변경 내용

- 애플리케이션 버전을 `1.1.38-alpha`로 갱신합니다.
- `applyLabelSettingsFromValues(values)`를 추가합니다.
  - `format`, `parentheses`, `order`, `fontFamily`, `fontSize`를 DOM 없이 받습니다.
  - 기존 최소 글꼴 크기 6pt와 invalid 값의 14pt fallback을 유지합니다.
  - 기존 preview/dashboard 갱신, Plotly resize, debug log, `LABEL_SETTINGS_CHANGED` notify를 재사용합니다.
- 기존 `applyLabelSettings()`는 native control 값을 payload로 만든 뒤 위 함수에 위임합니다.
- `applyLabelPositionFromValues(values)`를 추가합니다.
  - `x`, `y`를 DOM 없이 받습니다.
  - 기존 `finiteLabelPosition()`, preview/dashboard 갱신, resize, log, `LABEL_POSITION_CHANGED` notify를 재사용합니다.
- 기존 `applyLabelPosition()`은 native position input 값을 payload로 만든 뒤 위 함수에 위임합니다.
- `fastFigureUiBridge`에 `applyLabelSettings(values)`와 `applyLabelPosition(values)`를 노출합니다.

## 경계와 상태 소유권

Label의 영속 상태는 계속 `activeProject.labelSettings` 및 project object가 소유합니다. 이번 변경은 mutation의 입력 경계만 DOM-free values로 바꾸며, EFSM이나 label renderer를 재설계하지 않습니다.

legacy UI는 adapter로 남아 있으므로 현재 화면의 select/input/toggle 이벤트는 이전과 같은 경로와 결과를 가집니다. 미래 Mantine UI는 동일한 bridge method를 호출하므로 legacy DOM ID를 알 필요가 없습니다.

## 변경하지 않는 항목

- `renderLabelPreview()`와 preview 좌표계
- pointer drag 처리
- label enable/disable 경로
- position reset handler
- slot identifier/format renderer
- legacy UI ownership

position reset과 drag는 다음 staging 연결 단계에서 기존 DOM click forwarding을 하지 않고, 필요한 값 계약을 직접 재사용할 수 있으므로 이번 커밋에서 범위를 넓히지 않습니다.

## 검증 기준

- patch target은 `Fast-figure.html` 하나뿐이어야 합니다.
- `git apply --check`, `git diff --check`, main inline JS `node --check`를 통과해야 합니다.
- legacy `applyLabelSettings()`와 `applyLabelPosition()`은 기존 control 값으로 동일한 project state를 만들어야 합니다.
- bridge 경로는 native Label control ID를 읽지 않아야 합니다.
- 기존 EFSM notify event 이름을 바꾸지 않아야 합니다.

## 재시도 기록

첫 큐 커밋에서 마지막 `installLabelSettings()` 문맥 1줄이 hunk count에서 누락되어 `25/52`로 기록됐습니다. 실제 hunk는 기존 26줄, 변경 후 53줄이므로 헤더를 `26/53`으로 바로잡았습니다. 코드 내용과 적용 범위는 변경하지 않습니다.

## 후속 작업

다음 커밋에서 이 두 values 계약과 annotation visibility 경계를 사용해 `FastFigureLabelModalStaging`을 구성합니다. preview/drag surface는 domain renderer로 유지하고, 일반 form control만 Mantine primitive가 소유하도록 준비합니다.

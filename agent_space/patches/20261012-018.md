# 20261012-018 — Define and close r15 post-drag bookmark guard

## Layer classification
This is a Source Script change because the release point of click suppression determines whether a post-drag click becomes a SELECT_SLOT action. The prior Source Script only required suppression but did not define the release ordering.

## Source Script result
Drag start activates UI-local suppression. Drop/dragend clears drag source without releasing it. A guarded post-drag bookmark click is consumed and releases the guard; if no click occurs, cleanup releases only after the click-dispatch opportunity.

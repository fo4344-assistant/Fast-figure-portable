# 20260916-027 — orphan native debug-log CSS removal

## 목적과 변경 내용

Mantine `FastFigureStatusDebug`가 status/debug UI를 소유한 뒤 남아 있는 native `.debug-log` 전용 CSS를 제거한다.

변경 내용:
- `.debug-log` scroll/border/font style 제거
- centralized surface selector에서 `.debug-log` 제거

## 선택 이유

current HTML과 current JavaScript에는 `.debug-log` consumer가 없고 Mantine debug output은 component 내부 `<pre>`의 명시적 style을 사용한다. 따라서 이 selector는 더 이상 기능 renderer나 telemetry contract가 아니라 삭제 가능한 legacy frontend presentation 잔여물이다.

## 선택하지 않은 방향

- `debugLog`, telemetry state, `FastFigureStatusDebug`는 유지한다.
- status/debug 데이터 흐름이나 logic EFSM은 변경하지 않는다.
- `.status` native projection은 이 패치에서 함께 변경하지 않는다.

## 전제 / 후속 작업 / 누락

- 이 패치는 CSS presentation ownership만 정리한다.
- rollback은 이 패치를 되돌리면 native debug-log style이 복구된다.

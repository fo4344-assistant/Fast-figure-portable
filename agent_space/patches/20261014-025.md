# 20261014-025 — Verify r23/r9 batch-import atomicity in verification r22

## 변경
Interaction Core에 ASSETS_IMPORTED의 대표 CSV batch transition을 추가했다. 성공 시 요청 batch 전체가 한 상태 전이로 반영되고, reject 시 project가 이전 상태와 동일하다는 assertion을 둔다. command ownership mapping에도 ASSETS_IMPORTED를 추가했다.

## 추상화
image bytes/slot payload 전체를 복제하지 않고 여러 persistent asset의 all-or-nothing 성질을 CSV id 집합으로 대표한다. target-slot reference integrity는 기존 slot/reference slice가 검증한다. 서로 독립적인 표현 상태를 중복 추가하지 않는다.

## 이유
r23에서 새로 생긴 의미는 raw-file import의 batch atomicity다. 기존 singular create 검증만으로는 부분 commit 금지를 표현할 수 없어 최소 상태 전이를 추가했다.

## 기각
전체 import payload/VFS/bytes를 TLC state로 복제하는 방식은 검증하려는 atomicity에 비해 상태공간을 크게 늘린다.

## 후속
push-trigger PlusCal translation/SANY/TLC가 실제 성공한 뒤 validation review와 tlc: passed를 기록한다. 그 전 Source Code는 수정하지 않는다.

# 20260902-060 — Dashboard Capture command 분리 적용

## 목적

`20260902-059`는 bridge hunk의 current context 불일치로 `git apply --check`에서 실패했고 HTML에는 반영되지 않았다.

이 재시도에서는 capture 기능의 핵심 command만 먼저 적용한다.

## 변경 내용

- `captureDashboardTargetFromValues(values, statusOut)` 추가
- 현재 `#dashboard` renderer host의 실제 폭을 읽어 capture width로 사용
- 유효한 dashboard가 없으면 rejected result + status 반환
- height는 자동 계산으로 두어 current domain layout/caption geometry를 사용
- DPI/format 등 나머지 출력 조건은 기존 `exportDashboardTargetFromValues()`에 전달
- 실제 chart/image/label/caption 합성은 기존 target export engine 재사용

## 의도적으로 하지 않는 변경

- bridge wiring 없음
- Mantine Print button 없음
- 기존 target exporter 본문 변경 없음
- legacy capture 제거 없음

후속 patch에서 bridge와 UI를 각각 작은 단위로 연결한다.

## 파일/EFSM 영향

프로젝트 파일 schema와 EFSM에는 영향이 없다.

## 검증

- `git apply --check`
- `git diff --check`
- JavaScript `node --check`

## rollback

이 patch만 되돌리면 capture adapter 함수만 제거된다.

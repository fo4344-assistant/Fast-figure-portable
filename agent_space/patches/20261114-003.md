# 테스트 코드 제거

사용자 요청에 따라 browser regression 코드, Python 실행기·module build 테스트, 관련 실행 안내 두 문서와 전용 GitHub Actions workflow를 삭제했다. `agent_space/tests/`에는 남은 파일이 없어 디렉터리도 제거했다.

실행 경로를 그대로 두면 삭제한 파일을 호출하므로 전용 workflow도 함께 삭제했다. 테스트 수정·추가·실행을 계속하는 대안은 사용자 지시와 맞지 않아 채택하지 않았다.

패치는 삭제 직전의 실제 작업 파일을 `git diff --no-index`로 기록했다. 이전 테스트 변경까지 포함된 수정 전 내용이므로 HEAD 기준 삭제 diff와 줄 수가 다를 수 있다. Python 패치 생성이나 별도 해시 계산은 사용하지 않았다.

기존 패치·리뷰·로그의 역사적 테스트 기록은 삭제 대상에 포함하지 않았다. 버전 메타데이터의 의미 파일 목록에는 이번 삭제 파일이 없어 revision/fingerprint 변경은 없다.

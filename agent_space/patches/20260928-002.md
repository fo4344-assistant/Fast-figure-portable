# 20260928-002

## 목적과 변경 내용

사용자가 이번 작업에서 요구한 커밋 식별 문구 `불안정 chatgpt 작업본`이 GitHub Actions가 자동 생성하는 source 적용 커밋에도 남도록 patch applicator의 commit message를 수정한다.

변경 전:

```text
Apply agent patch <patch-id>
```

변경 후:

```text
Apply agent patch <patch-id> — 불안정 chatgpt 작업본
```

application source, patch 선택 조건, 적용 대상, syntax/build/smoke 검증, push 조건은 변경하지 않는다.

## 선택 이유

현재 patch workflow는 사람이 만드는 queue commit과 별도로 적용 결과를 bot commit으로 기록한다. `20260928-001` queue commit에는 요구 문구를 넣었지만 기존 workflow가 만든 적용 commit `26598045cf9efdeadcbdf3a4c98e9f7913582afd`에는 고정 메시지 때문에 해당 문구가 없었다.

앞으로 이 작업 흐름에서 생성되는 두 종류의 commit 모두 작업본 성격을 식별할 수 있어야 하므로 자동 적용 commit의 메시지에도 같은 문구를 추가한다.

## 선택하지 않은 방향

### 이미 생성된 적용 commit을 amend/rebase

공개 main 이력을 다시 쓰고 후속 SHA를 모두 바꾸므로 선택하지 않는다. 기존 `26598045...`는 당시 workflow의 결과로 그대로 보존한다.

### workflow 자체를 제거하고 source를 수동 commit

대형 source patch의 apply/syntax/build/file:// smoke 검증을 자동화하는 현재 안전장치를 잃으므로 선택하지 않는다.

### queue commit만 표시

사용자가 commit 자체에 작업본 표기를 요구했으므로, 실제 source를 기록하는 자동 적용 commit에도 앞으로 동일하게 표시한다.

## 적용 방식

이 패치는 workflow 자신을 수정하므로 application patch 자동 적용 경로를 사용하지 않는다. 실제 workflow 수정과 이 diff 기록, 설명 문서를 동일한 Git commit에 함께 넣는다. application source는 변경하지 않는다.

## 검증

- 현재 main HEAD가 `26598045cf9efdeadcbdf3a4c98e9f7913582afd`인지 확인한 뒤 수정한다.
- workflow에서 기존 고정 commit message 한 줄이 정확히 한 번 존재하는지 확인한다.
- 해당 한 줄 외 workflow 내용은 그대로 유지한다.
- diff patch는 실제 old/new workflow text에서 생성한다.

## 후속 작업

다음 application patch부터 queue commit과 Actions의 적용 commit 양쪽 모두 `불안정 chatgpt 작업본` 표기를 확인한다.

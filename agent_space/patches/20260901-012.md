# 20260901-012 — Caption editor DOM-free 계약

## 목적

Caption staging이 전역 캡션과 슬롯별 캡션의 대상 선택 규칙을 React component 안에서 다시 구현하지 않도록, 현재 편집 대상을 읽고 전체 draft를 적용하는 DOM-free editor 계약을 추가합니다.

## 변경 내용

- 애플리케이션 버전을 `1.1.42-alpha`로 갱신합니다.
- `readCaptionEditorState()`를 추가합니다.
  - 현재 `captions` project object와 기존 `activeCaptionView()`를 재사용합니다.
  - `enabled`, `slotMode`, 편집 대상(`global`/`slot`), 대상 slot ID, text, name/nameBold, font settings를 반환합니다.
- `applyCaptionEditorFromValues(values)`를 추가합니다.
  - 표시 여부는 기존 DOM-free annotation visibility 경계를 재사용합니다.
  - slot mode 변경은 기존 `SLOT_CAPTION_MODE_CHANGED` EFSM event를 사용합니다.
  - mode 변경 후 `activeCaptionView()`를 다시 평가해 실제 편집 대상을 결정합니다.
  - 일반 설정은 `applyCaptionSettingsFromValues()`를 사용합니다.
  - 슬롯 편집 중에는 legacy UI와 마찬가지로 global caption name/nameBold를 수정하지 않습니다.
  - 본문은 기존 `CAPTION_TEXT_INPUT` EFSM event로 적용합니다.
  - 적용 후 실제 editor state를 다시 반환합니다.
- `fastFigureUiBridge`에 `readCaptionEditor()`와 `applyCaptionEditor(values)`를 노출합니다.

## 이 계약이 필요한 이유

Caption은 `slotMode`와 현재 선택 slot에 따라 같은 본문 입력이 전역 `caption.text` 또는 `slot.caption`에 기록됩니다. 이 분기를 Mantine component가 직접 알게 하면 UI가 domain 규칙을 복제하게 됩니다.

이번 계약은 기존 `activeCaptionView()`, `SLOT_CAPTION_MODE_CHANGED`, `CAPTION_TEXT_INPUT`을 그대로 조합해 현재 domain 의미를 하나의 UI 경계로 노출합니다. 새 상태 머신이나 별도 저장소는 만들지 않습니다.

## 상태 및 EFSM 보존

- caption target 결정: 기존 `activeCaptionView()`
- slot mode mutation: 기존 workspace EFSM
- caption text mutation: 기존 workspace EFSM
- visibility: 기존 annotation mutation + notify
- style/name mutation: `20260901-011`의 values 계약

React는 이 결과를 읽고 draft를 제출할 뿐 target selection 규칙을 소유하지 않습니다.

## 검증 기준

- patch target은 `Fast-figure.html` 하나뿐이어야 합니다.
- `git apply --check`, `git diff --check`, main inline JavaScript `node --check`를 통과해야 합니다.
- editor 계약 내부에서 native caption control ID를 참조하지 않아야 합니다.
- slot mode 변경 이후 text가 새 mode의 실제 active target에 기록되어야 합니다.
- slot target에서는 global name/nameBold가 변경되지 않아야 합니다.
- 기존 EFSM event 이름과 direction 계약을 변경하지 않아야 합니다.

## 후속 작업

다음 커밋에서 이 editor 계약을 `FastFigureCaptionModalStaging`의 Mantine form과 본문 `Textarea`에 연결합니다. Component는 `readCaptionEditor()`로 초기화하고 `applyCaptionEditor()` 하나로 commit합니다.

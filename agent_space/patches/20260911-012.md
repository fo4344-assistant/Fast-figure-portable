# 20260911-012 — Complete Mantine layout preview interaction

## Purpose

Finish the last identified Mantine-side parity gap before legacy generic-UI removal: the layout preview must use the same dashboard geometry model as the real figure and retain an independent preview resize interaction.

## Exact changes

### `fast-figure-ui.js`
- Add local `previewWidth` and pointer-resize state to `FastFigureLayoutOverlay`.
- Derive preview dimensions, gap, outer margin, and radius from existing `dashboardGeometry(previewWidth)`.
- Render the slot selection grid using the configured dashboard aspect, outer margin, gap, and radius rather than a fixed 260px equal-cell preview.
- Preserve merged-slot `rowSpan` / `colSpan` geometry.
- Reflect the slot-border setting in preview slot border style.
- Add a horizontal pointer resize handle for preview-only scaling.
- Keep preview resizing transient: it does not change project layout, dashboard zoom, or persisted settings.

## Rationale

The Mantine layout editor already owns every persistent layout setting and merge/split command. Its remaining deficiency was that the visual map used arbitrary preview geometry and lacked the old panel's resize affordance. Using the existing dashboard geometry function gives one geometric authority without reintroducing legacy DOM.

## Source of truth

- Persistent layout: `activeProject.layout`.
- Geometry: `dashboardGeometry()` and existing slot row/column spans.
- Preview size: local React state only.

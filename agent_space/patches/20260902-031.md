# 20260902-031 — legacy graph object 목록 handler를 공통 command로 통합

## 목적

`20260902-030`에서 color/delete/reorder의 DOM-free command가 준비됐다. 현재 active legacy `renderGraphObjects()`에는 같은 mutation·selection 보정 규칙이 별도로 남아 있다.

이번 패치는 active legacy handler가 새 command를 재사용하도록 변경해 기능 규칙의 중복을 제거한다.

## 변경 내용

- 앱 버전 `1.1.73-alpha` → `1.1.74-alpha`
- drag/drop reorder handler:
  - inline 배열 이동/selected-index 보정/EFSM 전송 제거
  - `moveGraphObjectFromIndex(dragging, to)` 재사용
  - 성공 후 legacy list만 다시 렌더
- color input handler:
  - inline object copy + `saveGraphObjects()` 제거
  - `setGraphObjectColorFromIndex(index, color)` 재사용
  - 성공 후 legacy list 다시 렌더
- delete handler:
  - inline filter/save/CLEAR sequence 제거
  - `removeGraphObjectFromIndex(index)` 재사용
  - 성공 후 legacy list 다시 렌더

## 기능 의미 보존

### reorder

공통 command는 기존 handler의 selected-index 보정 조건을 그대로 사용하고 기존 `SELECT_GRAPH_OBJECT` event를 보낸다.

### color

대상 row index의 color만 변경하며 selection은 바꾸지 않는다.

### delete

기존과 같이 object replacement 후 selection을 clear한다. 마지막 object 삭제 시 기본 object recovery도 기존 EFSM action이 수행한다.

## legacy renderer

공통 command는 `renderGraphObjects()`를 호출하지 않는다. active legacy handler가 성공 후 목록을 다시 그린다.

따라서:

```text
legacy UI action
→ 공통 DOM-free command
→ 기존 EFSM/domain mutation
→ legacy renderGraphObjects
```

Mantine에서는 마지막 legacy render 단계 없이 같은 command를 사용할 수 있다.

## 최소복잡도

reorder의 배열 이동과 selection 보정, delete의 clear 규칙, color mutation을 legacy/Mantine 두 곳에 구현하지 않는다. 기능 규칙은 command 한 곳만 소유하고 renderer만 UI별로 분리한다.

## 변경하지 않는 영역

- graph object read model
- add object
- palette save/load/reset
- `GRAPH_OBJECTS_REPLACED` event/action
- `SELECT_GRAPH_OBJECT` / `CLEAR_GRAPH_OBJECT` 의미
- graph rebuild / updateGraphView
- Plotly renderer / trace 생성
- 인라인 Plotly library
- import/export

## 회귀 검사

- drag reorder 결과 동일
- reorder 시 선택 object가 같은 논리 object를 계속 가리킴
- color input 즉시 반영 및 list rerender 유지
- delete 후 selection clear 유지
- 마지막 object 삭제 recovery 유지
- selection 없는 상태에서도 세 동작 가능 (`025` 교정)
- legacy list 표시 갱신 유지
- Plotly/trace diff 없음

## rollback

세 legacy handler에 기존 inline mutation 코드를 복원하고 앱 버전을 `1.1.73-alpha`로 복원한다. `030` command 자체는 독립 유지 가능하다.

## Plotly 범위

이번 패치는 `renderGraphObjects()`의 세 이벤트 handler만 수정한다. 인라인 Plotly library는 읽거나 수정하지 않는다.

## 후속

Mantine graph-object 목록 staging renderer를 `readGraphObjects()` + `select/setColor/remove/moveGraphObject` bridge로 연결한다.

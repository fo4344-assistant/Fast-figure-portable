# policies

이 경로는 프로젝트 작업자가 임의로 바꾸어서는 안 되는 상위 개발 정책 원문을 보관한다.

현재 정책 원천:

- `source-script-policy.md`
  - 사용자 제공 `v0.1.1`
  - Source Script → pseudocode → 대상 언어 구현 순서
  - Source Script 닫힘 판정
  - Source of Truth, 참조 무결성, 최소 구현, 확정/미확정 규칙, 단계 간 번역 원칙

정책 문서 자체의 추가·수정·삭제는 사용자의 명시적 정책 변경 지시가 있을 때만 수행한다.

Fast Figure 프로젝트에만 해당하는 구조·파일명·상태·API·해결 방안은 이 경로에 섞지 않고 `sourcescript/`, `agent_space/plans/`, `agent_space/docs/`에 기록한다.

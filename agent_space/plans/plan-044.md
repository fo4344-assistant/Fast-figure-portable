# Plan044 — 선택 슬롯 갱신과 기존 화면 이동·확대·축소

## 1. 목표

Plan043의 선택 슬롯 자동 갱신과 수동 전체 갱신을 유지하고, 크기 변경 처리 방향을 수정한다. 이동·크기 변경에서는 이미 표시한 내용을 이동·확대·축소한다. Plotly 렌더링과 resize는 호출하지 않는다. Plan043 원문은 보존한다.

- 내용 변경: 현재 선택된 visible 슬롯 하나만 계산하고 표시한다. 선택 해제 시 자동 내용 갱신을 생략한다. id 0도 유효하다.
- 전체 내용 갱신: 상단의 `렌더링` 버튼을 눌렀을 때만 실행한다. 버튼은 `프린트` 바로 왼쪽이며 기존 공통 Button·UiCommand를 사용한다.
- 창·Sidebar·대시보드 이동과 크기 변경, 배율 조작: 기존 화면의 CSS 위치·배율만 바꾼다. 기존 글자·선·이미지도 함께 확대·축소한다.
- 저장·참조 보정·편집기 공식 조회는 유지한다. 아직 표시하지 않은 변경은 전체 렌더링에서 반영한다.

## 3. 처리 규칙

### 조회와 자동 갱신

- 현재 프로젝트는 Backend가 소유한다. Application이 현재 Frontend 선택 id와 요청 범위를 명시한다.
- 구조 조회는 배치·가시성·종류·소유 참조·기하만 반환한다. figure, CSV 변환, 이미지 바이트 복사를 실행하지 않는다.
- 선택 조회는 구조와 대상 슬롯 하나의 표시 입력을 같은 프로젝트 읽기에서 구성한다. 다른 슬롯의 figure를 계산한 뒤 걸러내는 구현을 피한다.
- 전체 조회는 전체 렌더링 버튼의 진입점에서만 요청한다. export의 독립 작업용 전체 계산은 기존 파일 출력 계약을 유지한다.
- 프로젝트 교체·삭제·종류 전환으로 유효하지 않은 기존 자원은 즉시 해제한다. 자원 정리에서 다른 슬롯의 내용을 다시 그리지 않는다.
- 선택 변경은 선택 장식·상호작용 권한을 먼저 바꾼다. 새로 선택한 슬롯의 내용만 갱신한다. 선택 해제는 내용 렌더링을 생략한다.
- 현재 틀로 선택 슬롯을 안전하게 갱신할 수 없으면 전체 렌더링 필요를 안내한다. 자동 전체 전환은 수행하지 않는다.

### 기존 화면 변환

- 이미 그린 각 내용 surface의 기준 치수와 DOM 연결은 renderer가 자원 수명 동안 유지한다. 프로젝트 값이나 다음 조회 원천으로 사용하지 않는다.
- 창·Sidebar·배율·단순 위치/치수 변경은 현재 내용 surface의 이동과 크기 비율을 CSS transform으로 적용한다. 포인터 좌표는 역변환한다.
- 변환만 수행하는 경로는 Backend figure/CSV 계산, Plotly.react/newPlot/resize, 이미지 재해석을 실행하지 않는다.
- grid/span 변경으로 틀이 호환되지 않으면 유효한 기존 내용은 보존하고 전체 렌더링 필요를 안내한다. 미리보기와 공식 편집 값은 새 설정을 표시한다.
- 선택 장식·bookmark·포커스·스크롤은 유지한다. 재렌더링 없는 배율 변경으로 글자와 선의 크기도 변한다.

### 비동기와 출력

- 슬롯별 작업 순번·host·chart/image 연결로 완료를 검증한다. A 슬롯 갱신이 B 슬롯의 유효한 작업을 무효화하지 않는다.
- 삭제·교체·프로젝트 교체와 더 최신 같은 슬롯 요청은 이전 작업을 무효화한다. 오래된 완료는 자신의 임시 자원만 해제한다.
- export는 독립 출력 host·작업 순번을 사용한다. 편집 화면의 자동 전체 갱신이나 수동 렌더링을 먼저 실행하지 않는다.

## 4. 정적 확인과 후속 검증

Source Script의 입력·반환·변경·절차를 예시 형식으로 수정한다. 정의에는 값의 의미만 두고 처리 절차는 함수에 둔다. 기존 저장 구조·Backend 명령·범위 규칙은 유지한다.

수정 후 호출 경로, 전체 요청 진입점, resize/선택/팔레트/캡션/시작 처리와 비동기 정리를 대조한다. 실제 native patch·후속 review·Source Script fingerprint를 기록한다. pseudocode와 source code 번역은 후속 단계다.

후속 실행 검증은 선택 0/해제, A→B 전환, 공유 CSV와 전역 설정, 빈/graph/image, 크기·위치·Sidebar·배율, grid/span 변경, 삭제/불러오기, 느린 비동기 완료, 전체 버튼과 export를 짧은 독립 작업으로 확인한다. debug를 켜고 각 작업의 로그를 저장·비운다. 정적 확인을 실행 결과나 성능 개선 측정으로 보고하지 않는다.
